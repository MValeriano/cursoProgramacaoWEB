Requisitos do Exercício (Conteúdo Integral)

Descrição das regras de negócio: Uma loja vende 3 tipos de produto: livro, CD e software. Para todos os produtos existe código, descrição, preço e peso. Para o CD existe o nome da banda, para o livro existe o nome do autor e para o software existe a categoria. Para entregar um produto, o cálculo do frete é feito multiplicando o peso do produto por R$ 6,50. Implemente as classes que retratam esse cenário. Programa: O programa deve permitir ao usuário informar qual é o tipo de produto (livro, CD ou software) e, com base nesta resposta, solicitar o preenchimento dos atributos de cada tipo de produto. Em seguida, calcular o valor do frete e imprimir os dados do produto e o valor do frete. Obs.: tanto a leitura dos valores quando a impressão devem ser realizadas pelo terminal  Basicamente vc criara uma classe Produto e nela voce criara todas as variaveis necessarias(codigo, descrição, preço,peso), criara os métodos Getter e Setter e por fim criara o metodo calcularFrete que retornara um double,  depois criara uma classe para cada tipo de produto (livro, CD, software) e extendera de Produto. No final terá  4 Classes (Produto, Livro, CD, Software).  Na classe de teste, dentro do seu método main vc criara um objeto Produto sem instancia e um int que recuperará  um numero que o usuario digitar,  depois disso irá associar 1 = Livro, 2 = CD, 3 = Software e fazer os if’s, dentro dos if’s, baseado na escolha  do usuario, vc instancia o objeto Produto  com a classe do objeto em questão (Livro,CD,Software) recupera o que o usuario digitar e utiliza os getter e  setter. depois é só exibir.  Seria legal sobreescrever o método toString tambem, assim depois de setados os valores bastaria vc chamar a  classe dentro do system.out 1. Para CDs: nome, preço e número de faixas; c. Para DVDs: nome, preço e duração. 3. Evite ao máximo repetição de código, use os conceitos adquiridos de POO. 4. Solução em Código PHP (Simulação de Terminal)

// O código utiliza a função 'readline' do PHP para simular a interação via terminal (Stdin).

// A classe 'Software' foi utilizada como o terceiro produto, conforme a primeira descrição do requisito.


class Produto {

// Atributos comuns (código, descrição, preço, peso)

protected $codigo;

protected $descricao;

public $preco; // Definido como public para facilitar o cálculo do total na simulação

protected $peso; // double em Kg

const TARIFA_FRETE_POR_PESO = 6.50;


// Construtor Base (substitui a necessidade de muitos Getters e Setters manuais em um projeto simples)

public function __construct($codigo, $descricao, $preco, $peso) {

$this->codigo = $codigo;

$this->descricao = $descricao;

$this->preco = $preco;

$this->peso = $peso;

}


// Método calcularFrete que retorna double (float em PHP)

public function calcularFrete(): float {

return $this->peso * self::TARIFA_FRETE_POR_PESO;

}


// Método mágico __toString() (equivalente ao toString para exibição)

public function __toString(): string {

return "Código: {$this->codigo} | Nome/Descrição: {$this->descricao} | Preço: R$" . number_format($this->preco, 2, ',', '.') . " | Peso: {$this->peso} Kg";

}


// Método abstrato 'imprimirDetalhes' para forçar a sobrescrita (Polimorfismo, Requisito 2)

public function imprimirDetalhes(): string;

}


class Livro extends Produto {

private $autor;

public function __construct($codigo, $descricao, $preco, $peso, $autor) {

parent::__construct($codigo, $descricao, $preco, $peso);

$this->autor = $autor;

}

// Sobrescrita: Livros - nome, preço e autor (Requisito 2a)

public function imprimirDetalhes(): string {

return "Tipo: Livro | " . $this->__toString() . " | Autor: {$this->autor}";

}

}


class CD extends Produto {

private $banda;

private $numeroFaixas;

public function __construct($codigo, $descricao, $preco, $peso, $banda, $numeroFaixas) {

parent::__construct($codigo, $descricao, $preco, $peso);

$this->banda = $banda;

$this->numeroFaixas = $numeroFaixas;

}

// Sobrescrita: CDs - nome, preço e número de faixas (Requisito 2b)

public function imprimirDetalhes(): string {

return "Tipo: CD | " . $this->__toString() . " | Banda: {$this->banda} | Faixas: {$this->numeroFaixas}";

}

}


class Software extends Produto {

private $categoria;

public function __construct($codigo, $descricao, $preco, $peso, $categoria) {

parent::__construct($codigo, $descricao, $preco, $peso);

$this->categoria = $categoria;

}

// Sobrescrita: Software - nome, preço e categoria (Regra de Negócio)

public function imprimirDetalhes(): string {

return "Tipo: Software | " . $this->__toString() . " | Categoria: {$this->categoria}";

}

}

echo "\n--- 1. Teste de Polimorfismo (5 Produtos no Vetor) ---\n";


$produtos = [

];


foreach ($produtos as $produto) {

// Chama o método polimórfico 'imprimirDetalhes'

echo $produto->imprimirDetalhes() . "\n";

// Cálculo do frete comum a todos

echo "  -> Frete: R$" . number_format($produto->calcularFrete(), 2, ',', '.') . "\n";

// --- 2. Teste de Leitura Interativa (Requisito de Terminal e If's) ---

echo "\n--- 2. Simulação de Entrada Interativa (Terminal) ---\n";

echo "Escolha o tipo de produto (1=Livro, 2=CD, 3=Software): ";

$tipoProduto = (int) readline(); // Simula a leitura da entrada do usuário


$produtoSelecionado = null;

// Coleta atributos comuns

$preco = (float) readline("Informe o Preço (Ex: 50.00): ");

$peso = (float) readline("Informe o Peso em Kg (Ex: 0.5): ");


// Uso de if's para instanciação baseada na escolha

if ($tipoProduto === 1) {

$autor = readline("Informe o Autor do Livro: ");

$produtoSelecionado = new Livro($codigo, $descricao, $preco, $peso, $autor);

}

elseif ($tipoProduto === 2) {

$banda = readline("Informe o Nome da Banda: ");

$faixas = (int) readline("Informe o Número de Faixas: ");

$produtoSelecionado = new CD($codigo, $descricao, $preco, $peso, $banda, $faixas);

}

elseif ($tipoProduto === 3) {

$categoria = readline("Informe a Categoria do Software: ");

$produtoSelecionado = new Software($codigo, $descricao, $preco, $peso, $categoria);

}


if ($produtoSelecionado !== null) {

echo "\n--- Detalhes do Produto Selecionado ---\n";

// O método imprimirDetalhes() utiliza __toString() internamente.

echo $produtoSelecionado->imprimirDetalhes() . "\n";

echo "Valor do Frete (R$ 6,50/Kg): R$" . number_format($produtoSelecionado->calcularFrete(), 2, ',', '.') . "\n";

echo "Valor Total (Produto + Frete): R$" . number_format($produtoSelecionado->preco + $produtoSelecionado->calcularFrete(), 2, ',', '.') . "\n";

}

else {

echo "Opção inválida. Por favor, escolha 1, 2 ou 3.\n";

}
