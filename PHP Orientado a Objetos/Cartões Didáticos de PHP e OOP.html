Cartões Didáticos Interativos

PHP, Programação Orientada a Objetos e SQL

I. Conceitos Fundamentais e Sintaxe

1

Qual é a principal função da tag de abertura de código PHP (`

1

É o delimitador que informa ao interpretador PHP para começar a analisar e executar o código da linguagem que o segue.

2

O que o ponto e vírgula (`;`) representa no final de uma instrução PHP?

2

Ele delimita e informa ao interpretador PHP que a instrução atual foi concluída.

3

Qual é a melhor prática para o tag de fechamento (`?>`) em arquivos que contêm somente código PHP?

3

A tag de fechamento deve ser omitida em arquivos puramente PHP para evitar problemas causados por espaços ou caracteres acidentais após o bloco.

4

O que é uma variável variante (*variable variable*) em PHP?

4

É o conceito onde o PHP utiliza dois cifrões (`$$`) para referenciar uma variável cujo nome é o conteúdo de outra variável (ex: `$nome` contém 'maria', `$$nome` aponta para a variável `$maria`).

5

Qual é a regra fundamental para a nomenclatura de variáveis em PHP em relação ao *case* (maiúsculas/minúsculas)?

5

O PHP é case sensitive. Variáveis como `$codigo` e `$Codigo` são tratadas de forma totalmente diferente.

6

O que é um Tipo Booleano em PHP?

6

É um valor lógico que pode ser verdadeiro (`TRUE`) ou falso (`FALSE`).

7

O que o PHP considera como FALSO em comparações lógicas?

7

O PHP considera o valor zero (`0`) como sendo falso em comparações lógicas.

8

Como se cria uma referência entre duas variáveis em PHP para que a alteração em uma afete a outra?

8

A atribuição deve ser precedida pelo operador `&` (e-comercial).

II. Operadores e Estruturas de Controle

9

Qual operador deve ser usado para verificar se duas variáveis são iguais em valor E no tipo de dado?

9

O operador Idêntico (`===`). Ele retorna `TRUE` se as expressões forem iguais e do mesmo tipo de dado.

10

O que o operador Módulo (`%`) retorna em uma operação aritmética?

10

Retorna o módulo (resto da divisão).

11

Qual é a função do operador lógico `XOR` (`ou exclusivo`)?

11

Retorna `TRUE` se apenas uma das expressões for verdadeira, de forma exclusiva.

12

O que o operador `BREAK` faz em um laço de repetição (`WHILE` ou `FOR`)?

12

O comando `BREAK` aborta a execução dos blocos de comandos.

13

Como se chama a atribuição condicional simplificada que substitui um bloco `IF/ELSE` em uma única linha?

13

É o Operador Ternário (`? :`).

14

Qual laço de repetição é ideal para iterar sobre *arrays* e matrizes?

14

O laço `FOREACH`, que decompõe um vetor ou matriz em cada um de seus elementos.

III. Arrays, Funções e Tipos de Dados Complexos

15

O que é um `array` em PHP?

15

É uma lista de valores armazenados na memória, que podem ser de diferentes tipos (números, *strings*, objetos) e são acessados por uma chave.

16

Como o PHP distingue um array indexado de um array associativo?

16

O array indexado usa índices numéricos (começando em 0), enquanto o array associativo usa strings como chaves de acesso.

17

Qual é o comando de saída usado para imprimir o conteúdo de um *array* de forma explanatória, mostrando o tipo de dado e todos os atributos, ideal para *debugging*?

17

É o `var_dump()`.

18

Qual é a principal característica que define um objeto (`object`) em PHP?

18

É uma entidade com um determinado comportamento definido por seus métodos (ações) e propriedades (dados).

19

O que a palavra-chave `return` faz em uma função?

19

É a cláusula utilizada no final de uma função para retornar o resultado da função (pode ser um inteiro, *string*, *array*, objeto, etc.).

20

Como você declara uma variável estática (`static`) dentro de uma função?

20

Deve-se utilizar o operador `static`. Variáveis estáticas mantêm o valor que lhes foi atribuído na última execução da função.

IV. Orientação a Objetos e Abstração

21

O que é Polimorfismo em Orientação a Objetos?

21

É o princípio que permite que classes derivadas de uma mesma superclasse tenham métodos iguais (mesma nomenclatura), mas com comportamentos diferentes (redefinidos em cada classe-filha).

22

O que significa declarar um método como `final`?

22

Significa que o método não pode ser sobrescrito (redefinido) nas classes filhas.

23

O que significa declarar uma classe como `final`?

23

Significa que a classe não pode ser uma superclasse, ou seja, não pode servir de base em uma estrutura de herança e não poderá ser especializada.

24

Qual a visibilidade que permite acesso aos membros de uma classe somente dentro da própria classe onde foram declarados?

24

A visibilidade `private`.

25

Qual a visibilidade que permite acesso aos membros dentro da própria classe e nas classes descendentes (herdeiras), mas não externamente?

25

A visibilidade `protected`.

V. Manipulação de Dados e SQL

26

Qual instrução SQL é usada para inserir uma ou mais linhas em uma tabela do banco de dados?

26

A instrução `INSERT INTO`.

27

Qual instrução SQL é usada para recuperar (ler) um conjunto de linhas a partir de uma ou mais tabelas?

27

A instrução `SELECT`.

28

O que a cláusula `WHERE` faz nas instruções SQL `SELECT`, `UPDATE` e `DELETE`?

28

Define uma condição (filtro) para que o comando seja aplicado apenas aos registros que a satisfaçam.

29

Qual instrução SQL é usada para apagar (remover) uma ou mais linhas de uma tabela?

29

A instrução `DELETE FROM`.

30

O que é a biblioteca PDO (PHP Data Objects)?

30

É uma biblioteca que provê uma API limpa e consistente para unificar o acesso às diversas extensões de bancos de dados existentes no PHP.
