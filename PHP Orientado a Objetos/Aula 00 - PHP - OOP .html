Programação Orientada a Objetos (POO)

Paradigmas, Bases e Pilares em PHP

O que é POO?

A POO é um dos paradigmas de programação mais populares. Ela simplifica programas complexos organizando o código em torno de objetos, que são unidades menores que combinam dados (atributos) e ações (métodos). O objetivo é aproximar a programação das coisas do mundo real.

Bases da POO: Classes e Objetos

O que são Objetos?

Objetos são as unidades concretas que combinam:

  • Atributos (Dados): As características do objeto (ex: modelo, cor, velocidade).
  • Métodos (Ações): As operações ou comportamentos que o objeto pode realizar (ex: acelerar, frear).

Exemplo da Classe `Carro` (PHP)

<?php
class Carro {
    public float $velocidade;
    public string $modelo;
    public string $cor;
    
    public function __construct(string $modelo, string $cor) {
        $this->modelo = $modelo;
        $this->cor = $cor;
        $this->velocidade = 0.0;
    }
    
    public function acelerar(): void {
        // código do carro para acelerar
    }
    public function frear(): void {
        // código do carro para frear
    }
}
?>

O que são Classes?

A classe é um conceito abstrato, servindo como um molde ou uma planta para criar objetos. Ela define o conjunto de características e comportamentos comuns a todos os objetos que pertencem a ela.

A criação de um objeto a partir de uma classe é chamada de instanciação. O seu carro específico (o objeto) é uma instância da classe genérica "Carro".

Exemplo de Instanciação (PHP)

<?php
// Usando a classe Carro para criar um objeto (instância)
$meuCarro = new Carro("Fit 2.0", "Vermelho");

// Acessando atributos e métodos do objeto
$meuCarro->acelerar();
echo $meuCarro->modelo; // Saída: Fit 2.0
?>

Os 4 Pilares da POO

🔒 1. Encapsulamento

O encapsulamento impede o vazamento de escopo, controlando a visibilidade dos atributos e métodos. Isso significa que o objeto esconde como ele funciona por dentro, expondo apenas o necessário. Atributos podem ser privados (só visíveis internamente) e métodos podem ser usados como "getters e setters" (para ler e alterar, respectivamente).

Exemplo de Encapsulamento (PHP)

<?php
class Carro {
    private float $velocidade = 0.0; // Acesso restrito
    
    // Getter: método público para ler o atributo privado
    public function getVelocidade(): float {
        return $this->velocidade;
    }
    
    // Setter: método privado para alterar o atributo (só o próprio Carro pode chamar)
    private function setVelocidade(float $novaVelocidade): void {
        $this->velocidade = $novaVelocidade;
    }

    // Método de comportamento público que usa o método privado
    public function acelerar(): void {
        $this->setVelocidade($this->velocidade + 10);
    }
}
?>

🧬 2. Herança

Herança é quando uma classe A "é um tipo de" classe B. A classe filha (A) herda os atributos e métodos da classe mãe (B), podendo adicionar ou modificar comportamentos. Isso promove o reaproveitamento de código.

Exemplo de Herança (`extends` em PHP)

<?php
// HondaFit herda todas as características e comportamentos de Carro
class HondaFit extends Carro {
    
    // Construtor de HondaFit
    public function __construct(string $cor) {
        // Chama o construtor da classe mãe (Carro)
        parent::__construct("Honda Fit", $cor);
    }
    
    // Adiciona um método específico do Fit
    public function ligarModoEconomico(): void {
        // Código para economizar combustível
    }
}
?>

📄 3. Interface

Uma Interface define um contrato: um conjunto de métodos que uma classe deve implementar. Quando classes diferentes (ex: `Carro` e `Moto`) implementam a mesma interface (ex: `Automovel`), elas compartilham um comportamento comum.

Exemplo de Interface (`interface` e `implements` em PHP)

<?php
// A Interface define o contrato: métodos SEM implementação
interface Automovel {
    public function acelerar(): void;
    public function frear(): void;
}

// Classes diferentes implementam o contrato
class Carro implements Automovel {
    /* ... atributos e construtor ... */
    public function acelerar(): void {
        // Implementação específica do Carro
    }
    public function frear(): void {
        // Implementação específica do Carro
    }
}

class Moto implements Automovel {
    /* ... atributos e construtor ... */
    public function acelerar(): void {
        // Implementação específica da Moto
    }
    public function frear(): void {
        // Implementação específica da Moto
    }
}
?>

✨ 4. Polimorfismo

Polimorfismo (muitas formas) permite que objetos de classes diferentes (que implementam a mesma interface) respondam ao mesmo método de maneiras distintas. O mesmo nome de método pode ter implementações diferentes em cada classe.

Exemplo de Polimorfismo (PHP)

<?php
// Instanciação: Objetos diferentes, mas tratados como o tipo 'Automovel' (Interface)
// Assumindo que Carro e Moto implementam a interface Automovel e possuem construtores.
$moto = new Moto("Yamaha XPTO-100");
$carro = new Carro("Honda Fit");
    
$listaAutomoveis = [$moto, $carro];
    
foreach ($listaAutomoveis as $automovel) {
    // A chamada do método é a mesma para todos (acelerar()),
    // mas a execução interna é polimórfica (diferente para Carro e Moto).
    $automovel->acelerar(); 
}
?>

🔄 POO vs. Programação Estruturada

Enquanto a Programação Estruturada foca no fluxo de execução (sequências, condições, repetições) geralmente em uma única ou poucas grandes rotinas, a POO foca na organização dos dados e ações em unidades (objetos).

A POO oferece vantagens como o encapsulamento (restrição de acesso), que ajuda a evitar o uso excessivo e perigoso de variáveis globais, facilitando a identificação do estado de cada variável e tornando o código mais seguro e manutenível.
