🧠 O que é uma Linguagem de Programação?

Vamos imaginar a linguagem de programação como se fosse uma forma de conversar com o computador.

  • É um conjunto de regras e comandos que os humanos usam para dar instruções ao computador.
  • Com ela, você pode criar programas, sites, jogos, aplicativos, sistemas e muito mais.
  • Cada linguagem tem sintaxe própria, como se fossem diferentes idiomas: PHP, Python, JavaScript, C++, etc.

🌍 Por que existem várias linguagens?

Assim como temos português, inglês, espanhol… cada linguagem de programação tem vantagens específicas:

  • Algumas são melhores para sites (como PHP e JavaScript)
  • Outras para inteligência artificial (como Python)
  • Outras para jogos e sistemas complexos (como C++)

🛠️ O que dá pra fazer com elas?

  • Criar sites interativos
  • Desenvolver aplicativos de celular
  • Automatizar tarefas repetitivas
  • Criar jogos e animações
  • Fazer robôs e inteligência artificial
  • Controlar sensores e dispositivos físicos

🗣️ Ok, entendi, mas como conversar com o computador?

Entendendo a sintaxe na programação com uma analogia simples

Para que seres humanos se comuniquem entre si, usamos idiomas — como português, inglês ou espanhol. Cada idioma possui um conjunto de regras que organizam as palavras e frases: isso é a gramática. Ela define, por exemplo, onde colocar acentos, vírgulas, ponto final, como conjugar verbos e estruturar sentenças.

Da mesma forma, quando queremos nos comunicar com um computador, usamos uma linguagem de programação. E essa linguagem também tem suas regras próprias, que chamamos de sintaxe. A sintaxe na programação funciona como a gramática de um idioma: ela determina como escrever os comandos corretamente para que o computador entenda e execute o que queremos. Se você escrever algo fora dessas regras, o computador não consegue interpretar — assim como uma frase mal escrita pode confundir uma pessoa.

Em resumo: Assim como usamos gramática para conversar com pessoas, usamos sintaxe para conversar com computadores. É ela que garante que nossa “fala digital” seja clara, precisa e compreensível.

📝 Sintaxe: a gramática do código

- Imagine que você está escrevendo uma frase em português:

  • Se você escrever: “Eu comer banana”, a gente entende, mas está gramaticalmente errado.
  • O certo seria: “Eu como banana”.

Assim como o português tem regras de escrita, as linguagens de programação também têm regras — e essas regras são chamadas de sintaxe.

No mundo da programação:

  • A sintaxe define como escrever os comandos corretamente para que o computador entenda e execute.
  • Se você errar a sintaxe, o computador não entende e mostra um erro.

Por que a sintaxe é importante?

  • Garante que o código funcione corretamente
  • Facilita a leitura e manutenção do programa
  • Evita erros e confusões no sistema

🔑 Palavras Reservadas

Como vimos cada linguagem de programação possui um conjunto de regras que define como os comandos devem ser escritos — esse conjunto é chamado de sintaxe. A sintaxe funciona como a gramática de um idioma, orientando a forma correta de organizar os elementos do código para que o computador consiga entender e executar as instruções.

Dentro dessa sintaxe, existem as chamadas palavras reservadas. Elas são como comandos especiais que já têm um significado definido pela linguagem. São instruções que dizem ao computador o que fazer — como tomar decisões, repetir ações ou criar funções.

  • Palavras reservadas são termos que têm um significado fixo para o computador.
  • Elas são usadas para controlar o fluxo do programa, definir estruturas, executar ações.
  • Você não pode usá-las como nomes de variáveis, funções ou identificadores, porque isso causaria confusão.

Algumas palavras reservadas comuns:

if → usado para fazer uma condição
while → usado para criar um laço de repetição
function → usado para criar uma função
echo → usado para mostrar algo na tela
return → usado para devolver um valor

Em resumo: Palavras reservadas são comandos fixos da linguagem de programação. Elas têm funções específicas e não podem ser usadas para outras coisas, como nomes de variáveis ou funções.

🐘 PHP: O Que É e Sua Origem

PHP é uma linguagem de programação de código aberto voltada principalmente para o desenvolvimento de aplicações web dinâmicas, executadas no servidor.

Definição e Origem

  • PHP é um acrônimo recursivo para PHP: Hypertext Preprocessor (Pré-Processador de Hipertexto).
  • Foi criado em 1994 por Rasmus Lerdorf como um conjunto de scripts para monitorar acessos ao seu site pessoal.
  • Inicialmente chamado de Personal Home Page Tools, evoluiu para uma linguagem robusta e amplamente usada na web.

Como Funciona

  • Executado no servidor: Diferente do JavaScript, que roda no navegador, o PHP processa os dados no servidor e envia apenas o resultado (HTML) para o usuário.
  • Embutido no HTML: Você pode misturar código PHP com HTML, o que facilita a criação de páginas dinâmicas.

👨‍🍳 Mas o que é um servidor?

Vamos imaginar o servidor como se fosse um garçom em um restaurante digital.

Imagine que você está em um restaurante:

  • Você (cliente) faz um pedido ao garçom.
  • O garçom (servidor) leva esse pedido para a cozinha (onde estão os dados e os programas).
  • A cozinha prepara o prato (a página ou informação que você quer).
  • O garçom traz o prato até sua mesa (mostra a página no seu navegador).

Trazendo para o mundo da tecnologia:

  • Você usa um navegador (como Chrome ou Firefox) e acessa um site.
  • Esse pedido vai para um servidor, que é um computador potente e sempre ligado.
  • O servidor processa o pedido, busca os dados, executa o código (como PHP) e envia a resposta para você.
  • Você vê o resultado na tela: uma página, uma imagem, um vídeo, etc.

⚙️ Tipos de Servidores e Popularidade do PHP

Exemplos práticos:

  • Quando você entra no Instagram, o servidor envia suas fotos, comentários e mensagens.
  • Quando você acessa um site de notícias, o servidor monta a página com as manchetes atualizadas.

Tipos de servidores:

  • Servidor web: entrega páginas da internet.
  • Servidor de banco de dados: guarda e organiza informações.
  • Servidor de e-mail: envia e recebe mensagens.
  • Servidor de arquivos: armazena documentos, fotos, vídeos.

Popularidade do PHP

  • Mais de 75% dos sites na internet usam PHP em seus servidores, incluindo plataformas como WordPress, Facebook e Slack.
