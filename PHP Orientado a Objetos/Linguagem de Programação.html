3. Sintaxe: A Gramática do Código

Ok, entendi, mas como conversar com o computador ?

Para que seres humanos se comuniquem entre si, usamos idiomas — como português, inglês ou espanhol. Cada idioma possui um conjunto de regras que organizam as palavras e frases: isso é a gramática. Ela define, por exemplo, onde colocar acentos, vírgulas, ponto final, como conjugar verbos e estruturar sentenças. Da mesma forma, quando queremos nos comunicar com um computador, usamos uma linguagem de programação. E essa linguagem também tem suas regras próprias, que chamamos de sintaxe. A sintaxe na programação funciona como a gramática de um idioma: ela determina como escrever os comandos corretamente para que o computador entenda e execute o que queremos. Se você escrever algo fora dessas regras, o computador não consegue interpretar — assim como uma frase mal escrita pode confundir uma pessoa.

Analogia Simples: Programação é um Idioma

Comunicação Humana (Português):

  • Usamos Gramática (regras) para organizar palavras.
  • Exemplo Errado: "Eu comer banana" vs. Certo: "Eu como banana"

Comunicação com o Computador (PHP):

  • Usamos Sintaxe (regras) para organizar comandos.
  • Se você errar a sintaxe, o computador não entende e mostra um erro.

Em resumo: Assim como usamos gramática para conversar com pessoas, usamos sintaxe para conversar com computadores.

Palavras Reservadas

São termos que têm um significado fixo para o computador, usados para controlar o fluxo do programa.

  • 🔑 if → Usado para fazer uma condição.
  • 🔑 while → Usado para criar laço de repetição.
  • 🔑 function → Usado para criar uma função.
  • 🔑 echo → Usado para mostrar algo na tela.
  • 🔑 return → Usado para devolver um valor.

Você não pode usá-las como nomes de variáveis.

4. Foco: A Linguagem PHP

Definição e Uso

PHP é uma linguagem de programação de código aberto voltada principalmente para o desenvolvimento de aplicações web dinâmicas.

  • Acrônimo: PHP: Hypertext Preprocessor.
  • Origem: Criado em 1994 por Rasmus Lerdorf.
  • Popularidade: Mais de 75% dos sites na internet usam PHP.

Execução no Servidor

O código PHP é processado no servidor e envia apenas o resultado final (HTML) para o navegador do usuário.

  • HTML Embutido: Você pode misturar código PHP com HTML (Ex: <?php echo "Olá Mundo"; ?>).
  • Web Dinâmica: Cria conteúdo que muda de acordo com o usuário ou o momento.

5. Analogia: O Servidor como um Garçom Digital

VOCÊ (CLIENTE)

Você usa o navegador e faz um pedido.

→

SERVIDOR (GARÇOM)

Leva o pedido à "cozinha" e busca os dados.

→

RESPOSTA (O PRATO)

O servidor envia a página (HTML) finalizada.

O servidor é um computador potente que processa o código (como PHP), busca dados e envia a resposta.
