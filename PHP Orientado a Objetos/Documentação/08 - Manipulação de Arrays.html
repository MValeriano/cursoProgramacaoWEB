Manipulação de Arrays em PHP

Arrays: o contêiner dinâmico para coleções de dados.

I. Tipos de Arrays e Estruturas

A. Arrays Indexados (Numéricos)

As chaves (posições) são números inteiros, começando em 0. Usados para listas simples onde a ordem é importante.

// Sintaxe Curta
$lista = ['A', 'B', 'C'];
// Acesso ao valor 'B'
echo $lista[1]; // Saída: B

B. Arrays Associativos (String Keys)

As chaves são strings (rótulos) que descrevem o valor. Usados para dados estruturados (registros, configurações).

// Chave => Valor
$usuario = [
'nome' => 'Ana',
'idade' => 25
];
// Acesso ao valor 'Ana'
echo $usuario['nome'];

C. Array Multidimensional (Matriz)

Um array que contém outros arrays como seus elementos (array de arrays). Essencial para simular tabelas de dados.

Acesso:

// Acesso: [Linha][Coluna]
$matriz[0]['email'];

II. Funções de Manipulação (Métodos)

Tamanho/Contagem

  • `count()`: Retorna o número de elementos.

Adicionar/Remover

  • `array_push()`: Adiciona ao final.
  • `array_pop()`: Remove do final.
  • `array_splice()`: Remove ou insere em qualquer ponto.

Ordenação

  • `sort()`: Ordena por valor, reinicia índices.
  • `asort()`: Ordena por valor, mantém chaves associativas.

III. 5 Exercícios para Raciocínio Estrutural

1. Gerenciamento de Fila Simples (array_push(), array_pop() e count())

Adicionar múltiplos pedidos e simular o cancelamento do último pedido na fila.

<?php
$pedidos = array('Pedido A', 'Pedido B');

// 1. Adiciona Pedido C e D no final
array_push($pedidos, 'Pedido C', 'Pedido D');

// 2. Simula o cancelamento do último (Pedido D)
array_pop($pedidos);

echo "Número de elementos restantes: " . count($pedidos) . "<br>";
print_r($pedidos); // Saída: Array ( [0] => Pedido A [1] => Pedido B [2] => Pedido C )
?>

2. Catálogo e Ordenação Associativa (sort() vs. asort())

Ordenar o array pelos valores (nomes dos produtos) mantendo a associação com as chaves (códigos).

<?php
// Código => Produto
$produtos = [50 => 'Maçã', 10 => 'Pêra', 30 => 'Banana'];

// Se usássemos sort(), perderíamos os códigos: sort($produtos);

// asort() ordena pelo valor, preservando a chave (código)
asort($produtos);

echo "Catálogo Ordenado por Nome (mantendo código):<br>";
print_r($produtos); // Saída: Array ( [30] => Banana [50] => Maçã [10] => Pêra )
?>

3. Segmentação e Inserção Cirúrgica (array_splice())

Remover e inserir elementos em um ponto específico de um array, forçando a reindexação.

<?php
$tarefas = ['Tarefa A', 'Tarefa B', 'Tarefa C', 'Tarefa D'];

// Início (índice 1, onde está B), Remover (1 elemento), Substituir (Novo Array)
array_splice($tarefas, 1, 1, [
'Tarefa B-1 (nova)',
'Tarefa B-2 (nova)'
]);

echo "Lista de Tarefas Atualizada:<br>";
print_r($tarefas);
// Saída: Array ( [0] => Tarefa A [1] => Tarefa B-1 (nova) [2] => Tarefa B-2 (nova) [3] => Tarefa C [4] => Tarefa D )
?>

4. Mapeamento de Configurações (Acesso Multidimensional)

Acessar dados em estruturas aninhadas usando o encadeamento de chaves associativas.

<?php
$catalogo_carros['Palio'] = [
'cor' => 'azul',
'opcionais' => [
'tipo' => 'Ar Cond.',
'status' => 'Instalado'
]
];

// Acessando o tipo do opcional (3 níveis de profundidade)
$tipo_opcional = $catalogo_carros['Palio']['opcionais']['tipo'];

// Acessando o status
$status_opcional = $catalogo_carros['Palio']['opcionais']['status'];

echo "Opcional: " . $tipo_opcional . " (Status: " . $status_opcional . ")";
?>

5. Simulação de Resultado de Banco de Dados (foreach Aninhado)

Usar loops aninhados para iterar sobre linhas e colunas de uma matriz 2D.

<?php
$resultados_db = [
['nome' => 'João', 'email' => 'joao@exemplo.com'],
['nome' => 'Maria', 'email' => 'maria@exemplo.com']
];

// Loop externo: Itera sobre as LINHAS (cada elemento é um array)
foreach ($resultados_db as $indice_linha => $linha) {
echo "<h3>Usuário #" . ($indice_linha + 1) . "</h3>";

// Loop interno: Itera sobre as COLUNAS (chave => valor) de cada linha
foreach ($linha as $coluna => $valor) {
echo "<li>" . $coluna . ": " . $valor . "</li>";
}
echo "<br>";
}
?>
