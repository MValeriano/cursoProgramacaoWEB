Operadores PHP: Ações e Comandos

As Ferramentas para Manipular os Dados (Variáveis)

Se as variáveis são as "caixas" onde guardamos informações, os operadores são as ferramentas que usamos para calcular, comparar e conectar esses dados.

#1 Atribuição (Assignment)

Usados para colocar um valor dentro de uma variável ou modificá-lo no local.

Operador Exemplo Ação
=$a = 10;Atribui o valor 10 a $a.
+=$a += 5;$a = $a + 5 (Adição Composta)
-=$a -= 2;$a = $a - 2
.=$s .= 'Olá';$s = $s . 'Olá' (Concatenação Composta)

Analogia: Colocar ou somar itens diretamente na "caixa" (variável).

#2 Aritméticos (Cálculo)

Usados para realizar cálculos matemáticos com números.

Operador Descrição Exemplo
+Adição1 + 2
*Multiplicação3 * 4
/Divisão10 / 2
%Módulo (Resto)10 % 3 (Retorna 1)
Exponenciação10 3 (Retorna 1000)

Precedência: Utilize parênteses () para forçar a ordem de cálculo, garantindo que o que está dentro seja processado primeiro.

#3 Relacionais (Comparação)

Usados para comparar valores. O resultado é sempre Booleano (TRUE ou FALSE).

Operador Conceito Exemplo
==Igualdade Solta (Só valor)5 == '5' (TRUE)
===Identidade Estrita (Valor E Tipo)5 === '5' (FALSE)
!= / <>Diferente (Solto)5 != 4 (TRUE)
> / <Maior / Menor$a > $b

Regra de Ouro: Sempre que a verificação de tipo for crucial (segurança, precisão), use ===.

#4 Lógicos (Combinar Condições)

Usados para combinar ou negar expressões lógicas em testes condicionais (ex: if).

&& (and)

E (AND): Retorna TRUE se *todas* as condições forem verdadeiras.
"Matemática >= 7 E Português >= 7"

|| (or)

OU (OR): Retorna TRUE se *pelo menos uma* condição for verdadeira.
"Chave OU Código de Acesso"

! (not)

NÃO (NOT): Nega o resultado. Transforma TRUE em FALSE, e FALSE em TRUE.
"Se NÃO for 'Ativo'"

#5 Incremento e Decremento

Forma curta de adicionar ou subtrair 1 da variável. Usado em for loops.

Operador Conceito
++$aPré-incremento: Soma 1, depois usa o valor.
$a++Pós-incremento: Usa o valor, depois soma 1.
--$aPré-decremento: Subtrai 1, depois usa.
$a--Pós-decremento: Usa, depois subtrai 1.

5 Desafios com Operadores

Teste seus conhecimentos com exercícios que exploram cada tipo de operador.

1. Distribuição de Tarefas (Aritméticos e Módulo)

Divida 25 tarefas para 7 programadores e descubra o resto.

$programadores = 7;
$tarefas = 25;
// Tarefas por programador: 25 / 7 (Divisão)
// Tarefas restantes: 25 % 7 (Módulo)

3. O Veredito Legal (Relacionais: == vs. ===)

Compare $data_registro = '0'; com 0 (inteiro), usando os dois operadores de igualdade.

$data_registro = '0';
// Resultado TRUE (só checa o valor):
echo $data_registro == 0;
// Resultado FALSE (checa valor E tipo):
echo $data_registro === 0;

4. A Decisão do Login (Lógicos: AND e OR)

Monte a expressão lógica complexa para liberar o acesso.

$is_admin = FALSE; $senha_correta = TRUE;
$is_vip = TRUE; $tem_token = FALSE;
// (Admin E Senha) OU (VIP OU Token)
$acesso_liberado = ($is_admin && $senha_correta) || ($is_vip || $tem_token);
echo $acesso_liberado; // Resultado esperado: TRUE

5. Contador de Vendas (Incremento Pré e Pós)

Entenda a diferença sutil entre $vendas++ (pós) e ++$vendas (pré).

$vendas = 5;
$venda_anunciada = $vendas++; // $venda_anunciada = 5, $vendas = 6
$venda_registrada = ++$vendas; // $venda_registrada = 7, $vendas = 7
