Estruturas de Controle de Fluxo em PHP

O GPS do seu Código: Tomando Decisões

Essas estruturas (IF, ELSE, SWITCH) são cruciais, pois permitem que o código tome decisões e altere o fluxo sequencial de execução com base em condições.

1. Decisão Sequencial (IF, ELSEIF, ELSE)

IF (SE)

Executa um bloco de código somente se a condição entre parênteses for avaliada como TRUE (Verdadeira).

Analogia: SE (combustível baixo) ENTÃO {acenda a luz de advertência}.

if ($idade >= 18) {
echo "Maior de idade";
}

ELSE e ELSEIF (SENÃO SE)

  • ELSEIF Testa uma próxima condição se a anterior falhou.
  • ELSE É o bloco padrão de "caso contrário", executado se *todas* as condições anteriores falharem.

Regra: Assim que uma condição é TRUE, o restante da cadeia é ignorado.

if ($nota >= 7) { ... }
elseif ($nota >= 5) { ... }
else { ... }

2. Comando SWITCH (Teste em Série)

O SWITCH testa o valor de uma única variável contra diferentes casos específicos (CASE).

CASE e BREAK

  • Cada CASE compara a variável com um valor.
  • O BREAK é crucial e obrigatório; ele impede que o código continue executando os CASEs seguintes.

DEFAULT

O bloco DEFAULT será executado se o valor da variável não corresponder a nenhum dos CASEs. É similar ao ELSE.

Analogia: Central Telefônica Automática: Digite a opção (variável). CASO 1: Atende. CASO 2: Suporte. DEFAULT: Opção Inválida.

switch ($operador) {
case 'add':
echo "Adição";
break; // Importante: para a execução aqui
default:
echo "Operação inválida";
}

Diferença: IF/ELSEIF vs. SWITCH

O SWITCH é focado em testar diferentes valores específicos de UMA ÚNICA variável.

O IF/ELSEIF permite checar diferentes condições e múltiplas variáveis em cada etapa da cadeia de decisão, oferecendo maior flexibilidade para lógica complexa.

5 Desafios de Estruturas de Controle

Aplique o IF/ELSEIF/ELSE e o SWITCH para criar códigos que tomam decisões.

1. Verificador de Faixa Etária (IF, ELSEIF, ELSE)

Classifique o usuário em "adulto", "adolescente" ou "criança" com base na $idade.

$idade = 15;
if ($idade >= 18) {
echo "Você é um adulto e pode dirigir.";
} elseif ($idade >= 14) {
echo "Você é um adolescente e precisa de permissão.";
} else {
echo "Você é uma criança.";
}

2. O Sinal de Trânsito (SWITCH)

Simule um semáforo usando SWITCH e garanta que haja um DEFAULT.

$cor = 'vermelho';
switch ($cor) {
case 'verde': echo "Prossiga..."; break;
case 'amarelo': echo "Atenção..."; break;
case 'vermelho': echo "Pare..."; break;
default: echo "Sinal com defeito.";
}

3. Sistema de Desconto (Lógicos e IF)

Use o operador lógico E (&&) para exigir que duas condições sejam verdadeiras para conceder o desconto.

$valor_compra = 150.00;
$cliente_vip = TRUE;
if ($valor_compra > 100 && $cliente_vip == TRUE) {
echo "Desconto de 15% aplicado!";
} else {
echo "Desconto não aplicável.";
}

5. Validação Múltipla (Múltiplos IFs Independentes)

Use IFs separados para verificar campos de formulário, exibindo todas as mensagens de erro, se houver.

$nome = ""; $email = "teste@exemplo.com";
$erros = 0;

// 1º IF: verifica nome
if (empty($nome)) {
echo "Erro: O nome é obrigatório.";
$erros++;
}

// 2º IF: verifica email
if (empty($email)) {
echo "Erro: O email é obrigatório.";
$erros++;
}

// 3º IF: verifica se pode enviar
if ($erros == 0) {
echo "Formulário enviado com sucesso.";
}
