Funções (Functions): A Reutilização de Código

Seu Mini-Robô de Serviço para Tarefas Específicas

Uma função é um bloco de código que **encapsula** uma tarefa. Ela pode receber dados (parâmetros) e gerar um resultado (`return`), eliminando a necessidade de escrever o mesmo código várias vezes.

1. Passagem de Parâmetros: Como o Robô Lida com os Dados

Tipo 1: Passagem por Valor (Padrão)

A função trabalha com uma **cópia** do dado original. O valor externo não é afetado pelas alterações internas.

  • **Conceito:** Variável local à função.
  • **Analogia:** A **Fotocópia**. Rabiscar a cópia não estraga o original.
$original = 100;
function mudar($num) {
$num = 50; // Altera SÓ a cópia
}
mudar($original);
// $original ainda é 100

Tipo 2: Passagem por Referência (&)

A função acessa o **dado original** na memória. As alterações internas **modificam** o valor externo.

  • **Marcação:** Usa o operador **< class="bg-gray-200 px-1 rounded text-sm">&** na declaração do parâmetro.
  • **Analogia:** A **Chave do Cofre**. Você altera o valor guardado no cofre original.
$original = 100;
function mudar(&$num) { // O & é crucial
$num = 50; // Altera o original
}
mudar($original);
// $original agora é 50

2. Estrutura Básica: Criação e Saída (Return)

Use a palavra-chave < class="bg-gray-200 px-1 rounded text-sm">function, defina parâmetros opcionais entre parênteses e use < class="bg-gray-200 px-1 rounded text-sm">return para devolver o resultado.

function somar($n1, $n2) {
return $n1 + $n2;
}

// Armazena o valor retornado em uma variável
$total = somar(5, 3); // $total recebe 8
echo $total;

5 Desafios com Funções e Parâmetros

Implemente as funções e observe a diferença entre a manipulação de valores e referências.

1. O Mini-Robô de Validação (Return e Reuso)

Crie a função < class="bg-gray-200 px-1 rounded text-sm">validar_email($email) e use **return** para reutilização.

function validar_email($email) {
if (empty($email)) {
return "Email Inválido";
} else {
return "Email Válido";
}
}

// Reutilização
$resultado1 = validar_email('teste@email.com');
$resultado2 = validar_email('');
echo "Teste 1: " . $resultado1 . "
";
echo "Teste 2: " . $resultado2 . "
";

2. O Documento Protegido (Passagem por Valor)

Incremente o salário na função e prove que o **valor original** permanece intocado.

$salario_original = 5000;

function ajustar_salario($salario) {
$salario += 1000; // Incrementa a CÓPIA
echo "Dentro da função (Cópia): R$ " . $salario . "
";
}

ajustar_salario($salario_original);
echo "Fora da função (Original): R$ " . $salario_original . "
"; // 5000

3. A Chave do Cofre (Passagem por Referência)

Use o **< class="bg-gray-200 px-1 rounded text-sm">&** para dobrar a dívida e modificar o valor externo permanentemente.

$minha_divida = 200;

function aplicar_juros(&$divida) {
$divida *= 2; // Multiplica o ORIGINAL
echo "Dentro da função (Referência): R$ " . $divida . "
";
}

aplicar_juros($minha_divida);
echo "Fora da função (Original Após): R$ " . $minha_divida . "
"; // 400

4. O Log de Acesso Global (Escopo e Referência)

Use referência para permitir que a função **modifique** uma variável de contador externa (global).

$contador_global = 0;

function registrar_acesso(&$contador) {
$contador++; // Incrementa a referência direta
echo "Acesso registrado. Total interno: " . $contador . "
";
}

registrar_acesso($contador_global); // 1
registrar_acesso($contador_global); // 2
registrar_acesso($contador_global); // 3
echo "Contador global final: " . $contador_global;

5. Funções com Valor Padrão e Referência (Combinação)

Crie uma função que use **< class="bg-gray-200 px-1 rounded text-sm">&** (referência) e um valor **default** (padrão) no segundo parâmetro.

$status_atual = 'Pendente';

function processar_pedido(&$status, $descricao_padrao = 'Processando Pedido') {
$status = $descricao_padrao; // Altera o status externo
echo "Status atualizado para: " . $status . "
";
}

// 1ª chamada: Usa o default ("Processando Pedido")
processar_pedido($status_atual);

// 2ª chamada: Sobrescreve o default ("Pronto para Envio")
processar_pedido($status_atual, 'Pronto para Envio');

echo "Status final externo: " . $status_atual;
