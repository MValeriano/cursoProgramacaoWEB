Manipulação de Datas e Tempo em PHP

Entendendo a diferença entre a data formatada e o Unix Timestamp.

I. Funções Essenciais para Tempo e Formato

A. date() (Formato Legível)

Recebe um formato como parâmetro (string) e retorna a data e/ou hora atual do servidor nesse formato. É usada para exibição humana.

  • `Y`: Ano com 4 dígitos
  • `m`: Mês numérico (01-12)
  • `d`: Dia do mês (01-31)
  • `H`: Hora (24h) | `i`: Minuto | `s`: Segundo
echo date('d/m/Y H:i'); // Ex: 05/10/2025 20:50

B. time() (Unix Timestamp)

Retorna um número inteiro que representa os segundos decorridos desde 1º de Janeiro de 1970 (Era Unix). Ideal para cálculos de diferença de tempo.

  • É um valor numérico.
  • Não precisa de parâmetros.
$timestamp = time(); // Ex: 1760074211

C. strtotime() (String para Timestamp)

Converte uma string contendo uma data legível (ex: "tomorrow", "2023-01-01") em um Unix Timestamp (número de segundos fixo) para essa data. Útil para datas históricas ou futuras.

$data_fixa_ts = strtotime('2020-07-20'); // Ex: 1595203200

II. 5 Exercícios Práticos com Datas

1. Formatação de Data Padrão para Relatórios (date())

Obter a data e hora atual no formato de relatório (YYYY-MM-DD HH:MM:SS).

<?php
$formato_relatorio = 'Y-m-d H:i:s';
$data_atual = date($formato_relatorio);

echo "Relatório gerado em: " . $data_atual;
// Saída: Relatório gerado em: 2025-10-05 20:50:30 (variável)
?>

2. Calculando a Duração de uma Sessão (time())

Medir o tempo de execução de um trecho de código em segundos usando o Unix Timestamp.

<?php
// 1. Captura o timestamp de início
$inicio_sessao = time();

// Simulação de processamento demorado (espera 2 segundos)
sleep(2);

// 2. Captura o timestamp de fim
$fim_sessao = time();

// 3. Calcula a duração
$duracao_segundos = $fim_sessao - $inicio_sessao;

echo "A sessão durou: " . $duracao_segundos . " segundos."; // Saída: 2 segundos
?>

3. Convertendo Datas Históricas para Timestamp (strtotime())

Obter o valor numérico (timestamp) de uma data específica para fins de armazenamento ou comparação.

<?php
$data_evento = "1985-10-26 13:00:00";

// Converte a string de data fixa para um timestamp fixo
$timestamp_evento = strtotime($data_evento);

echo "Data do Evento (String): " . $data_evento . "<br>";
echo "Timestamp Fixo: " . $timestamp_evento;

// Reflexão: Para o timestamp do momento exato da execução, usaríamos time().
?>

4. Formatando um Timestamp Fixo (date() com 2º Parâmetro)

Usar a função date() para formatar qualquer timestamp (não apenas o atual) para o formato amigável (DD/MM/YYYY).

<?php
// Timestamp Fixo (Exemplo: 1º de Janeiro de 2023)
$timestamp_fixo = 1672531200;

// date() recebe o formato (1º arg) e o timestamp a ser formatado (2º arg)
$data_formatada = date('d/m/Y', $timestamp_fixo);

echo "Timestamp original: " . $timestamp_fixo . "<br>";
echo "Data formatada: " . $data_formatada; // Saída: 01/01/2023
?>

5. Decisão de Arquitetura: PHP vs. Banco de Dados

Entender a responsabilidade de cada sistema na atribuição da data e hora de criação de um registro.

Pergunta 1: Palavra-chave do Banco de Dados para Default?

A palavra-chave usada na definição da coluna DATETIME no banco de dados para que ele insira a hora do servidor automaticamente é: CURRENT\_TIMESTAMP.

Pergunta 2: Função PHP para enviar a data exata?

A função mais adequada é date('Y-m-d H:i:s'). Embora time() retorne o momento exato, ela retorna um timestamp. A função date(), quando usada com o formato DATETIME padrão do banco de dados ('Y-m-d H:i:s'), fornece uma string que pode ser diretamente inserida na coluna do banco de dados, garantindo compatibilidade e legibilidade.
