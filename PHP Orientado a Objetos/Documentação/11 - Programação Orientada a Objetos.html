Programação Orientada a Objetos (POO) em PHP

Entendendo Classes (o modelo) e Objetos (a instância) para estruturar sistemas.

I. Classe, Objeto e Propriedades

Classe (O Modelo)

Uma classe é a estrutura estática, o molde ou o *template*. Ela define o tipo de dado e as funcionalidades que todos os objetos desse tipo terão.

  • Propriedades (var): As variáveis da classe (Ex: `$Nome`, `$Preco`).
  • Métodos: As funcionalidades ou funções da classe (Ex: `Depositar()`, `Envelhecer()`).

Objeto (A Instância)

Um objeto é a estrutura dinâmica e única criada a partir de uma classe usando o operador new.

  • Instanciação: Cria o objeto (Ex: `$produto = new Produto;`).
  • Acesso: Propriedades são acessadas e manipuladas com o operador -> (seta).

Sintaxe Básica

// 1. A CLASSE (Estrutura estática)
class Produto {
var $Codigo;
var $Descricao;
}

// 2. INSTANCIAÇÃO (Criação de objeto dinâmico)
$produto = new Produto;

// 3. ACESSO ÀS PROPRIEDADES (Atribuição de valores únicos)
$produto->Codigo = 4001;
$produto->Descricao = 'CD - Eric Clapton';

II. 5 Exercícios de Estruturação POO

1. Modelando um Item Simples (Classe, Propriedades e Instância)

Definir a classe `ItemBiblioteca` e instanciar um objeto, acessando suas propriedades.

<?php
class ItemBiblioteca {
var $id;
var $titulo;
var $tipo;
}

$meu_livro = new ItemBiblioteca;
$meu_livro->titulo = "O Guia do Mochileiro das Galáxias";
$meu_livro->tipo = "Livro";

echo "Título: " . $meu_livro->titulo;
?>

2. Unicidade dos Objetos (Múltiplas Instâncias Independentes)

Demonstrar que cada objeto é uma entidade única, mesmo vindo do mesmo modelo (Classe).

// Assumindo que a classe Produto está definida (com Codigo, Descricao, Quantidade)
$mouse = new Produto;
$teclado = new Produto;

$mouse->Quantidade = 50; // Valor inicial do Mouse
$teclado->Quantidade = 100; // Valor inicial do Teclado

$mouse->Quantidade -= 5; // Somente o mouse é afetado

echo "Mouse Quantidade: " . $mouse->Quantidade; // Saída: 45
echo " | Teclado Quantidade: " . $teclado->Quantidade; // Saída: 100

3. Métodos de Ação e o Uso da Variável $this

Implementar funcionalidades (Métodos) que interagem com as propriedades internas do próprio objeto usando $this.

<?php
class Conta {
var $Saldo = 0;

function Depositar($quantia) {
// $this referencia a propriedade Saldo DO PRÓPRIO objeto
$this->Saldo += $quantia;
}

function ObterSaldo() {
return $this->Saldo;
}
}

$minha_conta = new Conta;
$minha_conta->Depositar(500);
$minha_conta->Depositar(150);
echo "Saldo Final: " . $minha_conta->ObterSaldo(); // Saída: 650
?>

4. Modularização e Inclusão de Classes (require_once)

Usar a regra de modularização (`include_once`) para carregar o modelo (`Pessoa.class.php`) antes de instanciar o objeto.

// classes/Pessoa.class.php (Omitir tag de fechamento)
<?php
class Pessoa {
var $Nome;
var $Idade;
}

// index.php
<?php
require_once 'classes/Pessoa.class.php';

$aluno = new Pessoa; // Instanciação só é possível se a classe for carregada
$aluno->Nome = 'Carlos';
echo $aluno->Nome;
?>

5. Interação e Encapsulamento de Comportamento

Usar um método (`Envelhecer()`) para alterar o estado interno (`$Idade`) do objeto de forma controlada.

// Classe Pessoa com método Envelhecer()
class Pessoa {
var $Nome;
var $Idade = 0;

function Envelhecer($anos) {
$this->Idade += $anos;
}
}

// interacao.php
$cliente = new Pessoa;
$cliente->Nome = 'Maria'; $cliente->Idade = 30;

echo "Idade Inicial de Maria: " . $cliente->Idade . " <br>";
$cliente->Envelhecer(5);
echo "Idade Atualizada de Maria: " . $cliente->Idade; // Saída: 35
?>
