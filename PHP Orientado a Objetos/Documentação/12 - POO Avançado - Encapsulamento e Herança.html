POO Avançado: Encapsulamento e Herança

Controlando o acesso aos dados (Visibilidade) e Reutilizando estruturas (Herança).

I. Membros e Visibilidade (Encapsulamento)

public (Público)

Acessível por: Própria Classe, Classes Filhas e Código Externo. (Padrão)

private (Privado)

Acessível por: APENAS pela Própria Classe. Ideal para dados internos críticos.

protected (Protegido)

Acessível por: Própria Classe e Classes Filhas, mas não pelo código externo.

$this e Acesso aos Membros

A pseudo-variável $this representa o objeto atual. É usada internamente nos métodos para acessar as propriedades e outros métodos do objeto usando o operador -> (seta).

Herança (extends)

Permite que uma Classe-Filha receba todos os membros da Classe-Pai. Reutilização de código e estruturação de hierarquia.

// A classe Estagiario herda de Funcionario:
class Funcionario { /* ... */ }
class Estagiario extends Funcionario { /* ... */ }

II. 5 Exercícios para Raciocínio Estrutural

1. Manipulação de Estado Interno com $this

Garantir que o método interaja corretamente com a propriedade $TempoAtual da instância.

<?php
class Relogio {
public $TempoAtual = 0;

public function IncrementarMinuto() {
// Usa $this para modificar o TempoAtual do objeto em questão
$this->TempoAtual += 1;
}

public function ObterTempo() {
return $this->TempoAtual;
}
}

$meu_relogio = new Relogio;
for ($i = 0; $i < 45; $i++) {
$meu_relogio->IncrementarMinuto();
}
echo "Tempo Decorrido: " . $meu_relogio->ObterTempo(); // Saída: 45
?>

2. Encapsulamento com Visibilidade private (Getters/Setters)

Impedir acesso direto ao $Salario, forçando o uso de métodos para aplicar regras de validação.

<?php
class Pessoa {
public $Nome;
private $Salario; // DADO CRÍTICO: SÓ ACESSÍVEL AQUI DENTRO

public function SetSalario($valor) {
if (is_numeric($valor) && $valor > 0) {
$this->Salario = $valor;
echo "Salário definido corretamente. <br>";
} else {
echo "Erro: Salário inválido. <br>";
}
}

public function GetSalario() {
return $this->Salario;
}
}

$pessoa = new Pessoa;
$pessoa->Nome = 'João'; // OK - Public
$pessoa->SetSalario(10000); // OK - Usa o Setter com validação
echo "Nome: " . $pessoa->Nome . " | Salário Lido: " . $pessoa->GetSalario() . "<br>";
// Tentar $pessoa->Salario = 10000; geraria um Erro Fatal do PHP.
?>

3. Constantes de Classe (const e self::)

Definir valores fixos para toda a classe e usá-los em métodos para aplicar regras de negócio.

<?php
class Configuracao {
const PI = 3.14159;
const MAX_DESCONTO_PERCENTUAL = 15;

public function CalcularDesconto($valor, $percentual) {
// Acesso interno com self::
if ($percentual > self::MAX_DESCONTO_PERCENTUAL) {
$percentual = self::MAX_DESCONTO_PERCENTUAL;
}
return $valor * (1 - ($percentual / 100));
}
}

// Acesso externo com NomeDaClasse::
echo "O valor de PI é: " . Configuracao::PI . "<br>";
$config = new Configuracao;
echo "Valor com 20% de desconto (limitado a 15%): " . $config->CalcularDesconto(100, 20);
?>

4. Herança, Visibilidade protected e Sobrescrita

Usar extends para herdar e protected para permitir acesso da classe filha a um membro privado da classe pai.

<?php
class Funcionario {
public $Nome;
protected $SalarioBase; // Acessível em filhas

public function SetSalarioBase($base) {
$this->SalarioBase = $base;
}

public function CalcularSalarioBruto() {
return $this->SalarioBase;
}
}

class Estagiario extends Funcionario {
// Sobrescreve o método do pai para aplicar uma regra específica
public function CalcularSalarioBruto() {
return $this->SalarioBase * 1.12; // Acessa $SalarioBase (protected)
}
}

$pedrinho = new Estagiario;
$pedrinho->Nome = 'Pedrinho';
$pedrinho->SetSalarioBase(1000);
echo "Salário de Estagiário: R$" . $pedrinho->CalcularSalarioBruto(); // Saída: R$1120
?>

5. Herança, Constantes e parent:: (Estendendo o Pai)

Sobrescrever um método, mas chamar a funcionalidade original da classe-pai antes de aplicar a regra filha.

<?php
class Conta {
protected $Saldo = 0;
public function Depositar($quantia) { $this->Saldo += $quantia; }

public function Retirar($quantia) {
$this->Saldo -= $quantia;
}
public function ObterSaldo() { return $this->Saldo; }
}

class ContaCorrente extends Conta {
const TAXA_RETIRO = 5;

public function Retirar($quantia) {
$total_debito = $quantia + self::TAXA_RETIRO;
if ($this->Saldo >= $total_debito) {
// 1. Chama o método original do Pai para debitar a quantia base
parent::Retirar($quantia);
// 2. Aplica a regra adicional da classe filha
$this->Saldo -= self::TAXA_RETIRO;
echo "Retirada efetuada (Taxa: R$5) <br>";
} else {
echo "Saldo Insuficiente. <br>";
}
}
}

$minha_conta = new ContaCorrente;
$minha_conta->Depositar(100);
$minha_conta->Retirar(50); // Total debitado: 50 + 5 = 55
echo "Saldo Atual: " . $minha_conta->ObterSaldo(); // Saída: 45
?>
