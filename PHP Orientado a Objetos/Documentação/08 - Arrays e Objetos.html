Estruturas de Dados: Arrays e Objetos

Agrupando Informações Complexas em PHP

Arrays e Objetos são contêineres que armazenam múltiplos valores dentro de uma única variável, permitindo manipular informações como um único bloco de dados.

1. Array (O Container Multifuncional)

Conceito e Analogia

Um Array é uma coleção de valores (de qualquer tipo) acessada por meio de uma chave (índice).

Analogia: É uma caixa de ferramentas rotulada, guardando vários itens com uma única identificação.

$frutas = ['Maçã', 'Pêra', 'Uva'];
// Acessando o primeiro item:
echo $frutas[0]; // Saída: Maçã

Tipos de Arrays

  • Indexado: Acessado por índices numéricos (0, 1, 2...). (Ex: Lista de supermercado numerada).
  • Associativo: Acessado por chaves de string (rótulos). (Ex: Ficha cadastral com chaves 'nome', 'email').
  • Multidimensional: Array que contém outros Arrays. (Ex: Uma planilha ou tabela de DB).

2. Objeto (A Entidade Inteligente)

Classe vs. Objeto (OOP)

  • Classe: A Planta ou Template. Define as regras e propriedades (`cor`, `velocidade`).
  • Objeto: O Carro Pronto (instância). Estrutura viva com dados e identidade únicos.

Os dados (propriedades) do objeto são acessados com o operador de seta ->.

Criação e Acesso

// 1. A Classe (o template)
class Carro {
public $cor;
public $modelo;
}

// 2. O Objeto (a instância)
$meu_carro = new Carro();
$meu_carro->cor = 'Vermelho';
echo $meu_carro->cor;

5 Desafios de Estruturas de Dados

Pratique a criação e manipulação de arrays e objetos, a base de todo sistema web.

1. O Contador de Clientes (Array Indexado)

Crie um array indexado e acesse o terceiro cliente (índice 2). Use count().

$clientes_recentes = ['Maria', 'João', 'Pedro', 'Ana'];

// 2. Acessa o TERCEIRO cliente (índice 2)
echo "Terceiro cliente: " . $clientes_recentes[2] . "
";

// 3. Conta os elementos
echo "Total de clientes: " . count($clientes_recentes);

2. O Carrinho de Compras (Array Associativo)

Use chaves de string para associar o produto ao preço.

$carrinho = [
'Livro PHP' => 85.50,
'Mouse' => 49.90
];

// 2. Exibe o preço do livro
echo "Preço do livro: R$ " . $carrinho['Livro PHP'] . "
";

// 3. Adiciona novo item (Teclado)
$carrinho['Teclado'] = 150.00;

3. Gestão de Tarefas (Manipulação e Debugging)

Use array_push() e array_pop() para manipular a lista.

$tarefas = ['Limpar Janelas', 'Lavar Louça', 'Aspirar Sala'];

// 2. Adiciona item ao final
array_push($tarefas, 'Passar Roupa');

// 3. Remove o último item (Passar Roupa)
array_pop($tarefas);

// 4. Exibe o array formatado para debugging
print_r($tarefas);

4. O Template do Carro (Classe e Objeto)

Crie a Class, instancie o new Objeto e use o operador ->.

// 1. A Planta (Classe)
class Carro {
public $cor;
public $velocidade_maxima;
}

// 3. O Carro Pronto (Objeto)
$meu_carro = new Carro();

// 4. Atribui e exibe a propriedade
$meu_carro->cor = 'Vermelho';
echo "A cor do meu carro é: " . $meu_carro->cor;

5. Dados do Banco de Dados (Array Multidimensional)

Simule linhas de banco de dados e use a sintaxe [][] para acessar o dado.

$resultados_db = [
['id' => 1, 'nome' => 'Carlos', 'status' => 'ativo'],
['id' => 2, 'nome' => 'Marina', 'status' => 'inativo']
];

// 2. Exibe o nome do SEGUNDO registro (índice 1, chave 'nome')
echo "Nome do 2º registro: " . $resultados_db[1]['nome'] . "
";

// 3. Bônus: Iterando com FOREACH
foreach ($resultados_db as $registro) {
echo "Usuário: " . $registro['nome'] . " | Status: " . $registro['status'] . "
";
}
