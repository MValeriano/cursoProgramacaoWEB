PHP e HTML: A Geração de Páginas Dinâmicas

Aprenda a incorporar (embed) código PHP diretamente no HTML para construir websites.

I. Explicação: Sintaxe e Saída

1. Delimitadores e Extensão

O arquivo deve ter extensão .php. O código deve estar entre <?php e ?>.

2. Comando de Saída (echo)

A função principal para enviar texto, variáveis ou resultados de cálculos para o navegador é o comando echo.

3. Melhor Prática (Tags Puras)

Em arquivos que são puramente PHP (includes, handlers), omita a tag de fechamento ?> para evitar output indesejado.

Melhor Prática: Fechar e Reabrir Tags

Em vez de usar echo para imprimir grandes blocos de HTML, feche a tag PHP (?>) e reabra-a (<?php) em torno da marcação.

Isso melhora a legibilidade e permite que o editor aplique a sintaxe correta ao HTML puro.

II. 5 Exercícios Estruturais: PHP no HTML

1. Gerando uma Tabela de Dados Dinâmicos

Usando foreach e fechando/reabrindo tags para gerar linhas de uma tabela HTML.

// tabela.php
<?php $cores = ["Vermelho", "Azul", "Verde"]; ?>
<h2>Lista de Cores</h2>
<table class="border-collapse w-full">
<tbody>

<?php foreach ($cores as $cor): ?>

<tr class="border-b">
<td class="p-2">Cor: <?php echo $cor; ?></td>
</tr>

<?php endforeach; ?>

</tbody>
</table>

2. Componente Condicional de Navegação

Exibindo blocos HTML inteiros baseados em uma condição (if/else), mantendo o HTML limpo.

// menu.php
<?php $usuario_ativo = true; ?>
<nav>
<?php if ($usuario_ativo): ?>

<a href="painel.php">Painel de Controle</a>
<button>Sair</button> <!-- HTML PURO AQUI -->

<?php else: ?>

<a href="login.php">Login</a>
<a href="cadastro.php">Cadastro</a> <!-- HTML PURO AQUI -->

<?php endif; ?>
</nav>

3. Handler Puro vs. Arquivo Misto (Regras de Tags)

Omissão da tag de fechamento (?>) em arquivos que só contêm PHP para evitar erros de output/headers.

// processa_dados.inc.php (ARQUIVO PURO PHP)
<?php
function salvar_dados() {
// Lógica para salvar dados sem gerar HTML...
}

// A tag de fechamento (?>) é OMITIDA AQUI.

// formulario.php (ARQUIVO MISTO)
<?php require 'processa_dados.inc.php'; ?> <!-- Tag de fechamento é OBRIGATÓRIA AQUI para o HTML iniciar -->
<html>
...

4. Verificando a Submissão de Formulário (Superglobal)

Usando a superglobal $_POST e isset() para controlar se o formulário deve ser exibido ou processado.

// saudacao.php
<?php
$username = '';
if (isset($_POST['username']) && !empty($_POST['username'])) {
$username = $_POST['username'];
}
?>

<div class="p-4">
<?php if ($username): ?>

<h1 class="text-green-600 text-3xl">Bem-vindo, <?php echo $username; ?>!</h1>

<?php else: ?>

<h2>Entre com seu nome:</h2>
<form method="POST" action="saudacao.php">
<input type="text" name="username" class="border p-2 rounded-md" placeholder="Seu nome">
<button type="submit" class="bg-blue-500 text-white p-2 rounded-md">Enviar</button>
</form>

<?php endif; ?>
</div>

5. Validação com Manutenção de Dados (value)

Mantendo o valor digitado no campo (value) após uma falha de validação (empty()).

// Modificação de saudacao.php (somente a lógica e o formulário)
<?php
$username = ''; $mensagem_erro = ''; $erro = false;

if (isset($_POST['username'])) {
$username = $_POST['username'];
if (empty($username)) {
$erro = true;
$mensagem_erro = "O campo nome não pode estar vazio.";
}
// Se $erro for false, o código de sucesso (Ex. 4) viria aqui.
}
?>

<!-- Exibição de Erro e Formulário -->
<?php if ($erro): ?>
<p class="text-red-500 font-bold"><?php echo $mensagem_erro; ?></p>
<?php endif; ?>

<form method="POST" action="saudacao.php">
<input type="text" name="username" class="border p-2 rounded-md"

value="<?php echo $username; ?>">
<button type="submit" class="bg-blue-500 text-white p-2 rounded-md">Enviar</button>
</form>
