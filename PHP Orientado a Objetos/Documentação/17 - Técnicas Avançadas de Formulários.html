Formulários Robustos com PHP

O desenvolvimento de formulários interativos e robustos é um dos pilares do PHP. Os tópicos a seguir cobrem técnicas avançadas que garantem melhor experiência do usuário e maior segurança na aplicação.

Com base nos materiais fornecidos, apresentamos a explicação didática e 5 exercícios práticos.

1. Explicação Didática e Ilustrativa dos Conceitos

1.1 Auto Processamento de Formulários

Ocorre quando o formulário HTML envia os dados de volta para o próprio arquivo PHP que o contém.

if ($_SERVER['REQUEST_METHOD'] == 'POST') {

// Processamento dos dados...

}

Implementação: action="$_SERVER['PHP_SELF'] ?>"

O REQUEST_METHOD controla o fluxo, executando o código apenas após a submissão.

1.2 Validação de Formulários

Regra de Ouro (Segurança):

A validação deve ser sempre repetida no servidor (PHP). Nunca confie apenas na validação do lado do cliente (HTML/JS).

if (empty($_POST['nome'])) {

// Erro: Nome é obrigatório.

}

Utilize empty() para verificar campos vazios e funções como is_numeric() para verificar tipos.

1.3 Preenchendo Formulários (UX)

Em caso de erro, reexibir o formulário com os dados válidos previamente submetidos preenchidos para melhor experiência do usuário.

Mecanismo: Injeção de Valor

<input type="email" value="$email_enviado; ?>">

A variável $email_enviado captura o valor de $_POST['email'] e o injeta no atributo value.

1.4 Input com Múltiplos Valores

Campos como *checkboxes* que permitem múltiplas seleções são recebidos pelo PHP como um Array.

Estrutura de Recebimento:

<input type="checkbox" name="opcoes[]">

// PHP recebe: $_POST['opcoes'] (é um Array)

Use foreach no PHP para iterar sobre o array de opções selecionadas.

1.5 Upload de Arquivos

O envio de arquivos é tratado pela superglobal $_FILES.

Verificações Essenciais:

  • Tamanho: $_FILES['campo']['size'] (Prevenção de sobrecarga).
  • Tipo/Extensão: $_FILES['campo']['type'] (Segurança e formato).

2. 5 Exercícios para Raciocínio Estrutural

Exercício 1 & 2: Auto Processamento e UX

Temas: Auto Processamento, $_SERVER['REQUEST_METHOD'], empty(), Preenchimento Automático (value).

Enunciado Prático:

  • Crie um formulário (`contato.php`) com campos Nome e Email.
  • Use $_SERVER['PHP_SELF'] na `action` (Auto Processamento).
  • Use $_SERVER['REQUEST_METHOD'] para processar apenas no POST.
  • Valide se o Nome está vazio (empty()).
  • Se houver erro, o valor digitado no campo Email deve ser injetado de volta no atributo value para re-preenchimento (UX).

// Simulação da lógica PHP no topo de 'contato.php'

if ($_SERVER['REQUEST_METHOD'] == 'POST') {

$email_enviado = $_POST['email'] ?? '';

if (empty($_POST['nome'])) {

$erro = "Erro: O nome é obrigatório.";

}

}

// Simulação do HTML do campo Email:

<input type="email" name="email" value="$email_enviado; ?>">

Exercício 5: Validação Composta (Array de Erros)

Temas: Coleta de Erros em Array, count(), foreach.

Enunciado Prático:

  • Crie um array vazio: $erros_validacao.
  • Capture $nome e $idade de $_POST.
  • Use if e empty() para adicionar a string de erro ao array se $nome ou $idade estiverem vazios.
  • Use if (count($erros_validacao) > 0) para controlar o fluxo.
  • Se houver erros, use foreach para exibir todos os erros de uma vez.
  • Se o array estiver vazio, imprima "Formulário validado com sucesso.".

Raciocínio Estrutural: Essa metodologia evita parar no primeiro erro, melhorando a UX e a arquitetura do código.

Exercício 3: Escolha de Múltiplos Interesses

Temas: Input Array, foreach, Checkboxes.

Enunciado Prático:

  • Crie checkboxes para 'Esporte', 'Cultura', 'Tecnologia' com name="interesses[]".
  • Verifique se o array $_POST['interesses'] foi submetido.
  • Use um laço foreach para iterar sobre o array recebido.
  • Imprima uma lista não ordenada (<ul>) com cada interesse selecionado.

if (!empty($_POST['interesses'])) {

foreach ($_POST['interesses'] as $interesse) {

echo "<li>" . $interesse . "</li>";

}

}

Exercício 4: Verificação de Arquivo (Conceitual)

Temas: Upload de Arquivos, $_FILES, Segurança.

Respostas Conceituais:

  • Superglobal: O PHP usa a superglobal $_FILES para coletar informações sobre o arquivo enviado.
  • Verificação de Tamanho: Consultamos a chave ['size'] (Ex: $_FILES['imagem']['size']) para verificar o tamanho do arquivo em bytes.
  • Prevenção de Sobrecarga: A superglobal $_FILES permite verificar o tamanho antes de mover o arquivo do diretório temporário para o destino final (com a função move_uploaded_file()), garantindo que arquivos muito grandes sejam rejeitados antes de sobrecarregar os recursos do servidor.
