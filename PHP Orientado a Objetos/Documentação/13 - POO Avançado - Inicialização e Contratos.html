POO Avançado: Inicialização e Contratos

Dominando o ciclo de vida do objeto (Construtor), a imposição de regras (Abstração) e a garantia de funcionalidades (Interfaces).

I. Pilares de Estrutura e Comportamento

1. Constructor (__construct)

É o método especial executado automaticamente ao instanciar um objeto (`new`). Sua função é inicializar as propriedades com valores válidos, garantindo que o objeto "nasça" com um estado correto.

function __construct($nome) {
$this->Nome = $nome;
}
$p = new Pessoa('Ana');

2. Abstração (Classes e Métodos)

Foca na estrutura importante, ignorando detalhes iniciais. É usada para definir uma base.

  • Classes Abstratas: abstract class. Não podem ser instanciadas. Servem apenas como pai para herança.
  • Métodos Abstratos: abstract function. Não possuem código; obrigam as classes filhas a implementá-los.

3. Interfaces (interface e implements)

Uma Interface define um CONTRATO de métodos que uma classe deve obrigatoriamente fornecer. É como uma promessa de funcionalidade.

// Contrato: APENAS ASSINATURAS DE MÉTODOS
interface IConectavel {
public function conectar();
}

// Implementação: A classe PROMETE cumprir o contrato
class Servidor implements IConectavel {
public function conectar() { // Implementação obrigatória }
}

II. 5 Exercícios para Raciocínio Estrutural

1. Constructor em Herança: Chamando o Ancestral (parent::__construct)

Garantir que a classe-filha inicialize suas próprias propriedades e delegue a inicialização das propriedades herdadas para o construtor da classe-pai.

<?php
class Veiculo {
protected $cor;
protected $fabricante;
public function __construct($cor, $fabricante) {
$this->cor = $cor;
$this->fabricante = $fabricante;
}
public function ObterFabricante() { return $this->fabricante; }
}

class Carro extends Veiculo {
public $numeroPortas;
public function __construct($cor, $fabricante, $portas) {
// Chama o construtor do Pai para inicializar as propriedades herdadas
parent::__construct($cor, $fabricante);
// Inicializa a propriedade própria
$this->numeroPortas = $portas;
}
}

$meu_carro = new Carro('Vermelho', 'Ford', 4);
echo "Fabricante: " . $meu_carro->ObterFabricante();
?>

2. Abstração e Contrato de Implementação (abstract)

Criar uma classe-base não instanciável que obriga as classes filhas a definir o comportamento do método ProcessarPagamento().

<?php
abstract class MetodoPagamento { // Não pode ser instanciada diretamente
// Define a assinatura que TODAS as filhas devem ter
abstract public function ProcessarPagamento($valor);
}

class Pix extends MetodoPagamento {
// OBRIGATORIAMENTE implementa o método abstrato
public function ProcessarPagamento($valor) {
return "Pagamento Pix de R$" . $valor . " processado.";
}
}

$pag_pix = new Pix;
echo $pag_pix->ProcessarPagamento(50);
// Tentar $erro = new MetodoPagamento(); resultaria em Erro Fatal.
?>

3. Contratos Múltiplos (interface e implements)

Usar Interfaces para impor contratos de funcionalidade (IConectavel e ILogavel) que a classe Servidor deve cumprir.

<?php
interface IConectavel {
public function conectar();
public function desconectar();
}
interface ILogavel {
public function registrarLog($mensagem);
}

class Servidor implements IConectavel, ILogavel { // Cumpre 2 contratos
public function conectar() { return "Conectado ao Servidor X."; }
public function desconectar() { return "Desconectado."; }
public function registrarLog($mensagem) { return "LOG: " . $mensagem; }
}

$serv = new Servidor;
echo $serv->conectar() . "<br>";
echo $serv->registrarLog('Início da sessão');
// Se registrarLog() fosse omitido, PHP geraria um Erro Fatal (Contrato quebrado).
?>

4. Verificando Ancestralidade (get_parent_class)

Utilizar uma função utilitária do PHP para identificar o nome da classe-pai de um objeto, confirmando a hierarquia.

<?php
class Usuario {}
class Admin extends Usuario {}
class SuperAdmin extends Admin {}

function VerificarHierarquia($objeto_alvo) {
return get_parent_class($objeto_alvo);
}

$super_admin = new SuperAdmin;

$pai_direto = VerificarHierarquia($super_admin);
echo "Classe Ancestral de SuperAdmin: " . $pai_direto . "<br>"; // Saída: Admin
echo "Classe Ancestral de Admin: " . get_parent_class('Admin'); // Saída: Usuario
?>

5. Abstração + Constructor + Método final (Fluxo de Dados)

Impor a inicialização de dados via construtor (classe abstrata) e proteger o método de exportação final contra sobrescrita (final).

<?php
abstract class FormatoExportacao {
protected $dados;

public function __construct($dados) { // Obriga a inicialização ao nascer
$this->dados = $dados;
}

abstract protected function GerarSaida(); // As filhas implementam a formatação

// Final: Não pode ser sobrescrito para garantir a lógica de exportação
final public function Exportar() {
return "Processando e Enviando: " . $this->GerarSaida();
}
}

class ExportacaoXML extends FormatoExportacao {
protected function GerarSaida() { // Implementação obrigatória
return "<XML>DADOS_TOTAIS</XML>";
}
}

$dados_mock = ['id' => 1, 'valor' => 100];
$xml_exp = new ExportacaoXML($dados_mock);
echo $xml_exp->Exportar();
// Tentar sobrescrever Exportar() geraria um Erro Fatal.
?>
