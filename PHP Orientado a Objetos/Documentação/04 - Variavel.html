O Conceito de Variável em PHP

A Chave para Armazenar Informação na Web

Entenda de forma simples o que é uma variável, como ela funciona e quais são as regras essenciais para começar a programar em PHP.

O que é uma Variável? (Analogia da Caixa)

Pense na variável como uma caixa na sua mudança:

  • 📦

    A Variável é a Caixa (Local de Memória)

    É um local volátil na memória RAM do servidor que armazena dados enquanto a aplicação está rodando. O conteúdo é destruído após o programa finalizar.

  • 🏷️

    O Nome da Variável é a Etiqueta

    Você usa a etiqueta (ex: $nome_cliente) para identificar e acessar o Conteúdo (o dado) que está dentro da caixa.

  • 🍎

    O Conteúdo é o Dado

    É o valor real que você quer guardar (ex: "Maria da Silva", 30 ou TRUE).

Regras Essenciais e Boas Práticas

1. Sinal de Cifrão ($) é Obrigatório

Toda variável PHP DEVE começar com o caractere cifrão, seguido pelo nome.

// Declaração e Inicialização
$nome = "Daniel";

2. Case Sensitive (Sensível a Maiúsculas/Minúsculas)

PHP trata letras maiúsculas e minúsculas como distintas no nome da variável.

$nomeCliente = "João";
$nomecliente = "Maria"; // Variáveis diferentes!

3. Boas Práticas de Nomenclatura

  • Proibido: Iniciar com números, usar espaços ou caracteres especiais (!, @, /).
  • Recomendado: Utilizar snake_case (palavras minúsculas com underscore: $nome_completo) ou camelCase (primeira letra maiúscula nas palavras seguintes: $nomeCliente).

Tipos de Variáveis (O Conteúdo da Caixa)

Os tipos de dados mais básicos (escalares) contêm apenas um valor:

Tipo de Dado O que é Exemplo em PHP
String Cadeia de caracteres alfanuméricos (texto). $frase = "Olá Mundo";
Integer (Int) Números inteiros (sem ponto decimal). $idade = 30;
Float Números de ponto flutuante (com decimais). $preco = 5.99;
Boolean Um valor lógico: Verdadeiro (TRUE) ou Falso (FALSE). $estaAtivo = TRUE;
Array Contém múltiplos valores (não é escalar), como uma lista. $cores = ['Azul', 'Verde'];

5 Exercícios Práticos

Aplique os conceitos de declaração, tipos de dados e sensibilidade a maiúsculas/minúsculas.

1. A Ficha Cadastral (Declaração e Tipos)

Crie quatro variáveis para armazenar: nome completo (string), idade (int), se é bolsista (boolean) e valor da mensalidade (float).

// Sugestão de Resolução:
$nome_aluno = "Júlia Silva";
$idade = 22;
$e_bolsista = TRUE;
$mensalidade = 950.50;

2. O Erro do Estagiário (Case Sensitivity)

Corrija o código que não exibe o usuário logado devido à sensibilidade de maiúsculas/minúsculas.

// Código Corrigido:
$usuario = "admin_master";
$senha = "123456";
echo "Usuário logado: " . $usuario; // Corrigido: '$Usuario' para '$usuario'

3. O Saldo Bancário (Atribuição e Reatribuição)

Simule uma transação subtraindo o valor da compra (25) do saldo inicial (100) e exiba o resultado final (75).

$saldo_inicial = 100;
$compra = 25;
$saldo_final = $saldo_inicial - $compra;
echo $saldo_final;

4. O Endereço Completo (Concatenação de Strings)

Combine as variáveis de rua, número e cidade em uma única variável formatada.

$rua = "Rua das Flores";
$numero = 120;
$cidade = "São Paulo";
$endereco_completo = $rua . ", " . $numero . " - " . $cidade;
echo $endereco_completo;

5. Caixa Vazia (Boas Práticas de Inicialização)

Atribua valores padrão (zero ou string vazia) para evitar erros de variáveis não definidas.

// Inicialização para números (int)
$total_itens = 0;
// Inicialização para texto (string)
$mensagem_aviso = "";
