Conceitos Fundamentais de PHP

Estrutura, Sintaxe e Elementos Chave para o Desenvolvimento Web

O PHP (PHP Hypertext Preprocessor) é a linguagem de *script* que processa dados e gera conteúdo dinâmico. Ele atua como a cozinha de uma aplicação web.

1. Estrutura e Sintaxe Essenciais

Delimitadores de Código

Todo código PHP deve estar contido entre ``. Em arquivos *pure PHP* (só código PHP), o delimitador de fechamento é omitido.

<?php
// Código aqui
?>

Ponto e Vírgula (;)

Cada comando (declaração) no PHP deve terminar com um ponto e vírgula (;). É o "ponto final" da instrução.

$nome = 'Alice';
echo $nome;

Saída (Output) e Comentários

`echo` e `print` exibem dados. Comentários (linhas não executadas) usam `//`, `#` ou `/* ... */`.

echo 'Olá!'; // Saída
/* Comentário
de Múltiplas Linhas */

2. Variáveis e Tipos de Dados (As Caixas Rotuladas)

Variáveis armazenam valores e devem começar com o cifrão ($). O PHP é Case Sensitive para nomes de variáveis.

Tipo de Dado O que Armazena Exemplo
String Texto (cadeia de caracteres). $nome = "Maria";
Numérico Inteiros (`int`) ou com decimal (`float`). $idade = 25; $preco = 9.99;
Booleano Valor lógico: `TRUE` ou `FALSE`. $ativo = TRUE;
Array Lista ou coleção de valores. $cores = ['vermelho', 'azul'];

3. Operadores e Estruturas de Controle

Operadores (As Ferramentas de Ação)

  • Atribuição: `=` (Atribui valor).
  • Aritméticos: `+`, `-`, `*`, `/`, `%` (Módulo).
  • Incremento/Decremento: `++`, `--` (Adiciona/Subtrai 1).
  • Relacionais: `==` (Igual valor), `===` (Igual valor E tipo).
  • Lógicos: `&&` (AND), `||` (OR).

Estruturas de Controle (Tomada de Decisão)

  • IF/ELSE: Executa um bloco se uma condição for `TRUE`.
  • WHILE / FOR: Laços de repetição (iteração).
  • FOREACH: Laço específico para percorrer arrays.
  • SWITCH: Testa uma variável contra múltiplos casos (`CASE`).

5 Desafios de Fundamentos PHP

Combine variáveis, operadores e estruturas de controle para resolver tarefas comuns.

1. A Fatura do Cliente (Variáveis e Output)

Calcule o subtotal e exiba a fatura completa em uma única linha.

$produto = 'Café';
$preco_unitario = 5.50;
$quantidade = 4;

$subtotal = $preco_unitario * $quantidade;

echo "Fatura: " . $quantidade . " unidades de " . $produto . ". Total: R$ " . $subtotal;

2. O Verificador de Status (Lógicos e IF/ELSE)

Use o operador lógico `&&` para garantir que ambas as condições sejam satisfeitas.

$idade = 17;
$is_ativo = TRUE;

if ($idade >= 18 && $is_ativo) {
echo "Acesso Concedido.";
} else {
echo "Acesso Negado: Condições não atendidas.";
}

3. O Menu Interativo (SWITCH e BREAK)

Simule um menu interativo usando a estrutura SWITCH.

$opcao_menu = 2;

switch ($opcao_menu) {
case 1:
echo "Navegando para Home";
break;
case 2:
echo "Navegando para Perfil";
break;
case 3:
echo "Navegando para Configurações";
break;
default:
echo "Opção Inválida";
}

4. O Log de Eventos (Laço FOR e Contador)

Use o FOR para iterar um número conhecido de vezes (8 eventos).

for ($i = 1; $i <= 8; $i++) {
echo "Evento [" . $i . "] registrado.
";
}

foreach ($funcionarios as $nome_atual) {
echo "Funcionário: " . $nome_atual . "
";
