Tratando Formulários com PHP

O Básico: Variáveis Automáticas

Uma das maiores forças do PHP é como ele trata formulários HTML. O conceito essencial é que qualquer elemento de formulário é automaticamente disponibilizado para seus scripts PHP através de variáveis superglobais.

Exemplo #1: O Formulário HTML

Este é um formulário HTML padrão, sem nenhuma tag especial do PHP.

Código HTML do Formulário:

<form action="action.php" method="post">
    <label for="nome">Seu nome:</label>
    <input name="nome" id="nome" type="text">

    <label for="idade">Sua idade:</label>
    <input name="idade" id="idade" type="number">

    <button type="submit">Enviar</button>
</form>

Exemplo #2: Imprimindo Dados (action.php)

Código PHP:

Olá, <?php echo htmlspecialchars($_POST['nome']); ?>.
Você tem <?php echo (int) $_POST['idade']; ?> anos de idade.

A superglobal `$_POST` contém todos os dados enviados pelo formulário com o método POST. Para acessar um campo, usamos o seu atributo `name` como chave.

Saída (Exemplo):

Olá, Maria. Você tem 22 anos de idade.

Sanitização e Superglobais

1. Segurança (Sanitização)

  • `htmlspecialchars()`: Essencial! Converte caracteres especiais do HTML (como `<` e `>`) em entidades codificadas, prevenindo a injeção de tags HTML ou JavaScript maliciosos (XSS - Cross-Site Scripting).
  • Type Casting: O uso de `(int)` converte o dado para um inteiro, removendo automaticamente qualquer caractere estranho que não seja um número.

2. As Superglobais do Formulário

  • `$_POST`: Contém dados enviados usando o método `POST` (mais seguro para dados sensíveis).
  • `$_GET`: Contém dados enviados usando o método `GET` (dados ficam visíveis na URL).
  • `$_REQUEST`: Contém os dados mesclados das origens GET, POST e COOKIE. Geralmente é recomendado usar `$_POST` ou `$_GET` diretamente para saber a origem do dado.
