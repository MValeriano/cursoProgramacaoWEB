Palavras Reservadas do PHP (Keywords)

Se a sintaxe é a gramática, as Palavras Reservadas são o vocabulário obrigatório. Você não pode usá-las para nomear seus próprios elementos.

1. O Dicionário Interno do PHP

Analogia: Comandos de Voz Específicos

O PHP já tem comandos definidos como `if`, `while`, ou `return`. Se você tentar nomear uma variável de `$if`, o interpretador pode confundir sua intenção, gerando erros ou comportamento inesperado.

Regra: Não use Palavras Reservadas para nomear Variáveis, Funções, Classes ou Constantes.

Exemplos Comuns de Keywords

  • Estruturas de Decisão: if, else, switch, break.
  • Laços de Repetição: while, for, foreach, continue.
  • Definição de Estruturas: function, class, return.
  • Orientação a Objetos: new, public, private.

2. 5 Desafios de Nomenclatura e Keywords

Identifique e corrija o uso incorreto de Palavras Reservadas como identificadores.

1. Conflito de Nomes de Variáveis

As palavras `if`, `while` e `class` são reservadas. Corrigimos renomeando-as para nomes descritivos.

<?php
// CÓDIGO ORIGINAL (Erro de sintaxe): $if = TRUE; $while = 10; $class = "Produto";

$estado_decisao = TRUE;
$contador_loop = 10;
$nome_estrutura = "Produto";

echo $estado_decisao;
?>

2. Conflito de Nomes de Funções

A palavra `return` é usada para devolver um valor de uma função, e não pode ser usada como nome dela.

<?php
// CÓDIGO ORIGINAL (Erro): function return($dado) { ... }

function retornar_dado($dado) {
echo "Função executada. O nome é seguro.";
return $dado;
}

retornar_dado('Sucesso');
?>

3. Conflito de Nomes de Classes

A palavra `class` é uma palavra reservada que o PHP usa para definir uma classe, logo, ela não pode ser usada como o nome da classe.

<?php
// CÓDIGO ORIGINAL (Erro de Sintaxe): class Class { ... }

class EstruturaPadrao {
// Definição da classe aqui
public function saudar() {
echo "Estrutura padrão pronta.";
}
}

$obj = new EstruturaPadrao();
$obj->saudar();
?>

4. Constantes e Keywords de SGBD

Evitar o nome `SELECT` é uma boa prática porque ele é um comando crucial de SQL, o que causa confusão no contexto de banco de dados.

<?php
// define('SELECT', 'comando'); // MÁ PRÁTICA! Não use comandos SQL como nomes.

define('MAXIMO_USUARIOS', 50); // Alternativa segura e descritiva

echo "Limite de usuários: " . MAXIMO_USUARIOS;
?>

5. O Controle de Fluxo como Argumento

Embora o PHP aceite `$if` (devido ao `$`), essa nomenclatura é péssima prática e confunde o leitor, pois colide com a palavra reservada `if`.

<?php
// Nome do parâmetro descritivo é sempre melhor do que usar Palavras Reservadas:
function checar_dados($dados_entrada) {
if ($dados_entrada == 0) {
return FALSE;
}
return TRUE;
}

echo "Resultado: " . (checar_dados(5) ? 'OK' : 'Erro');
?>
