Interagindo com Formulários em PHP

GET, POST e as Superglobais para a coleta de dados do usuário.

I. Explicação Didática: Formulários, GET e POST

Método GET

Os dados são anexados à URL ($\text{chave}=\text{valor}$) e acessados via `$_GET`. Ideal para buscas e conteúdos compartilháveis.

Regra de Ouro: Use para Obter/Exibir dados.

Método POST

Os dados são enviados no corpo da requisição e acessados via `$_POST`. Mais seguro para dados sensíveis.

Regra de Ouro: Use para Enviar/Submeter dados (Login, Cadastro).

Boas Práticas de Formulário

  • Validação da Submissão: Use `$_SERVER['REQUEST_METHOD']` para garantir que o script só processe dados se o método correto (POST/GET) foi usado.
  • Saneamento: Use `htmlspecialchars()` em todos os dados de saída (`echo`) para prevenir XSS.
  • Action = Própria Página: Use `action=""` para enviar o formulário de volta ao próprio script para processamento (Padrão Calculadora).
