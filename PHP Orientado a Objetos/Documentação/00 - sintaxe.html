Sintaxe do PHP: A Gramática da Cozinha

A sintaxe é o conjunto de regras que o servidor deve seguir. Se a pontuação e a formatação estiverem erradas, o código não executa.

1. Pilares da Sintaxe PHP

Delimitadores (Chave de Ignição)

O servidor só executa o que está entre `` (Fechamento). Omitir o fechamento em arquivos puros PHP é a melhor prática.

<?php
// Código aqui...
?>

Ponto e Vírgula (Ponto Final)

Todo comando ou instrução (statement) no PHP deve ser encerrado com `;`. Ele indica o fim do comando.

$idade = 30;
echo $idade;

Variáveis (Símbolo $)

Toda variável deve começar com o cifrão (`$`). O PHP é case sensitive (sensível a maiúsculas/minúsculas) para variáveis.

$nome = 'João';
// $Nome é outra variável!

2. Comandos de Saída e Comentários

Comandos de Saída (Output)

Usados para enviar o conteúdo processado de volta ao navegador.

  • `echo`: Comando mais comum e ligeiramente mais rápido.
  • `print`: É uma função, também usada para imprimir.

Comentários (Notas Internas)

Linhas que o PHP ignora durante a execução, usadas para documentação interna.

  • Linha Única: `//` ou `#`
  • Múltiplas Linhas: `/* ... */`

3. 5 Desafios de Sintaxe PHP

Pratique o uso correto de delimitadores, variáveis, concatenação e a regra de arquivos puros.

1. Delimitadores e Ponto Final (saudacao.php)

Mistura de HTML e PHP. Note o uso obrigatório do `;` e a abertura/fechamento do bloco.

<?php
$mensagem = "Bem-vindo!";
?>
<h1>Site em PHP</h1>

<?php
echo $mensagem;
?>

2. Variáveis e Case Sensitivity

A variável `$Produto` (com P maiúsculo) na linha do `echo` está errada, pois não foi declarada. Abaixo, provamos que `$TOTAL` e `$total` são diferentes.

<?php
$produto = "Teclado";
$Preco = 150.00; // Variável $Preco

// ERRO NO CÓDIGO ORIGINAL: A variável abaixo não existe!
// echo "Produto: " . $Produto;
echo "Produto: " . $produto . "
"; // Correção

$TOTAL = 100; // Em maiúsculas
$total = 50; // Em minúsculas
echo "TOTAL (1): R$ " . $TOTAL . "
";
echo "total (2): R$ " . $total;
?>

3. Comentários e Depuração

Uso de comentários de linha única (`//`) e múltiplas linhas (`/* */`) para documentação.

<?php
$valor = 250; // Valor base do produto ou serviço

/*
Cálculo do imposto: Aplicamos 10% sobre o valor base.
Isso nos dará o valor do imposto a ser pago.
*/
$imposto = $valor * 0.10;

echo "Imposto a pagar: R$ " . $imposto;
?>

4. Concatenação e Caracteres Especiais (\n)

O caractere de nova linha `\n` funciona dentro de strings de aspas duplas (`"`) e é combinado com o ponto (`.`).

<?php
$cidade = "Porto Alegre";
$cep = "90000-000";

echo "Remessa para:\n" .
$cidade . "\n" .
"CEP: " . $cep;
?>

5. O Arquivo Puro (config.php)

Em um arquivo que só tem código PHP, o delimitador de fechamento `?>` é omitido para prevenir erros.

<?php
// config.php - Arquivo Pure PHP. Omitimos o ?> no final.

$DEBUG_MODE = TRUE;
$versao_app = '1.0';
// Fim do arquivo.
// NÃO FECHA COM ?>
