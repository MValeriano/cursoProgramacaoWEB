Escopo (Scope) no PHP

Define a visibilidade e o tempo de vida de variáveis e outras estruturas no código.

Analogia: O Alcance do Rádio Comunicador

I. Tipos Principais de Escopo

1. Global

Declarado fora de funções. Acessível em qualquer lugar, mas não diretamente dentro de funções sem global ou $GLOBALS.

2. Local

Declarado dentro de uma função. Acessível somente dentro daquela função. Destruído ao final da execução da função.

3. Parâmetros

Argumentos passados para uma função. Comportam-se como variáveis locais, mas são a forma preferida de passar dados para o escopo local.

4. Estático (Static)

Declarado dentro de uma função com static. Mantém o valor entre diferentes chamadas da função (não é resetado).

Superglobals & Constantes: Variáveis Superglobais (como $_GET) e Constantes (criadas com define()) são acessíveis de qualquer escopo sem a necessidade de usar global.

II. 5 Exercícios Práticos: Quebrando e Corrigindo o Escopo

1. O Muro do Escopo (Global em Função)

Variáveis globais não entram em funções automaticamente. É preciso usar a palavra-chave global.

// php_ex1_global.php
<?php
$fruta_favorita = "Maçã"; // Escopo Global

function dizer_fruta() {
// Tentar usar $fruta_favorita aqui daria 'Undefined variable'
global $fruta_favorita; // Importa a variável global
echo "Minha fruta favorita é: " . $fruta_favorita . " (Acessada via global).";
}

dizer_fruta();
?>

2. O Robô que Acumula (Escopo Estático)

Variáveis static mantêm seu valor entre as chamadas da função, agindo como um contador persistente.

// php_ex2_static.php
<?php
function contar_pedidos() {
static $total = 0; // Escopo Estático: Valor persiste
$total++;
echo "Pedido número: " . $total . "
";
}

contar_pedidos(); // Resultado: 1
contar_pedidos(); // Resultado: 2
contar_pedidos(); // Resultado: 3
?>

3. Acesso Global via Superglobal $GLOBALS

A superglobal $GLOBALS é um array associativo que contém todas as variáveis globais e é acessível de qualquer escopo.

// php_ex3_globals.php
<?php
$database_host = "localhost"; // Variável Global

function conectar_db() {
$host = $GLOBALS['database_host']; // Acessa a variável global via array $GLOBALS
echo "Conectando ao HOST: " . $host . " (Método GLOBALS).";
}

conectar_db();
?>

4. Parâmetro como Prioridade (Escopo Local > Global)

Se um parâmetro (variável local) tem o mesmo nome de uma variável global, o PHP usa o valor local.

// php_ex4_param.php
<?php
$item = "Cadeira"; // Global: "Cadeira"

function exibir_item($item) { // Parâmetro: cria um novo $item no escopo local
echo "O item exibido é: " . $item;
}

exibir_item("Mesa"); // Resultado: "Mesa", provando a precedência do escopo local.
?>

5. Escopo e Constantes (Sempre Globais)

Constantes definidas com define() são inerentemente globais e acessíveis em qualquer função sem esforço extra.

// php_ex5_const.php
<?php
define("LIMITE_CARACTERES", 140); // Constante global

function checar_limite() {
// A constante é acessada diretamente, sem 'global' ou '$GLOBALS'
echo "Limite permitido: " . LIMITE_CARACTERES;
}

checar_limite();
?>
