Strings em PHP: Funções e Sintaxe

Aprenda a normalizar, dividir, concatenar e transformar dados de texto usando funções nativas.

I. Métodos e Sintaxe de Strings

1. Aspas e Interpolação

Aspas Duplas (" "): Permitem a Interpolação de variáveis (`"Olá $nome"`). São avaliadas pelo PHP.

Aspas Simples (' '): Não permitem a interpolação; tratam o conteúdo literalmente (`'Olá $nome'`). Mais rápidas.

2. Formato e Comprimento

  • `strlen()`: Retorna o comprimento da string (inclui espaços).
  • `strtoupper()`: Converte para MAIÚSCULO.
  • `strtolower()`: Converte para minúsculo (Normalização).
  • `substr()`: Extrai uma parte da string (resumo/trecho).

3. Busca, Troca e Array

  • `str_replace()`: Substitui todas as ocorrências de um texto por outro.
  • `strpos()`: Encontra a posição (índice) de uma substring.
  • `explode()`: Converte string para Array usando um delimitador.
  • `implode()`: Converte Array de volta para string com um separador.

Concatenação (.)

O ponto é o operador usado para juntar duas ou mais strings de forma explícita. É obrigatório ao usar aspas simples ou ao juntar strings e variáveis.

$msg = 'Total é ' . $valor . ' reais.';

II. 5 Exercícios Práticos com Strings

1. Normalização e Validação de Login (strtolower() e strlen())

Garantir que o username esteja em minúsculo (normalização) e verificar se ele atende ao requisito de comprimento mínimo.

<?php
$username_bruto = "UsuarioAdmin";

// 1. Normalização (garante que maiúsculas/minúsculas não importam)
$username_limpo = strtolower($username_bruto);

// 2. Contagem e Validação
$comprimento = strlen($username_limpo);

if ($comprimento < 6) {
echo "Erro: O nome de usuário deve ter pelo menos 6 caracteres.";
} else {
echo "Usuário validado (" . $comprimento . " caracteres): " . $username_limpo;
}
?>

2. Geração de Resumo (Snippet) (substr() e Concatenação)

Extrair os primeiros 50 caracteres de um texto longo e adicionar uma elipse indicando continuação.

<?php
$artigo = "A Programação Orientada a Objetos em PHP oferece recursos poderosos para a criação de sistemas modulares e reutilizáveis, baseando-se em princípios como herança e encapsulamento.";

// Extrai 50 caracteres a partir do índice 0
$resumo = substr($artigo, 0, 50);

// Concatena o resumo com a indicação de continuação
$resumo_final = $resumo . "... [Continuar Lendo]";

echo "Resumo: " . $resumo_final;
?>

3. Filtragem de Conteúdo (str_replace())

Detectar uma palavra proibida e substituí-la por um filtro (Embora strpos() seja para detecção, o str_replace() faz a ação de filtragem diretamente).

<?php
$comentario = "Este serviço é chato e lento.";

// Define o que buscar, o que substituir e onde buscar
$comentario_filtrado = str_replace('chato', '*', $comentario);

echo "Comentário Original: " . $comentario . "<br>";
echo "Comentário Filtrado: " . $comentario_filtrado;
?>

4. String para Array e Array para String (explode() e implode())

Dividir uma lista em um vetor (Array) e depois reagrupar com um novo separador.

<?php
$lista_tags = "php, poo, string, array";

// 1. String -> Array (Delimitador: ", ")
$array_tags = explode(', ', $lista_tags);
echo "Conteúdo do Array: "; print_r($array_tags); echo "<br>";

// 2. Array -> String (Novo Separador: "|")
$tags_formatadas = implode(' | ', $array_tags);

echo "Tags Formatadas: " . $tags_formatadas;
?>

5. Sintaxe: Aspas Duplas vs. Concatenção (.)

Demonstrar as duas formas válidas de construir uma frase, e o perigo de usar aspas simples com variáveis.

<?php
$saudacao = "Olá";
$nome = "Visitante";

// A) Interpolação (Aspas Duplas)
$frase_a = "$saudacao, $nome!"; // PHP traduz as variáveis
echo "Frase A (Interpolação): " . $frase_a . "<br>";

// B) Concatenacao (Aspas Simples + Ponto)
$frase_b = $saudacao . ', ' . $nome . '!'; // Concatenação Explícita
echo "Frase B (Concatenação): " . $frase_b . "<br>";

// C) Aspas Simples com Variável (NÃO TRADUZ)
$frase_c = 'A $saudacao diz...';
echo "Frase C (Erro de Sintaxe): " . $frase_c; // Saída: A $saudacao diz...
?>
