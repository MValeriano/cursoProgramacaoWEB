Tipos de Dados no PHP

Se a variável é a caixa, o Tipo de Dado é a natureza exata do conteúdo: texto, número, ou uma lista.

Analogia: O Estoque da Fábrica

I. Tipos Escalares (Valor Único)

Tipo de Dado O que Armazena Características e Fontes
String Cadeia de caracteres alfanuméricos (Texto). Declarada com aspas simples (`'`) ou duplas (`"`).
Integer/Float Números. (Int: Sem ponto decimal; Float: Com ponto decimal). Int: Contagens, códigos. Float: Dinheiro, medições.
Boolean Valor lógico: TRUE (verdadeiro) ou FALSE (falso). Muitos valores (como 0, "0", "", NULL) são avaliados como FALSE.
NULL Significa que a variável não tem valor. O único valor do tipo NULL. Avaliado como falso em booleanos.

II. Tipos Compostos e Estruturas

Array

Uma variável que armazena múltiplos valores de diferentes tipos (coleção).

<?php
$produtos = ['Pão', 2.50, TRUE];
?>

Objeto, Recurso, Misto

  • Objeto: Entidade criada a partir de uma classe (estrutura complexa com propriedades e métodos).
  • Recurso: Referência a algo externo (ex: conexão de banco de dados, arquivo aberto).
  • Misto (Mixed): Indica que um parâmetro ou retorno de função aceita diversos tipos (string, int, array...).

Diferença Fundamental (Tipagem Fraca): Em PHP, o valor `10` (Integer) é diferente de `"10"` (String). O PHP tenta converter automaticamente, mas isso muda como ele trata a informação.

III. 5 Exercícios Estruturados sobre Tipos

1. Formulário de Cadastro (String vs. Integer)

O CEP completo e o Nome devem ser strings, pois contêm caracteres especiais ou alfanuméricos.

// php_cadastro.php
<?php
$nome_usuario = "Rui Barbosa"; // String: Contém texto e espaço
$cod_interno = 4005; // Integer: Número inteiro puro
$digito_cep = 9; // Integer
$cep_completo = "90000-000"; // String: Contém o caractere hífen '-'

echo "Nome: " . $nome_usuario . " | ID: " . $cod_interno;
?>

2. Cálculo Financeiro (Float vs. Integer)

O preço usa Float (ponto decimal). A quantidade é Integer. O resultado da multiplicação é automaticamente um Float.

// php_calculo.php
<?php
$valor_produto = 199.99; // Float (ponto flutuante)
$quantidade_em_estoque = 45; // Integer (inteiro)

$total_venda = $valor_produto * $quantidade_em_estoque;

echo "Total da venda (Float): R$ " . $total_venda; // Resultado: 8999.55
?>

3. Luz de Status (Boolean e Valores Falsos)

NULL é avaliado como FALSE em um contexto booleano simples (como um `if`).

// php_boolean.php
<?php
$tem_permissao = TRUE; // Boolean TRUE
$dados_carregados = NULL; // Tipo NULL

if (!$dados_carregados) { // NULL é avaliado como FALSE (falsy)
echo "Os dados não foram carregados. (NULL é FALSO)";
}
?>

4. Teste Rigoroso (Igualdade `==` vs. Identidade `===`)

`==` compara valor (com conversão de tipo). `===` compara valor E tipo.

// php_identidade.php
<?php
$a = 10; // Integer
$b = "10"; // String

echo "Resultado '==' (Igualdade): " . ($a == $b ? 'TRUE' : 'FALSE') . "
"; // TRUE (valor é igual)
echo "Resultado '===' (Identidade): " . ($a === $b ? 'TRUE' : 'FALSE'); // FALSE (tipo é diferente)
?>

5. Container de Múltiplos Tipos (Array)

Um array armazena uma coleção, diferente dos escalares que armazenam apenas um único item.

// php_array.php
<?php
$perfil_misto = [
123, // Integer (ID)
"Ana Silva", // String (Nome)
TRUE // Boolean (Ativo)
];

echo "Demonstração do tipo Array:
";
var_dump($perfil_misto); // var_dump exibe o tipo e valor de cada elemento
?>
