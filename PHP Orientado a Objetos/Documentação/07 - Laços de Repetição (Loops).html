Laços de Repetição (Loops) em PHP

O Modo Automático para Executar Tarefas Múltiplas

Loops são a linha de produção do seu código, executando um bloco de comandos repetidamente enquanto uma condição for verdadeira. Eles evitam a repetição de código.

1. Repetição Baseada em Condição e Contagem

WHILE (ENQUANTO)

Repete ENQUANTO a condição for verdadeira. Ideal para quando o número de iterações não é conhecido.

  • Checa a condição antes da primeira execução.
  • Analogia: Dirigir ENQUANTO a gasolina não acaba.
$i = 0;
while ($i < 5) {
echo $i;
$i++; // Evita loop infinito!
}

FOR (PARA)

Repetição com contador definido. Ideal para quando o número de iterações é conhecido.

  • Combina Início, Condição e Incremento em uma linha.
  • Analogia: Subir uma escadaria contada, do degrau 1 ATÉ o 10.
for ($i = 1; $i <= 10; $i++) {
echo $i;
}

DO WHILE (FAÇA ENQUANTO)

Executa o código pelo menos uma vez antes de checar a condição.

  • A condição é checada no final do bloco.
  • Analogia: Tentativa Obrigatória: FAÇA a conexão, ENQUANTO falhar.
do {
echo "Tentando...";
$sucesso = FALSE;
} while (!$sucesso);

2. FOREACH (PARA CADA)

FOREACH (Para Cada Elemento)

Laço especializado em arrays e objetos. Não requer contadores e é o mais usado para processar dados de banco de dados.

Sintaxe 1: Somente Valor

Usado em arrays simples (indexados).

foreach ($produtos as $item) {
echo $item; // Exibe: Teclado, Mouse...
}

Sintaxe 2: Chave (Rótulo) e Valor

Usado em arrays associativos (com rótulos).

foreach ($usuario as $chave => $valor) {
echo $chave . ": " . $valor;
}

Analogia: O Carteiro: Para CADA caixa postal (item do array), entregue a carta (valor).

5 Desafios com Laços de Repetição

Aplique o loop correto para contagem, condições e iteração de arrays.

1. O Lançamento de Foguetes (FOR)

Crie a contagem regressiva de 10 a 0. Lembre-se de usar o decremento (--) e a condição correta.

for ($i = 10; $i >= 0; $i--) {
echo "Contagem regressiva: " . $i . "
";
}

2. A Verificação de Estoque (WHILE)

Processe caixas (subtraia 3) ENQUANTO o estoque for maior ou igual a 10. Atenção ao Loop Infinito!

$caixas_no_estoque = 60;
while ($caixas_no_estoque >= 10) {
$caixas_no_estoque -= 3; // Processa 3 caixas (Atualiza a variável de condição)
echo "Caixas restantes: " . $caixas_no_estoque . "
";
}

3. O Leitor de Arquivo (DO WHILE)

Simule uma tentativa de leitura que garante a execução pelo menos uma vez e para na 3ª tentativa.

$tentativas = 0;
$arquivo_lido = FALSE;
do {
$tentativas++;
echo "Tentativa de leitura: " . $tentativas . "
";
if ($tentativas == 3) {
$arquivo_lido = TRUE;
}
} while (!$arquivo_lido); // Repete enquanto NÃO TRUE

5. Exibindo Chaves e Valores (FOREACH Associativo)

Use a sintaxe as $chave => $valor para extrair rótulos de um array de usuário.

$dados_usuario = [
'Nome' => 'João da Silva',
'Email' => 'joao@exemplo.com',
'Telefone' => '(11) 98765-4321'
];

foreach ($dados_usuario as $campo => $dado) {
echo $campo . : " . $dado . "
";
}
