Sua Primeira Página PHP

1. O Script Básico: hello.php

Para começar, crie um novo arquivo chamado hello.php e coloque-o no diretório raiz do seu servidor web (DOCUMENT_ROOT).

Exemplo #1 Nosso primeiro script PHP:

<?php

echo "Olá, Mundo!";

?>

Ao acessar a URL correta (ex: http://localhost/hello.php), o servidor interpreta o código PHP e exibe a mensagem no navegador.

2. PHP Embutido no HTML

O PHP pode ser incorporado em uma página HTML normal. O código PHP é delimitado pelas instruções de processamento de início (`) e fim (`?>`).

Exemplo de Incorporação:

<!DOCTYPE html>
<html>
    <head>
        <title>Teste PHP</title>
    </head>
    <body>
        <?php echo '<p>Olá, Mundo!</p>'; ?>
    </body>
</html>

Importante: O servidor web sabe que precisa interpretar este arquivo por causa da extensão ".php". Se você tentar acessar o arquivo diretamente pelo sistema de arquivos (e não via HTTP), o PHP não será executado.

Resultado da Saída (HTML Gerado):

<!DOCTYPE html>
<html>
    <head>
        <title>Teste PHP</title>
    </head>
    <body>
        <p>Olá, Mundo!</p>
    </body>
</html>

3. Como Obter Informações sobre o PHP (phpinfo())

O script mais famoso do PHP é uma simples chamada à função `phpinfo()`. Ele exibe uma página com todas as informações úteis sobre seu sistema e configurações (variáveis predefinidas, módulos carregados, opções de configuração, etc.).

Exemplo #2 Informações do PHP:

<?php phpinfo(); ?>

Problemas? Se o PHP não estiver habilitado ou configurado corretamente, você pode ver o código fonte em texto ou uma caixa de diálogo para salvar o arquivo. Se isso acontecer, você precisará verificar a configuração do seu servidor web (Apache, Nginx, etc.).
