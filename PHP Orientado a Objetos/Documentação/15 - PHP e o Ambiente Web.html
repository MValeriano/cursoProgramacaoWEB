PHP e o Ambiente Web

Controlando o fluxo da aplicação com Superglobais e Métodos HTTP.

I. Interação Servidor-Cliente

Superglobais

Variáveis predefinidas (arrays) que armazenam dados do ambiente, do cliente ou da sessão.

  • `$_SERVER`: Informações do servidor e requisição.
  • `$_GET`: Dados visíveis na URL.
  • `$_POST`: Dados invisíveis no corpo da requisição.

Método GET

Dados submetidos via URL (query string). Ideal para consultas ou links que podem ser compartilhados.

// Acessa dados via URL: ?busca=termo
echo $_GET['busca'];

Método POST

Dados enviados no corpo da requisição. Ideal para submissão de formulários, login ou dados sensíveis.

// Acessa dados via corpo da requisição
echo $_POST['usuario'];

Chaves Essenciais de $_SERVER

  • `REQUEST_METHOD`: "GET" ou "POST". Controla o fluxo da aplicação.
  • `PHP_SELF`: Caminho do arquivo atual. Usado em `action` de formulários.
  • `DOCUMENT_ROOT`: Caminho físico raiz do servidor (disco rígido).

II. 5 Exercícios Estruturais

Resultado dos Exercícios:

<?php
// --------------------------------------------------------------------------------------------------
// EXERCÍCIO 1: Diagnóstico de Ambiente e Caminho Absoluto
// --------------------------------------------------------------------------------------------------
echo "<h3 class='text-lg font-bold text-yellow-500'>1. Diagnóstico do Ambiente:</h3>";
echo "<ul class='list-disc list-inside text-sm'>";
echo "<li>ROOT Físico (DOCUMENT_ROOT): " . $_SERVER['DOCUMENT_ROOT'] . "</li>";
echo "<li>Nome do Servidor (SERVER_NAME): " . $_SERVER['SERVER_NAME'] . "</li>";
echo "<li>Caminho do Arquivo Atual (PHP_SELF): " . $_SERVER['PHP_SELF'] . "</li>";
echo "</ul><br>";
// Explicação: DOCUMENT_ROOT é o caminho completo no disco. PHP_SELF é o caminho acessível pela Web.

// --------------------------------------------------------------------------------------------------
// EXERCÍCIO 3 & 5: Validação de Submissão Segura / Controle de Fluxo (POST)
// Usamos REQUEST_METHOD para decidir se processamos (POST) ou apenas exibimos o formulário (GET)
// --------------------------------------------------------------------------------------------------
echo "<h3 class='text-lg font-bold text-red-500'>3. & 5. Validação de Submissão e Fluxo (POST):</h3>";
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
echo "<p class='text-green-500'>* SUCESSO! MÉTODDO POST DETECTADO.</p>";
// Simulação da captura de dados (Exercício 5)
$usuario = $_POST['username'] ?? '[Não Enviado]';
echo "<p class='text-sm'>Processamento de dados iniciado para o usuário: <b>" . $usuario . "</b></p>";
} else {
echo "<p class='text-blue-500'>* REQUISIÇÃO GET DETECTADA. Acesso negado ao processamento, exibindo o formulário.</p>";
}
echo "<br>";
// --------------------------------------------------------------------------------------------------
// EXERCÍCIO 4: Logs de Acesso e Método
// --------------------------------------------------------------------------------------------------
echo "<h3 class='text-lg font-bold text-gray-700'>4. Log de Acesso:</h3>";
echo "<p class='text-sm'>LOG: " . $_SERVER['REQUEST_METHOD'] . " - Acesso em " . $_SERVER['SERVER_NAME'] . "</p><br>";

// --------------------------------------------------------------------------------------------------
// EXERCÍCIO 2: Criando um Formulário que se Processa (GET)
// --------------------------------------------------------------------------------------------------
echo "<h3 class='text-lg font-bold text-green-500'>2. Formulário de Busca (GET):</h3>";

// Captura o termo de busca se ele existir na URL
if (isset($_GET['termo_pesquisa']) && $_GET['termo_pesquisa'] !== '') {
$termo = $_GET['termo_pesquisa'];
echo "<p class='text-green-700 font-bold'>Você buscou por: " . $termo . ". (Verifique a URL)</p>";
} else {
echo "<p class='text-gray-500'>Nenhum termo de busca enviado.</p>";
}
?>
Formulário GET (Ex. 2)

Os dados aparecem na URL (query string).

Formulário POST (Ex. 3, 4 e 5)

Os dados são invisíveis na URL.
