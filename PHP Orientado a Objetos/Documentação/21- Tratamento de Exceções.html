Tratamento de Exceções: TRY...CATCH

Permite gerenciar e reagir a erros de forma controlada, evitando que falhas inesperadas encerrem o programa.

Analogia: O Paraquedas e o Plano de Voo (Plano de Resgate)

I. Componentes e Fluxo

TRY (A Tentativa)

Contém o código de risco (ex: conexão a banco de dados). O PHP tenta executá-lo.

THROW (Lançamento)

Sinal de alerta. É a instrução que gera e lança o objeto Exceção (erro) ao detectar uma falha.

CATCH (A Captura)

O plano de resgate. Se o TRY falhar, o CATCH captura a exceção lançada e executa o código de tratamento de erro.

Exceção ($e)

Um objeto especial (da classe `Exception`) que carrega detalhes do erro: mensagem (`getMessage()`), linha (`getLine()`), etc.

Vantagem: O `TRY...CATCH` isola o erro. Se o bloco `TRY` falhar, o código principal continua a execução após o bloco `CATCH`, a menos que você use `die()` ou `exit()`.

II. 5 Exercícios Estruturados de TRY...CATCH

1. A Conexão Crítica (TRY...CATCH Básico)

Protegendo um bloco de código que simula a falha na conexão com um recurso.

// php_ex1_basico.php
<?php
$recurso_online = FALSE;

try { // Tente executar o código de risco
if (!$recurso_online) {
throw new Exception("Recurso não encontrado ou offline.");
}
echo "Conexão estabelecida com sucesso.";

} catch (Exception $e) { // Captura qualquer erro do tipo Exception
echo "ERRO DE CONEXÃO: " . $e->getMessage();
}
?>

2. Divisão por Zero (Isolamento de Risco)

Evitando um erro fatal que encerraria o programa, isolando a checagem.

// php_ex2_divisao.php
<?php
$dividendo = 10;
$divisor = 0; // Causa de falha

try {
if ($divisor === 0) {
throw new Exception("Divisão por zero não permitida.");
}
$resultado = $dividendo / $divisor;
echo "Resultado: " . $resultado;

} catch (Exception $e) {
echo "ERRO ARITMÉTICO: " . $e->getMessage();
}
?>

3. Detalhes do Erro (getMessage, getFile, getLine)

O objeto da exceção (`$e`) fornece metadados cruciais para a depuração.

// php_ex3_detalhes.php
<?php
try {
throw new Exception("Falha crítica no processamento."); // Linha 4

} catch (Exception $erro) {
echo "=== LOG DE ERRO ===
";
echo "Mensagem: " . $erro->getMessage() . "
";
echo "Arquivo: " . $erro->getFile() . "
";
echo "Linha: " . $erro->getLine() . "
";
}
?>

4. Múltiplos CATCHES (Tratamentos Específicos)

Usando CATCHES encadeados para criar planos de resgate diferentes para cada tipo de erro.

// php_ex4_multi.php
<?php
// Criando uma classe de exceção específica (deve herdar de Exception)
class File_NotFound_Exception extends Exception {}

try {
throw new File_NotFound_Exception("Arquivo de configuração não existe.");

} catch (File_NotFound_Exception $e) { // CATCH mais Específico
echo "LOG: Arquivo Ausente. Tentando backup...
";

} catch (Exception $e) { // CATCH Genérico (captura o que sobrou)
echo "ERRO GERAL: Algo desconhecido aconteceu.
";
}
?>

5. O Encerramento Seguro (Usando die())

Garantindo que o programa pare imediatamente após um erro crítico, para evitar processamento com dados inválidos.

// php_ex5_die.php
<?php
try {
throw new Exception("Falha de Processamento, dados corrompidos.");

} catch (Exception $e) {
echo "ERRO CRÍTICO CAPTURADO: " . $e->getMessage() . "
";
die("Script encerrado."); // Interrompe a execução imediatamente
}

echo "Este código NUNCA deve ser executado se o erro ocorrer.";
?>
