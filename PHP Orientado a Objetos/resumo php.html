Módulo 1: Introdução, Variáveis e Comandos de Saída

Conceito Lúdico: A Cozinha PHP

O PHP é a cozinha (o backend), onde os pedidos (dados) são processados e o resultado é enviado de volta ao cliente (o navegador), enquanto HTML/CSS são o cardápio.

Pontos Chave

  • O que é PHP? Linguagem de script para processamento de dados (web ou console).
  • Delimitadores: O código deve estar entre <?php e ?>.
  • Variáveis ($ Caixas Mágicas): Identificadores para valores mutáveis, precedidas por `$`. PHP é case sensitive para variáveis e funções.
  • Comandos de Saída: echo e print (output); var_dump() (essencial para debug, mostra tipo e valor).

Exercícios Práticos (5)

echo "Bem-vindo à Cozinha PHP!";
$prato_favorito = "Feijoada"; echo $prato_favorito;
echo "Eu tenho " . $idade . $texto;

Simule a criação de um array e use var_dump(). Teste a sensibilidade a maiúsculas/minúsculas ($Nome vs $nome).

Módulo 2: Tipos de Dados e Operadores Essenciais

Conceito Lúdico: A Estrutura da Receita

Os Tipos de Dados definem a natureza dos ingredientes (farinha, água) e os Operadores são as ações que realizamos sobre eles (somar, comparar).

Pontos Chave: Tipos e Operadores

  • Escalares: Booleano (TRUE/FALSE), Numérico (int, float), String (aspas simples ' ou duplas ").
  • Operadores Relacionais: Resultam em TRUE ou FALSE.
  • Igualdade Fraca (==): Compara valores (não checa o tipo).
  • Identidade Forte (===): Compara valores E tipos de dados.

Analogia do Padeiro: == vs. ===

Se $farinha1 é '10' (string) e $farinha2 é 10 (int):

  • $farinha1 == $farinha2 é TRUE (Conteúdo igual).
  • $farinha1 === $farinha2 é FALSE (Tipos diferentes).

Exercícios Práticos (5)

// 1. Igualdade Fraca
$a = 5; $b = '5'; echo $a == $b; // TRUE
// 2. Identidade Forte
echo $a === $b; // FALSE
// 3. Módulo
echo 10 % 3; // 1

Módulo 3: Estruturas de Controle

Conceito Lúdico: O GPS do Código

As estruturas desviam o fluxo (decisão) ou repetem tarefas (iteração), agindo como um GPS para o código.

Decisão e Repetição

  • Decisão: IF / ELSE / ELSEIF (desvio condicional).
  • Alternativa: SWITCH (para diversos valores, exige break).
  • Loops Conhecidos: FOR (número de repetições conhecido).
  • Loops Condicionais: WHILE (repete enquanto a condição for TRUE).
  • Iteração em Arrays: FOREACH (essencial para percorrer arrays).

Exercícios (Decisão e Loop)

if ($velocidade > 80) { echo "Multado"; }
for ($i=1; $i<=5; $i++) { echo $i; }
foreach ($frutas as $f) { echo $f; }

Módulo 4: Arrays

Conceito Lúdico: A Caixa de Ferramentas

Containers que armazenam múltiplos valores (strings, números, objetos) de forma dinâmica.

Tipos e Funções

  • Indexados: Acesso por índice numérico (começa em 0). (Ex: Lista de Compras numerada).
  • Associativos: Acesso por chave de string (rótulo). (Ex: Ficha Cadastral: 'Nome' -> 'Carlos').
  • Multidimensionais: Arrays que contêm outros arrays (Matrizes).
  • Funções Essenciais: count(), array_push().

Exercícios (Acesso e Manipulação)

$times = ['Time A', 'Time B', 'Time C'];
echo $times[2]; // Terceiro item (Time C)
$aluno = ['nota' => 9.5];
echo $aluno['nota']; // Acessando pela chave

Módulo 5: Orientação a Objetos (OOP)

Conceito Lúdico: A Fábrica de Carros

OOP lida com estruturas que se assemelham ao mundo real (classes, objetos, herança).

Pilares da OOP

  • Classe (A Planta): Estrutura estática que define atributos (variáveis) e métodos (funcionalidades).
  • Objeto (O Carro Pronto): Instância dinâmica da classe, criada com o operador new.
  • Construtor (__construct): Método especial executado na criação do objeto, para inicializar propriedades.
  • Herança (extends): Permite que classes-filhas reutilizem comportamentos da classe-pai.

Exercícios (5)

class Pessoa {
  public $nome, $idade;
  public function __construct($n, $i) { ... }
  public function Apresentar() { return $this->nome; }
}
$usuario = new Pessoa("João", 30);
class Funcionario extends Pessoa { ... }

Módulo 6: Persistência e Segurança de Dados

Conceito Lúdico: O Cofre e o Carteiro

Dados duradouros (DB) e comunicação segura (HTTP, Hashing).

Persistência (DB)

  • SQL: Linguagem para DB (SELECT, INSERT, UPDATE, DELETE).
  • PDO: Biblioteca de acesso a DB recomendada por ser consistente e unificada.

Métodos HTTP (O Carteiro)

  • GET: Dados na URL (Query String). Use para obter dados não sensíveis (Cartão Postal).
  • POST: Dados no corpo da requisição (oculto). Use para dados sensíveis (Carta Selada).

Segurança

  • Hashing: Senhas nunca em texto puro. Use password_hash() (irreversível).
  • Custo (Cost Factor): Define a lentidão proposital do hash para dificultar ataques de Força Bruta.

echo $_POST['nome'];
