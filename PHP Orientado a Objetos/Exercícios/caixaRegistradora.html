✅ MINI CAIXA REGISTRADORA

Um exercício prático de lógica e programação.

1. Explicação do problema

Você vai criar um programa que simula uma caixa registradora simples.

O usuário digita o valor de cada produto comprado.

Quando terminar, digita 0 para parar.

O sistema soma todos os valores digitados e mostra o total da compra.

2. Entradas

  • Valor de cada produto (número decimal).
  • O valor 0 será usado para encerrar.

3. Processamento

  • Repetir a leitura de valores usando um loop.
  • Somar os valores em uma variável acumuladora.
  • Parar o loop quando o valor digitado for 0.

4. Saídas

O total final da compra.

5. Algoritmo passo a passo (bem detalhado)

  1. Criar uma variável para guardar o total da compra e começar com 0.
  2. Repetir o seguinte:
    • 2.1. Pedir para o usuário digitar o valor de um produto.
    • 2.2. Se o valor digitado for 0, parar a repetição.
    • 2.3. Caso contrário, somar o valor digitado ao total.
  3. Após sair do loop, mostrar o total da compra.

6. Código PHP funcional e comentado

<?php

$total = 0; // Variável acumuladora para somar os valores

while (true) { // Loop infinito (vamos quebrar com break)
    
    // Pede o valor do produto
    echo "Digite o valor do produto (0 para finalizar): ";
    $valor = floatval(trim(fgets(STDIN))); // Lê e converte para número

    // Se o valor for 0, sai do loop
    if ($valor == 0) {
        break;
    }

    // Soma o valor ao total
    $total += $valor;
}

// Exibe o total da compra
echo "Total da compra: R$ " . number_format($total, 2, ',', '.') . "\n";
?>

7. O que esse exercício ensina?

  • ✔ Uso de loop (while): Como criar repetições de forma controlada.
  • ✔ Uso de variável acumuladora: Como somar valores sequenciais de forma eficiente.
  • ✔ Entrada e saída de dados: Como interagir com o usuário (lê entrada e mostra resultado).
  • ✔ Condição para encerrar o loop (if + break): Como quebrar um loop infinito com base em uma condição.
  • ✔ Formatação de valores (number_format): Como apresentar números de forma amigável ao usuário (padrão monetário brasileiro).
