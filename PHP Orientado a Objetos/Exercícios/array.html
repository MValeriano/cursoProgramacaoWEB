Arrays (Vetores e Matrizes) em PHP

5 Desafios para dominar a manipulação de listas de dados.

Resumo

O tema Arrays (vetores e matrizes) é fundamental em PHP, pois esta estrutura de dados permite armazenar múltiplos valores dentro de uma única variável. Arrays servem como verdadeiros contêineres e podem crescer dinamicamente com a adição de novos itens.

Os *arrays* em PHP são acessados por uma chave, que pode ser um índice numérico (array indexado/vetor) ou uma string (array associativo). Arrays multidimensionais são aqueles que contêm outros *arrays* dentro deles.

Abaixo, estão 5 exercícios estruturados que utilizam diferentes tipos de *arrays* e as funções de manipulação mencionadas nas fontes, projetados para levar o aluno a pensar na solução:

5 Exercícios sobre Arrays em PHP

Exercício 1: Gerenciamento de Lista Indexada e Acesso

Problema: Você está criando uma lista de tarefas básicas (`TO-DO List`) para o dia, onde a ordem importa. Você precisa criar a lista, listar o primeiro item (lembrando que a contagem começa em zero) e, em seguida, adicionar um novo item no final da lista.

Conceitos Chave: Criação de *Array* Indexado (Vetor), Índice Zero, Adição de Item no Final, Acesso Direto.

Enunciado do Exercício:

  1. Crie um *array* chamado $tarefas_semanais contendo: "Comprar Pão", "Estudar PHP" e "Pagar Contas".
  2. Utilize echo para exibir apenas o segundo item da lista ("Estudar PHP").
  3. Adicione um novo item, "Enviar Email", ao final do *array*, utilizando a sintaxe de colchetes vazios.
  4. Use o var_dump() para exibir o *array* completo e confirmar a adição.

<?php
// 1. Criação do array indexado
$tarefas_semanais = ["Comprar Pão", "Estudar PHP", "Pagar Contas"];

echo "--- Acessando o segundo item ---\n";
// 2. Acesso ao segundo item (índice 1)
echo $tarefas_semanais[1] . "\n\n";

// 3. Adição de um novo item ao final
$tarefas_semanais[] = "Enviar Email";

echo "--- Array completo após adição ---\n";
// 4. Exibição da estrutura final do array
var_dump($tarefas_semanais);
?>

Exercício 2: Manipulação e Alteração de Array Associativo

Problema: Você está configurando um perfil de usuário onde cada dado é rotulado. Você precisa definir um perfil associativo, atualizar um dado existente e, em seguida, simular a exclusão de uma informação chave.

Conceitos Chave: *Array* Associativo, Acesso por String, Alteração de Valor, `unset()`.

Enunciado do Exercício:

  1. Crie um *array* associativo $perfil_cliente com as chaves: 'nome' => "João Silva", 'idade' => 30, e 'status' => "Ativo".
  2. Altere o valor da chave 'status' para "Inativo".
  3. Remova a informação 'idade' do *array* utilizando a função unset().
  4. Utilize print_r() para exibir o *array* final.
  5. Raciocínio Estrutural: Por que, no *array* associativo, você precisa usar as *strings* `'nome'` e `'idade'` para acessar os dados, em vez de índices numéricos?

<?php
// 1. Criação do array associativo
$perfil_cliente = [
    'nome' => "João Silva",
    'idade' => 30,
    'status' => "Ativo"
];

// 2. Alteração de um valor
$perfil_cliente['status'] = "Inativo";

// 3. Remoção de um elemento
unset($perfil_cliente['idade']);

echo "--- Perfil do cliente atualizado ---\n";
// 4. Exibição do array final
print_r($perfil_cliente);

echo "\n--- Raciocínio Estrutural ---\n";
// 5. Explicação
echo "Em arrays associativos, as chaves são strings (rótulos) que dão nome aos valores. Elas servem como identificadores únicos e significativos. Usar índices numéricos como 0 ou 1 não faria sentido, pois a ordem dos elementos não é o principal meio de identificação, e sim o nome da chave.\n";
?>

Exercício 3: Iteração e Contagem (`FOREACH` e `count`)

Problema: Você recebeu um *array* associativo representando o estoque. Você precisa listar cada produto e sua quantidade, e informar o total de tipos de produtos.

Conceitos Chave: `FOREACH` loop, `count()`, Iteração por Chave e Valor.

Enunciado do Exercício:

  1. Crie um *array* associativo $estoque_produtos (Ex: 'Teclado' => 150, 'Mouse' => 200).
  2. Use count() para exibir o total de produtos distintos.
  3. Utilize um laço FOREACH que capture a chave e o valor.
  4. Dentro do *loop*, imprima uma mensagem formatada para cada item: "Produto: [NOME] - Quantidade disponível: [QUANTIDADE]".

<?php
// 1. Criação do array de estoque
$estoque_produtos = [
    'Teclado' => 150,
    'Mouse' => 200,
    'Monitor' => 80,
    'Webcam' => 50
];

// 2. Contagem do total de produtos distintos
echo "Total de tipos de produtos no estoque: " . count($estoque_produtos) . "\n\n";

echo "--- Lista de Estoque ---\n";
// 3. Loop FOREACH para iterar sobre o array
foreach ($estoque_produtos as $produto => $quantidade) {
    // 4. Impressão formatada
    echo "Produto: " . $produto . " - Quantidade disponível: " . $quantidade . "\n";
}
?>

Exercício 4: Criação e Acesso a Matriz (Array Multidimensional)

Problema: Você precisa armazenar dados de vários alunos (nome e nota). Isso exige uma matriz. Você deve acessar e exibir uma informação específica do segundo aluno.

Conceitos Chave: *Array* Multidimensional (Matriz), Acesso Aninhado.

Enunciado do Exercício:

  1. Crie um *array* $alunos contendo dois *arrays* internos (Ex: ['Alice', 9.5] e ['Bruno', 7.0]).
  2. Utilize var_dump() para inspecionar a estrutura da matriz.
  3. Utilize echo e acesso aninhado para exibir apenas o nome do segundo aluno.
  4. Raciocínio Estrutural: Se você quisesse acessar a nota de Alice, quais seriam os índices numéricos que você precisaria usar?

<?php
// 1. Criação do array multidimensional (matriz)
$alunos = [
    ['Alice', 9.5], // índice 0
    ['Bruno', 7.0]  // índice 1
];

echo "--- Estrutura da Matriz ---\n";
// 2. Inspeção da estrutura
var_dump($alunos);

echo "\n--- Acesso a um dado específico ---\n";
// 3. Acesso aninhado: índice 1 (segundo aluno), índice 0 (primeiro item, o nome)
echo "Nome do segundo aluno: " . $alunos[1][0] . "\n";

echo "\n--- Raciocínio Estrutural ---\n";
// 4. Explicação
echo "Para acessar a nota de Alice, você usaria os índices [0][1].\n";
echo "  \$alunos[0] -> Acessa o primeiro array interno: ['Alice', 9.5]\n";
echo "  \$alunos[0][1] -> Acessa o segundo item (índice 1) desse array interno: 9.5\n";
?>

Exercício 5: Mesclagem e Combinação de Dados (`array_merge`)

Problema: Você tem dois *arrays* de frutas separados e precisa combiná-los em uma única lista para um catálogo.

Conceitos Chave: `array_merge()`, Arrays Indexados.

Enunciado do Exercício:

  1. Crie $tropicais = ['Manga', 'Maracujá'];.
  2. Crie $citricas = ['Laranja', 'Limão'];.
  3. Utilize array_merge() para combinar os dois em um novo *array* $catalogo_frutas.
  4. Utilize print_r() para exibir o resultado.
  5. Desafio de Raciocínio: Se ambos os *arrays* tivessem chaves associativas iguais, o que aconteceria com os valores da chave repetida?

<?php
// 1. Array de frutas tropicais
$tropicais = ['Manga', 'Maracujá'];

// 2. Array de frutas cítricas
$citricas = ['Laranja', 'Limão'];

// 3. Mesclagem dos arrays
$catalogo_frutas = array_merge($tropicais, $citricas);

echo "--- Catálogo de Frutas Combinado ---\n";
// 4. Exibição do resultado
print_r($catalogo_frutas);

echo "\n--- Desafio de Raciocínio ---\n";
// 5. Explicação
echo "Se os arrays tivessem chaves associativas iguais, o valor da chave no SEGUNDO array ('\$citricas') sobrescreveria o valor da mesma chave no PRIMEIRO array ('\$tropicais'). O último valor sempre prevalece.\n";
?>
