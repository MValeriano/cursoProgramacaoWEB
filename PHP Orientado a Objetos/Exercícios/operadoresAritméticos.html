Operadores Aritméticos Fundamentais em PHP

Resumo:

Os **Operadores Aritméticos** são utilizados para realizar cálculos matemáticos. Eles são fundamentais em PHP para qualquer tipo de operação matemática, incluindo adição, subtração, multiplicação, divisão e módulo (resto da divisão). Em cálculos mais complexos, o uso de parênteses é crucial para garantir a precedência correta das operações.

A seguir, estão 5 exercícios estruturados que utilizam operadores aritméticos para resolver problemas, forçando o aluno a considerar a precedência e o comportamento de cada operador:

5 Exercícios sobre Operadores Aritméticos em PHP

Exercício 1: Cálculo de Preço com Margem e Imposto (Precedência)

Problema: Você precisa calcular o preço final de um produto. O custo base é de R$ 50,00. Primeiro, você aplica uma margem de lucro de 20% (multiplicação). Em seguida, você adiciona um imposto fixo de R$ 5,00. Você deve calcular o valor correto do preço de venda final e garantir que a margem de lucro seja calculada **antes** de somar o imposto.

Conceitos Chave: Adição (`+`), Multiplicação (`*`), Precedência de Operadores (Uso de Parênteses).

Enunciado do Exercício:

  1. Crie as variáveis `$custo_base = 50;`, `$margem_percentual = 0.20;` e `$imposto_fixo = 5;`.
  2. Calcule o **Valor do Lucro** (`$lucro`) multiplicando `$custo_base` por `$margem_percentual`.
  3. Calcule o **Preço de Venda Final** (`$preco_final`) somando o `$custo_base` ao `$lucro` e ao `$imposto_fixo`.
  4. **Desafio de Precedência:** Tente calcular o `$preco_final_errado` em uma única linha, omitindo os parênteses: `$custo_base + $margem_percentual * $custo_base + $imposto_fixo`. Explique por que, matematicamente, a multiplicação sempre ocorre antes da adição.
  5. Imprima o `$preco_final` correto e o `$preco_final_errado` para comparação.

Resolução Sugerida em PHP:

$custo_base = 50;
$margem_percentual = 0.20;
$imposto_fixo = 5;

// 2. Cálculo do Lucro
$lucro = $custo_base * $margem_percentual; // 50 * 0.20 = 10

// 3. Cálculo Correto do Preço Final
$preco_final = $custo_base + $lucro + $imposto_fixo; // 50 + 10 + 5 = 65

// 4. Desafio de Precedência (Cálculo Errado)
$preco_final_errado = $custo_base + $margem_percentual * $custo_base + $imposto_fixo;
/*
Explicação: Sem parênteses, a multiplicação tem precedência.
A ordem de cálculo será: $margem_percentual * $custo_base (0.20 * 50 = 10),
e só então as adições: 50 + 10 + 5 = 65.
Neste caso específico (onde a margem é calculada com a multiplicação),
o resultado será o mesmo, mas a ordem de raciocínio é crucial.
Se o problema fosse "Aplicar 20% APÓS a soma do custo e imposto", os parênteses
seriam MANDATÓRIOS. Ex: ($custo_base + $imposto_fixo) * (1 + $margem_percentual)
*/

// 5. Impressão
echo "Preço Final Correto: R$ " . $preco_final . "\n"; // Saída: R$ 65
echo "Preço Final Errado: R$ " . $preco_final_errado . "\n"; // Saída: R$ 65

Exercício 2: Divisão de Estoque e Resto de Unidades (Módulo)

Problema: Uma loja recebeu 85 camisetas e precisa empacotá-las em caixas que cabem exatamente 12 camisetas cada. Você precisa saber quantas caixas completas serão usadas **e** quantas camisetas sobrarão (o resto) que não completarão uma caixa.

Conceitos Chave: Divisão (`/`), Módulo (Resto da Divisão - `%`).

Enunciado do Exercício:

  1. Crie as variáveis `$total_camisetas = 85;` e `$capacidade_caixa = 12;`.
  2. Use o operador de **divisão (`/`)** para calcular o **Número Total de Caixas** (o resultado pode ser um número decimal, o que é esperado).
  3. Use o operador **Módulo (`%`)** para calcular o **Número de Camisetas Restantes** (o resto da divisão).
  4. Imprima o número de caixas completas (ignore as casas decimais) e o número de camisetas restantes.
  5. **Raciocínio Estrutural:** Explique o que o operador Módulo (`%`) representa. Por exemplo, qual seria o resultado de `10 % 3`?

Resolução Sugerida em PHP:

$total_camisetas = 85;
$capacidade_caixa = 12;

// 2. Divisão (Resultado decimal esperado)
$numero_total_caixas_decimal = $total_camisetas / $capacidade_caixa; // 7.0833...

// 3. Cálculo do Resto (Módulo)
$camisetas_restantes = $total_camisetas % $capacidade_caixa; // 85 % 12 = 1

// Cálculo de Caixas Completas (usando floor para remover casas decimais)
$caixas_completas = floor($numero_total_caixas_decimal); // 7

// 4. Impressão
echo "Número Total de Caixas (incluindo incompletas): " . $numero_total_caixas_decimal . "\n";
echo "Número de Caixas Completas: " . $caixas_completas . "\n"; // Saída: 7
echo "Número de Camisetas Restantes: " . $camisetas_restantes . "\n"; // Saída: 1

// 5. Raciocínio Estrutural:
/*
O operador Módulo (%) retorna o **resto da divisão** de dois números.
Exemplo: 10 % 3.
10 dividido por 3 é 3, com resto 1. (3 * 3 = 9. 10 - 9 = 1).
Portanto, o resultado de `10 % 3` é **1**.
*/

Exercício 3: Cálculo de Juros Compostos (Exponenciação)

Problema: Você precisa calcular o valor futuro de um investimento simples sujeito a juros compostos por um curto período de tempo. O cálculo envolve elevar um número à potência de outro (exponenciação).

Conceitos Chave: Exponenciação (dois asteriscos - `**`), Multiplicação (`*`).

Enunciado do Exercício:

  1. Crie as variáveis: `$principal = 1000;` (capital inicial) e `$taxa_juros = 1.05;` (juros de 5%).
  2. Calcule o valor do investimento após 4 anos. A fórmula é: `Principal * (Taxa de Juros) ^ Anos`.
  3. Utilize o operador de **Exponenciação (`**`)** (ou `pow()`, se preferir, como visto nas funções matemáticas) para elevar `$taxa_juros` à potência de 4.
  4. Atribua o resultado a `$valor_futuro`.
  5. Imprima o `$valor_futuro`.

Resolução Sugerida em PHP:

$principal = 1000;
$taxa_juros = 1.05;
$anos = 4;

// 3. e 4. Cálculo do Valor Futuro usando o operador **
// A fórmula completa: $valor_futuro = $principal * ($taxa_juros ** $anos);
$valor_futuro = $principal * ($taxa_juros ** $anos);
// Resultado de 1.05 ** 4 é aproximadamente 1.2155
// 1000 * 1.2155 = 1215.50625

// Ou utilizando a função pow()
// $valor_futuro = $principal * pow($taxa_juros, $anos);

// 5. Impressão
echo "Valor Futuro do Investimento (após 4 anos): R$ " . number_format($valor_futuro, 2, ',', '.') . "\n";
// Saída: R$ 1.215,51 (aproximadamente, após formatação)

Exercício 4: Operação Mista e Conversão de Tipo

Problema: O PHP realiza conversão automática de tipos (*type casting*) em operações aritméticas. Você precisa testar o que acontece quando uma *string* que parece um número é somada a um número inteiro.

Conceitos Chave: Adição (`+`), Conversão Automática de Tipo (Implícita).

Enunciado do Exercício:

  1. Crie as variáveis: `$string_dez = "10";` (tipo *string*) e `$numero_cinco = 5;` (tipo numérico).
  2. Crie a variável `$resultado_soma = $string_dez + $numero_cinco;`.
  3. Utilize `echo` para exibir o `$resultado_soma`.
  4. **Raciocínio Estrutural:** O PHP realiza automaticamente a conversão de tipos em operações. Qual tipo de dado o PHP considera para `$string_dez` para que a adição funcione e qual será o tipo de dado da variável `$resultado_soma` após a operação?

Resolução Sugerida em PHP:

$string_dez = "10";
$numero_cinco = 5;

// 2. A adição é realizada. PHP converte a string "10" para o número inteiro 10.
$resultado_soma = $string_dez + $numero_cinco; // 10 + 5 = 15

// 3. Impressão
echo "Resultado da Soma: " . $resultado_soma . "\n"; // Saída: 15
echo "Tipo de dado do resultado: " . gettype($resultado_soma) . "\n"; // Saída: integer

// 4. Raciocínio Estrutural:
/*
Para que a adição funcione, o PHP realiza uma **Conversão de Tipo Implícita (Type Casting)**.
Ele converte a string `$string_dez` ("10") para o tipo de dado **Integer (número inteiro)**.
O tipo de dado da variável `$resultado_soma` após a operação será **Integer**, pois a adição
de dois números inteiros (ou de um inteiro e um float) resulta em um tipo numérico.
*/

Exercício 5: Manipulação de Número Negativo (Valor Absoluto)

Problema: Você está processando uma variação de temperatura ou saldo bancário, e o resultado é um número negativo (`-15.5`). Para fins de exibição, você precisa apenas do valor numérico (a magnitude), independentemente de ser negativo ou positivo.

Conceitos Chave: Funções Matemáticas (`abs()`), Números Negativos.

Enunciado do Exercício:

  1. Crie a variável `$variacao_saldo = -15.5;`.
  2. Utilize a função **`abs()`** (valor absoluto) para obter o valor positivo da variação de saldo.
  3. Atribua o resultado a `$valor_magnitude`.
  4. Exiba o `$valor_magnitude`.
  5. **Desafio de Raciocínio:** Se `$variacao_saldo` fosse `15.5` positivo, qual seria a saída de `abs($variacao_saldo)`? Explique por que essa função é útil em casos onde você só precisa da magnitude do número, ignorando o sinal.

Resolução Sugerida em PHP:

$variacao_saldo = -15.5;

// 2. Uso da função abs()
$valor_magnitude = abs($variacao_saldo); // abs(-15.5) = 15.5

// 4. Impressão
echo "Variação de Saldo (Original): " . $variacao_saldo . "\n"; // Saída: -15.5
echo "Valor da Magnitude (Absoluto): " . $valor_magnitude . "\n"; // Saída: 15.5

// 5. Desafio de Raciocínio:
/*
Se `$variacao_saldo` fosse 15.5 positivo, a saída de `abs($variacao_saldo)`
também seria **15.5**.

A função `abs()` é útil porque ela retorna o **valor absoluto** ou a **magnitude**
de um número, removendo qualquer sinal negativo. Em contextos como distância,
variação, erro ou diferença, muitas vezes o que importa é o tamanho da alteração,
e não se ela foi para cima ou para baixo (positivo ou negativo).
*/
