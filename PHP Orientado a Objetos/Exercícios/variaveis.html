PHP: Conceitos e Exercícios Práticos de Variáveis

Foco em Declaração, Nomenclatura, Tipagem e Atribuição.

Resumo: Variáveis em PHP

As variáveis em PHP são identificadores utilizados para representar valores mutáveis e voláteis, sendo armazenadas na memória RAM e destruídas após a execução do programa. Elas devem ter um nome de identificação precedido pelo caractere cifrão ($). O PHP é sensível a letras maiúsculas e minúsculas (case sensitive), então `$codigo` e `$Codigo` são tratadas como variáveis diferentes.

5 Exercícios sobre Variáveis em PHP

Exercício 1: Validação de Nomenclatura e Tipo de Dado

Problema: Você está desenvolvendo um módulo de registro de usuários e precisa armazenar o nome completo e o ID do cliente. Durante a codificação, você cometeu um erro de nomenclatura em uma das variáveis, e precisa identificar a melhor prática correta, além de garantir que a idade seja tratada como um número.

Conceitos Chave: Declaração de Variáveis, Nomenclatura (Regras de Ouro), Case Sensitivity, Tipo Numérico e Tipo String.

Enunciado do Exercício:

  • Tente declarar as seguintes variáveis e, com base nas dicas de nomenclatura, identifique qual delas resultará em erro de sintaxe ou é considerada uma má prática (e justifique): $NomeCompleto, $3id_usuario, $email-cliente, $nome_completo
  • Declare as seguintes informações, atribuindo o tipo de dado correto a cada variável: Nome Completo (String), Idade (Numérico/Inteiro), Está Ativo (Booleano: TRUE ou FALSE)
  • Utilize o comando de saída echo para exibir o Nome Completo e a Idade.
  • Se a variável $NomeCompleto for declarada como $nomecompleto e você tentar acessá-la como $NomeCompleto, o que o PHP exibirá?

Resolução e Explicação

  • Erros de Sintaxe: $3id_usuario (não pode começar com número) e $email-cliente (o hífen é interpretado como operador de subtração).
  • Má Prática: $NomeCompleto é permitida, mas $nome_completo é a convenção recomendada (snake_case).
  • Case Sensitivity: O PHP exibirá um Notice: Undefined variable, pois ele diferencia maiúsculas de minúsculas.
<?php // Declaração de Variáveis com tipos corretos $nome_completo = "João da Silva"; // String $idade = 28; // Integer (Numérico) $esta_ativo = true; // Boolean // Exibição echo "Nome: " . $nome_completo . "<br>"; echo "Idade: " . $idade . " anos<br>"; // Exemplo de Case Sensitivity (se tentar acessar uma variável com nome diferente) $nome_sem_maiusculas = "Ana"; // echo $Nome_sem_maiusculas; // Causaria um Notice (variável indefinida) ?>

Exercício 2: Gerenciamento de Estoque e Atribuição

Problema: Você está gerenciando o estoque de um produto chamado "Caneta Azul". O sistema começa com 10 unidades. Durante o dia, 3 unidades são vendidas e, em seguida, 5 novas unidades são adicionadas ao estoque. Você precisa registrar o valor final e utilizar operadores de atribuição para facilitar os cálculos.

Conceitos Chave: Atribuição Simples (=), Operadores de Atribuição Composta (+=, -=), Tipo Numérico.

Enunciado do Exercício:

  • Crie a variável $estoque_caneta_azul e atribua o valor inicial de 10.
  • Use um operador de atribuição composta para subtrair 3 unidades, simulando uma venda.
  • Use um operador de atribuição composta para adicionar 5 novas unidades, simulando uma reposição de estoque.
  • Crie uma variável $preco_unitario e atribua o valor 2.50. Calcule e exiba o Valor Total do Estoque Atual (Estoque atual * Preço Unitário).

Resolução em PHP (Operadores de Atribuição)

<?php // 1. Estoque inicial $estoque_caneta_azul = 10; // 2. Venda de 3 unidades $estoque_caneta_azul -= 3; // Estoque agora é 7 // 3. Reposição de 5 unidades $estoque_caneta_azul += 5; // Estoque agora é 12 // 4. Cálculo do Valor Total do Estoque $preco_unitario = 2.50; $valor_total_estoque = $estoque_caneta_azul * $preco_unitario; echo "Estoque Final: " . $estoque_caneta_azul . " unidades<br>"; echo "Valor Total do Estoque: R$ " . number_format($valor_total_estoque, 2, ',', '.') . "<br>"; ?>

Exercício 3: Variáveis de Referência vs. Variáveis por Valor

Problema: Simular e entender a diferença entre atribuição por valor (cópia de memória) e atribuição por referência (&).

Conceitos Chave: Atribuição por Valor (Cópia de Memória), Atribuição por Referência (&).

Enunciado do Exercício:

  • Crie $saldo_inicial e atribua 1000.
  • Cenário 1 (Atribuição por Valor): Atribua $saldo_caixa = $saldo_inicial;. Altere $saldo_caixa para 500. Exiba ambos os valores e confirme que o $saldo_inicial ainda é 1000.
  • Cenário 2 (Atribuição por Referência): Começando do zero, atribua $saldo_caixa por referência a $saldo_inicial (usando o operador &). Altere $saldo_caixa para 200. Exiba $saldo_inicial e $saldo_caixa. O que você observa sobre os dois valores agora e por que isso acontece?

Resolução em PHP (Referência vs. Valor)

<?php // Cenário 1: Atribuição por VALOR (Cópia de Memória) echo "// --- Cenário 1: Por VALOR (Cópia) --- <br>"; $saldo_inicial = 1000; $saldo_caixa = $saldo_inicial; // $saldo_caixa recebe uma cópia do valor $saldo_caixa = 500; // Altera apenas a cópia echo "Saldo Inicial (esperado 1000): " . $saldo_inicial . "<br>"; echo "Saldo Caixa (esperado 500): " . $saldo_caixa . "<br>"; echo "<br>"; // Cenário 2: Atribuição por REFERÊNCIA echo "// --- Cenário 2: Por REFERÊNCIA (&) --- <br>"; $saldo_inicial = 1000; $saldo_caixa = & $saldo_inicial; // $saldo_caixa aponta para o mesmo local de memória $saldo_caixa = 200; // Altera o valor na memória compartilhada echo "Saldo Inicial (esperado 200): " . $saldo_inicial . "<br>"; echo "Saldo Caixa (esperado 200): " . $saldo_caixa . "<br>"; // Explicação: No Cenário 2, ambas variáveis compartilham o mesmo dado. A mudança em uma afeta a outra. ?>

Exercício 4: Interpolação de Strings e Variáveis Variantes

Problema: Construir uma mensagem dinâmica de boas-vindas e explorar o recurso de "Variáveis Variantes" do PHP.

Conceitos Chave: Tipo String, Concatenação, Variáveis Variantes (Variable Variables).

Enunciado do Exercício:

  • Crie a variável $nome_loja com o valor "Mercado Central" e $produto_destaque com o valor "Maçã".
  • Use o comando echo para imprimir a mensagem: "Bem-vindo ao Mercado Central. A fruta do dia é a Maçã!". Utilize aspas duplas (" ") para inserir as variáveis diretamente na string (interpolação).
  • Crie uma variável $fruta_favorita e atribua a ela a string "banana".
  • Crie uma segunda variável chamada $banana e atribua a ela o valor "amarela".
  • Utilize o conceito de Variável Variante (usando cifrão duplo, $$) para exibir o valor "amarela", utilizando apenas a variável $fruta_favorita.

Resolução em PHP (Interpolação e $$)

<?php // 1. Interpolação de Strings $nome_loja = "Mercado Central"; $produto_destaque = "Maçã"; // Aspas duplas ("") permitem a interpolação das variáveis. echo "Bem-vindo ao $nome_loja. A fruta do dia é a $produto_destaque!<br>"; // 2. Variáveis Variantes $fruta_favorita = "banana"; // Conteúdo: "banana" $banana = "amarela"; // Variável cujo nome é "banana" e valor é "amarela" // $$fruta_favorita é equivalente a $$("banana"), que se torna $banana. echo "Usando Variável Variante: " . $$fruta_favorita . "<br>"; ?>

Exercício 5: Conversão Implícita e Tipagem

Problema: Testar como o PHP lida com conversão automática (implícita) em operações e em contextos booleanos.

Conceitos Chave: Conversão Implícita de Tipos, Tipo Booleano (TRUE/FALSE), Valores Falsos em Comparações.

Enunciado do Exercício:

  • Crie a variável $a e atribua a ela a string "10". Crie a variável $b e atribua a ela o número inteiro 5.
  • Utilize echo para exibir o resultado da soma $a + $b. O que acontece com a string "10" durante essa operação?
  • Crie a variável $status_pagamento e atribua o número 0 (zero).
  • Utilize uma estrutura if para testar a variável $status_pagamento (sem compará-la explicitamente a FALSE ou 0). Se a condição for TRUE, imprima "Pagamento Válido". Caso contrário, imprima "Pagamento Inválido".
  • O que o PHP considera como o valor booleano da variável $status_pagamento = 0? Explique por que o resultado foi "Pagamento Inválido". (Lembre-se que o PHP considera o inteiro 0 como FALSO em comparações booleanas).

Resolução em PHP (Conversão Implícita)

<?php // 1. Conversão Implícita na Soma $a = "10"; // String $b = 5; // Inteiro $soma = $a + $b; // Resultado: 15 echo "Resultado da soma ('10' + 5): " . $soma . "<br>"; // Explicação: O PHP realizou a Conversão Implícita de Tipos. A string "10" foi convertida para o número inteiro 10 // para que a operação aritmética pudesse ser realizada, resultando em 15. echo "<br>"; // 2. Valores Falsos em Contexto Booleano $status_pagamento = 0; // Inteiro 0 echo "Status do Pagamento (valor 0): "; if ($status_pagamento) { echo "Pagamento Válido<br>"; } else { echo "Pagamento Inválido<br>"; } // Explicação: O PHP considera o inteiro 0 (zero) como FALSE em um contexto booleano (falsy). // Por isso, a condição 'if (0)' falha, e o resultado é "Pagamento Inválido". ?>
