IF, ELSE IF, SWITCH, Operadores Relacionais e Lógicos.

Resumo: Operadores Condicionais e Estruturas

Operadores Condicionais (Relacionais e Lógicos) e Estruturas de Controle condicionais (`IF`, `ELSE IF`, `SWITCH`), que são amplamente utilizados para navegar o código em diferentes direções, apresento 5 exercícios estruturados para levar o aluno a pensar na resolução de problemas.

Os operadores condicionais (*comparison operators*) são usados para realizar comparações entre valores ou expressões, resultando sempre em um valor booleano (`TRUE` ou `FALSE`).

5 Exercícios sobre Operadores Condicionais (Relacionais e Lógicos)

Exercício 1: Verificação de Elegibilidade para Promoção

Problema: A promoção exige duas condições que devem ser obrigatoriamente verdadeiras ao mesmo tempo: o salário deve ser superior a R$ 3000,00 E o tempo de serviço deve ser de 12 meses ou mais.

Conceitos Chave: Operador Lógico `AND` (`&&`), Operadores Relacionais (`>`, `>=`), Estrutura `IF`.

Enunciado do Exercício:

  • 1. Crie as variáveis $salario = 3200; e $tempo_servico = 10;.
  • 2. Utilize o comando `IF` e o operador lógico `AND` para verificar se o `$salario` é maior que 3000 E se o `$tempo_servico` é maior ou igual a 12.
  • 3. Se a condição for `TRUE`, imprima "Parabéns, você foi promovido!".
  • 4. Se a condição for `FALSE`, imprima "Você ainda não atende aos critérios para promoção.".
  • 5. Desafio de Raciocínio: Modifique apenas o valor de `$tempo_servico` para 12 e explique por que a saída do programa mudou.

Resolução em PHP

<?php // 1. Variáveis Iniciais $salario = 3200; $tempo_servico = 10; echo "// Teste 1: Salário ok, Tempo insuficiente (10 meses)<br>"; if ($salario > 3000 && $tempo_servico >= 12) { echo "Parabéns, você foi promovido!<br>"; } else { echo "Você ainda não atende aos critérios para promoção.<br>"; } echo "<br>// Teste 2: Tempo modificado para 12 meses<br>"; $tempo_servico = 12; if ($salario > 3000 && $tempo_servico >= 12) { echo "Parabéns, você foi promovido!<br>"; } else { echo "Você ainda não atende aos critérios para promoção.<br>"; } // Explicação: A saída mudou porque o operador AND (&&) exige que ambas as subcondições sejam TRUE. // No Teste 1, a segunda subcondição (10 >= 12) é FALSE, então o resultado final é FALSE. // No Teste 2, ambas subcondições são TRUE, resultando em TRUE, e a mensagem de promoção é exibida. ?>

Exercício 2: Validação de Campos Opcionais no Formulário

Problema: Retornar `TRUE` para um erro se o `username` estiver vazio OU se a `password` estiver vazia. O preenchimento do email é opcional.

Conceitos Chave: Operador Lógico `OR` (`||`), `empty()`.

Enunciado do Exercício:

  • 1. Crie as variáveis $username = "joao123";, $password = ""; e $email = "joao@email.com";.
  • 2. Crie uma variável booleana $tem_erro e defina seu valor inicial como FALSE.
  • 3. Use o comando `IF` com o operador lógico `OR` (`||`) para verificar se `$username` está vazio OU se `$password` está vazio (utilize a função empty()).
  • 4. Se a condição for `TRUE` (houver erro em pelo menos um dos campos obrigatórios), atribua `TRUE` à variável `$tem_erro` e exiba "Erro de submissão: Preencha todos os campos obrigatórios.".
  • 5. O que aconteceria se você usasse o operador `AND` (`&&`) em vez de `OR` neste cenário e por que ele seria incorreto?

Resolução em PHP

<?php // 1. Variáveis (Password está vazia) $username = "joao123"; $password = ""; $email = "joao@email.com"; // 2. Variável de Controle $tem_erro = false; // 3. Verificação com OR (||) if (empty($username) || empty($password)) { // 4. Se qualquer uma for TRUE (vazia), a condição total é TRUE. $tem_erro = true; echo "Erro de submissão: Preencha todos os campos obrigatórios.<br>"; } else { echo "Formulário validado com sucesso.<br>"; } // 5. Raciocínio: // Se usássemos AND (&&), a mensagem de erro só seria exibida se AMBOS $username E $password estivessem vazios. // Como $username não está vazio, a condição total seria FALSE, e o erro não seria detectado. ?>

Exercício 3: Comparação Estrita de Tipos de Dados

Problema: Garantir que duas variáveis sejam iguais em valor E no tipo de dado para evitar a comparação "solta" do PHP.

Conceitos Chave: Operador Relacional Idêntico (`===`), Operador Relacional Não Idêntico (`!==`).

Enunciado do Exercício:

  • 1. Crie as variáveis: $valor_a = 1234; (inteiro) e $valor_b = "1234"; (string).
  • 2. Use um `IF` para comparar `$valor_a` e `$valor_b` usando o operador de igualdade simples (`==`). Imprima o resultado ("Valores são iguais, ignorando o tipo.").
  • 3. Use um `ELSE IF` para comparar `$valor_a` e `$valor_b` usando o operador idêntico (`===`). Se a condição for `TRUE`, imprima "Valores são idênticos (mesmo tipo).".
  • 4. Adicione um `ELSE` que imprima "Valores não são idênticos (tipos diferentes)."
  • 5. Raciocínio Estrutural: Explique o que aconteceu no passo 2 e 3 e demonstre qual operador (relacional) você usaria para verificar se as variáveis são diferentes em valor ou tipo ao mesmo tempo.

Resolução em PHP

<?php // 1. Variáveis $valor_a = 1234; // integer $valor_b = "1234"; // string // 2. Comparação Solta (==) if ($valor_a == $valor_b) { echo "Resultado do (==): Valores são iguais, ignorando o tipo. <br>"; } // 3. Comparação Estrita (===) else if ($valor_a === $valor_b) { echo "Resultado do (===): Valores são idênticos (mesmo tipo). <br>"; } // 4. Caso contrário else { echo "Resultado do ELSE: Valores não são idênticos (tipos diferentes). <br>"; } // Explicação e Operador de Diferença echo "<br>"; if ($valor_a !== $valor_b) { echo "Usando (!==): Variáveis são diferentes em valor OU tipo (resultado TRUE).<br>"; } // O passo 2 (==) é TRUE porque PHP converte a string "1234" para int 1234 antes da comparação. // O passo 3 (===) é FALSE, e por isso o código nunca entra nele (pois o IF anterior já foi TRUE). // O operador para verificar se são diferentes em valor OU tipo ao mesmo tempo é o Não Idêntico: (!==). ?>

Exercício 4: Atribuição Condicional Simplificada (Operador Ternário)

Problema: Atribuir um valor a uma variável `$mensagem` baseado em uma condição simples usando o Operador Ternário.

Conceitos Chave: Operador Ternário (Atribuição Condicional Simplificada).

Enunciado do Exercício:

  • 1. Crie a variável $valor_venda = 85;.
  • 2. Utilize o Operador Ternário (`condição ? valor_se_verdadeiro : valor_se_falso`) para atribuir o valor à variável `$resultado`.
  • 3. A condição deve ser: $valor_venda > 100.
  • 4. O valor se verdadeiro deve ser `'muito caro'`.
  • 5. O valor se falso deve ser `'pode comprar'`.
  • 6. Exiba o valor de `$resultado`. (Altere o `$valor_venda` para 120 e teste novamente).

Resolução em PHP

<?php // 1. Variável $valor_venda_1 = 85; // 2. Operador Ternário para $valor_venda_1 (85) $resultado_1 = ($valor_venda_1 > 100) ? 'muito caro' : 'pode comprar'; echo "Valor R$85,00: " . $resultado_1 . "<br>"; // Saída: pode comprar // 6. Teste com 120 $valor_venda_2 = 120; $resultado_2 = ($valor_venda_2 > 100) ? 'muito caro' : 'pode comprar'; echo "Valor R$120,00: " . $resultado_2 . "<br>"; // Saída: muito caro ?>

Exercício 5: Controle de Fluxo por Múltiplos Estados (`SWITCH`)

Problema: Processar o *status* de um pedido que pode assumir valores inteiros específicos (1, 2, 3, ou qualquer outro) usando o comando `SWITCH`.

Conceitos Chave: Comando `SWITCH`, `CASE`, `BREAK`, `DEFAULT`.

Enunciado do Exercício:

  • 1. Crie a variável $status_pedido e atribua o valor 2.
  • 2. Utilize o comando `SWITCH` para testar a variável `$status_pedido`.
  • 3. Crie os seguintes casos: Case 1: Imprima "Pedido Recebido."; Case 2: Imprima "Em Processamento."; Case 3: Imprima "Enviado.". Use `break` após cada `CASE`.
  • 4. Crie a cláusula `default` para todos os outros valores, exibindo "Status Desconhecido ou Inválido.".
  • 5. Raciocínio Estrutural: Explique a principal diferença entre usar esta estrutura `SWITCH` e usar uma série de comandos `IF/ELSE IF` para resolver o mesmo problema, e quando o `SWITCH` é mais apropriado.

Resolução em PHP

<?php // 1. Variável de Status $status_pedido = 2; echo "Status do Pedido ($status_pedido): "; // 2, 3 e 4. Estrutura SWITCH switch ($status_pedido) { case 1: echo "Pedido Recebido.<br>"; break; case 2: echo "Em Processamento.<br>"; break; case 3: echo "Enviado.<br>"; break; default: echo "Status Desconhecido ou Inválido.<br>"; break; } // 5. Raciocínio Estrutural: // A principal diferença é que o SWITCH testa o valor de UMA ÚNICA VARIÁVEL contra múltiplos valores. // O IF/ELSE IF testa MULTIPLAS EXPRESSÕES (que podem envolver diferentes variáveis e operadores). // O SWITCH é mais apropriado (e geralmente mais legível e eficiente) quando você está comparando uma única variável // contra uma lista de possíveis valores discretos (como inteiros, strings ou enums). ?>
