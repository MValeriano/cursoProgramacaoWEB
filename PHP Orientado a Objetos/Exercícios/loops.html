PHP: Estruturas de Repetição (Loops)

WHILE, FOR, FOREACH: Comandos Essenciais para Iteração de Código.

Resumo: Loops em PHP

As estruturas de repetição, ou loops, são comandos essenciais em PHP que permitem a execução repetitiva de um bloco de comandos enquanto uma condição for verdadeira, ou para iterar sobre coleções de dados. Os loops garantem que o código seja repetido continuamente até que o programa diga para ele parar.

Os principais tipos de loops abordados nas fontes são: `WHILE` (enquanto uma condição for verdadeira), `FOR` (baseado em um contador), e `FOREACH` (específico para arrays e matrizes).

6 Exercícios sobre Estruturas de Repetição (Loops)

Exercício 1: Geração de Relatório Anual (Loop `FOR`)

Problema: Você precisa gerar um relatório de vendas que exibe a taxa de crescimento anual (um valor fixo de 5%) para os próximos 10 anos, começando no ano atual. Você precisa de uma estrutura de repetição baseada em um contador exato.

Conceitos Chave: `FOR` loop, Incremento (`++`), Condição de Parada.

Enunciado do Exercício:

  • 1. Defina a variável $ano_inicial como o ano atual (simule com 2024).
  • 2. Utilize um `FOR` loop para iterar por 10 vezes. A variável de iteração ($i) deve começar em 1 e ir até 10.
  • 3. Dentro do loop, exiba o ano ($ano_inicial + $i) e a taxa de crescimento, simulando um texto como: "No ano [ANO], a taxa de crescimento prevista é de 5%."
  • 4. Certifique-se de usar um incremento (++) na variável de controle do `FOR` para avançar a contagem.

Foco Estrutural: O aluno deve dominar os três parâmetros obrigatórios do `FOR`: valor inicial (`expr1`), condição de execução (`expr2`), e valor a ser incrementado (`expr3`).

Resolução em PHP (Loop FOR)

<?php $ano_inicial = 2024; echo "<strong>Relatório de Crescimento Anual:</strong><br>"; // O FOR executa exatamente 10 vezes, de $i=1 até $i=10 for ($i = 1; $i <= 10; $i++) { $ano_previsto = $ano_inicial + $i; echo "No ano <strong>{$ano_previsto}</strong>, a taxa de crescimento prevista é de 5%.<br>"; } ?>

Exercício 2: Simulação de Download com Condição (`WHILE`)

Problema: O download só deve continuar enquanto a porcentagem de progresso for inferior a 100%. Você precisa garantir que o loop não seja infinito, incrementando a porcentagem a cada iteração.

Conceitos Chave: `WHILE` loop, Condição Baseada em Variável, Prevenção de Infinite Loop.

Enunciado do Exercício:

  • 1. Defina a variável $progresso_percentual = 0;.
  • 2. Utilize um laço `WHILE` para executar o bloco de comandos enquanto $progresso_percentual for menor que 100.
  • 3. Dentro do loop, imprima o progresso atual: "Download em andamento: [PERCENTUAL]%" e adicione 10 à variável $progresso_percentual usando um operador de atribuição.
  • 4. Após o loop, imprima "Download concluído!".

Foco Estrutural: O aluno deve entender que o `WHILE` testa a condição antes de cada execução e deve garantir que algo dentro do bloco mude o estado da condição para `FALSE`, evitando um loop infinito.

Resolução em PHP (Loop WHILE)

<?php $progresso_percentual = 0; echo "<strong>Iniciando Download...</strong><br>"; // Executa enquanto a condição for TRUE while ($progresso_percentual < 100) { echo "Download em andamento: {$progresso_percentual}%<br>"; // O incremento é essencial para que a condição se torne FALSE em algum momento. $progresso_percentual += 10; } echo "<strong>Download concluído!</strong><br>"; ?>

Exercício 3: Processamento de Itens de Carrinho (`FOREACH`)

Problema: Calcular o valor total de um array associativo (`$carrinho_itens`) com produtos (Chave: Nome; Valor: Preço).

Conceitos Chave: `FOREACH` com Chave e Valor, Array Associativo, Acumulação de Soma.

Enunciado do Exercício:

  • 1. Crie um array associativo $carrinho_itens com pelo menos três itens (Ex: 'Maçã' => 2.50, 'Banana' => 1.99).
  • 2. Crie a variável $total = 0;.
  • 3. Utilize um laço `FOREACH` para iterar sobre $carrinho_itens, capturando o nome do produto como chave e o preço como valor.
  • 4. Dentro do loop, imprima a chave e o valor do item, e acumule o preço na variável $total.
  • 5. Após o loop, exiba o $total do carrinho.

Foco Estrutural: O aluno deve saber como o `FOREACH` simplifica a iteração de arrays, especialmente ao acessar tanto a chave quanto o valor (`foreach ($array as $chave => $valor)`).

Resolução em PHP (Loop FOREACH)

<?php $carrinho_itens = [ 'Maçã' => 2.50, 'Banana' => 1.99, 'Pera' => 3.00, 'Uva' => 8.50 ]; $total = 0; echo "<strong>Itens no Carrinho:</strong><br>"; // Itera sobre chave ($produto) e valor ($preco) foreach ($carrinho_itens as $produto => $preco) { echo "Produto: {$produto} | Preço: R\$ " . number_format($preco, 2, ',', '.') . "<br>"; // Acumulação da soma $total += $preco; } echo "<strong>Valor Total: R\$ " . number_format($total, 2, ',', '.') . "</strong><br>"; ?>

Exercício 4: Controle de Fluxo Dentro do Loop (`CONTINUE` e `BREAK`)

Problema: Processar uma lista de 10 números, mas aplicar regras de controle. Se o número for ímpar, ele deve ser pulado. Se o número for 8, a repetição deve ser interrompida imediatamente.

Conceitos Chave: `FOR`, `CONTINUE`, `BREAK`, Condicionais.

Enunciado do Exercício:

  • 1. Use um `FOR` loop que conte de 1 a 10.
  • 2. Dentro do loop, use uma condição (`IF`) para verificar se o número atual é ímpar. Se for, utilize o comando `CONTINUE` para ignorar a impressão e ir para a próxima iteração.
  • 3. Use uma segunda condição (`IF`) para verificar se o número atual é igual a 8. Se for, utilize o comando `BREAK` para abortar o loop completamente.
  • 4. Se o número for par e não for 8, imprima o número.

Foco Estrutural: Entender que `CONTINUE` pula a iteração atual, e `BREAK` encerra totalmente o loop.

Resolução em PHP (BREAK e CONTINUE)

<?php echo "<strong>Números Processados (Apenas Pares, Parada no 8):</strong><br>"; for ($i = 1; $i <= 10; $i++) { // 2. Se for ímpar, pula para a próxima iteração, ignorando o código abaixo. if ($i % 2 !== 0) { echo "Número {$i} é ímpar, pulando. <br>"; continue; } // 3. Se for 8, encerra o loop completamente. if ($i === 8) { echo "Número {$i} atingido, quebrando o loop. <br>"; break; } // 4. Imprime apenas se for par e não for 8 echo "Número Par processado: <strong>{$i}</strong><br>"; } ?>

Exercício 5: Confirmação de Execução Mínima (`DO WHILE`)

Problema: Você deve garantir que a ação (registro de log) seja executada pelo menos uma vez, mesmo que a condição de repetição falhe na primeira vez.

Conceitos Chave: `DO WHILE` loop, Execução Mínima.

Enunciado do Exercício:

  • 1. Defina a variável $contador = 10;.
  • 2. Utilize a estrutura `DO WHILE`.
  • 3. Dentro do bloco `DO`, imprima a mensagem: "Log registrado. Contador atual: [VALOR]" e decremente o contador ($contador--).
  • 4. Defina a condição `WHILE` como $contador < 10 (o que é falso, já que ele começa em 10).

Raciocínio Estrutural: Explique por que a mensagem de log foi impressa uma vez, apesar da condição `WHILE` ter sido `FALSE` na primeira verificação.

Resolução em PHP (Loop DO WHILE)

<?php $contador = 10; echo "<strong>Execução DO WHILE:</strong><br>"; do { // 3. Este bloco é executado ANTES da condição ser checada pela primeira vez. echo "Log registrado. Contador atual: {$contador}<br>"; $contador--; } while ($contador < 10); // 4. A condição é 9 < 10 (TRUE). Se $contador fosse 10, a condição seria FALSE. // Raciocínio Estrutural: // A mensagem de log foi impressa uma vez porque no 'DO WHILE' o bloco de comandos ('DO') // é executado uma primeira vez ANTES de a condição ('WHILE') ser avaliada. // O loop só para após a primeira verificação da condição. ?>

Exercício 6: Iteração sobre Arquivos (Loop Prático)

Problema: Simular a leitura do conteúdo de um diretório, onde a leitura depende de um `WHILE` loop para ler arquivo por arquivo até o fim.

Conceitos Chave: `WHILE`, Manipulação de Arquivos/Diretórios (Conceitual).

Enunciado do Exercício:

  • 1. Crie (conceitualmente) um código que simule a abertura de um diretório e atribua o recurso a uma variável $identificador_diretorio.
  • 2. Utilize um laço `WHILE` cuja condição seja a leitura sequencial de arquivos do diretório (Ex: while ($arquivo = readdir($identificador_diretorio))).
  • 3. Dentro do loop, utilize echo para exibir o nome de cada $arquivo lido.

Raciocínio Estrutural: O que determina a condição de parada do `WHILE` neste contexto de leitura de arquivos ou diretórios? (Dica: A leitura de uma linha de arquivo, ou a leitura de um diretório, retorna `FALSE` ao atingir o fim).

O WHILE executa o comando de leitura e testa o resultado. // Neste exemplo, simulamos a atribuição sequencial do array. while ( $arquivo = ($indice_leitura < count($arquivos_simulados)) ? $arquivos_simulados[$indice_leitura++] : false ) { // O readdir real retornaria FALSE no final, encerrando o loop. if ($arquivo === false) { break; } // 3. Exibe o nome do arquivo echo "Arquivo lido: {$arquivo}<br>"; } // Raciocínio Estrutural: // A condição de parada do WHILE neste contexto (como com readdir() ou fgets()) é determinada // quando a função de leitura atinge o fim do recurso (diretório ou arquivo) e retorna o valor // que é avaliado como FALSE (como NULL, 0, ou FALSE explícito). A atribuição ($arquivo = readdir(...)) // ocorre, e o resultado da atribuição é usado para avaliar o teste do loop. ?>
