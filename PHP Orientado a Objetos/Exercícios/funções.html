PHP: Funções (Functions)

Reutilização de Código, Parâmetros, Escopo e Retorno.

Resumo: Funções em PHP

As funções são blocos de código encapsulados sob uma estrutura única, projetados para executar um objetivo específico, permitindo a reutilização de código. Em PHP, uma função é declarada usando o operador `function` seguido pelo nome, que deve começar obrigatoriamente com uma letra.

As fontes destacam os seguintes aspectos das funções que devem ser explorados nos exercícios:

  • Reusabilidade: Evitar reescrever o mesmo código várias vezes.
  • Propósito Único: Uma função deve ter um propósito particular.
  • Parâmetros: Receber dados externos para alterar seu comportamento.
  • Retorno vs. Saída (`return` vs. `echo`): É mais comum retornar um valor do que apenas exibi-lo.
  • Escopo: Variáveis declaradas dentro de uma função são locais (localmente *scoped*) e só são acessíveis dentro dela.

6 Exercícios sobre Funções (Functions) em PHP

Exercício 1: Cálculo e Retorno de Valor (Função Básica)

Problema: Criar uma função reutilizável que receba o peso e a altura e retorne o valor do IMC calculado (IMC = peso / (altura * altura)).

Conceitos Chave: Criação de Função (`function`), Parâmetros, Palavra-chave `return`.

Enunciado do Exercício:

  • 1. Crie uma função chamada calculaIMC que aceite dois parâmetros numéricos: $peso e $altura.
  • 2. Dentro da função, calcule o IMC usando a fórmula e utilize a instrução `return` para devolver o resultado.
  • 3. Crie duas variáveis externas: $meu_peso = 70; e $minha_altura = 1.75;.
  • 4. Chame a função calculaIMC, passando essas variáveis. Atribua o resultado retornado a uma nova variável $meu_imc.
  • 5. Utilize echo para exibir o valor final de $meu_imc. Por que foi necessário usar echo (ou print) na chamada da função se você usou return dentro dela?

Resolução em PHP (Função Básica)

<?php // 1. Criação da função com parâmetros e retorno function calculaIMC($peso, $altura) { $imc = $peso / ($altura * $altura); return $imc; // 2. Retorna o valor calculado } // 3. Variáveis externas $meu_peso = 70; $minha_altura = 1.75; // 4. Chamada da função e atribuição $meu_imc = calculaIMC($meu_peso, $minha_altura); // 5. Exibição do resultado echo "Meu peso: {$meu_peso}kg, Minha altura: {$minha_altura}m <br>"; echo "Meu IMC calculado é: <strong>" . number_format($meu_imc, 2) . "</strong><br>"; // Explicação: Foi necessário usar 'echo' na chamada da função porque 'return' apenas envia o valor de volta para onde a função foi chamada, // mas não o exibe na tela. O 'echo' é o comando responsável por produzir a saída (output) para o usuário. ?>

Exercício 2: Configuração de Mensagem com Parâmetro Opcional

Problema: Criar uma função que gera uma saudação personalizada (`saudar_usuario`), mas use um nome padrão ("Visitante") se nenhum argumento for fornecido.

Conceitos Chave: Parâmetros com Valor Padrão (*Default Value*).

Enunciado do Exercício:

  • 1. Crie uma função chamada saudar_usuario que aceite um parâmetro $nome.
  • 2. Defina o valor padrão de $nome como "Visitante" dentro da declaração da função.
  • 3. A função deve retornar a *string* formatada: "Olá, [NOME]! Bem-vindo(a) ao sistema."
  • 4. Chame a função duas vezes: a. Uma vez sem passar nenhum argumento; b. Uma vez passando o argumento "Daniel".
  • 5. Exiba o resultado de ambas as chamadas.

Foco Estrutural: O aluno deve reescrever a função anterior, definindo o *default value* do parâmetro `$nome`.

Resolução em PHP (Parâmetro Opcional)

<?php // 1. e 2. Função com parâmetro opcional (Default Value) function saudar_usuario($nome = "Visitante") { // 3. Retorna a string formatada return "Olá, {$nome}! Bem-vindo(a) ao sistema.<br>"; } echo "<strong>Testes de Saudação:</strong><br>"; // 4a. Chamada sem argumento (usa "Visitante") echo saudar_usuario(); // 4b. Chamada com argumento echo saudar_usuario("Daniel"); ?>

Exercício 3: Acumulação de Valor com Variável Estática

Problema: Acumular o total de quilômetros percorridos globalmente a cada chamada da função, utilizando uma variável que persista seu valor entre as chamadas.

Conceitos Chave: Variáveis Estáticas (`static`), Escopo Local e Persistência de Valor.

Enunciado do Exercício:

  • 1. Crie uma função chamada registrar_distancia que receba um parâmetro $quilometros.
  • 2. Dentro da função, declare uma variável estática (static) chamada $total e inicialize-a com 0 (zero).
  • 3. A cada chamada, adicione o valor de $quilometros a $total e exiba (não retorne) o total acumulado.
  • 4. Chame a função três vezes: registrar_distancia(100), registrar_distancia(200), registrar_distancia(50).

Raciocínio Estrutural: Se você tivesse usado uma variável local `$total` em vez de uma variável `static`, qual seria o resultado de cada chamada e por quê?

Resolução em PHP (Variável Estática)

<?php // 1. Função de registro function registrar_distancia($quilometros) { // 2. Variável estática (mantém o valor entre as chamadas) static $total = 0; // 3. Acumulação e exibição $total += $quilometros; echo "Distância registrada: {$quilometros}km. Total acumulado: <strong>{$total}km</strong>.<br>"; } echo "<strong>Registro de Distâncias:</strong><br>"; // 4. Chamadas registrar_distancia(100); registrar_distancia(200); registrar_distancia(50); // Raciocínio Estrutural: // Se fosse usada uma variável local ($total), ela seria reinicializada para 0 em CADA chamada. // Os resultados seriam: 100km, 200km, 50km. A variável local não persiste seu valor fora da execução da função. ?>

Exercício 4: Inversão de Lógica com Passagem por Referência

Problema: Mudar o valor de uma variável externa (`$status_login`) permanentemente dentro de uma função (`alternar_status`) sem precisar reatribuir o resultado.

Conceitos Chave: Passagem de Parâmetros por Referência (`&`).

Enunciado do Exercício:

  • 1. Crie a variável externa $status_login = 'OFFLINE';.
  • 2. Crie uma função chamada alternar_status que aceite o parâmetro $estado por referência (usando & na declaração do parâmetro).
  • 3. A função deve conter uma lógica condicional para mudar o valor de $estado de 'OFFLINE' para 'ONLINE' ou vice-versa.
  • 4. Chame a função alternar_status duas vezes, passando $status_login.
  • 5. Exiba o valor de $status_login após a segunda chamada. Observe que a variável externa foi alterada sem usar o operador de atribuição fora da função.

Resolução em PHP (Passagem por Referência)

<?php // 1. Variável externa $status_login = 'OFFLINE'; echo "Status Inicial: <strong>{$status_login}</strong><br>"; // 2. Função aceitando parâmetro por referência (&) function alternar_status(&$estado) { // 3. Lógica de inversão, alterando a variável original if ($estado === 'OFFLINE') { $estado = 'ONLINE'; } else { $estado = 'OFFLINE'; } } // 4. Chamadas alternar_status($status_login); // $status_login agora é 'ONLINE' echo "Status após 1ª chamada: <strong>{$status_login}</strong><br>"; alternar_status($status_login); // $status_login agora é 'OFFLINE' echo "Status após 2ª chamada: <strong>{$status_login}</strong><br>"; // A variável externa foi alterada diretamente porque ela foi passada por referência. ?>

Exercício 5: Criação de um *Handler* de Erros (Propósito Único)

Problema: Criar uma função específica (`isInputEmpty`) que apenas valide se uma *string* de entrada (`$input`) é vazia e retorne o resultado (verdadeiro ou falso), aderindo ao princípio de ter um propósito particular.

Conceitos Chave: Propósito Único, `empty()` (Função nativa), Retorno Booleano.

Enunciado do Exercício:

  • 1. Crie uma função chamada isInputEmpty que aceite uma variável $input como parâmetro.
  • 2. A função deve usar a função nativa empty() para verificar se $input está vazia e retornar o resultado booleano (TRUE se estiver vazia, FALSE caso contrário).
  • 3. Crie as variáveis $nome_submetido = ""; e $email_submetido = "teste@email.com";.
  • 4. Utilize a função isInputEmpty em dois comandos if: a. Se isInputEmpty($nome_submetido) retornar TRUE, exiba "Erro: Nome é obrigatório." b. Se isInputEmpty($email_submetido) retornar TRUE, exiba "Erro: Email é obrigatório."

Foco Estrutural: Explique por que delegar essa verificação de vazio a uma função separada aumenta a reutilização do código em sua aplicação.

Resolução em PHP (Propósito Único e Reutilização)

<?php // 1. e 2. Função de propósito único: apenas checar se está vazio. function isInputEmpty($input) { return empty($input); } // 3. Variáveis de teste $nome_submetido = ""; $email_submetido = "teste@email.com"; echo "<strong>Resultados da Validação:</strong><br>"; // 4a. Teste do nome if (isInputEmpty($nome_submetido)) { echo "Erro: Nome é obrigatório.<br>"; } // 4b. Teste do email if (isInputEmpty($email_submetido)) { echo "Erro: Email é obrigatório.<br>"; } else { echo "Email validado com sucesso.<br>"; } // Foco Estrutural: // Delegar essa verificação a uma função separada aumenta a reutilização porque a lógica de checagem de vazio // pode ser usada em qualquer parte da aplicação (validação de formulário, validação de URL, checagem de variáveis, etc.) // sem precisar reescrever 'return empty($variavel)' repetidamente. Isso torna o código mais limpo e fácil de manter. ?>

Exercício 6: Funções com Número Variável de Argumentos

Problema: Criar uma função de registro de logs (`registrarLog`) que pode receber de um a quatro parâmetros (*strings* que descrevem o erro), e deve conseguir lidar com qualquer quantidade e exibi-los.

Conceitos Chave: Argumentos Variáveis (Obtenção Dinâmica de Argumentos).

Enunciado do Exercício:

  • 1. Crie uma função chamada registrarLog que não declare parâmetros na sua assinatura (mas esteja pronta para recebê-los).
  • 2. Dentro da função, use a função nativa func_get_args() para obter todos os argumentos passados e armazene-os em uma variável $mensagens.
  • 3. Utilize um laço `FOR` para iterar sobre o array $mensagens, exibindo cada mensagem de log com um prefixo "LOG: ".
  • 4. Chame a função duas vezes com diferentes quantidades de argumentos: a. registrarLog("Erro Crítico", "Falha no Banco de Dados"); b. registrarLog("Aviso", "Memória baixa", "Servidor lento");

Foco Estrutural: O aluno deve usar as funções dinâmicas (`func_get_args`) para trabalhar com o número variável de argumentos, conforme visto nos exemplos do Capítulo 1.

Resolução em PHP (Argumentos Variáveis)

<?php // 1. Função sem declaração de parâmetros function registrarLog() { // 2. Obtém todos os argumentos passados dinamicamente $mensagens = func_get_args(); echo "<strong>Novo Log Iniciado:</strong><br>"; // 3. Itera sobre o array de mensagens for ($i = 0; $i < count($mensagens); $i++) { echo "LOG: {$mensagens[$i]}<br>"; } echo "----<br>"; } // 4a. Chamada com 2 argumentos registrarLog("Erro Crítico", "Falha no Banco de Dados"); // 4b. Chamada com 3 argumentos registrarLog("Aviso", "Memória baixa", "Servidor lento"); ?>
