Estruturas de Entrada e Saída em PHP

5 Exercícios práticos para dominar Input/Output.

Resumo

O tema Estruturas de Entrada e Saída (Input/Output) é fundamental em PHP, pois permite que o programa receba dados (entrada) e exiba informações para o usuário ou para fins de depuração (saída).

As fontes destacam os seguintes comandos de saída:

  • echo: Comando utilizado para imprimir uma ou mais variáveis no console.
  • print: Função que imprime uma *string* no console.
  • var_dump(): Imprime o conteúdo de uma variável de forma explanatória, muito útil para *debug*, mostrando o tipo e o valor dos dados.
  • print_r(): Imprime o conteúdo de uma variável em um formato mais legível para o programador, suprimindo os tipos de dados.

Para a Entrada de Dados (*Input*), em um contexto de *website*, as fontes referenciam a captura de dados via formulário HTML usando as superglobais:

  • $_POST: Usada para capturar dados submetidos por formulários.
  • $_GET: Usada para capturar dados na URL, frequentemente usada para mensagens de sucesso.

Abaixo estão 5 exercícios práticos que utilizam esses comandos de entrada e saída para resolver problemas.

5 Exercícios sobre Entrada e Saída em PHP

Exercício 1: Exibição Simples e Concatenação (`echo` / `print`)

Problema: Você precisa gerar uma mensagem de boas-vindas na tela para um cliente, que deve incluir o nome do cliente, o produto comprado e uma quebra de linha HTML para formatação.

Conceitos Chave: `echo`, `print`, Concatenação, Quebra de Linha.

Enunciado do Exercício:

  1. Crie as variáveis $nome_cliente = "Maria"; e $produto = "Curso de PHP";.
  2. Utilize echo para imprimir o nome, uma quebra de linha HTML (<br>), e a mensagem: "Obrigado por adquirir o [PRODUTO]".
  3. Repita a operação com print, usando o caractere de escape de nova linha (\n).

<?php
// 1. Criação das variáveis
$nome_cliente = "Maria";
$produto = "Curso de PHP";

echo "--- Usando echo com <br> ---\n";
// 2. Exibição com echo e quebra de linha HTML
echo $nome_cliente . "<br>";
echo "Obrigado por adquirir o " . $produto . "\n\n";

echo "--- Usando print com \\n ---\n";
// 3. Exibição com print e nova linha
print($produto . " adquirido por " . $nome_cliente . ".\n");
?>

Exercício 2: Captura de Dados via URL (`$_GET`)

Problema: Após um cadastro, o sistema redireciona o usuário com uma mensagem de sucesso na URL (ex: `index.php?status=sucesso`). Você precisa verificar a URL e exibir uma mensagem de confirmação.

Conceitos Chave: `$_GET`, Estrutura `IF`.

Enunciado do Exercício:

  1. Simule o recebimento de dados verificando se $_GET['status'] existe e é igual a "sucesso".
  2. Se a condição for verdadeira, exiba: <p style="color: green;">Cadastro realizado com sucesso!</p>.
  3. Caso contrário, exiba: "Aguardando ação do usuário."

<?php
// Para testar, acesse este script com ?status=sucesso na URL.
// Exemplo: http://localhost/seu_script.php?status=sucesso

// 1. Simulação: Definindo a superglobal para o exemplo funcionar
$_GET['status'] = 'sucesso'; // Comente esta linha para testar o 'else'

// 2. Verificação da variável na URL
if (isset($_GET['status']) && $_GET['status'] == 'sucesso') {
    // 3. Exibição da mensagem de sucesso
    echo '<p style="color: green;">Cadastro realizado com sucesso!</p>';
} else {
    // 4. Exibição da mensagem padrão
    echo "Aguardando ação do usuário.";
}
?>

Exercício 3: Depuração Detalhada de Arrays (`var_dump()`)

Problema: Você precisa inspecionar o conteúdo de um *array* de configurações para verificar o tipo de dado de cada elemento e sua estrutura exata.

Conceitos Chave: `var_dump()` para *debug*, *Array* Associativo.

Enunciado do Exercício:

  1. Crie um *array* $configuracao com: 'versao' => "1.0", 'limite' => 500, e 'ativo' => TRUE.
  2. Utilize var_dump() para exibir o conteúdo da variável.
  3. Responda: Por que var_dump() é superior ao echo para *debugging* de tipagem?

<?php
// 1. Criação do array associativo
$configuracao = [
    'versao' => "1.0",
    'limite' => 500,
    'ativo'  => TRUE
];

// 2. Exibição com var_dump()
var_dump($configuracao);

echo "\n--- Resposta do Raciocínio ---\n";
// 3. Explicação
echo "Não, o 'echo' normal exibiria apenas o valor '1.0', sem indicar que é uma string. \n";
echo "O var_dump() é superior para debugging de tipagem porque ele mostra explicitamente o tipo de cada valor (string, int, bool), o tamanho (para strings) e o valor exato. Isso é crucial para encontrar erros onde, por exemplo, um número está sendo tratado como texto.\n";
?>

Exercício 4: Saída Formatada e Legível (`print_r()`)

Problema: Você precisa exibir o conteúdo de um *array* aninhado de forma legível para um programador, sem a poluição visual dos tipos de dados detalhados.

Conceitos Chave: `print_r()`, *Array* Multidimensional.

Enunciado do Exercício:

  1. Crie um *array* $estoque com a chave 'Frutas' apontando para um sub-array: ['Maçã', 'Banana', 'Laranja'].
  2. Utilize print_r() para exibir o conteúdo completo do *array*.
  3. Raciocínio Estrutural: Compare a saída de print_r() com var_dump(). Quando um é preferível ao outro?

<?php
// 1. Criação do array multidimensional
$estoque = [
    'Frutas' => ['Maçã', 'Banana', 'Laranja']
];

echo "--- Saída com print_r() ---\n";
// 2. Exibição com print_r()
print_r($estoque);

echo "\n--- Raciocínio Estrutural ---\n";
// 3. Explicação
echo "O print_r() é preferível quando você só quer ver a estrutura e os valores de um array de forma limpa e rápida. É ótimo para visualização.\n";
echo "O var_dump() é melhor quando você precisa de uma depuração profunda, especialmente para verificar os tipos exatos dos dados (ex: '5' vs 5) e o tamanho das strings, o que é crucial para encontrar bugs sutis.\n";
?>

Exercício 5: Recebendo Dados de Formulário (`$_POST`)

Problema: Você está construindo o processador para um formulário de contato. Precisa capturar o nome e o telefone submetidos via `POST` e exibi-los em um formato de *ticket*.

Conceitos Chave: `$_POST`, `echo`, Concatenação.

Enunciado do Exercício:

  1. Simule o recebimento de dados via $_POST para os campos cliente_nome e cliente_telefone.
  2. Atribua esses valores a duas variáveis, $nome e $telefone.
  3. Utilize echo para exibir um *ticket* de atendimento formatado.
  4. O que a superglobal $_POST contém e como difere da $_GET?

<?php
// 1. Simulação do recebimento de dados via POST
$_POST['cliente_nome'] = 'Carlos Pereira';
$_POST['cliente_telefone'] = '(11) 98765-4321';

// 2. Atribuição dos valores a variáveis
$nome = $_POST['cliente_nome'];
$telefone = $_POST['cliente_telefone'];

// 3. Exibição do ticket formatado
echo "* TICKET DE ATENDIMENTO *\n";
echo "Nome: " . $nome . "\n";
echo "Telefone: " . $telefone . "\n";

echo "\n--- Raciocínio Estrutural ---\n";
// 4. Explicação
echo "\$_POST é um array associativo que contém os dados enviados ao script através do método HTTP POST. \n";
echo "A principal diferença para \$_GET é que os dados do \$_POST são enviados no corpo da requisição HTTP, tornando-os invisíveis na URL. \$_GET envia os dados diretamente na URL, o que é menos seguro para informações sensíveis.\n";
?>
