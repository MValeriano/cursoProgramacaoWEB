Operadores em PHP: Teoria e Prática

Uma introdução completa com 6 desafios para fixar o conhecimento.

Resumo

As fontes definem Operadores como elementos que auxiliam na lógica, conexão de dados, matemática e qualquer coisa relacionada a operações no código. Eles são divididos em categorias como Operadores de Atribuição (para definir o valor de uma variável), Aritméticos (para cálculos matemáticos), Relacionais (para comparações) e Lógicos (para combinar expressões).

Abaixo, estão 6 exercícios que cobrem os diferentes tipos de operadores essenciais em PHP, projetados para forçar o aluno a pensar em como estruturar a resolução de um problema.

6 Exercícios sobre Operadores em PHP

Exercício 1: Cálculo de Faturamento Bruto (Operadores Aritméticos)

Problema: Você é responsável por calcular o faturamento de um produto vendido por um e-commerce. Você precisa calcular o valor total da venda e o resto da divisão (módulo) após agrupar as unidades em caixas de 7.

Conceitos Chave: Operadores Aritméticos (`+`, `*`, `/`, `%`), Precedência.

Enunciado do Exercício:

  1. Crie as seguintes variáveis: $preco_unitario = 15.50; e $quantidade_vendida = 40;.
  2. Calcule o Faturamento Bruto ($faturamento_bruto) usando o operador de multiplicação.
  3. Calcule o Número de Unidades Restantes após serem empacotadas em caixas de 7, usando o operador Módulo (`%`).
  4. Utilize echo para exibir o Faturamento Bruto e o Número de Unidades Restantes.
  5. Desafio de Raciocínio: Se você tivesse uma variável $desconto = 5; e tentasse calcular $faturamento_bruto - $desconto * 2, o que seria calculado primeiro, e como você usaria parênteses para garantir que a subtração ocorresse antes da multiplicação?

<?php
// 1. Criação das variáveis
$preco_unitario = 15.50;
$quantidade_vendida = 40;

// 2. Cálculo do Faturamento Bruto
$faturamento_bruto = $preco_unitario * $quantidade_vendida;

// 3. Cálculo das Unidades Restantes
$unidades_restantes = $quantidade_vendida % 7;

// 4. Exibição dos resultados
echo "Faturamento Bruto: R$ " . number_format($faturamento_bruto, 2, ',', '.') . "\n";
echo "Número de Unidades Restantes: " . $unidades_restantes . "\n";

echo "\n--- Desafio de Raciocínio ---\n";

// 5. Desafio de Precedência
$desconto = 5;

// Sem parênteses, a multiplicação ocorre primeiro (5 * 2 = 10)
$calculo_sem_parenteses = $faturamento_bruto - $desconto * 2; 
echo "Cálculo sem parênteses (620 - 5 * 2): " . $calculo_sem_parenteses . "\n";

// Com parênteses, a subtração ocorre primeiro (620 - 5 = 615)
$calculo_com_parenteses = ($faturamento_bruto - $desconto) * 2;
echo "Cálculo com parênteses ((620 - 5) * 2): " . $calculo_com_parenteses . "\n";
?>

Exercício 2: Atualização de Contador e Atribuição Simplificada

Problema: Você está desenvolvendo um sistema de pontuação para um jogo. O jogador $pontuacao começa com 100 pontos. Ele ganha 25 pontos em uma fase e depois a pontuação total é dobrada. Você deve usar operadores de atribuição composta para simplificar a manipulação da variável.

Conceitos Chave: Operador de Atribuição (`=`), Operadores de Atribuição Composta (`+=`, `*=`).

Enunciado do Exercício:

  1. Crie a variável $pontuacao e atribua o valor inicial de 100.
  2. Use o operador += para adicionar 25 pontos à $pontuacao (ganho na fase).
  3. Use o operador *= para multiplicar a $pontuacao por 2 (dobrando o valor).
  4. Crie uma nova variável chamada $pontuacao_final e use o operador de atribuição simples (=) para atribuir o valor final da $pontuacao a ela.
  5. Exiba o valor final de $pontuacao_final.

<?php
// 1. Variável inicial
$pontuacao = 100;
echo "Pontuação inicial: " . $pontuacao . "\n";

// 2. Adiciona 25 pontos
$pontuacao += 25; // Equivalente a: $pontuacao = $pontuacao + 25;
echo "Após ganhar 25 pontos: " . $pontuacao . "\n";

// 3. Dobra a pontuação
$pontuacao *= 2; // Equivalente a: $pontuacao = $pontuacao * 2;
echo "Após dobrar: " . $pontuacao . "\n";

// 4. Atribui a uma variável final
$pontuacao_final = $pontuacao;

// 5. Exibe o resultado final
echo "\nPontuação Final do Jogador: " . $pontuacao_final . "\n";
?>

Exercício 3: Verificação de Elegibilidade e Tipagem (Operadores Relacionais)

Problema: Um sistema de segurança precisa verificar se uma chave de acesso é válida. A chave é válida se o $codigo_inteiro é igual em valor E tipo ao $codigo_fornecido. Você também deve testar se o $limite_tentativas (valor 3) foi atingido.

Conceitos Chave: Operador Idêntico (`===`), Operador Menor ou Igual (`<=`), Operadores Relacionais.

Enunciado do Exercício:

  1. Crie as variáveis: $codigo_inteiro = 500; (inteiro) e $codigo_fornecido = "500"; (string).
  2. Crie $tentativas_usadas = 3; e $limite_tentativas = 3;.
  3. Use um IF para testar se $codigo_inteiro é idêntico (===) a $codigo_fornecido. Imprima se são idênticos ou se são iguais, mas de tipos diferentes.
  4. Use um segundo IF para checar se $tentativas_usadas é menor ou igual (<=) a $limite_tentativas.
  5. Raciocínio Estrutural: Explique o resultado do teste no Passo 3. Qual operador (== ou ===) deve ser usado em programação para evitar a conversão automática de tipo de dado pelo PHP?

<?php
// 1. Variáveis de código
$codigo_inteiro = 500;
$codigo_fornecido = "500";

// 2. Variáveis de tentativa
$tentativas_usadas = 3;
$limite_tentativas = 3;

echo "--- Teste de Identidade de Código ---\n";
// 3. Teste de identidade (===)
if ($codigo_inteiro === $codigo_fornecido) {
    echo "Os códigos são IDÊNTICOS (mesmo valor e mesmo tipo).\n";
} else {
    echo "Os códigos NÃO são idênticos. Um é " . gettype($codigo_inteiro) . " e o outro é " . gettype($codigo_fornecido) . ".\n";
}

echo "\n--- Teste de Limite de Tentativas ---\n";
// 4. Teste de menor ou igual (<=)
if ($tentativas_usadas <= $limite_tentativas) {
    echo "O usuário ainda está dentro do limite de tentativas.\n";
} else {
    echo "O usuário excedeu o limite de tentativas.\n";
}

echo "\n--- Raciocínio Estrutural ---\n";
// 5. Explicação
echo "O resultado do Passo 3 é 'NÃO são idênticos' porque, embora o valor seja 500 para ambos, um é do tipo 'integer' e o outro é 'string'.\n";
echo "O operador '===' (idêntico) é mais seguro e deve ser preferido, pois ele verifica tanto o VALOR quanto o TIPO, evitando conversões automáticas que podem levar a bugs.\n";
echo "Se usássemos '==' (igual), o PHP converteria a string '500' para um número e o resultado seria TRUE, o que poderia ser uma falha de segurança.\n";
?>

Exercício 4: Lógica de Combinação de Férias (`AND` e `OR`)

Problema: Você está montando um agendamento de férias. Um funcionário pode tirar férias se ele tiver (A) 30 dias de saldo E não estiver em licença OU se (B) for um gerente.

Conceitos Chave: Operadores Lógicos (`AND` / `&&`, `OR` / `||`), Precedência Lógica (Parênteses).

Enunciado do Exercício:

  1. Crie as variáveis: $dias_saldo = 30;, $em_licenca = TRUE;, $is_gerente = FALSE;.
  2. Crie uma única expressão lógica usando AND e OR dentro de um IF para verificar a regra complexa (Lembre-se de usar parênteses para agrupar as condições obrigatórias).
    Lógica: (($dias_saldo == 30) AND (!$em_licenca)) OR ($is_gerente)
  3. Se a condição for TRUE, imprima "Férias Aprovadas". Caso contrário, imprima "Férias Negadas".
  4. Desafio de Raciocínio: Altere $is_gerente para TRUE e $em_licenca para FALSE. O que acontece com o resultado final do IF e por quê?

<?php
// --- Cenário 1 ---
echo "--- Cenário 1 ---\n";
// 1. Variáveis
$dias_saldo = 30;
$em_licenca = TRUE;
$is_gerente = FALSE;

echo "Dias: $dias_saldo, Licença: " . ($em_licenca ? 'Sim':'Não') . ", Gerente: " . ($is_gerente ? 'Sim':'Não') . "\n";

// 2. Expressão Lógica
// (($dias_saldo == 30) AND (!$em_licenca)) -> (TRUE AND FALSE) -> FALSE
// (FALSE) OR ($is_gerente) -> (FALSE OR FALSE) -> FALSE
if ((($dias_saldo == 30) && (!$em_licenca)) || ($is_gerente)) {
    echo "Resultado: Férias Aprovadas\n";
} else {
    echo "Resultado: Férias Negadas\n";
}

// --- Cenário 2 (Desafio) ---
echo "\n--- Cenário 2 (Desafio de Raciocínio) ---\n";
// 4. Alterando as variáveis
$em_licenca = FALSE;
$is_gerente = TRUE;

echo "Dias: $dias_saldo, Licença: " . ($em_licenca ? 'Sim':'Não') . ", Gerente: " . ($is_gerente ? 'Sim':'Não') . "\n";

// Nova avaliação
// (($dias_saldo == 30) AND (!$em_licenca)) -> (TRUE AND TRUE) -> TRUE
// (TRUE) OR ($is_gerente) -> (TRUE OR TRUE) -> TRUE
if ((($dias_saldo == 30) && (!$em_licenca)) || ($is_gerente)) {
    echo "Resultado: Férias Aprovadas\n";
} else {
    echo "Resultado: Férias Negadas\n";
}

echo "\nExplicação: No cenário 2, ambas as condições principais se tornam verdadeiras. A primeira parte (saldo E não estar em licença) é TRUE, e a segunda parte (ser gerente) também é TRUE. Como o operador OR precisa que apenas UMA das condições seja verdadeira, o resultado final é 'Férias Aprovadas'.\n";
?>

Exercício 5: Contador de Loop e Incremento (Operadores de Incremento)

Problema: Você precisa simular um contador regressivo para um foguete, de 5 a 1. Você deve garantir que a contagem seja impressa antes que o valor da variável seja alterado na memória.

Conceitos Chave: Operador de Pós-Decremento (`$var--`), Pré-Incremento vs. Pós-Incremento.

Enunciado do Exercício:

  1. Crie a variável $countdown = 5;.
  2. Utilize um loop (como WHILE) que se repita enquanto $countdown for maior que 0.
  3. Dentro do loop, imprima o valor de $countdown e utilize o operador de Pós-Decremento (--).
  4. Após o loop, imprima "Decolagem!".
  5. Raciocínio Estrutural: Se você tivesse usado o operador de Pré-Incremento (++$contador) ou Pré-Decremento (--$contador) na linha de echo dentro do loop, como o resultado na tela mudaria em relação ao que foi impresso na primeira iteração?

<?php
// 1. Variável inicial
$countdown = 5;

echo "Iniciando contagem regressiva...\n";

// 2. Loop WHILE
while ($countdown > 0) {
    // 3. Imprime e depois decrementa
    echo $countdown . "...\n";
    $countdown--; // Pós-decremento: usa o valor atual e DEPOIS subtrai 1.
}

// 4. Mensagem final
echo "Decolagem!\n";

echo "\n--- Raciocínio Estrutural ---\n";
echo "Se tivéssemos usado o pré-decremento (--\$countdown) dentro do echo, como em 'echo --\$countdown;', o valor seria alterado ANTES de ser impresso.\n";
echo "Na primeira iteração, ele mudaria de 5 para 4 e então imprimiria '4...'. A contagem na tela seria de 4 a 0, em vez de 5 a 1.\n";
echo "O pós-decremento (\$countdown--) garante que o valor atual (5) seja usado/impresso primeiro, e só então a variável é atualizada para 4 para a próxima verificação do loop.\n";
?>

Exercício 6: Conexão Dinâmica de Texto (Operador String)

Problema: Você precisa construir uma mensagem dinâmica para um cabeçalho de página. A mensagem deve concatenar o nome do usuário com uma mensagem fixa e incluir uma quebra de linha.

Conceitos Chave: Operador String (Concatenação - `.`), Atribuição de String Composta (`.=`).

Enunciado do Exercício:

  1. Crie as variáveis $usuario = "Pedro"; e $boas_vindas = "Seja bem-vindo";.
  2. Use o operador de concatenação (`.`) para criar uma variável $mensagem_final que combine: $boas_vindas + , + $usuario + ! (utilize o caractere de escape \n para simular uma quebra de linha).
  3. Começando com uma $mensagem_log = "Log: ";, use o operador de atribuição de string composta (`.=`) para adicionar (concatenar) a $mensagem_final a $mensagem_log.
  4. Exiba o valor final de $mensagem_log.

<?php
// 1. Variáveis iniciais
$usuario = "Pedro";
$boas_vindas = "Seja bem-vindo";

// 2. Concatenação simples com o operador '.'
$mensagem_final = $boas_vindas . ", " . $usuario . "!\n";

// 3. Concatenação composta com o operador '.='
$mensagem_log = "Log: "; // Inicia a string de log
$mensagem_log .= $mensagem_final; // Adiciona a mensagem final ao log

// 4. Exibe o resultado final
echo $mensagem_log;
?>
