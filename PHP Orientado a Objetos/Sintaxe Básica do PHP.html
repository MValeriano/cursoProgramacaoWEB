Módulo de Curso: Sintaxe Básica do PHP para Iniciantes

Seu primeiro passo no desenvolvimento web de back-end.

1.0 Introdução ao PHP: O que é e Onde Ele Vive?

Bem-vindo ao seu primeiro passo no mundo do desenvolvimento web de back-end! Para construir sites e aplicações web verdadeiramente dinâmicas e interativas, é crucial entender o papel fundamental de linguagens como o PHP. Enquanto tecnologias como HTML e CSS definem a estrutura e a aparência de uma página, o PHP é o motor que trabalha nos bastidores, processando dados, interagindo com bancos de dados e personalizando o conteúdo antes mesmo que ele chegue ao seu navegador. Este módulo foi desenhado para desmistificar esse processo, mostrando como o PHP se tornou a espinha dorsal de uma vasta porção da internet.

O PHP (um acrônimo recursivo para PHP: Hypertext Preprocessor) é uma linguagem de programação de lado do servidor (server-side). Isso o diferencia fundamentalmente de linguagens de lado do cliente (client-side), como HTML, CSS e JavaScript. O código de lado do cliente é executado diretamente no navegador do usuário, mas o código PHP opera de forma diferente: ele é executado no servidor web, tornando sua lógica interna completamente invisível para o visitante do site.

O Fluxo de Execução do PHP:

  1. Um usuário, através de seu navegador, solicita uma página de um site (ex: www.meusite.com/contato.php).
  2. O servidor web recebe a solicitação e encontra o arquivo .php correspondente.
  3. O servidor então executa o código PHP contido nesse arquivo. Esse código pode realizar tarefas como buscar informações de um banco de dados, processar dados de um formulário ou criar conteúdo dinamicamente.
  4. O resultado final da execução do PHP é uma saída em HTML puro.
  5. O servidor envia este HTML gerado para o navegador do usuário, que o renderiza como uma página web padrão.

A relevância do PHP no cenário atual é inegável. Estatísticas mostram que mais de 78% de todos os sites da internet cuja linguagem de back-end é conhecida utilizam PHP. Isso inclui gigantes da tecnologia como o Facebook e a Wikipedia, além de ser a tecnologia por trás do sistema de gerenciamento de conteúdo mais popular do mundo, o WordPress.

Agora que você compreende o papel estratégico do PHP no ecossistema web, vamos mergulhar na sintaxe fundamental que dá vida a toda essa engrenagem.

2.0 A Estrutura Fundamental de um Script PHP

Assim como qualquer idioma, o PHP possui suas próprias regras gramaticais — sua sintaxe — que precisam ser seguidas para que o código funcione corretamente. Esta seção é o seu primeiro passo prático para escrever código PHP funcional, aprendendo como delimitar seus scripts, exibir informações e documentar sua lógica.

2.1 Delimitadores de Código: Abrindo e Fechando o PHP

Todo código PHP deve ser inserido dentro de um par de tags específicas que informam ao servidor onde a execução do PHP começa e termina. Essas tags são <?php para abrir o bloco de código e ?> para fechá-lo.

Qualquer comando PHP que você escrever deve estar contido nesses delimitadores. É uma regra fundamental que cada instrução (ou comando) dentro de um bloco PHP termine com um ponto e vírgula (;).

<?php
// código;
// código;
?>
Dica de Iniciante: O ponto e vírgula (;) é como o ponto final de uma frase em português. Esquecê-lo é um dos erros mais comuns e frustrantes para quem está começando!

2.2 Comandos de Saída: Mostrando Informações na Tela

Para que seu script PHP seja útil, ele precisa gerar uma saída que será enviada ao navegador. O comando mais comum e fundamental para isso é o echo. Ele pode ser usado para exibir texto simples, o valor de variáveis e até mesmo tags HTML.

Vamos ao exemplo clássico de "Olá, Mundo!" para ver o echo em ação:

<?php
echo "Olá, Mundo!";
?>

Saída: Olá, Mundo!

2.3 Comentários: Deixando Anotações no Código

Comentários são trechos de texto em seu código que são completamente ignorados pelo servidor. Eles são essenciais para documentar sua lógica, seja para referência futura ou para que outros desenvolvedores possam entender o que seu código faz. O PHP oferece três maneiras de escrever comentários.

  • Comentário de linha única com //: Tudo após as duas barras até o final da linha é considerado um comentário.
  • Comentário de linha única com #: Funciona da mesma forma que o //.
  • Comentário de múltiplas linhas com /* ... */: Permite escrever comentários que se estendem por várias linhas, começando com /* e terminando com */.

Aqui está um exemplo que ilustra os três tipos:

<?php
// Este é um comentário de linha única. A linha abaixo exibe uma saudação.
echo "Olá!";

# Este é outro estilo de comentário de linha única.

/*
Este é um comentário
que abrange múltiplas
linhas. É útil para
explicações mais longas.
*/
echo " Mundo!";
?>

Com a estrutura básica dominada, estamos prontos para o próximo passo essencial: aprender a armazenar e manipular informações. Faremos isso utilizando variáveis, os blocos de construção de qualquer programa.

3.0 Variáveis e Tipos de Dados: As Caixas de Informação do Código

Variáveis são os contêineres fundamentais para armazenar dados em qualquer programa. Pense em uma variável como uma "caixa com uma etiqueta": você dá um nome (a etiqueta) à caixa e guarda uma informação dentro dela. Mais tarde, sempre que precisar daquela informação, basta chamar a caixa pela sua etiqueta.

3.1 Declarando Variáveis

Em PHP, a regra para declarar uma variável é simples e consistente: o nome da variável sempre começa com o símbolo do cifrão ($).

<?php
$saudacao = "Bem-vindo ao curso de PHP!";
echo $saudacao;
?>

Saída: Bem-vindo ao curso de PHP!

3.2 Tipos de Dados Primitivos (Escalares)

Um tipo de dado "escalar" significa que a variável armazena apenas um único valor. O PHP trabalha com vários tipos de dados primitivos, e ele é flexível o suficiente para, na maioria das vezes, entender o tipo de dado com base no valor que você atribui.

  • String: Uma sequência de caracteres, como texto. O valor deve estar entre aspas (simples ou duplas).Exemplo: $nome = "João";
  • Integer: Números inteiros, sem casas decimais.Exemplo: $idade = 30;
  • Float: Números de ponto flutuante, ou seja, números com casas decimais.Exemplo: $preco = 19.99;
  • Boolean: Representa um valor lógico que só pode ser true (verdadeiro) ou false (falso). É muito usado em testes condicionais.Exemplo: $estaLogado = true;
  • NULL: Um tipo especial que representa a ausência intencional de um valor. Uma variável é nula se nenhum valor foi atribuído a ela ou se ela foi explicitamente definida como NULL.Exemplo: $valorNulo = NULL;

3.3 Verificando Tipos de Dados

Durante o desenvolvimento, especialmente ao depurar, pode ser útil verificar qual o tipo de dado e o valor que uma variável contém. A função var_dump() é perfeita para isso, pois ela exibe informações detalhadas sobre uma ou mais variáveis.

<?php
$nome = "Maria";
$numeroDeFilhos = 2;

var_dump($nome);
echo "<br>"; // A tag <br> cria uma quebra de linha em HTML
var_dump($numeroDeFilhos);
?>

Saída:
string(5) "Maria"
int(2)

A saída nos informa que a variável $nome é uma string de 5 caracteres com o valor "Maria", e $numeroDeFilhos é um integer (int) com o valor 2.

Dica de Iniciante: Lembre-se de que os nomes das variáveis em PHP diferenciam maiúsculas de minúsculas! A variável $nome é completamente diferente da variável $Nome. Para evitar dores de cabeça, adote um padrão e seja consistente! A convenção mais comum em PHP é usar camelCase para nomes de variáveis (ex: $numeroDeFilhos).

Agora que sabemos como armazenar dados em "caixas", vamos aprender como realizar operações e manipular essas informações usando os operadores do PHP.

4.0 Operadores: As Ferramentas de Ação do PHP

Operadores são símbolos que nos permitem executar operações em variáveis e valores. Eles são as ferramentas que usamos para tudo, desde realizar cálculos matemáticos simples até fazer comparações lógicas complexas que direcionam o fluxo de nossos programas.

4.1 Operadores Aritméticos

Esses são os operadores que você provavelmente já conhece da matemática. Eles são usados para realizar operações aritméticas básicas.

  • + (Adição)
  • - (Subtração)
  • * (Multiplicação)
  • / (Divisão)
  • % (Módulo - Retorna o resto de uma divisão)
<?php
$soma = 5 + 3; // $soma será 8
$resto = 10 % 3; // 10 dividido por 3 é 3, com resto 1. $resto será 1.
echo "10 dividido por 3 tem um resto de: " . $resto;
?>

Saída: 10 dividido por 3 tem um resto de: 1

4.2 Operadores de Atribuição

O operador de atribuição mais básico é o = (igual), que atribui o valor à direita a uma variável à esquerda. No entanto, existem formas abreviadas que combinam uma operação aritmética com uma atribuição, tornando o código mais conciso.

  • = (Atribuição simples)
  • += (Adiciona e atribui)
  • -= (Subtrai e atribui)
  • *= (Multiplica e atribui)
  • /= (Divide e atribui)
<?php
$numero = 10;
$numero += 5; // Isto é o mesmo que: $numero = $numero + 5;
echo $numero;
?>

Saída: 15

4.3 Operadores de Comparação

Esses operadores são cruciais para a lógica de um programa. Eles são usados para comparar dois valores e o resultado da comparação é sempre um valor booleano: true ou false.

Operador Nome Exemplo Resultado
== Igual $a == $b true se $a é igual a $b após a conversão de tipo.
=== Idêntico $a === $b true se $a é igual a $b e são do mesmo tipo.
!= Diferente $a != $b true se $a não é igual a $b.
!== Não idêntico $a !== $b true se $a não é igual a $b ou não são do mesmo tipo.
> Maior que $a > $b true se $a é maior que $b.
< Menor que $a < $b true se $a é menor que $b.
Nota Importante: A diferença entre == (igual) e === (idêntico) é uma fonte comum de bugs. Sempre prefira === para uma comparação mais estrita e segura, pois ela não apenas compara os valores, mas também os tipos de dados.

Veja a diferença na prática:

<?php
// Comparação "igual" (==) - Converte os tipos antes de comparar.
var_dump(5 == "5"); // O PHP converte a string "5" para um número.

echo "<br>";

// Comparação "idêntica" (===) - Não converte, os tipos devem ser os mesmos.
var_dump(5 === "5"); // Um é integer, o outro é string.
?>

Saída:
bool(true)
bool(false)

4.4 Operadores Lógicos

Operadores lógicos são usados para combinar múltiplas declarações condicionais.

  • && ou and (E): Retorna true somente se ambas as condições forem verdadeiras.
  • || ou or (OU): Retorna true se pelo menos uma das condições for verdadeira.
<?php
$idade = 25;
$temHabilitacao = true;

// A condição só será verdadeira se a idade for 18 ou mais E a habilitação for verdadeira.
if ($idade >= 18 && $temHabilitacao == true) {
echo "Pode dirigir.";
}
?>

Saída: Pode dirigir.

Dominar os operadores nos deu a capacidade de fazer perguntas ao nosso código ('isto é igual a aquilo?'). Agora, com as estruturas de controle, vamos aprender a dar ordens com base nas respostas, transformando nosso script de uma lista de tarefas em um programa que pensa e reage.

5.0 Estruturas de Controle: Direcionando o Fluxo do Seu Código

Por padrão, um script PHP é executado sequencialmente, de cima para baixo. No entanto, raramente queremos que um programa faça a mesma coisa todas as vezes. As estruturas de controle nos permitem alterar esse fluxo, seja para tomar decisões com base em certas condições ou para repetir um bloco de código várias vezes.

5.1 Estruturas Condicionais

As estruturas condicionais executam diferentes blocos de código com base no resultado de uma expressão booleana (true ou false).

  • if, else, elseif Esta é a estrutura condicional mais comum. Ela permite que você execute um código se uma condição for verdadeira e, opcionalmente, execute outro código se ela for falsa. Usando uma analogia do dia a dia: "se estiver chovendo, leve um guarda-chuva; senão, leve óculos de sol." A cláusula elseif permite testar múltiplas condições em sequência.
  • switch A estrutura switch é uma alternativa mais limpa e organizada para uma longa cadeia de if/elseifs. Ela é ideal quando você precisa comparar o valor de uma única variável com vários valores possíveis e executar um código diferente para cada caso.

5.2 Laços de Repetição (Loops)

Loops são usados para executar o mesmo bloco de código repetidamente, enquanto uma determinada condição for atendida.

  • while O loop while diz: "Execute este bloco de código repetidamente enquanto uma condição for verdadeira." A condição é verificada antes de cada execução do bloco.
    Use quando: você precisa repetir uma ação, mas não sabe de antemão quantas vezes, como ao ler linhas de um arquivo.
  • do...while Este loop é muito semelhante ao while, com uma diferença crucial: ele garante que o bloco de código seja executado pelo menos uma vez. A condição é verificada depois de cada execução.
    Use quando: em situações raras onde a primeira execução é garantida, como um menu que deve ser exibido pelo menos uma vez.
  • for O loop for é ideal para quando você sabe exatamente quantas vezes precisa repetir uma ação. Ele combina a inicialização de um contador, a condição de continuação e a atualização do contador em uma única linha.
    Use quando: você sabe exatamente o número de repetições, como ao exibir os 10 produtos mais vendidos.
  • foreach Esta é a forma mais fácil, segura e recomendada para percorrer cada item de um array. Em vez de gerenciar um contador manual, o foreach simplesmente pega um array e executa um bloco de código para cada elemento dentro dele.
    Use quando: sempre que precisar iterar sobre todos os itens de um array. É a sua escolha padrão para listas.

A menção ao foreach nos leva diretamente ao nosso próximo tópico essencial. Agora que sabemos como controlar o fluxo, vamos aprender a trabalhar com coleções de dados usando a estrutura mais importante para isso: os arrays.

6.0 Arrays: Coleções de Dados Organizados

Até agora, nossas variáveis armazenaram apenas um valor de cada vez. No entanto, muitas vezes precisamos trabalhar com uma coleção de valores relacionados. Um array é um tipo especial de variável que pode conter múltiplos valores em uma única estrutura, funcionando como uma lista de compras, uma lista de nomes de alunos ou uma coleção de configurações.

6.1 Arrays Indexados

Arrays indexados (ou numéricos) são o tipo mais simples de array. Eles usam índices numéricos para identificar cada elemento da coleção. É importante lembrar que, na maioria das linguagens de programação, incluindo o PHP, a contagem de índices começa em 0.

<?php
// Cria um array indexado com três frutas
$frutas = ["Maçã", "Banana", "Laranja"];

// Acessa o segundo elemento do array (índice 1)
echo "A segunda fruta na lista é: " . $frutas[1];
?>

Saída: A segunda fruta na lista é: Banana

6.2 Arrays Associativos

Arrays associativos são mais descritivos. Em vez de usar índices numéricos, eles usam strings nomeadas, chamadas de "chaves" (keys), para identificar cada valor. Isso torna o código mais legível, pois as chaves podem descrever o que o valor representa.

<?php
// Cria um array associativo com informações de um aluno
$aluno = [
"nome" => "Carlos",
"idade" => 22,
"curso" => "Engenharia"
];

// Acessa os valores usando suas chaves
echo $aluno["nome"] . " tem " . $aluno["idade"] . " anos.";
?>

Saída: Carlos tem 22 anos.

6.3 Funções Úteis para Arrays

O PHP oferece um vasto conjunto de funções para manipular arrays. Aqui estão duas das mais essenciais para começar:

  • count($array): Retorna o número de elementos em um array. É útil para saber o tamanho da sua coleção.
  • array_push($array, "novo_valor"): Adiciona um ou mais elementos ao final de um array indexado.

O PHP vem com muitas funções prontas não apenas para arrays, mas para vários outros tipos de dados, que podem economizar muito tempo e esforço. Elas são como atalhos poderosos que veremos a seguir.

7.0 Funções Básicas Essenciais

Uma das grandes vantagens do PHP é sua extensa biblioteca de funções incorporadas (built-in functions). São pedaços de código reutilizáveis que já vêm com a linguagem para realizar tarefas comuns, desde manipular texto até gerar números aleatórios. Usá-las economiza tempo, reduz a chance de erros e torna seu código mais eficiente.

7.1 Funções de String

Desde contar caracteres até encontrar e substituir texto, estas funções são o seu canivete suíço para qualquer manipulação de strings.

  • strlen($string): Retorna o comprimento (número de caracteres) de uma string.
  • strtoupper($string): Converte todos os caracteres de uma string para maiúsculas.
  • strtolower($string): Converte todos os caracteres de uma string para minúsculas.
  • str_replace("buscar", "substituir", $string): Substitui todas as ocorrências de um texto por outro dentro de uma string.
<?php
$frase = "Eu gosto de maçãs.";
$nova_frase = str_replace("maçãs", "bananas", $frase);
echo $nova_frase;
?>

Saída: Eu gosto de bananas.

7.2 Funções de Números

Estas funções ajudam a realizar verificações e operações matemáticas de forma rápida e segura.

  • is_numeric($valor): Verifica se uma variável contém um número ou uma string numérica. Retorna true ou false.
  • round($numero): Arredonda um número de ponto flutuante (float) para o inteiro mais próximo.
  • rand(min, max): Gera um número inteiro aleatório dentro do intervalo especificado (inclusivo).

7.3 Funções de Array

Além das que já vimos, aqui estão mais algumas ferramentas poderosas para gerenciar suas coleções de dados.

  • in_array("valor", $array): Verifica se um valor existe em um array.
  • array_merge($array1, $array2): Combina (mescla) dois ou mais arrays em um único array.
  • array_reverse($array): Retorna um novo array com os elementos do array original na ordem inversa.

Agora que você tem um arsenal de ferramentas para manipular dados, vamos aplicá-las em um dos cenários mais importantes do desenvolvimento web: processar dados enviados por usuários através de formulários HTML.

8.0 Manipulando Formulários HTML com PHP

A manipulação de formulários é a ponte entre a interação do usuário no front-end e a lógica de processamento no back-end. É aqui que o PHP realmente brilha, permitindo que você colete, valide e processe informações enviadas por visitantes, como em formulários de contato, login, cadastro e pesquisas.

8.1 Métodos de Envio: GET vs. POST

Quando um formulário HTML é submetido, os dados são enviados ao servidor usando um de dois métodos principais, especificados no atributo method da tag <form>:

  • GET: Envia os dados do formulário anexados diretamente à URL. Os dados ficam visíveis na barra de endereço do navegador (ex: pagina.php?nome=joao&idade=30). É ideal para funcionalidades como pesquisas ou filtros, onde você pode querer compartilhar ou salvar a URL com os parâmetros.
  • POST: Envia os dados do formulário no corpo da requisição HTTP. Os dados não são visíveis na URL, tornando este método mais seguro e essencial para o envio de informações sensíveis, como senhas, ou grandes volumes de dados.

8.2 Recebendo os Dados com Superglobais

O PHP torna extremamente fácil acessar os dados enviados por um formulário através de variáveis especiais chamadas superglobais. Elas são arrays associativos que estão disponíveis em qualquer parte do seu script.

  • $_GET: Um array associativo contendo os dados enviados via método GET.
  • $_POST: Um array associativo contendo os dados enviados via método POST.

As chaves desses arrays correspondem aos atributos name dos campos do seu formulário HTML.

8.3 Exemplo Prático e a Importância da Segurança

Vamos criar um formulário simples de contato e o script PHP para processá-lo.

Passo 1: Crie o Formulário HTML

Este formulário usa o método POST e envia os dados para um script chamado processar.php.

<form action="processar.php" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="username">
    <br><br>
    <label for="email">Email:</label>
    <input type="email" id="email" name="email">
    <br><br>
    <button type="submit">Enviar</button>
</form>

Passo 2: Crie o Script PHP (processar.php)

Este script verifica se o formulário foi enviado via POST, coleta os dados e os exibe.

ALERTA DE SEGURANÇA

A regra número um da programação web é: NUNCA confie nos dados do usuário. Qualquer informação vinda de um formulário pode ter sido manipulada. Antes de usar ou exibir esses dados, você deve sempre validá-los e "higienizá-los" (sanitized).

Uma das principais ameaças é o Cross-Site Scripting (XSS), onde um invasor injeta scripts maliciosos (como JavaScript) nos campos de um formulário.

Para se proteger contra isso, use a função htmlspecialchars(). Ela converte caracteres especiais (como < e >) em suas respectivas entidades HTML, tornando-os inofensivos e impedindo que o navegador os interprete como código.

// Arquivo: processar.php
<?php
// Verifica se o formulário foi submetido usando o método POST
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Coleta os dados do formulário e higieniza a saída para prevenir XSS
    $nome = htmlspecialchars($_POST['username']);
    $email = htmlspecialchars($_POST['email']);

    echo "<h1>Dados Recebidos</h1>";
    echo "Olá, " . $nome . "!<br>";
    echo "Seu email é: " . $email;
} else {
    // Se o acesso não foi via POST, informa que o método está incorreto
    echo "O formulário não foi enviado corretamente.";
}
?>
