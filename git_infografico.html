Um guia simples, visual e didático

O que é um repositório?

É como uma "pasta inteligente" onde o Git acompanha tudo o que muda. Assim você pode voltar no tempo, comparar versões e trabalhar com segurança.

Tipos mais usados

  • GitHub – mais popular do mundo
  • GitLab – muito usado em empresas
  • Bitbucket – integração com Jira

Principais comandos Git

Iniciar um repositório local

git init

Clonar um repositório online

git clone URL_DO_REPOSITORIO

Enviar alterações para o repositório online

git push

Baixar atualizações do repositório online

git pull

Configurando o Git em máquinas públicas

Configuração deve ser apenas no repositório, nunca global.

git config user.name "Seu Nome"
git config user.email "seu.email@exemplo.com"

O que é uma Branch?

É como criar uma cópia paralela do seu projeto para trabalhar sem mexer na versão principal.

Criar uma branch:

git branch nome-da-branch

Trocar de branch:

git checkout nome-da-branch
