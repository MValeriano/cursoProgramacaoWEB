Feirinha Virtual - Talentos Locais

Guia interativo para estilização CSS

Instruções Iniciais

Objetivo do Exercício

Criar um arquivo CSS completo para estilizar uma página web de uma feirinha virtual de talentos locais, utilizando os conceitos aprendidos sobre CSS (seletores, propriedades).

Arquivo base (HTML fornecido)

Você deverá utilizar exatamente o HTML enviado, sem alterar a estrutura.

Adicionei IDs e Classes (Inclusive no HTML do arquivo Javascript) para facilitar a vida de vocês.

O trabalho de vocês é usar o arquivo style.css e adicionar ao arquivo HTML disponibilizado, contendo todas as regras de estilo necessárias para que a página fique com aparência da imagem enviada.

Use também o script.js pois temos os cards que deveram ser estilizados.

Dicas:

  • Organização: Comece estilizando do elemento pai para os filhos;
  • Flexbox: Lembre-se que o flexbox funciona no elemento pai para controlar os filhos;
  • Especificidade: Use seletores específicos para não afetar outros elementos;
  • Teste: Verifique constantemente no navegador as mudanças;
  • Utilize o Validador HTML para testar o código HTML;
  • Da mesma forma utilize o Validador de CSS para testar o código CSS.

Obs: As animações não serão necessárias, mas se quiser adicionar alguma, estão na documentação Propriedades/transform.html, Propriedades/FilterEEfects.html e Propriedades/trnasicoesEanimacoes.html (podendo usar somente uma ou combinar algumas delas);

As propriedades usadas estão nos arquivos abaixo, para consulta:

  • Propriedades/box_model.html
  • Propriedades/background.html
  • Propriedades/gradiente.html
  • Propriedades/borda.html
  • Propriedades/fonte.html
  • Propriedades/texto.html
