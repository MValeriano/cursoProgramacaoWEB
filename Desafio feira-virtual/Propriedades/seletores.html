Seletores CSS

Este guia cobre a maioria dos seletores CSS que você usará no desenvolvimento web moderno!

Tabela de Referência Rápida

Categoria Seletores Principais Uso Comum
Básicos .class, #id, element, * Estilos fundamentais
Relacionamento (espaço), >, +, ~ Navegação no DOM
Atributo [attr], [attr=value], [attr^=value] Seleção por características
Pseudo-classes :hover, :focus, :nth-child() Interatividade e posição
Pseudo-elementos ::before, ::after, ::first-letter Conteúdo gerado e formatação

Dicas de Performance

  1. Evite seletores muito específicos - .nav ul li a é menos eficiente que .nav-link
  2. Prefira classes sobre seletores de elemento para reutilização
  3. Use > quando possível para limitar o escopo de busca
  4. Evite o seletor universal * em regras complexas
  5. Mantenha os seletores simples - navegadores os leem da direita para a esquerda

Seletores Básicos

Seletor de Classe (.class)

Descrição: Seleciona todos os elementos com class="intro"

CSS:

.intro {
    color: blue;
    font-size: 16px;
}

Exemplo HTML:

<p class="intro">Este parágrafo será azul</p>
<div class="intro">Esta div também será azul</div>

Múltiplas Classes (.class1.class2)

Descrição: Seleciona elementos que têm AMBAS as classes

CSS:

.btn.primary {
    background-color: #007bff;
    color: white;
}

Exemplo HTML:

<button class="btn">Botão normal</button>
<button class="btn primary">Botão primário (selecionado)</button>
<button class="primary btn">Também selecionado</button>

Classe Descendente (.class1 .class2)

Descrição: Seleciona elementos com .title que estão dentro de elementos com .card

CSS:

.card .title {
    font-weight: bold;
    margin-bottom: 10px;
}

Exemplo HTML:

<div class="card">
    <h2 class="title">Título do card (selecionado)</h2>
</div>
<h2 class="title">Título normal (não selecionado)</h2>

Seletor de ID (#id)

Descrição: Seleciona o elemento único com id="header"

CSS:

#header {
    background-color: #333;
    color: white;
    padding: 20px;
}

Exemplo HTML:

<header id="header">Cabeçalho principal</header>

Seletor Universal (*)

Descrição: Seleciona TODOS os elementos da página

CSS:

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Seletor de Elemento (elemento)

Descrição: Seleciona todos os elementos <p>

CSS:

p {
    line-height: 1.6;
    margin-bottom: 1em;
}

Elemento com Classe (element.class)

Descrição: Seleciona apenas elementos <p> com a classe highlight

CSS:

p.highlight {
    background-color: yellow;
    padding: 10px;
}

Exemplo HTML:

<p class="highlight">Este parágrafo será amarelo</p>
<div class="highlight">Esta div NÃO será amarela</div>

Seletores Múltiplos (element,element)

Descrição: Seleciona todos os elementos h1, h2 e h3

CSS:

h1, h2, h3 {
    font-family: 'Arial', sans-serif;
    color: #333;
}

Seletores de Relacionamento

Descendente (elemento elemento)

Descrição: Seleciona todos os elementos ul dentro de nav, e todos os p dentro de article

CSS:

nav ul {
    list-style: none;
    padding: 0;
}

article p {
    text-align: justify;
}

Exemplo HTML:

<nav>
    <ul> <!-- Selecionado -->
        <li>Item 1</li>
    </ul>
</nav>
<ul> <!-- Não selecionado -->
    <li>Item 2</li>
</ul>

Filho Direto (elemento > elemento)

Descrição: Seleciona apenas elementos p que são filhos DIRETOS de div

CSS:

div > p {
    border-left: 3px solid blue;
    padding-left: 10px;
}

Exemplo HTML:

<div>
    <p>Este parágrafo é selecionado (filho direto)</p>
    <section>
        <p>Este NÃO é selecionado (neto)</p>
    </section>
</div>

Irmão Adjacente (element + element)

Descrição: Seleciona o primeiro p que vem IMEDIATAMENTE após um h2

CSS:

h2 + p {
    font-weight: bold;
    margin-top: 0;
}

Exemplo HTML:

<h2>Título</h2>
<p>Este parágrafo é selecionado</p>
<p>Este NÃO é selecionado</p>

Irmão Geral (element1 ~ element2)

Descrição: Seleciona TODOS os elementos p que vêm após um h2 (não necessariamente imediatamente)

CSS:

h2 ~ p {
    color: #666;
    font-style: italic;
}

Exemplo HTML:

<h2>Título</h2>
<div>Outro conteúdo</div>
<p>Este parágrafo é selecionado</p>
<p>Este também é selecionado</p>

Seletores de Atributo

Atributo Genérico ([attribute])

Descrição: Seleciona elementos que possuem o atributo (independente do valor)

CSS:

[target] {
    border: 2px dashed orange;
}

[disabled] {
    opacity: 0.5;
    cursor: not-allowed;
}

Exemplo HTML:

<a href="#" target="_blank">Link com target</a>
<button disabled>Botão desabilitado</button>

Atributo com Valor Exato ([attribute=value])

Descrição: Seleciona elementos onde o atributo tem exatamente o valor especificado

CSS:

[type="submit"] {
    background-color: green;
    color: white;
}

[lang="en"] {
    font-style: italic;
}

Exemplo HTML:

<input type="submit" value="Enviar">
<input type="button" value="Cancelar">
<p lang="en">English text</p>

Atributo Contém Palavra ([attribute~=value])

Descrição: Seleciona elementos onde o atributo contém a palavra especificada

CSS:

[title~="important"] {
    border: 2px solid red;
}

Exemplo HTML:

<p title="very important text">Texto importante</p>
<p title="important notice">Aviso importante</p>
<p title="not-important">Não é importante</p>

Atributo Começa Com ([attribute|=value])

Descrição: Seleciona elementos onde o atributo começa com o valor ou valor seguido de hífen

CSS:

[lang|="en"] {
    quotes: '"' '"' "'" "'";
}

Exemplo HTML:

<p lang="en">English</p>
<p lang="en-US">American English</p>
<p lang="en-GB">British English</p>
<p lang="pt">Português (não selecionado)</p>

Atributo Começa Com String ([attribute^=value])

Descrição: Seleciona elementos onde o atributo começa com a string especificada

CSS:

a[href^="https"] {
    color: green;
}

a[href^="mailto:"] {
    color: purple;
}

Exemplo HTML:

<a href="https://exemplo.com">Site seguro</a>
<a href="http://exemplo.com">Site normal</a>
<a href="mailto:email@exemplo.com">Enviar email</a>

Atributo Termina Com ([attribute$=value])

Descrição: Seleciona elementos onde o atributo termina com a string especificada

CSS:

a[href$=".pdf"] {
    background: url('pdf-icon.png') no-repeat left center;
    padding-left: 20px;
}

img[src$=".jpg"] {
    border: 2px solid #ccc;
}

Exemplo HTML:

<a href="documento.pdf">Download PDF</a>
<a href="planilha.xlsx">Download Excel</a>
<img src="foto.jpg">

Atributo Contém Substring ([attribute*=value])

Descrição: Seleciona elementos onde o atributo contém a substring em qualquer posição

CSS:

a[href*="google"] {
    background-color: #f0f0f0;
}

div[class*="col-"] {
    float: left;
    padding: 10px;
}

Exemplo HTML:

<a href="https://google.com">Google</a>
<a href="https://maps.google.com">Google Maps</a>
<div class="col-6">Coluna 6</div>
<div class="col-12">Coluna 12</div>

Pseudo-classes

Interação do Usuário

/* Link ativo (enquanto clicado) */
a:active {
    color: red;
}

/* Checkbox/radio selecionado */
input:checked {
    border-color: blue;
}

/* Elemento desabilitado */
input:disabled {
    background-color: #f5f5f5;
}

/* Elemento vazio */
div:empty {
    display: none;
}

/* Elemento habilitado */
input:enabled {
    border: 1px solid #ccc;
}

/* Elemento em foco */
input:focus {
    border-color: #007bff;
    box-shadow: 0 0 5px rgba(0,123,255,0.5);
}

/* Mouse sobre o elemento */
button:hover {
    background-color: #0056b3;
    transform: translateY(-2px);
}

/* Link não visitado */
a:link {
    color: blue;
}

/* Link visitado */
a:visited {
    color: purple;
}

Seleção de Posição

/* Primeiro filho */
li:first-child {
    font-weight: bold;
}

/* Último filho */
li:last-child {
    border-bottom: none;
}

/* Primeiro do tipo */
p:first-of-type {
    font-size: 1.2em;
}

/* Último do tipo */
p:last-of-type {
    margin-bottom: 0;
}

/* Enésimo filho */
li:nth-child(odd) {  /* Ímpares */
    background-color: #f9f9f9;
}

li:nth-child(even) { /* Pares */
    background-color: #fff;
}

tr:nth-child(3n) {   /* A cada 3 */
    background-color: #f0f0f0;
}

/* Enésimo do tipo */
p:nth-of-type(2) {
    font-style: italic;
}

/* Único filho */
div:only-child {
    text-align: center;
}

/* Único do tipo */
p:only-of-type {
    color: #666;
}

Formulários

/* Entrada válida */
input:valid {
    border-color: green;
}

/* Entrada inválida */
input:invalid {
    border-color: red;
}

/* Entrada obrigatória */
input:required {
    border-left: 3px solid orange;
}

/* Entrada opcional */
input:optional {
    border-left: 3px solid #ccc;
}

/* Entrada somente leitura */
input:read-only {
    background-color: #f8f8f8;
}

/* Entrada editável */
input:read-write {
    background-color: white;
}

/* Dentro do range */
input:in-range {
    color: green;
}

/* Fora do range */
input:out-of-range {
    color: red;
}

/* Placeholder */
input::placeholder {
    color: #999;
    font-style: italic;
}

Outras Pseudo-classes

/* Negação */
div:not(.special) {
    opacity: 0.8;
}

/* Elemento raiz */
:root {
    --cor-principal: #007bff;
    --fonte-base: 16px;
}

/* Elemento alvo (âncora) */
:target {
    background-color: yellow;
}

/* Seleção do usuário */
::selection {
    background-color: #007bff;
    color: white;
}

/* Marcador de lista */
::marker {
    color: blue;
    font-weight: bold;
}
