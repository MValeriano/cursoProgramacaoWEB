Unidades de Medida CSS

Essas unidades oferecem flexibilidade poderosa para criar designs responsivos, acessíveis e consistentes em CSS.

Tabela de Referência Rápida

Unidade Tipo Relativo a Uso Recomendado
px Absoluta Pixel do dispositivo Bordas, sombras, elementos pequenos
% Relativa Elemento pai Layouts fluidos, grids
em Relativa Tamanho da fonte do elemento Componentes escaláveis
rem Relativa Tamanho da fonte do :root Sistema de design consistente
vw/vh Relativa Viewport width/height Layouts de tela cheia
vmin/vmax Relativa Viewport menor/maior dimensão Elementos responsivos
ch Relativa Largura do caractere "0" Limitação de texto, inputs
cm/in/mm Absoluta Unidades físicas Impressão, mídia física

Dicas de Boas Práticas

  • Estabeleça um sistema base no :root com font-size: 16px (ou 62.5% para cálculo mais fácil)
  • Use REM para sistema de design - cria consistência em todo o projeto
  • Combine unidades - use % para layout, rem para espaçamento, vw/vh para elementos de tela cheia
  • Prefira unidades relativas para acessibilidade - usuários podem aumentar o tamanho da fonte
  • Use clamp() para tipografia responsiva: font-size: clamp(1rem, 2.5vw, 2rem)
  • Teste em diferentes viewports - especialmente unidades viewport em dispositivos móveis
  • Considere acessibilidade - unidades relativas funcionam melhor com zoom do navegador

Unidades de Medida Absolutas

As unidades de comprimento absoluto são fixas e aparecem exatamente com o tamanho especificado. São mais indicadas para mídia impressa.

px (Pixel)

.pixel-example {
    width: 300px;
    height: 200px;
    font-size: 16px;
    border: 1px solid #000;
}

cm (Centímetro)

.centimeter-example {
    width: 10cm;
    height: 5cm;
    margin: 1cm;
    font-size: 0.5cm;
}

in (Polegada)

.inch-example {
    width: 4in;  /* ≈ 10.16cm */
    height: 2in; /* ≈ 5.08cm */
    padding: 0.5in;
}

mm (Milímetro)

.millimeter-example {
    width: 100mm;
    height: 50mm;
    border: 2mm solid red;
}

pt (Ponto) - 1pt = 1/72in

.point-example {
    font-size: 12pt; /* Comum em impressão */
    line-height: 14pt;
    margin: 10pt;
}

pc (Pica) - 1pc = 12pt

.pica-example {
    font-size: 1pc; /* 12pt */
    width: 6pc;     /* 72pt */
}

Unidades de Medida Relativas

As unidades de comprimento relativo especificam um comprimento relativo a outra propriedade.

% (Porcentagem)

.percentage-example {
    width: 50%;         /* 50% da largura do elemento pai */
    height: 25%;        /* 25% da altura do elemento pai */
    font-size: 150%;    /* 150% do tamanho da fonte do elemento pai */
    margin: 10% 5%;     /* 10% da largura do pai para top/bottom, 5% para left/right */
}

.container {
    width: 800px;
    height: 400px;
}

.container .child {
    width: 50%;   /* 400px */
    height: 25%;  /* 100px */
}

em

Relativo ao tamanho da fonte do elemento atual.

.em-example {
    font-size: 16px;
    padding: 1em;       /* 16px */
    margin: 2em;        /* 32px */
    line-height: 1.5em; /* 24px */
}

.nested-em {
    font-size: 20px;
}

.nested-em .child {
    font-size: 1.2em;   /* 24px (20px × 1.2) */
    padding: 0.5em;     /* 12px (24px × 0.5) */
}

/* Problema com em aninhado */
.problem-em {
    font-size: 16px;
}

.problem-em .level1 {
    font-size: 1.5em; /* 24px */
}

.problem-em .level1 .level2 {
    font-size: 1.5em; /* 36px (24px × 1.5) - Pode ser indesejado! */
}

rem (Root EM)

Relativo ao tamanho da fonte do elemento raiz (html).

:root {
    font-size: 16px; /* Padrão da maioria dos navegadores */
}

.rem-example {
    font-size: 1rem;    /* 16px */
    padding: 1rem;      /* 16px */
    margin: 2rem;       /* 32px */
    width: 20rem;       /* 320px */
}

/* Não sofre do problema de aninhamento */
.consistent-rem .level1 {
    font-size: 1.5rem; /* 24px */
}

.consistent-rem .level1 .level2 {
    font-size: 1.5rem; /* 24px - Consistente! */
}

vh e vw (Viewport Height e Width)

.viewport-example {
    width: 50vw;        /* 50% da largura da viewport */
    height: 75vh;       /* 75% da altura da viewport */
    font-size: 5vw;     /* 5% da largura da viewport */
    margin: 2vh 3vw;    /* 2% da altura e 3% da largura da viewport */
}

.full-screen {
    width: 100vw;
    height: 100vh;
}

.half-viewport {
    width: 50vw;  /* Metade da largura da tela */
    height: 50vh; /* Metade da altura da tela */
}

vmin e vmax

.vmin-vmax-example {
    width: 50vmin;  /* 50% da menor dimensão da viewport */
    height: 75vmax; /* 75% da maior dimensão da viewport */
    font-size: 4vmin; /* Tamanho responsivo baseado na menor dimensão */
}

/* Quadrado que sempre se ajusta à viewport */
.responsive-square {
    width: 50vmin;
    height: 50vmin;
}

/* Texto que se ajusta ao tamanho da tela */
.responsive-text {
    font-size: 5vmin; /* Bom para headings responsivos */
}

ch (Largura do caractere "0")

.ch-example {
    width: 20ch;    /* Largura de 20 caracteres "0" */
    max-width: 60ch; /* Ideal para legibilidade de texto */
    font-family: monospace;
}

/* Ótimo para inputs e textos com limite de caracteres */
.input-field {
    width: 20ch;    /* Espaço para ~20 caracteres */
}

.readable-text {
    max-width: 60ch; /* Linhas com comprimento ideal para leitura */
    line-height: 1.6;
}

ex (Altura x da fonte)

.ex-example {
    font-size: 16px;
    line-height: 2ex;   /* Duas vezes a altura do caractere "x" */
    margin: 1ex;
}

/* Útil para alinhamento vertical preciso */
.vertical-align {
    vertical-align: 0.5ex;
    position: relative;
    top: 0.3ex;
}

MELHORES PRÁTICAS:

1. Use REM para:
   - Tamanhos de fonte
   - Espaçamento (padding, margin)
   - Layout geral

2. Use EM para:
   - Componentes que precisam escalar com seu contexto
   - Margens/paddings relativos ao tamanho da fonte do elemento

3. Use Viewport Units para:
   - Elementos de layout de tela cheia
   - Tipografia responsiva
   - Componentes que devem preencher a viewport

4. Use % para:
   - Layouts de grade
   - Elementos dentro de contêineres com tamanho definido

5. Use CH para:
   - Limitar largura de texto para melhor legibilidade
   - Inputs com limite de caracteres

EVITE:
- Unidades absolutas (cm, in, mm, pt, pc) para telas
- Muitas unidades diferentes no mesmo projeto
*/
            </div>
        </div>
    </div>
</body>
