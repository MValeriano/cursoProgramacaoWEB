Transições e Animações CSS

Essas propriedades são essenciais para criar interfaces modernas, dinâmicas e atraentes, mas devem ser usadas com moderação.

Tabela de Referência Rápida

transition-delay 0.2s, 1s Atraso para iniciar

animation-name fade-in, bounce Nome da @keyframes

Dicas de Performance

  • Prefira transform e opacity - São otimizadas pela GPU
  • Evite animar width e height - Use transform: scale() em vez disso
  • Use will-change para propriedades que você planeja animar
  • Teste em dispositivos móveis - Animações podem ser mais pesadas
  • Considere prefers-reduced-motion para acessibilidade

transition

A propriedade transition é uma shorthand que permite definir a transição entre dois estados de um elemento. É a maneira mais comum de criar animações suaves em CSS.

Sintaxe:

transition: [property] [duration] [timing-function] [delay];

Valores possíveis:

  • Combina até 4 propriedades: transition-property, transition-duration, transition-timing-function, transition-delay
  • Pode definir múltiplas transições separadas por vírgulas

Exemplos:

/* Transição básica - todas as propriedades, 0.3s, easing padrão */
transition: all 0.3s;

/* Transição específica para transform */
transition: transform 0.5s ease-in-out;

/* Múltiplas transições */
transition: opacity 0.3s ease, transform 0.5s cubic-bezier(0.4, 0, 0.2, 1);

/* Com delay */
transition: all 0.4s ease-out 0.1s;

/* Transições diferentes para diferentes propriedades */
transition: 
    background-color 0.2s ease,
    color 0.2s ease,
    transform 0.4s cubic-bezier(0.68, -0.55, 0.265, 1.55);

transition-property

Especifica quais propriedades CSS terão transições aplicadas.

Valores possíveis:

  • all - Todas as propriedades animáveis (padrão)
  • none - Nenhuma propriedade
  • Nomes de propriedades específicas: width, height, opacity, transform, etc.
  • Múltiplas propriedades separadas por vírgulas

Exemplos:

/* Apenas opacity */
transition-property: opacity;

/* Múltiplas propriedades */
transition-property: width, height, background-color;

/* Todas as propriedades */
transition-property: all;

/* Propriedades específicas com prefixo */
transition-property: transform, opacity, box-shadow;

transition-duration

Define por quanto tempo a transição ocorre.

Valores possíveis:

  • <time> - Segundos (s) ou milissegundos (ms)
  • 0s - Sem duração (padrão)
  • Valores separados por vírgulas para múltiplas propriedades

Exemplos:

/* 0.3 segundos */
transition-duration: 0.3s;

/* 500 milissegundos */
transition-duration: 500ms;

/* Durações diferentes para diferentes propriedades */
transition-property: opacity, transform;
transition-duration: 0.2s, 0.5s;

/* Transição rápida */
transition-duration: 0.1s;

/* Transição lenta */
transition-duration: 2s;

transition-timing-function

Define a curva de aceleração da transição (como a animação progride ao longo do tempo).

Valores possíveis:

  • Palavras-chave: ease, linear, ease-in, ease-out, ease-in-out
  • Funções cúbicas de Bézier: cubic-bezier(n,n,n,n)
  • Steps: steps(int, start|end)
  • Valores globais: inherit, initial, unset

Exemplos:

/* Palavras-chave comuns */
transition-timing-function: ease; /* Padrão - começa devagar, acelera, termina devagar */
transition-timing-function: linear; /* Velocidade constante */
transition-timing-function: ease-in; /* Começa devagar */
transition-timing-function: ease-out; /* Termina devagar */
transition-timing-function: ease-in-out; /* Começa e termina devagar */

/* Bézier personalizada */
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); /* Material Design */
transition-timing-function: cubic-bezier(0.68, -0.55, 0.265, 1.55); /* Bounce */

/* Steps para animação frame a frame */
transition-timing-function: steps(4, jump-start);
transition-timing-function: steps(10, end);

/* Diferentes funções para diferentes propriedades */
transition-property: opacity, transform;
transition-timing-function: ease-in, cubic-bezier(0.4, 0, 0.2, 1);

transition-delay

Define quanto tempo esperar antes de iniciar a transição.

Valores possíveis:

  • <time> - Segundos (s) ou milissegundos (ms)
  • 0s - Sem delay (padrão)
  • Valores negativos - Começa a transição imediatamente, mas parte do meio

Exemplos:

/* Delay de 0.2 segundos */
transition-delay: 0.2s;

/* Delay de 500ms */
transition-delay: 500ms;

/* Múltiplos delays */
transition-property: opacity, transform;
transition-delay: 0s, 0.1s;

/* Delay negativo - começa do meio */
transition-delay: -0.3s;

/* Delay longo */
transition-delay: 2s;

animation

Shorthand property para configurar todas as propriedades de animação de uma vez.

Sintaxe:

animation: [name] [duration] [timing-function] [delay] [iteration-count] [direction] [fill-mode] [play-state];

Exemplos:

/* Animação básica */
animation: slide-in 0.5s ease;

/* Com múltiplos parâmetros */
animation: bounce 1s ease-in-out 0.5s infinite alternate;

/* Múltiplas animações */
animation: 
    fade-in 0.8s ease-out,
    slide-up 0.6s cubic-bezier(0.4, 0, 0.2, 1) 0.1s;

/* Todos os parâmetros */
animation: pulse 2s ease-in-out 0s infinite normal both running;

animation-name

Especifica o nome da animação definida com @keyframes.

Valores possíveis:

  • none - Nenhuma animação (padrão)
  • <custom-ident> - Nome personalizado da animação
  • Múltiplos nomes separados por vírgulas

Exemplos:

/* Nome único */
animation-name: slide-in;

/* Múltiplas animações */
animation-name: fade-in, slide-up;

/* Sem animação */
animation-name: none;

/* Nomes descritivos */
animation-name: button-pulse, menu-expand;

animation-duration

Define por quanto tempo um ciclo de animação deve levar.

Valores possíveis:

  • <time> - Segundos (s) ou milissegundos (ms)
  • 0s - Duração zero (padrão)

Exemplos:

/* 0.3 segundos */
animation-duration: 0.3s;

/* 2 segundos */
animation-duration: 2s;

/* Durações diferentes para múltiplas animações */
animation-name: fade-in, slide-up;
animation-duration: 0.5s, 0.8s;

/* Animação muito rápida */
animation-duration: 0.1s;

/* Animação muito lenta */
animation-duration: 5s;

animation-timing-function

Define como a animação progride através de cada ciclo.

Valores possíveis:

  • Mesmos valores que transition-timing-function
  • ease, linear, ease-in, ease-out, ease-in-out
  • cubic-bezier(n,n,n,n)
  • steps(int, start|end)

Exemplos:

/* Timing functions comuns */
animation-timing-function: ease;
animation-timing-function: linear;
animation-timing-function: ease-in-out;

/* Bézier personalizada */
animation-timing-function: cubic-bezier(0.4, 0, 0.2, 1);

/* Steps para animação frame a frame */
animation-timing-function: steps(6, jump-end);

/* Diferentes funções para múltiplas animações */
animation-name: move, fade;
animation-timing-function: ease-in, linear;

animation-delay

Define o atraso antes do início da animação.

Valores possíveis:

  • <time> - Segundos (s) ou milissegundos (ms)
  • 0s - Sem delay (padrão)
  • Valores negativos - Começa imediatamente, mas parte do meio

Exemplos:

/* Delay de 1 segundo */
animation-delay: 1s;

/* Delay de 500ms */
animation-delay: 500ms;

/* Múltiplos delays */
animation-name: first, second;
animation-delay: 0s, 0.5s;

/* Delay negativo */
animation-delay: -0.5s; /* Começa no meio da animação */

/* Delay em cascata */
animation-delay: 0.1s, 0.3s, 0.5s;

animation-iteration-count

Define quantas vezes a animação deve ser executada.

Valores possíveis:

  • <number> - Número de vezes (ex: 1, 2, 3.5)
  • infinite - Repete infinitamente
  • Múltiplos valores separados por vírgulas

Exemplos:

/* Uma vez (padrão) */
animation-iteration-count: 1;

/* Infinitas vezes */
animation-iteration-count: infinite;

/* 3 vezes */
animation-iteration-count: 3;

/* 2.5 vezes (para no meio) */
animation-iteration-count: 2.5;

/* Diferentes contagens para múltiplas animações */
animation-name: pulse, rotate;
animation-iteration-count: infinite, 3;

animation-direction

Define se a animação deve ser reproduzida para frente, para trás ou em ciclos alternados.

Valores possíveis:

  • normal - Reproduz normally (padrão)
  • reverse - Reproduz na direção reversa
  • alternate - Alterna entre normal e reversa a cada ciclo
  • alternate-reverse - Alterna começando com reversa

Exemplos:

/* Direção normal */
animation-direction: normal;

/* Reversa */
animation-direction: reverse;

/* Alterna a cada ciclo */
animation-direction: alternate;

/* Alterna começando reverso */
animation-direction: alternate-reverse;

/* Diferentes direções para múltiplas animações */
animation-name: slide, fade;
animation-direction: alternate, normal;

animation-fill-mode

Define quais valores são aplicados antes e depois da execução da animação.

Valores possíveis:

  • none - Nenhum estilo aplicado (padrão)
  • forwards - Mantém o estilo do último keyframe
  • backwards - Aplica o estilo do primeiro keyframe durante o delay
  • both - Aplica tanto forwards quanto backwards

Exemplos:

/* Mantém o estado final */
animation-fill-mode: forwards;

/* Aplica estado inicial durante delay */
animation-fill-mode: backwards;

/* Ambos - aplica estado inicial e mantém final */
animation-fill-mode: both;

/* Nenhum - volta ao estado original */
animation-fill-mode: none;

/* Diferentes modos para múltiplas animações */
animation-name: enter, exit;
animation-fill-mode: both, forwards;

animation-play-state

Define se a animação está rodando ou pausada.

Valores possíveis:

  • running - Animação rodando (padrão)
  • paused - Animação pausada

Exemplos:

/* Rodando normalmente */
animation-play-state: running;

/* Pausada */
animation-play-state: paused;

/* Controlável via JavaScript */
.element:hover {
    animation-play-state: paused;
}

/* Diferentes estados para múltiplas animações */
animation-name: move, blink;
animation-play-state: running, paused;

@keyframes

Define a sequência de estágios da animação.

Sintaxe:

@keyframes animation-name {
    from {
        /* Estilos iniciais */
    }
    to {
        /* Estilos finais */
    }
}

/* Ou com porcentagens */
@keyframes animation-name {
    0% {
        /* Estilo em 0% */
    }
    50% {
        /* Estilo em 50% */
    }
    100% {
        /* Estilo em 100% */
    }
}

Exemplos:

/* Animação simples de fade */
@keyframes fade-in {
    from {
        opacity: 0;
    }
    to {
        opacity: 1;
    }
}

/* Animação com múltiplos estágios */
@keyframes bounce {
    0% {
        transform: translateY(0);
    }
    50% {
        transform: translateY(-30px);
    }
    100% {
        transform: translateY(0);
    }
}

/* Animação complexa */
@keyframes slide-and-fade {
    0% {
        opacity: 0;
        transform: translateX(-100px);
    }
    50% {
        opacity: 0.5;
        transform: translateX(20px);
    }
    100% {
        opacity: 1;
        transform: translateX(0);
    }
}

/* Múltiplas propriedades */
@keyframes complex-animation {
    0% {
        opacity: 0;
        transform: scale(0.5) rotate(0deg);
    }
    50% {
        opacity: 1;
        transform: scale(1.2) rotate(180deg);
    }
    100% {
        opacity: 1;
        transform: scale(1) rotate(360deg);
    }
}

/* TRANSIÇÕES */

.button {
    padding: 10px 20px;
    background: #2ecc71;
    color: white;
    border: none;
    border-radius: 4px;
    transition: 
        background-color 0.3s ease,
        transform 0.2s cubic-bezier(0.68, -0.55, 0.265, 1.55),
        box-shadow 0.3s ease;

.button:hover {
    background: #27ae60;
    transform: translateY(-2px);
    box-shadow: 0 4px 8px rgba(0,0,0,0.2);

.button:active {
    transform: translateY(0);
    transition-duration: 0.1s;
}

/* ANIMAÇÕES */
@keyframes slide-in {
    from {
        opacity: 0;
        transform: translateX(-100px);
    }
    to {
        opacity: 1;
        transform: translateX(0);
    }

    0%, 20%, 50%, 80%, 100% {
        transform: translateY(0);

        transform: translateY(-30px);

        transform: translateY(-15px);
    }

@keyframes pulse {
    0% {
        transform: scale(1);
        box-shadow: 0 0 0 0 rgba(52, 152, 219, 0.7);
    }

        box-shadow: 0 0 0 10px rgba(52, 152, 219, 0);
    }

        transform: rotate(0deg);
    }

        transform: rotate(360deg);
    }

Acessibilidade:

/* Respeitar preferências de movimento */
@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}
