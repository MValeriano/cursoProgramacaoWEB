Media Queries CSS

As media queries são essenciais para criar experiências web modernas, responsivas e acessíveis em todos os dispositivos e situações.

Tabela de Referência Rápida

Feature Valores Comuns Uso Principal
@media screen and (min-width: 768px) Define blocos de media queries
screen - Aplica apenas para telas
print - Estilos para impressão
speech - Leitores de tela
min-width 768px, 1024px Breakpoints para telas maiores
max-width 767px, 1023px Breakpoints para telas menores
orientation portrait, landscape Orientação do dispositivo
aspect-ratio 16/9, 4/3 Proporção da tela
hover hover, none Suporte a hover
prefers-color-scheme light, dark Preferência de tema
prefers-reduced-motion reduce, no-preference Redução de animações

Dicas de Boas Práticas

  • Mobile First: Comece com estilos para mobile e use min-width
  • Breakpoints comuns: 576px, 768px, 992px, 1200px
  • Teste em dispositivos reais sempre que possível
  • Use unidades relativas (rem, em, %) para melhor responsividade
  • Considere acessibilidade com prefers-reduced-motion
  • Implemente dark mode com prefers-color-scheme
  • Otimize para impressão com @media print

@media

A regra @media é usada para aplicar estilos CSS apenas quando determinadas condições são atendidas. É a base do design responsivo e da adaptação a diferentes dispositivos e preferências do usuário.

Sintaxe:

@media [tipo-de-midia] and (condições) {
  /* regras CSS */
}

Valores possíveis:

  • Tipos de mídia: all, print, screen, speech
  • Condições: diversas features como width, height, orientation, etc.

Exemplos:

/* Para todos os tipos de mídia */
@media all {
  body { font-size: 16px; }
}

/* Apenas para telas */
@media screen {
  .menu { display: flex; }
}

/* Combinação de condições */
@media screen and (min-width: 768px) {
  .container { max-width: 1200px; }
}

/* Múltiplas condições */
@media screen and (min-width: 768px) and (max-width: 1024px) {
  .sidebar { width: 250px; }
}

Tipos de Mídia

screen

Aplica estilos apenas para dispositivos com telas (computadores, tablets, smartphones).

Exemplos:

@media screen {
  body {
    background-color: white;
    color: black;
  }
}

/* Para telas com largura mínima de 768px */
@media screen and (min-width: 768px) {
  .navigation {
    display: flex;
  }
}

/* Para telas com orientação paisagem */
@media screen and (orientation: landscape) {
  .hero {
    height: 100vh;
  }
}

print

Aplica estilos apenas quando a página é impressa.

Exemplos:

@media print {
  /* Esconder elementos não essenciais para impressão */
  .navigation, .sidebar, .ads {
    display: none !important;
  }
 
  /* Garantir bom contraste para impressão */
  body {
    background: white !important;
    color: black !important;
    font-size: 12pt;
  }
 
  /* Links visíveis no papel */
  a::after {
    content: " (" attr(href) ")";
  }
 
  /* Quebras de página adequadas */
  h1, h2, h3 {
    page-break-after: avoid;
  }
 
  .page-break {
    page-break-before: always;
  }
}

speech

Aplica estilos para leitores de tela e dispositivos de síntese de voz.

Exemplos:

@media speech {
  /* Pausas na leitura para melhor compreensão */
  h1 {
    pause: 2s;
  }
 
  h2 {
    pause: 1s;
  }
 
  /* Pronúncia especial para siglas */
  .abbr {
    speak: spell-out;
  }
 
  /* Silenciar elementos decorativos */
  .decorative {
    speak: none;
  }
 
  /* Ditar pontuação */
  .code-block {
    speak-punctuation: code;
  }
}

all

Aplica estilos para todos os dispositivos (valor padrão).

Exemplos:

@media all {
  /* Estilos base que se aplicam a todos os dispositivos */
  * {
    box-sizing: border-box;
  }
 
  html {
    font-family: sans-serif;
  }
}

/* Equivalente a não especificar tipo de mídia */
@media all and (min-width: 768px) {
  .container {
    margin: 0 auto;
  }
}

Features de Mídia Comuns

min-width e max-width

Define breakpoints baseados na largura da viewport.

Exemplos:

/* Mobile First - Começa com estilos para mobile */

/* Tablets (768px e acima) */
@media screen and (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }
 
  .grid {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 2rem;
  }
}

/* Desktop (1024px e acima) */
@media screen and (min-width: 1024px) {
  .container {
    max-width: 1140px;
  }
 
  .grid {
    grid-template-columns: 1fr 1fr 1fr;
  }
 
  .sidebar {
    display: block;
  }
}

/* Desktop grande (1200px e acima) */
@media screen and (min-width: 1200px) {
  .container {
    max-width: 1320px;
  }
}

/* Dispositivos muito pequenos (até 375px) */
@media screen and (max-width: 374px) {
  body {
    font-size: 14px;
  }
 
  .button {
    padding: 0.5rem 1rem;
  }
}

orientation

Detecta a orientação do dispositivo (retrato ou paisagem).

Exemplos:

/* Orientação retrato (altura maior que largura) */
@media screen and (orientation: portrait) {
  .header {
    height: 60px;
  }
 
  .hero-section {
    height: 50vh;
  }
}

/* Orientação paisagem (largura maior que altura) */
@media screen and (orientation: landscape) {
  .header {
    height: 80px;
  }
 
  .hero-section {
    height: 80vh;
  }
 
  /* Para mobile landscape */
  @media screen and (max-width: 896px) and (orientation: landscape) {
    .navigation {
      display: none;
    }
   
    .mobile-menu {
      display: block;
    }
  }
}

aspect-ratio

Define estilos baseados na proporção da viewport.

Exemplos:

/* Proporção 16:9 (widescreen) */
@media screen and (aspect-ratio: 16/9) {
  .video-container {
    padding-bottom: 56.25%; /* 16:9 aspect ratio */
  }
}

/* Proporção 4:3 (antigos monitores) */
@media screen and (aspect-ratio: 4/3) {
  .content {
    max-width: 1024px;
  }
}

/* Proporções mínimas e máximas */
@media screen and (min-aspect-ratio: 16/9) {
  .wide-screen-layout {
    display: flex;
  }
}

@media screen and (max-aspect-ratio: 3/4) {
  .tall-screen-layout {
    display: block;
  }
}

hover

Detecta se o dispositivo suporta hover (como mouse).

Exemplos:

/* Dispositivos com hover (mouse) */
@media (hover: hover) {
  .button:hover {
    background-color: #0056b3;
    transform: translateY(-2px);
  }
 
  .menu-item:hover .submenu {
    display: block;
  }
 
  .card:hover {
    box-shadow: 0 8px 25px rgba(0,0,0,0.15);
  }
}

/* Dispositivos sem hover (touch) */
@media (hover: none) {
  .button:active {
    background-color: #0056b3;
  }
 
  .menu-item:focus .submenu {
    display: block;
  }
 
  /* Melhorar área de toque */
  .touch-element {
    min-height: 44px;
    min-width: 44px;
  }
}

prefers-color-scheme

Detecta a preferência do usuário por tema claro ou escuro.

Exemplos:

/* Tema escuro */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #1a1a1a;
    --bg-secondary: #2d2d2d;
    --text-primary: #ffffff;
    --text-secondary: #b0b0b0;
    --accent-color: #4dabf7;
  }
 
  body {
    background-color: var(--bg-primary);
    color: var(--text-primary);
  }
 
  .card {
    background-color: var(--bg-secondary);
    border: 1px solid #444;
  }
 
  a {
    color: var(--accent-color);
  }
}

/* Tema claro (padrão) */
@media (prefers-color-scheme: light) {
  :root {
    --bg-primary: #ffffff;
    --bg-secondary: #f8f9fa;
    --text-primary: #212529;
    --text-secondary: #6c757d;
    --accent-color: #007bff;
  }
}

/* Sistema automático com fallback */
body {
  background-color: var(--bg-primary);
  color: var(--text-primary);
  transition: background-color 0.3s ease, color 0.3s ease;
}

prefers-reduced-motion

Respeita a preferência do usuário por reduzir animações.

Exemplos:

/* Usuário prefere reduzir movimento */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
 
  /* Alternativas para animações essenciais */
  .fade-in {
    opacity: 1;
    animation: none;
  }
 
  .slide-in {
    transform: translateX(0);
    animation: none;
  }
}

/* Animações normais (apenas se o usuário não as reduz) */
@media (prefers-reduced-motion: no-preference) {
  .fade-in {
    animation: fadeIn 0.5s ease-in;
  }
 
  .slide-in {
    animation: slideIn 0.3s ease-out;
  }
 
  .smooth-scroll {
    scroll-behavior: smooth;
  }
}

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideIn {
  from { transform: translateX(-100%); }
  to { transform: translateX(0); }
}
