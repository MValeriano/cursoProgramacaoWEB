Propriedades de Filtros e Efeitos CSS

Essas propriedades são essenciais para criar interfaces modernas e visualmente atraentes!

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
filter blur(), grayscale(), brightness() Efeitos visuais em elementos
backdrop-filter blur(), saturate() Efeitos no fundo atrás do elemento
mix-blend-mode multiply, screen, overlay Mistura entre elemento e fundo
background-blend-mode overlay, multiply Mistura entre imagens de fundo
opacity 0.0 a 1.0 Transparência do elemento
visibility visible, hidden Controle de visibilidade

Dicas de Uso Prático

Performance:

  • Use backdrop-filter com moderação (pode ser pesado)
  • Prefira opacity sobre visibility para animações
  • Combine filtros para efeitos complexos

Compatibilidade:

  • Verifique suporte para backdrop-filter em navegadores antigos
  • Use @supports para fallbacks:
@supports (backdrop-filter: blur(10px)) {
    .glass-effect {
        backdrop-filter: blur(10px);
    }
}

@supports not (backdrop-filter: blur(10px)) {
    .glass-effect {
        background-color: rgba(255, 255, 255, 0.9);
    }
}

Casos de Uso Comuns:

  • Glassmorphism: backdrop-filter: blur()
  • Modo escuro: filter: invert() hue-rotate()
  • Efeitos hover: filter com transition
  • Overlays: opacity com visibility

filter

A propriedade filter aplica efeitos gráficos como desfoque, mudança de cor e outros a um elemento. É comumente usada em imagens, mas funciona em qualquer elemento.

Valores possíveis:

  • none - Sem filtro (padrão)
  • blur() - Desfoque gaussiano
  • brightness() - Brilho
  • contrast() - Contraste
  • drop-shadow() - Sombra projetada
  • grayscale() - Escala de cinza
  • hue-rotate() - Rotação de matiz
  • invert() - Inversão de cores
  • opacity() - Opacidade
  • saturate() - Saturação
  • sepia() - Efeito sépia
  • url() - Filtro SVG personalizado

Exemplos:

/* Múltiplos filtros */
.image {
    filter: brightness(1.2) contrast(0.8) saturate(1.5);
}

/* Desfoque */
.blurred {
    filter: blur(5px);
}

/* Escala de cinza */
.grayscale {
    filter: grayscale(100%);
}

/* Sombra projetada */
.shadow-effect {
    filter: drop-shadow(10px 10px 5px rgba(0,0,0,0.5));
}

/* Efeito sépia */
.vintage {
    filter: sepia(80%);
}

/* Inversão de cores */
.inverted {
    filter: invert(100%);
}

/* Rotação de matiz */
.hue-shift {
    filter: hue-rotate(90deg);
}

/* Combinação complexa */
.artistic {
    filter: contrast(1.5) brightness(0.9) saturate(1.2) hue-rotate(-10deg);
}

backdrop-filter

A propriedade backdrop-filter aplica efeitos de filtro à área behind de um elemento, criando efeitos de vidro fosco (glassmorphism).

Valores possíveis:

  • Mesmos valores da propriedade filter
  • Funciona apenas em elementos com fundo semi-transparente

Exemplos:

/* Efeito de desfoque no fundo */
.glass-effect {
    background-color: rgba(255, 255, 255, 0.2);
    backdrop-filter: blur(10px);
}

/* Múltiplos efeitos no fundo */
.frosted-glass {
    backdrop-filter: blur(20px) brightness(0.8) contrast(1.2);
}

/* Efeito de vidro colorido */
.colored-glass {
    background-color: rgba(100, 100, 255, 0.3);
    backdrop-filter: blur(15px) saturate(180%);
}

/* Header com efeito glassmorphism */
.header {
    background-color: rgba(255, 255, 255, 0.1);
    backdrop-filter: blur(8px) saturate(160%);
    border-bottom: 1px solid rgba(255, 255, 255, 0.2);
}

/* Modal com fundo desfocado */
.modal-overlay {
    background-color: rgba(0, 0, 0, 0.5);
    backdrop-filter: blur(5px);
}

mix-blend-mode

A propriedade mix-blend-mode especifica como o conteúdo de um elemento deve se misturar com o conteúdo do elemento pai e com seu plano de fundo.

Valores possíveis:

  • normal, multiply, screen, overlay
  • darken, lighten, color-dodge, color-burn
  • hard-light, soft-light, difference, exclusion
  • hue, saturation, color, luminosity

Exemplos:

/* Texto que se mistura com o fundo */
.blend-text {
    mix-blend-mode: multiply;
    color: #ff0000;
}

/* Imagem com blend mode */
.blend-image {
    mix-blend-mode: screen;
}

/* Overlay colorido com blend */
.overlay {
    background-color: #00ff00;
    mix-blend-mode: overlay;
}

/* Efeito de duotone */
.duotone {
    mix-blend-mode: multiply;
    background-color: #ff6b6b;
}

/* Texto que corta através do fundo */
.cutout-text {
    color: white;
    mix-blend-mode: difference;
}

/* Efeito de luz */
.light-effect {
    mix-blend-mode: color-dodge;
    background: radial-gradient(circle, yellow, transparent);
}

background-blend-mode

A propriedade background-blend-mode define como as imagens de fundo de um elemento e sua cor de fundo devem se misturar entre si.

Valores possíveis:

  • Mesmos valores de mix-blend-mode

Exemplos:

/* Mistura entre cor e imagem de fundo */
.blended-bg {
    background-image: url('texture.jpg');
    background-color: #3498db;
    background-blend-mode: overlay;
}

/* Múltiplas imagens de fundo com blend */
.multiple-blends {
    background-image: url('pattern.png'), url('gradient.jpg');
    background-blend-mode: multiply, screen;
}

/* Efeito de textura */
.textured {
    background-image: url('noise.png');
    background-color: #2c3e50;
    background-blend-mode: soft-light;
}

/* Gradiente com textura */
.gradient-texture {
    background-image: linear-gradient(45deg, #ff6b6b, #4ecdc4), url('grain.jpg');
    background-blend-mode: overlay;
}

/* Efeito vintage */
.vintage-bg {
    background-image: url('photo.jpg');
    background-color: #8b4513;
    background-blend-mode: luminosity;
}

opacity

A propriedade opacity define a transparência de um elemento, incluindo seu conteúdo.

Valores possíveis:

  • 0.0 - Completamente transparente
  • 1.0 - Completamente opaco (padrão)
  • Valores entre 0.0 e 1.0

Exemplos:

/* Totalmente transparente */
.hidden {
    opacity: 0;
}

/* Semi-transparente */
.semi-transparent {
    opacity: 0.5;
}

/* Quase invisível */
.very-transparent {
    opacity: 0.1;
}

/* Efeito de fade-in */
.fade-in {
    opacity: 0;
    animation: fadeIn 1s forwards;
}

@keyframes fadeIn {
    to {
        opacity: 1;
    }
}

/* Hover com transição de opacidade */
.button {
    opacity: 0.8;
    transition: opacity 0.3s ease;
}

.button:hover {
    opacity: 1;
}

/* Overlay escuro */
.overlay {
    background-color: black;
    opacity: 0.7;
}

visibility

A propriedade visibility especifica se um elemento é visível ou não. Diferente de display: none, o espaço do elemento é preservado quando oculto.

Valores possíveis:

  • visible - Elemento é visível (padrão)
  • hidden - Elemento é invisível, mas ocupa espaço
  • collapse - Para elementos de tabela, remove linhas/colunas

Exemplos:

/* Elemento invisível mas ocupando espaço */
.hidden-element {
    visibility: hidden;
}

/* Elemento visível */
.visible-element {
    visibility: visible;
}

/* Colapso de linha de tabela */
tr.collapsed {
    visibility: collapse;
}

/* Toggle de visibilidade com transição */
.toggle-content {
    visibility: hidden;
    opacity: 0;
    transition: visibility 0s 0.3s, opacity 0.3s ease;
}

.toggle-content.show {
    visibility: visible;
    opacity: 1;
    transition: opacity 0.3s ease;
}

/* Menu dropdown */
.dropdown {
    visibility: hidden;
    position: absolute;
}

.dropdown-trigger:hover + .dropdown {
    visibility: visible;
}

Acessibilidade: Respeitar Preferências

É uma boa prática desativar ou reduzir animações para usuários que solicitaram movimento reduzido em seus dispositivos.

@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}
