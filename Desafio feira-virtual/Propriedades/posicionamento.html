Propriedades de Posicionamento CSS

Estas propriedades são fundamentais para criar layouts complexos e interfaces de usuário interativas em CSS.

Tabela de Referência Rápida

Propriedade Valores Comuns Descrição
position static, relative, absolute, fixed, sticky Método de posicionamento
top auto, length, percentage Distância do topo do ancestral
right auto, length, percentage Distância da direita do ancestral
bottom auto, length, percentage Distância do fundo do ancestral
left auto, length, percentage Distância da esquerda do ancestral
z-index auto, number Ordem de empilhamento
clip auto, rect() Recorte retangular (obsoleto)
clip-path circle(), polygon(), ellipse(), url() Recorte em formas

Dicas de Boas Práticas

  • Use position: relative no contêiner para elementos absolute internos
  • Prefira clip-path em vez de clip - é mais moderno e flexível
  • Use z-index com moderação - crie um sistema consistente de camadas
  • Teste position: sticky em diferentes navegadores (precisa de suporte)
  • Combine top/left com transform para centralização precisa
  • Use position: fixed para elementos que devem sempre estar visíveis
  • Evite z-index muito altos - mantenha entre 0-1000 para maior controle

bottom

A propriedade bottom afeta a posição vertical de um elemento posicionado.

Comportamento por tipo de posicionamento:

  • absolute/fixed: Define a distância da borda inferior do elemento ancestral
  • relative: Move o elemento em relação à sua posição normal
  • sticky: Comporta-se como relative dentro da viewport e como fixed fora
  • static: Não tem efeito

Valores possíveis:

  • auto - O navegador calcula a posição (padrão)
  • length - Valor em px, em, rem, etc. (valores negativos permitidos)
  • percentage - Porcentagem do elemento contêiner (valores negativos permitidos)
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Posicionamento absoluto - 10px do fundo do ancestral */
.absolute-bottom {
    position: absolute;
    bottom: 10px;
    width: 50%;
    border: 3px solid #8AC007;
}

/* Posicionamento fixo - sempre visível no fundo da tela */
.fixed-footer {
    position: fixed;
    bottom: 0;
    left: 0;
    width: 100%;
    background: #333;
    color: white;
    padding: 10px;
}

/* Posicionamento relativo - move 20px para cima da posição normal */
.relative-move {
    position: relative;
    bottom: 20px;
    background: #f0f0f0;
}

/* Posicionamento sticky - gruda no fundo da viewport */
.sticky-bottom {
    position: sticky;
    bottom: 0;
    background: #ffeb3b;
    padding: 10px;
}

clip Obsoleto

A propriedade clip especifica um retângulo para recortar um elemento posicionado absolutamente.

⚠️ OBSOLETO: Esta propriedade está obsoleta e deve ser substituída por clip-path

Valores possíveis:

  • auto - Sem recorte (padrão)
  • shape - Apenas rect(top, right, bottom, left)
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Recorte retangular - mostra apenas 100x100px do canto superior esquerdo */
.clipped-image {
    position: absolute;
    clip: rect(0px, 100px, 100px, 0px);
}

/* Recorte mostrando apenas o centro da imagem */
.center-clip {
    position: absolute;
    clip: rect(50px, 150px, 150px, 50px);
}

/* Múltiplos recortes em elementos diferentes */
.clip-demo-1 { clip: rect(0px, 200px, 100px, 0px); }
.clip-demo-2 { clip: rect(100px, 200px, 200px, 0px); }

clip-path

A propriedade clip-path substitui clip e permite recortar elementos em formas básicas ou SVG.

Valores possíveis:

  • clip-source - URL para um elemento SVG <clipPath>
  • basic-shape - circle(), ellipse(), polygon(), inset()
  • margin-box - Usa a caixa de margem como referência
  • border-box - Usa a caixa de borda como referência
  • padding-box - Usa a caixa de padding como referência
  • content-box - Usa a caixa de conteúdo como referência
  • none - Sem recorte (padrão)
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Forma circular */
.circle-clip {
    clip-path: circle(50%);
}

/* Forma elíptica */
.ellipse-clip {
    clip-path: ellipse(25% 40% at 50% 50%);
}

/* Polígono personalizado */
.polygon-clip {
    clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
}

/* Recorte de inserção */
.inset-clip {
    clip-path: inset(10% 20% 30% 40%);
}

/* Usando SVG clipPath */
.svg-clip {
    clip-path: url(#myClip);
}

/* Animação com clip-path */
.animated-clip {
    clip-path: circle(0% at 50% 50%);
    transition: clip-path 0.5s ease;
}

.animated-clip:hover {
    clip-path: circle(75% at 50% 50%);
}

left

A propriedade left afeta a posição horizontal de um elemento posicionado.

Comportamento por tipo de posicionamento:

  • absolute/fixed: Define a distância da borda esquerda do elemento ancestral
  • relative: Move o elemento em relação à sua posição normal
  • sticky: Comporta-se como relative dentro da viewport e como fixed fora
  • static: Não tem efeito

Valores possíveis:

  • auto - O navegador calcula a posição (padrão)
  • length - Valor em px, em, rem, etc. (valores negativos permitidos)
  • percentage - Porcentagem do elemento contêiner (valores negativos permitidos)
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Posicionamento absoluto - 150px da esquerda do ancestral */
.absolute-left {
    position: absolute;
    left: 150px;
    width: 200px;
    height: 120px;
    border: 3px solid green;
}

/* Menu lateral fixo */
.sidebar {
    position: fixed;
    left: 0;
    top: 0;
    width: 250px;
    height: 100vh;
    background: #2c3e50;
    color: white;
}

/* Movimento relativo - desloca 50px para direita */
.relative-right {
    position: relative;
    left: 50px;
    background: #e74c3c;
}

/* Centralização horizontal com left e transform */
.center-horizontal {
    position: absolute;
    left: 50%;
    transform: translateX(-50%);
}

position

A propriedade position especifica o método de posicionamento de um elemento.

Valores possíveis:

  • static - Posicionamento normal (padrão)
  • relative - Posicionado em relação à sua posição normal
  • absolute - Posicionado em relação ao ancestral posicionado mais próximo
  • fixed - Posicionado em relação à viewport
  • sticky - Alterna entre relative e fixed baseado no scroll
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Posicionamento estático (comportamento normal) */
.static-box {
    position: static;
    background: #ecf0f1;
}

/* Posicionamento relativo - pode usar top, right, bottom, left */
.relative-box {
    position: relative;
    top: 20px;
    left: 30px;
    background: #3498db;
}

/* Posicionamento absoluto - removido do fluxo normal */
.absolute-box {
    position: absolute;
    top: 0;
    right: 0;
    background: #e74c3c;
    color: white;
}

/* Posicionamento fixo - sempre visível na viewport */
.fixed-header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    background: #34495e;
    color: white;
    z-index: 1000;
}

/* Posicionamento sticky - gruda durante o scroll */
.sticky-nav {
    position: sticky;
    top: 0;
    background: #2ecc71;
    padding: 10px;
    z-index: 100;
}

/* Container para posicionamento absoluto */
.container {
    position: relative;
    height: 400px;
    border: 2px dashed #bdc3c7;
}

.container .absolute-child {
    position: absolute;
    bottom: 20px;
    right: 20px;
}

Comportamento por tipo de posicionamento:

  • absolute/fixed: Define a distância da borda direita do elemento ancestral
  • relative: Move o elemento em relação à sua posição normal
  • sticky: Comporta-se como relative dentro da viewport e como fixed fora
  • static: Não tem efeito

Valores possíveis:

  • auto - O navegador calcula a posição (padrão)
  • length - Valor em px, em, rem, etc. (valores negativos permitidos)
  • percentage - Porcentagem do elemento contêiner (valores negativos permitidos)
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Posicionamento absoluto - 150px da direita do ancestral */
.absolute-right {
    position: absolute;
    right: 150px;
    width: 200px;
    height: 120px;
    border: 3px solid green;
}

/* Botão de fechar no canto superior direito */
.close-button {

    right: 10px;
    background: #e74c3c;

    position: fixed;
    right: 20px;

    border: 1px solid #ddd;

/* Movimento relativo para esquerda */

    position: relative;
    right: 25px;
    background: #9b59b6;
}

z-index

A propriedade z-index especifica a ordem de empilhamento (stack order) de um elemento.

Regras importantes:

  • Só funciona em elementos posicionados (absolute, relative, fixed, sticky)
  • Também funciona em itens flex (filhos diretos de display: flex)
  • Elementos com maior z-index ficam na frente
  • Se não especificado, o último elemento no HTML fica na frente

Valores possíveis:

  • auto - Ordem de empilhamento igual aos pais (padrão)
  • number - Número inteiro (positivo ou negativo)
  • initial - Valor padrão
  • inherit - Herda do elemento pai

Exemplos:

/* Elemento atrás do conteúdo */
.background-element {
    position: absolute;
    left: 0px;
    top: 0px;
    z-index: -1;
    opacity: 0.5;
}

/* Sistema de camadas para overlay */
.overlay {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: rgba(0,0,0,0.7);
    z-index: 1000;
}

.modal {
    position: fixed;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    background: white;
    padding: 20px;
    z-index: 1001; /* Acima do overlay */
}

/* Navegação com dropdown */
.navbar {
    position: relative;
    z-index: 100;
}

.dropdown {
    position: absolute;
    top: 100%;
    left: 0;
    z-index: 101; /* Acima da navbar */
}

/* Cards sobrepostos com z-index diferente */
.card-1 {
    position: relative;
    z-index: 1;
    transform: rotate(-5deg);
}

.card-2 {
    position: relative;
    z-index: 2;
    transform: rotate(0deg);
    margin-top: -50px;
}

.card-3 {
    position: relative;
    z-index: 3;
    transform: rotate(5deg);
    margin-top: -50px;
}

/* Z-index negativo para elementos de fundo */
.background-pattern {
    position: absolute;
    z-index: -10;
    opacity: 0.1;
}

                <div class="demo-box bottom-absolute">Absolute Bottom</div>

            </div>
        </div>

                <div class="z-box z-3">z-index: 3</div>
                <div class="z-box z-negative">z-index: -1</div>
            </div>
        </div>

        <!-- Sticky Example -->
        <div class="section">
            <h2>position: sticky</h2>
            <p>Elemento que gruda durante o scroll.</p>
            <div class="sticky-demo">
                Eu sou sticky! Role para baixo para me ver grudar no topo.
            </div>
            <div style="height: 800px; padding: 20px; background: #f8f9fa;">
                <p>Conteúdo para scroll...</p>
                <p>Role para baixo para ver o elemento sticky em ação.</p>
            </div>
        </div>
    </div>
</body>
</html>
