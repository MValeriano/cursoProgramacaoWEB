Propriedades de Tabela CSS

Essas propriedades oferecem controle completo sobre a aparência e layout de tabelas HTML.

Tabela de Referência Rápida

Propriedade Valores Padrão Descrição
border-collapse separate, collapse separate Bordas separadas ou colapsadas
border-spacing length, horizontal vertical 0 Espaço entre células (apenas separate)
caption-side top, bottom, left, right top Posição da legenda
empty-cells show, hide show Exibir células vazias (apenas separate)
table-layout auto, fixed auto Algoritmo de layout

Dicas de Boas Práticas

  • Use border-collapse: collapse para a maioria das tabelas - é mais limpo
  • Prefira table-layout: fixed para tabelas com dados consistentes
  • Use caption-side: bottom para legendas explicativas
  • Combine com empty-cells: hide para dados opcionais
  • Defina larguras específicas em table-layout: fixed para melhor controle
  • Use border-spacing criativamente para designs de cartão em tabelas

border-collapse

A propriedade border-collapse define se as bordas da tabela são separadas ou colapsadas em uma única borda.

Valores possíveis:

  • separate - Bordas separadas (padrão)
  • collapse - Bordas colapsadas
  • inherit - Herda do elemento pai

Características:

  • Quando collapse, as bordas adjacentes são mescladas
  • O espaçamento entre células é removido
  • border-spacing e empty-cells são ignorados

Exemplos:

/* Tabela com bordas separadas */
.separated-table {
    border-collapse: separate;
    border-spacing: 10px;
}

/* Tabela com bordas colapsadas (mais comum) */
.collapsed-table {
    border-collapse: collapse;
}

/* Exemplo prático - tabela moderna */
.modern-table {
    border-collapse: collapse;
    width: 100%;
    font-family: Arial, sans-serif;
}

.modern-table th,
.modern-table td {
    border: 1px solid #ddd;
    padding: 12px;
    text-align: left;
}

.modern-table th {
    background-color: #f2f2f2;
    font-weight: bold;
}

.modern-table tr:nth-child(even) {
    background-color: #f9f9f9;
}

.modern-table tr:hover {
    background-color: #f5f5f5;
}

border-spacing

A propriedade border-spacing define a distância entre as bordas das células adjacentes. Só funciona quando border-collapse: separate.

Valores possíveis:

  • length - Um valor para todas as direções
  • horizontal vertical - Dois valores para horizontal e vertical
  • inherit - Herda do elemento pai

Exemplos:

/* Espaçamento igual em todas as direções */
.spaced-table-1 {
    border-collapse: separate;
    border-spacing: 10px;
}

/* Espaçamento diferente horizontal e vertical */
.spaced-table-2 {
    border-collapse: separate;
    border-spacing: 15px 5px;
}

/* Sem espaçamento */
.no-spacing {
    border-collapse: separate;
    border-spacing: 0;
}

/* Exemplo prático */
.calendar {
    border-collapse: separate;
    border-spacing: 2px;
    width: 100%;
}

.calendar th,
.calendar td {
    border: 1px solid #ccc;
    padding: 8px;
    text-align: center;
    background: white;
}

.calendar th {
    background: #e0e0e0;
}

caption-side

A propriedade caption-side define a posição da legenda () da tabela.

Valores possíveis:

  • top - Acima da tabela (padrão)
  • bottom - Abaixo da tabela
  • left - À esquerda da tabela (experimental)
  • right - À direita da tabela (experimental)
  • inherit - Herda do elemento pai

Exemplos:

/* Legenda acima (padrão) */
.caption-top {
    caption-side: top;
}

/* Legenda abaixo */
.caption-bottom {
    caption-side: bottom;
}

/* Legenda à esquerda (suporte limitado) */
.caption-left {
    caption-side: left;
    text-align: right;
    padding-right: 10px;
}

/* Exemplo prático */
.data-table {
    border-collapse: collapse;
    width: 100%;
    margin: 20px 0;
    caption-side: bottom;
}

.data-table caption {
    font-style: italic;
    color: #666;
    margin-top: 10px;
    caption-side: bottom;
}

.stats-table {
    border-collapse: collapse;
    caption-side: top;
}

.stats-table caption {
    font-weight: bold;
    font-size: 1.2em;
    margin-bottom: 10px;
    text-align: left;
}

empty-cells

A propriedade empty-cells define se devem ser exibidas bordas e fundo em células vazias. Só funciona quando border-collapse: separate.

Valores possíveis:

  • show - Exibe bordas em células vazias (padrão)
  • hide - Oculta bordas em células vazias
  • inherit - Herda do elemento pai

Exemplos:

/* Mostrar células vazias (padrão) */
.show-empty {
    border-collapse: separate;
    empty-cells: show;
}

/* Esconder células vazias */
.hide-empty {
    border-collapse: separate;
    empty-cells: hide;
}

/* Exemplo prático */
.invoice-table {
    border-collapse: separate;
    empty-cells: hide;
    border-spacing: 0;
    width: 100%;
}

.invoice-table td {
    border: 1px solid #000;
    padding: 8px;
}

.invoice-table th {
    border: 1px solid #000;
    padding: 8px;
    background: #f0f0f0;
}

/* Tabela de dados com células opcionais */
.data-grid {
    border-collapse: separate;
    empty-cells: show;
    border-spacing: 1px;
}

.data-grid td:empty {
    background-color: #f9f9f9;
}

table-layout

A propriedade table-layout define o algoritmo usado para layout da tabela.

Valores possíveis:

  • auto - Layout automático (padrão)
  • fixed - Layout fixo
  • inherit - Herda do elemento pai

Características:

  • auto: Largura da tabela é determinada pelo conteúdo
  • fixed: Largura da tabela é determinada pela largura da tabela e colunas
  • fixed é mais rápido para renderização

Exemplos:

/* Layout automático (padrão) */
.auto-layout {
    table-layout: auto;
    width: 100%;
}

/* Layout fixo - mais previsível */
.fixed-layout {
    table-layout: fixed;
    width: 100%;
}

/* Layout fixo com colunas específicas */
.fixed-columns {
    table-layout: fixed;
    width: 100%;
}

.fixed-columns th:nth-child(1),
.fixed-columns td:nth-child(1) {
    width: 20%;
}

.fixed-columns th:nth-child(2),
.fixed-columns td:nth-child(2) {
    width: 30%;
}

.fixed-columns th:nth-child(3),
.fixed-columns td:nth-child(3) {
    width: 50%;
}

/* Exemplo prático para dados tabulares */
.data-table-fixed {
    table-layout: fixed;
    width: 100%;
    border-collapse: collapse;
}

.data-table-fixed th,
.data-table-fixed td {
    border: 1px solid #ddd;
    padding: 8px;
    overflow: hidden;
    text-overflow: ellipsis;
    white-space: nowrap;
}

/* Para conteúdo de tamanho variável */
.data-table-auto {
    table-layout: auto;
    width: 100%;
    border-collapse: collapse;
}

.data-table-auto th,
.data-table-auto td {
    border: 1px solid #ddd;
    padding: 8px;
}
