Gradientes CSS

Gradientes são poderosos para criar designs modernos e atraentes sem a necessidade de imagens!

Tabela de Referência Rápida

Função Uso Principal Características
linear-gradient() Transição linear entre cores Direção reta, mais comum
radial-gradient() Transição circular/elíptica Emana do centro, efeitos de foco
conic-gradient() Transição angular Cores giradas em torno de um ponto
repeating-linear-gradient() Padrões lineares repetitivos Listras, padrões regulares
repeating-radial-gradient() Padrões radiais repetitivos Alvos, círculos concêntricos

Dicas de Boas Práticas

  • Use gradientes sutis para backgrounds profissionais
  • Combine com transparência (rgba) para sobreposições
  • Teste a performance - gradientes complexos podem afetar rendering
  • Use fallbacks para navegadores antigos
  • Experimente com blend-modes para efeitos avançados
  • Considere a acessibilidade - contraste adequado entre texto e fundo

linear-gradient()

A função linear-gradient() cria uma imagem que consiste em uma transição progressiva entre duas ou mais cores ao longo de uma linha reta.

Sintaxe:

background: linear-gradient(direction, color-stop1, color-stop2, ...);

Valores:

  • direction: Pode ser um ângulo (0deg a 360deg) ou palavras-chave (to top, to bottom, to left, to right, to top right, etc.)
  • color-stop: Cor e posição opcional (ex: red 20%, blue 50%)

Exemplos:

/* Gradiente vertical (padrão) */
.gradient-1 {
    background: linear-gradient(red, blue);
}

/* Com direção explícita */
.gradient-2 {
    background: linear-gradient(to right, red, blue);
}

/* Com ângulo */
.gradient-3 {
    background: linear-gradient(45deg, red, blue);
}

/* Múltiplas cores */
.gradient-4 {
    background: linear-gradient(to right, red, orange, yellow, green, blue, indigo, violet);
}

/* Com posições específicas */
.gradient-5 {
    background: linear-gradient(to right, red 0%, yellow 50%, blue 100%);
}

/* Gradiente transparente */
.gradient-6 {
    background: linear-gradient(to bottom, rgba(255,0,0,0), rgba(255,0,0,1));
}

radial-gradient()

A função radial-gradient() cria uma imagem que consiste em uma transição progressiva entre duas ou mais cores que emanam de um ponto central.

Sintaxe:

background: radial-gradient(shape size at position, start-color, ..., last-color);

Valores:

  • shape: ellipse (padrão) ou circle
  • size: closest-side, farthest-side, closest-corner, farthest-corner, ou medidas específicas
  • position: center (padrão), ou coordenadas como top, bottom, left, right, 30% 60%

Exemplos:

/* Radial padrão (elipse no centro) */
.radial-1 {
    background: radial-gradient(red, blue);
}

/* Círculo */
.radial-2 {
    background: radial-gradient(circle, red, blue);
}

/* Com posição específica */
.radial-3 {
    background: radial-gradient(circle at top left, red, blue);
}

/* Com tamanho específico */
.radial-4 {
    background: radial-gradient(circle 50px at center, red, blue);
}

/* Múltiplas cores com posições */
.radial-5 {
    background: radial-gradient(circle, red 0%, yellow 30%, blue 60%);
}

/* Gradiente elíptico com tamanho */
.radial-6 {
    background: radial-gradient(ellipse 100px 50px at center, red, blue);
}

conic-gradient()

A função conic-gradient() cria uma imagem que consiste em uma transição progressiva entre duas ou mais cores giradas em torno de um ponto central.

Sintaxe:

background: conic-gradient(from angle at position, start-color, color-stop, ..., end-color);

Valores:

  • from angle: Ângulo inicial (ex: from 45deg)
  • at position: Posição do centro (ex: at 30% 60%)
  • color-stop: Cor e ângulo opcional (ex: red 0deg, blue 180deg)

Exemplos:

/* Conic básico */
.conic-1 {
    background: conic-gradient(red, blue);
}

/* Com ângulo inicial */
.conic-2 {
    background: conic-gradient(from 45deg, red, blue);
}

/* Com posição do centro */
.conic-3 {
    background: conic-gradient(at 30% 60%, red, blue);
}

/* Múltiplas cores com ângulos */
.conic-4 {
    background: conic-gradient(red 0deg, yellow 90deg, blue 180deg, green 270deg);
}

/* Círculo cromático */
.conic-5 {
    background: conic-gradient(
        red, orange, yellow, green, blue, indigo, violet, red
    );
}

/* Gráfico de pizza */
.conic-6 {
    background: conic-gradient(
        red 0deg 120deg,
        blue 120deg 240deg,
        green 240deg 360deg
    );
}

repeating-linear-gradient()

A função repeating-linear-gradient() é similar à linear-gradient(), mas repete o gradiente para preencher todo o container.

Sintaxe:

background: repeating-linear-gradient(direction, color-stop1, color-stop2, ...);

Características:

  • Repete o padrão de gradiente
  • Útil para criar padrões listrados
  • As posições das cores determinam o tamanho da repetição

Exemplos:

/* Listras horizontais */
.repeating-linear-1 {
    background: repeating-linear-gradient(
        to bottom,
        red,
        red 10px,
        blue 10px,
        blue 20px
    );
}

/* Listras diagonais */
.repeating-linear-2 {
    background: repeating-linear-gradient(
        45deg,
        red,
        red 10px,
        blue 10px,
        blue 20px
    );
}

/* Gradiente suave repetido */
.repeating-linear-3 {
    background: repeating-linear-gradient(
        to right,
        red 0%,
        yellow 10%,
        red 20%
    );
}

/* Múltiplas cores */
.repeating-linear-4 {
    background: repeating-linear-gradient(
        90deg,
        red 0px 20px,
        blue 20px 40px,
        green 40px 60px
    );
}

repeating-radial-gradient()

A função repeating-radial-gradient() é similar à radial-gradient(), mas repete o gradiente para preencher todo o container.

Sintaxe:

background: repeating-radial-gradient(shape size at position, start-color, ..., last-color);

Características:

  • Cria padrões radiais repetitivos
  • Ideal para criar efeitos de alvo ou círculos concêntricos

Exemplos:

/* Círculos concêntricos */
.repeating-radial-1 {
    background: repeating-radial-gradient(
        circle,
        red,
        red 10px,
        blue 10px,
        blue 20px
    );
}

/* Elipses repetidas */
.repeating-radial-2 {
    background: repeating-radial-gradient(
        ellipse 100px 50px,
        red,
        red 10px,
        blue 10px,
        blue 20px
    );
}

/* Gradiente suave radial repetido */
.repeating-radial-3 {
    background: repeating-radial-gradient(
        circle at center,
        red 0%,
        yellow 10%,
        red 20%
    );
}

/* Múltiplos anéis */
.repeating-radial-4 {
    background: repeating-radial-gradient(
        circle,
        transparent 0px 20px,
        red 20px 40px,
        transparent 40px 60px,
        blue 60px 80px
    );
}
