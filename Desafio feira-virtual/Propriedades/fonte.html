Propriedades de Fonte CSS

Essas propriedades são fundamentais para o controle tipográfico em CSS e são usadas em praticamente todos os projetos web.

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
font italic bold 16px/1.5 Arial Shorthand para múltiplas propriedades
font-family "Arial", sans-serif Especifica a família da fonte
font-size 16px, 1rem, 100% Define o tamanho da fonte
font-style normal, italic, oblique Controla o estilo (itálico)
font-weight 400, bold, 700 Controla a espessura (negrito)

Dicas de Boas Práticas

  • Sempre forneça fallbacks na font-family
  • Use unidades relativas (rem, em) para melhor responsividade
  • Mantenha a hierarquia de pesos (100-900) consistente
  • Use a shorthand font para código mais limpo
  • Teste a legibilidade em diferentes tamanhos e pesos

font

A propriedade font é uma propriedade abreviada (shorthand) que permite definir várias propriedades de fonte em uma única declaração.

Sintaxe:

font: [font-style] [font-variant] [font-weight] [font-size]/[line-height] [font-family];

Valores possíveis:

  • Combina valores das propriedades individuais de fonte
  • Pode incluir: font-style, font-variant, font-weight, font-size, line-height, font-family
  • Os valores font-size e font-family são obrigatórios

Exemplos:

/* Sintaxe completa */
p {
    font: italic small-caps bold 16px/1.5 "Arial", sans-serif;
}

/* Apenas tamanho e família */
h1 {
    font: 2rem "Georgia", serif;
}

/* Com line-height */
div {
    font: 14px/1.4 "Helvetica Neue", Arial, sans-serif;
}

/* Com peso e tamanho */
strong {
    font: bold 1.2em "Arial";
}

font-family

A propriedade font-family especifica a família da fonte para um elemento. Pode ser uma lista de fontes ordenadas por preferência.

Valores possíveis:

  • Nomes de fontes específicas: "Arial", "Times New Roman", "Helvetica"
  • Famílias genéricas: serif, sans-serif, monospace, cursive, fantasy
  • Múltiplos valores (fallback): "Fonte Primária", "Fonte Secundária", família-genérica

Exemplos:

/* Fonte específica */
body {
    font-family: "Arial";
}

/* Lista de fallback */
p {
    font-family: "Helvetica Neue", Arial, sans-serif;
}

/* Famílias genéricas */
.code {
    font-family: "Courier New", monospace;
}

.creative {
    font-family: "Comic Sans MS", cursive, sans-serif;
}

/* Fontes com espaços no nome */
h1 {
    font-family: "Times New Roman", Times, serif;
}

font-size

A propriedade font-size define o tamanho da fonte. Pode ser especificado em várias unidades.

Valores possíveis:

  • Unidades absolutas: px, pt, cm, mm, in
  • Unidades relativas: em, rem, %
  • Palavras-chave: xx-small, x-small, small, medium, large, x-large, xx-large
  • Relativas ao viewport: vw, vh
  • Valor relativo: smaller, larger

Exemplos:

/* Pixels (valor fixo) */
.base {
    font-size: 16px;
}

/* EM (relativo ao elemento pai) */
.container {
    font-size: 1.5em; /* 1.5 × tamanho do pai */
}

/* REM (relativo ao elemento raiz) */
.title {
    font-size: 2rem; /* 2 × tamanho do html */
}

/* Porcentagem */
.large {
    font-size: 150%; /* 150% do tamanho do pai */
}

/* Viewport units */
.responsive {
    font-size: 4vw; /* 4% da largura da viewport */
}

/* Palavras-chave */
.small-text {
    font-size: small;
}

.large-text {
    font-size: x-large;
}

font-style

A propriedade font-style especifica o estilo da fonte, principalmente para texto em itálico.

Valores possíveis:

  • normal - Texto normal (padrão)
  • italic - Texto em itálico
  • oblique - Texto inclinado (similar ao itálico)

Exemplos:

/* Normal (remove itálico) */
.normal {
    font-style: normal;
}

/* Itálico tradicional */
.italic {
    font-style: italic;
}

/* Texto inclinado */
.oblique {
    font-style: oblique;
}

/* Uso prático em elementos semânticos */
em {
    font-style: italic;
}

.citation {
    font-style: italic;
}

.technical-term {
    font-style: oblique 10deg; /* Inclinação específica */
}

font-weight

A propriedade font-weight define a espessura ou "peso" da fonte (quão negrito o texto aparece).

Valores possíveis:

  • Palavras-chave: normal, bold, lighter, bolder
  • Valores numéricos: 100 (Thin), 200 (Extra Light), 300 (Light), 400 (Normal), 500 (Medium), 600 (Semi Bold), 700 (Bold), 800 (Extra Bold), 900 (Black)

Exemplos:

/* Palavras-chave */
.normal-text {
    font-weight: normal;
}

.bold-text {
    font-weight: bold;
}

.extra-bold {
    font-weight: bolder;
}

/* Valores numéricos */
.thin {
    font-weight: 100;
}

.light {
    font-weight: 300;
}

.regular {
    font-weight: 400; /* Equivalente a normal */
}

.medium {
    font-weight: 500;
}

.semi-bold {
    font-weight: 600;
}

.bold {
    font-weight: 700; /* Equivalente a bold */
}

.black {
    font-weight: 900;
}

/* Uso semântico */
strong {
    font-weight: 700;
}

.heading {
    font-weight: 600;
}
