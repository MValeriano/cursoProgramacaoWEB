Propriedades de Transformação CSS

Essas propriedades são essenciais para criar interfaces modernas, animações suaves e efeitos 3D impressionantes no CSS.

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
transform translate(), rotate(), scale() Aplica transformações 2D/3D
transform-origin center, top left, 50px 100px Define origem da transformação
transform-style flat, preserve-3d Controla renderização 3D de filhos
perspective none, 500px, 1000px Define profundidade 3D
perspective-origin center, top left, 25% 75% Define ponto de fuga da perspectiva
backface-visibility visible, hidden Controla visibilidade da face traseira

Dicas de Boas Práticas

  • Use transform para animações - Mais eficiente que mudar left/top
  • Combine transformações - Use múltiplas transformações em uma declaração
  • Defina transform-style: preserve-3d para hierarquias 3D complexas
  • Use backface-visibility: hidden para elementos que giram 180°+
  • Teste performance - Transformações 3D complexas podem ser pesadas
  • Forneça fallbacks para navegadores que não suportam transformações 3D

transform

A propriedade transform aplica transformações 2D ou 3D a um elemento. Permite rotacionar, escalar, inclinar ou transladar elementos.

Valores possíveis:

  • Transformações 2D: translate(x, y), rotate(angle), scale(x, y), skew(x-angle, y-angle), matrix(...)
  • Transformações 3D: translate3d(x, y, z), rotate3d(x, y, z, angle), scale3d(x, y, z), perspective(n)

Exemplos:

/* Translação (movimento) */
.translate {
    transform: translate(50px, 100px);
}

.translateX {
    transform: translateX(100px);
}

.translateY {
    transform: translateY(50px);
}

/* Rotação */
.rotate {
    transform: rotate(45deg);
}

.rotate3d {
    transform: rotate3d(1, 1, 1, 45deg);
}

/* Escala */
.scale {
    transform: scale(1.5);
}

.scaleX {
    transform: scaleX(2);
}

.scaleY {
    transform: scaleY(0.5);
}

/* Inclinação */
.skew {
    transform: skew(30deg, 20deg);
}

.skewX {
    transform: skewX(25deg);
}

/* Múltiplas transformações */
.multiple {
    transform: translate(50px, 50px) rotate(45deg) scale(1.2);
}

/* Transformações 3D */
.transform3d {
    transform: perspective(500px) rotateY(45deg) translateZ(100px);
}

transform-origin

A propriedade transform-origin permite mudar a posição da origem das transformações. Por padrão, a origem é o centro do elemento.

Valores possíveis:

  • Valores de posição: left, center, right, top, bottom
  • Porcentagens: 50% 50% (padrão)
  • Unidades de comprimento: px, em, rem, etc.

Sintaxe:

transform-origin: x-axis y-axis z-axis;

Exemplos:

/* Posições básicas */
.origin-top-left {
    transform-origin: left top;
    transform: rotate(45deg);
}

.origin-bottom-right {
    transform-origin: right bottom;
    transform: rotate(-45deg);
}

.origin-center {
    transform-origin: center center;
    transform: scale(1.5);
}

/* Valores em porcentagem */
.origin-percentage {
    transform-origin: 25% 75%;
    transform: rotate(30deg);
}

/* Valores em pixels */
.origin-pixels {
    transform-origin: 100px 200px;
    transform: skew(15deg);
}

/* Para transformações 3D */
.origin-3d {
    transform-origin: center center 100px;
    transform: rotate3d(1, 0, 0, 60deg);
}

/* Exemplo prático - ponto de rotação personalizado */
.hinge-effect {
    transform-origin: top left;
    transform: rotate(15deg);
}

.scale-from-corner {
    transform-origin: bottom right;
    transform: scale(1.3);
}

transform-style

A propriedade transform-style define como os elementos filhos são renderizados no espaço 3D.

Valores possíveis:

  • flat - Elementos filhos são renderizados no plano do elemento (padrão)
  • preserve-3d - Elementos filhos são posicionados no espaço 3D

Exemplos:

/* Plano 2D (padrão) */
.container-2d {
    transform-style: flat;
    transform: rotateY(45deg);
}

/* Espaço 3D preservado */
.container-3d {
    transform-style: preserve-3d;
    perspective: 500px;
}

.child-3d {
    transform: rotateX(45deg) translateZ(50px);
}

/* Exemplo de cubo 3D */
.cube {
    transform-style: preserve-3d;
    transform: rotateX(45deg) rotateY(45deg);
}

.cube-face {
    position: absolute;
    transform-style: preserve-3d;
}

.front { transform: translateZ(50px); }
.back { transform: translateZ(-50px) rotateY(180deg); }

perspective

A propriedade perspective define a distância entre o plano z=0 e o usuário, criando um efeito de profundidade para elementos 3D transformados.

Valores possíveis:

  • none - Sem perspectiva (padrão)
  • length - Distância em px, em, etc. (valores menores criam efeito mais dramático)

Exemplos:

/* Perspectiva suave */
.perspective-mild {
    perspective: 1000px;
}

.perspective-strong {
    perspective: 500px;
}

/* Aplicado diretamente no elemento */
.direct-perspective {
    transform: perspective(500px) rotateY(45deg);
}

/* Aplicado no container */
.container-perspective {
    perspective: 800px;
}

.container-perspective .child {
    transform: rotateY(45deg);
}

/* Comparação de diferentes perspectivas */
.mild-depth {
    perspective: 1200px;
}

.medium-depth {
    perspective: 600px;
}

.strong-depth {
    perspective: 300px;
}

perspective-origin

A propriedade perspective-origin define a posição de onde o usuário está olhando (ponto de fuga da perspectiva).

Valores possíveis:

  • Posições: left, center, right, top, bottom
  • Porcentagens: 50% 50% (padrão - centro)
  • Unidades de comprimento: px, em, etc.

Exemplos:

/* Posições básicas */
.origin-top {
    perspective: 500px;
    perspective-origin: top;
}

.origin-left {
    perspective: 500px;
    perspective-origin: left;
}

.origin-bottom-right {
    perspective: 500px;
    perspective-origin: right bottom;
}

/* Valores em porcentagem */
.origin-custom {
    perspective: 600px;
    perspective-origin: 25% 75%;
}

/* Valores em pixels */
.origin-pixel {
    perspective: 800px;
    perspective-origin: 200px 100px;
}

/* Efeitos visuais diferentes */
.above-view {
    perspective: 500px;
    perspective-origin: center top;
}

.below-view {
    perspective: 500px;
    perspective-origin: center bottom;
}

.side-view {
    perspective: 500px;
    perspective-origin: left center;
}

backface-visibility

A propriedade backface-visibility define se a face traseira de um elemento é visível quando está de costas para o visualizador.

Valores possíveis:

  • visible - Face traseira é visível (padrão)
  • hidden - Face traseira é invisível

Exemplos:

/* Face traseira visível */
.backface-visible {
    backface-visibility: visible;
    transform: rotateY(180deg);
}

/* Face traseira oculta (útil para cartões 3D) */
.backface-hidden {
    backface-visibility: hidden;
    transform: rotateY(180deg);
}

/* Exemplo de cartão 3D */
.card {
    transform-style: preserve-3d;
    transition: transform 0.6s;
}

.card-face {
    position: absolute;
    backface-visibility: hidden;
}

.card-back {
    transform: rotateY(180deg);
}

.card:hover {
    transform: rotateY(180deg);
}

/* Para elementos que giram completamente */
.spinning-element {
    backface-visibility: hidden;
    animation: spin 3s infinite linear;
}

@keyframes spin {
    from { transform: rotateY(0deg); }
    to { transform: rotateY(360deg); }
}
