Propriedades do Box Model CSS

Essas propriedades formam a base do layout CSS e são essenciais para criar designs responsivos e bem estruturados.

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
width/height 300px, 50%, auto Dimensões do elemento
max-width/height 100%, 1200px, none Limites máximos de dimensão
min-width/height 200px, 100vh, 0 Limites mínimos de dimensão
margin 20px, 0 auto, 10px 20px Espaço externo
padding 15px, 10px 20px, 0 Espaço interno
box-sizing border-box, content-box Modelo de cálculo de dimensões
overflow auto, hidden, scroll Controle de conteúdo transbordante

Dicas de Boas Práticas

  • Use box-sizing: border-box globalmente para facilitar cálculos
  • Prefira max-width em containers para responsividade
  • Use margin: auto para centralização horizontal
  • Combine min-height e max-height para controle flexível
  • Prefira overflow: auto sobre scroll para melhor UX
  • Use unidades relativas (%, vw/vh) para layouts responsivos
  • Teste diferentes combinações de margin/padding para espaçamento consistente

width

A propriedade width define a largura de um elemento.

Valores possíveis:

  • auto - Largura automática (padrão)
  • length - Valor fixo em px, em, rem, etc.
  • % - Porcentagem da largura do elemento pai
  • fit-content - Largura baseada no conteúdo
  • max-content - Largura mínima para caber todo conteúdo
  • min-content - Largura mínima baseada no maior pedaço de conteúdo

Exemplos:

.fixed-width {
    width: 300px;
}

.percentage-width {
    width: 50%;
}

.viewport-width {
    width: 100vw;
}

.auto-width {
    width: auto;
}

.fit-content {
    width: fit-content;
}

.max-content {
    width: max-content;
}

.min-content {
    width: min-content;
}

height

A propriedade height define a altura de um elemento.

Valores possíveis:

  • auto - Altura automática (padrão)
  • length - Valor fixo em px, em, rem, etc.
  • % - Porcentagem da altura do elemento pai
  • fit-content - Altura baseada no conteúdo
  • vh - Porcentagem da altura da viewport

Exemplos:

.fixed-height {
    height: 200px;
}

.percentage-height {
    height: 75%;
}

.viewport-height {
    height: 100vh;
}

.auto-height {
    height: auto;
}

.min-height {
    height: min-content;
}

max-width

A propriedade max-width define a largura máxima de um elemento.

Valores possíveis:

  • none - Sem largura máxima (padrão)
  • length - Valor máximo em px, em, rem, etc.
  • % - Porcentagem máxima da largura do elemento pai
  • fit-content - Largura máxima baseada no conteúdo

Exemplos:

.responsive-container {
    max-width: 1200px;
    width: 100%;
}

.fluid-image {
    max-width: 100%;
    height: auto;
}

.text-container {
    max-width: 65ch; /* Ótimo para legibilidade */
}

.no-max {
    max-width: none;
}

min-width

A propriedade min-width define a largura mínima de um elemento.

Valores possíveis:

  • 0 - Largura mínima zero (padrão)
  • length - Valor mínimo em px, em, rem, etc.
  • % - Porcentagem mínima da largura do elemento pai

Exemplos:

.button {
    min-width: 120px;
}

.sidebar {
    min-width: 250px;
}

.responsive-element {
    min-width: 300px;
    max-width: 800px;
    width: 100%;
}

.no-wrap {
    min-width: max-content;
    white-space: nowrap;
}

max-height

A propriedade max-height define a altura máxima de um elemento.

Valores possíveis:

  • none - Sem altura máxima (padrão)
  • length - Valor máximo em px, em, rem, etc.
  • % - Porcentagem máxima da altura do elemento pai

Exemplos:

.modal {
    max-height: 80vh;
}

.scrollable-content {
    max-height: 400px;
    overflow-y: auto;
}

.image-container {
    max-height: 500px;
}

.collapsible {
    max-height: 0;
    overflow: hidden;
    transition: max-height 0.3s ease;
}

min-height

A propriedade min-height define a altura mínima de um elemento.

Valores possíveis:

  • 0 - Altura mínima zero (padrão)
  • length - Valor mínimo em px, em, rem, etc.
  • % - Porcentagem mínima da altura do elemento pai
  • vh - Porcentagem mínima da altura da viewport

Exemplos:

.page-section {
    min-height: 100vh;
}

.card {
    min-height: 200px;
}

.button {
    min-height: 44px; /* Tamanho mínimo para touch */
}

.flex-container {
    min-height: 400px;
    display: flex;
    align-items: center;
}

margin

A propriedade margin define o espaço externo ao redor de um elemento (shorthand).

Sintaxe:

margin: [top] [right] [bottom] [left];
margin: [vertical] [horizontal];
margin: [all];

Valores possíveis:

  • length - Valor em px, em, rem, etc.
  • % - Porcentagem da largura do elemento pai
  • auto - Centralização automática

Exemplos:

/* Todos os lados iguais */
.margin-all {
    margin: 20px;
}

/* Vertical | Horizontal */
.margin-vh {
    margin: 10px 20px;
}

/* Top | Right | Bottom | Left */
.margin-trb {
    margin: 10px 15px 20px 25px;
}

/* Centralização horizontal */
.margin-center {
    margin: 0 auto;
}

/* Margem negativa */
.margin-negative {
    margin: -10px;
}

margin-top, margin-right, margin-bottom, margin-left

Propriedades individuais para cada lado da margem.

Exemplos:

.custom-margins {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 15px;
    margin-left: 5px;
}

.push-down {
    margin-top: 50px;
}

.push-right {
    margin-left: auto;
}

.no-top-margin {
    margin-top: 0;
}

.negative-margin {
    margin-left: -20px;
}

padding

A propriedade padding define o espaço interno dentro de um elemento (shorthand).

Sintaxe:

padding: [top] [right] [bottom] [left];
padding: [vertical] [horizontal];
padding: [all];

Valores possíveis:

  • length - Valor em px, em, rem, etc.
  • % - Porcentagem da largura do elemento pai

Exemplos:

/* Todos os lados iguais */
.padding-all {
    padding: 20px;
}

/* Vertical | Horizontal */
.padding-vh {
    padding: 10px 20px;
}

/* Top | Right | Bottom | Left */
.padding-trb {
    padding: 10px 15px 20px 25px;
}

/* Padding em unidades relativas */
.padding-relative {
    padding: 1em;
}

/* Padding zero */
.no-padding {
    padding: 0;
}

padding-top, padding-right, padding-bottom, padding-left

Propriedades individuais para cada lado do padding.

Exemplos:

.custom-padding {
    padding-top: 15px;
    padding-right: 25px;
    padding-bottom: 15px;
    padding-left: 10px;
}

.extra-top-padding {
    padding-top: 30px;
}

.symmetric-padding {
    padding-left: 20px;
    padding-right: 20px;
}

.no-side-padding {
    padding-left: 0;
    padding-right: 0;
}

box-sizing

A propriedade box-sizing altera como a largura e altura de um elemento são calculadas.

Valores possíveis:

  • content-box - Largura/altura incluem apenas o conteúdo (padrão)
  • border-box - Largura/altura incluem conteúdo, padding e border

Exemplos:

/* Modelo tradicional */
.content-box {
    box-sizing: content-box;
    width: 300px;
    padding: 20px;
    border: 5px solid #000;
    /* Largura total: 300 + 20 + 20 + 5 + 5 = 350px */
}

/* Modelo moderno (recomendado) */
.border-box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid #000;
    /* Largura total: 300px (já inclui padding e border) */
}

/* Aplicar para todos os elementos */
* {
    box-sizing: border-box;
}

.legacy-element {
    box-sizing: content-box;
}

overflow

A propriedade overflow controla o que acontece quando o conteúdo transborda do elemento.

Valores possíveis:

  • visible - Conteúdo transborda visivelmente (padrão)
  • hidden - Conteúdo é cortado, sem scrollbars
  • scroll - Sempre mostra scrollbars
  • auto - Mostra scrollbars apenas quando necessário
  • clip - Similar ao hidden, mas não permite programmatic scrolling

Exemplos:

.visible-overflow {
    overflow: visible;
}

.hidden-overflow {
    overflow: hidden;
}

.scroll-overflow {
    overflow: scroll;
}

.auto-overflow {
    overflow: auto;
}

.clip-overflow {
    overflow: clip;
}

/* Combinado */
.both-overflow {
    overflow: auto hidden; /* x: auto, y: hidden */
}

overflow-x e overflow-y

Propriedades individuais para controle de overflow horizontal e vertical.

Exemplos:

.horizontal-scroll {
    overflow-x: auto;
    overflow-y: hidden;
    white-space: nowrap;
}

.vertical-scroll {
    overflow-x: hidden;
    overflow-y: auto;
    max-height: 300px;
}

.custom-scroll {
    overflow-x: scroll;
    overflow-y: auto;
}

.no-horizontal-scroll {
    overflow-x: hidden;
}

.no-vertical-scroll {
    overflow-y: hidden;
}
