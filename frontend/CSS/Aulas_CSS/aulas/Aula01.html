CSS

CSS é a linguagem usada para estilizar documentos HTML. Ela descreve como os elementos HTML devem ser exibidos na tela, no papel ou em outras mídias.

O que é CSS?

  • CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata).
  • O CSS define a aparência e a formatação dos elementos HTML.
  • Ele permite controlar o design, o layout e a estilização de várias páginas ao mesmo tempo.
  • As folhas de estilo externas são armazenadas em arquivos com extensão .css.

Por que usar CSS?

  • O CSS separa conteúdo (HTML) de estilo (cores, tamanhos, posicionamento).
  • Facilita a manutenção: você pode alterar o visual de um site inteiro editando apenas um arquivo CSS.
  • Permite adaptar o design para diferentes tamanhos de tela e dispositivos.

Sintaxe do CSS

Uma regra CSS é composta por:

  • Seletor → indica quais elementos HTML receberão o estilo.
  • Bloco de declaração → contém uma ou mais propriedades e seus valores.

Estrutura:

seletor {
    propriedade1: valor1;
    propriedade2: valor2;
}

Cada propriedade é seguida de dois pontos.
Cada valor termina com ponto e vírgula.
O bloco é delimitado por chaves { }.

Exemplo

Este exemplo aplica estilos a todos os elementos <p>:

p {
    color: red;
    text-align: center;
}

Explicação do exemplo

  • p → é o seletor, representando todos os parágrafos <p>.
  • color → é a propriedade que define a cor do texto.
  • red → é o valor da propriedade color.
  • text-align → é a propriedade que define o alinhamento do texto.
  • center → é o valor que centraliza o texto.

Resumo Visual — CSS (Mapa / Tabela)

Exercícios sobre CSS

Exercício 1: Identificação

Diga se cada frase é Verdadeira (V) ou Falsa (F):

( ) CSS é usado para definir o layout e o estilo das páginas da web.

( ) O seletor define qual elemento HTML será estilizado.

( ) A propriedade CSS sempre termina com vírgula.

( ) O CSS pode ser reutilizado em várias páginas através de arquivos externos.

( ) O valor de uma propriedade vem antes do nome da propriedade.

Resolução:

(V) CSS é usado para definir o layout e o estilo das páginas da web.

(V) O seletor define qual elemento HTML será estilizado.

(F) A propriedade CSS sempre termina com vírgula. (Falso, a declaração termina com ponto e vírgula).

(V) O CSS pode ser reutilizado em várias páginas através de arquivos externos.

(F) O valor de uma propriedade vem antes do nome da propriedade. (Falso, o nome da propriedade vem antes).

Exercício 2: Complete os espaços

a) CSS significa C________ S______ S______.

b) Arquivos externos de CSS usam a extensão: ._____

c) Uma regra CSS é formada por um s________ e um b_____ de d__________.

Resolução:

a) CSS significa Cascading Style Sheets.

b) Arquivos externos de CSS usam a extensão: .css

c) Uma regra CSS é formada por um seletor e um bloco de declaração.

Exercício 3: Estilização básica

Escreva o CSS correto para:

a) Todos os parágrafos terem cor azul.

________________ {
    color: ________;
}

b) O texto de todos os <h1> ficar centralizado:

h1 {
    __________________;
}

Resolução:

a) Todos os parágrafos terem cor azul.

p {
    color: blue;
}

b) O texto de todos os <h1> ficar centralizado:

h1 {
    text-align: center;
}

Exercício 4: Corrija os erros no código abaixo

p {
    color red;
    text-align center
}

Resolução:

Faltaram os dois-pontos (:) depois das propriedades e os ponto-e-vírgula (;) no final das declarações.

p {
    color: red;
    text-align: center;
}

Exercício 5: Desafio prático

Dado o HTML:

<p class="mensagem">Bem-vindo ao site!</p>

Crie o CSS para:

  • Cor do texto: verde
  • Tamanho da fonte: 20px
  • Alinhamento: centro
/* escreva aqui */

Resolução:

.mensagem {
    color: green;
    font-size: 20px;
    text-align: center;
}
