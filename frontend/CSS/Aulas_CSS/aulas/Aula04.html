🚫 Erros Comuns em CSS

Quando há erros no CSS, o navegador muitas vezes não exibe o estilo desejado, mas não mostra mensagens de erro — por isso é importante saber identificá-los.

1. Ponto e vírgula ausente

Cada declaração deve terminar com ;.

Se faltar, o navegador pode ignorar a próxima linha.

❌ ERRADO:

.bad {
  color: red
  background-color: yellow;
}

✅ CERTO:

.bad {
  color: red;
  background-color: yellow;
}

2. Nome de propriedade inválido

Se você digitar a propriedade errado, ela será simplesmente ignorada.

❌ ERRADO:

.bad {
  colr: blue;
}

✅ CERTO:

.bad {
  color: blue;
}

3. Valor inválido

Mesmo que a propriedade esteja correta, se o valor não for válido, ela não será aplicada.

❌ ERRADO:

.bad {
  width: -100px;
}

✅ CERTO:

.bad {
  width: 100px;
}

4. Chave não fechada

Se faltar uma }, todo o restante do arquivo pode ser afetado.

❌ ERRADO:

.bad {
  padding: 20px;
  margin: 10px;

✅ CERTO:

.bad {
  padding: 20px;
  margin: 10px;
}

5. Dois-pontos extras ou símbolos errados

❌ ERRADO:

.bad {
  color:: blue;
}

✅ CERTO:

.bad {
  color: blue;
}

⭐ Dicas para Evitar Erros

Dica Por quê?
Use editor com destaque de sintaxe (VS Code) Mostra erros visuais
Teste seu CSS aos poucos Facilita identificar a linha do erro
Valide seu CSS online (ex: https://jigsaw.w3.org/css-validator/) Mostra mensagens de correção
Indente e organize seu código Facilita leitura e manutenção

📝 Exercícios

Exercício 1: Corrija o CSS abaixo

.box {
  background-colr: blue
  padding: 20px
}

Resolução:

Havia 3 erros:

  1. background-color (nome da propriedade errado).
  2. Faltou ; depois de blue.
  3. Faltou ; depois de 20px.
.box {
  background-color: blue;
  padding: 20px;
}

Exercício 2: Indique o erro e corrija

h1 {
  color:: red;
}

Resolução:

O erro foi o uso de dois-pontos duplos (::) em vez de um único (:) entre a propriedade e o valor.

h1 {
  color: red;
}

Exercício 3: O código abaixo não funciona. Explique por quê.

p {
  width: -50px;
}

Resolução:

O código não funciona porque a propriedade width (largura) não aceita valores negativos (-50px). O navegador considera isso um valor inválido e simplesmente ignora a regra.

Exercício 4: Complete corretamente a regra CSS

Um seletor deve abrir com { e fechar com ___ .

Cada declaração deve terminar com ___ .

Resolução:

Um seletor deve abrir com { e fechar com } .

Cada declaração deve terminar com ; .

Exercício 5: Desafio Criativo

Escreva uma regra CSS válida para:

  • fundo amarelo
  • texto preto
  • espaçamento interno de 15px

Resolução (Exemplo):

Você pode usar qualquer seletor (classe, id, tag). Usando uma classe .destaque como exemplo:

.destaque {
  background-color: yellow;
  color: black;
  padding: 15px;
}
