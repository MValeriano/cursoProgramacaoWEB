Como Adicionar CSS a uma Página HTML

Quando o navegador carrega uma página HTML, ele pode usar CSS para controlar a aparência dos elementos (cores, tamanhos, alinhamentos, margens, etc.).

Existem três maneiras principais de incluir CSS em um documento HTML:

1. CSS Externo

O CSS externo é escrito em um arquivo separado, com extensão .css.

Vantagem: permite estilizar várias páginas usando apenas um arquivo.

O arquivo CSS é linkado dentro da tag <head> do HTML.

Exemplo de HTML usando CSS externo

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="mystyle.css">
</head>
<body>

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
</html>

Exemplo do arquivo mystyle.css

body {
    background-color: lightblue;
}

h1 {
    color: navy;
    margin-left: 20px;
}
Atenção:

Não coloque espaço entre número e unidade:
✅ 20px
❌ 20 px

2. CSS Interno

O CSS interno é usado dentro da própria página, na tag <style> localizada no <head>.

Use quando apenas essa página precisa desse estilo.

Exemplo

<!DOCTYPE html>
<html>
<head>
<style>
body {
    background-color: linen;
}

h1 {
    color: maroon;
    margin-left: 40px;
}
</style>
</head>
<body>

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
</html>

3. CSS Embutido (Inline)

O CSS embutido é inserido diretamente no elemento através do atributo style.

Use apenas quando quiser estilizar um elemento específico de forma pontual.

Exemplo

<!DOCTYPE html>
<html>
<body>

<h1 style="color:blue; text-align:center;">This is a heading</h1>
<p style="color:red;">This is a paragraph.</p>

</body>
</html>
Dica: Evite usar CSS embutido em excesso, pois mistura conteúdo com aparência e dificulta a manutenção.

Várias Folhas de Estilo e Ordem de Prioridade (Cascata)

Se um mesmo elemento receber estilos de vários lugares, o navegador seguirá esta ordem de prioridade:

  • 1️⃣
    Prioridade (da maior para a menor): CSS embutido (inline) Tipo de Estilo
  • 2️⃣
    Prioridade (da maior para a menor): CSS interno e CSS externo Tipo de Estilo
  • 3️⃣
    Prioridade (da maior para a menor): Estilos padrão do navegador Tipo de Estilo

Exemplo de conflito

CSS externo:

h1 { color: navy; }

CSS interno:

<style>
h1 { color: orange; }
</style>

Se o CSS interno vier depois do externo, o título ficará laranja.

🧠 EXERCÍCIOS (PRÁTICOS)

Exercício 1: CSS Externo

Crie um arquivo HTML chamado index.html e um arquivo CSS chamado style.css.

No style.css, adicione:

body {
    background-color: lightgray;
}

p {
    color: blue;
}

No index.html, linke o arquivo CSS e mostre um texto.

→ O que acontece quando você muda a cor no CSS externo?

Resolução:

O index.html deve ficar assim:

<!DOCTYPE html>
<html>
<head>
    <title>Exercício 1</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <p>Este parágrafo será azul.</p>
</body>
</html>

O style.css já foi fornecido no enunciado.

→ O que acontece? Ao mudar a cor no style.css (ex: de blue para green) e salvar, o texto no navegador mudará de cor automaticamente (após atualizar a página). Isso prova que o arquivo externo está controlando o estilo.

Exercício 2: CSS Interno

Crie uma página HTML usando apenas CSS interno que:

  • Deixa o fundo da página rosa claro
  • Colora os títulos <h1> de verde
  • Alinha os parágrafos ao centro

Escreva o código no <style>.

Resolução:

<!DOCTYPE html>
<html>
<head>
<style>
body {
    background-color: lightpink; /* Rosa claro */
}

h1 {
    color: green; /* Verde */
}

p {
    text-align: center; /* Centralizado */
}
</style>
</head>
<body>

<h1>Este título é verde</h1>
<p>Este parágrafo está centralizado.</p>

</body>
</html>

Exercício 3: CSS Embutido

Use apenas CSS embutido para:

  • Colocar um <h2> de cor vermelha
  • Colocar um <p> com tamanho de fonte 20px

Exemplo:

<h2 style="color: red;">Texto exemplo</h2>
<p style="font-size: 20px;">Parágrafo exemplo.</p>

Agora crie o seu próprio exemplo com outro texto.

Resolução (Exemplo):

Seu código HTML poderia ser assim:

<!DOCTYPE html>
<html>
<body>

<h2 style="color: purple;">Meu próprio exemplo de título</h2>
<p style="font-size: 24px; font-family: Arial;">Meu próprio parágrafo com 24px.</p>

</body>
</html>

Exercício 4: Ordem em Cascata

Observe o código abaixo e responda:
Qual será a cor final do texto <h1>?

<head>
<link rel="stylesheet" href="style.css">
<style>
    h1 { color: purple; }
</style>
</head>
<body>
<h1 style="color: orange;">Título</h1>
</body>

Resolução:

Resposta esperada: Laranja, pois CSS embutido tem maior prioridade.

O estilo embutido (style="color: orange;") é o mais específico (Prioridade 1), por isso ele sobrescreve o CSS interno (purple) e qualquer CSS externo.

Exercício 5: Desafio

Explique, com suas palavras, quando é melhor usar:

  • CSS externo
  • CSS interno
  • CSS embutido

(Resposta livre, para fixação.)

Resolução (Sugestão):

CSS externo: É a melhor opção na maioria das vezes. Deve ser usado quando você quer que os mesmos estilos (cores, fontes, layout) se apliquem a várias páginas do seu site. Facilita muito a manutenção.

CSS interno: Deve ser usado quando os estilos são exclusivos para uma única página. Se você tem uma página de "Contato" que é visualmente muito diferente das outras, pode usar o CSS interno nela.

CSS embutido: Deve ser evitado, mas é útil para testes rápidos ou para aplicar um estilo muito específico a um único elemento (ex: um <p> específico em uma página que precisa ser vermelho por um motivo especial).
