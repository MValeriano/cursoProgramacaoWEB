Seletores CSS

Os seletores CSS são usados para encontrar (selecionar) os elementos HTML que você deseja estilizar.

Categorias Principais

Eles podem ser agrupados em cinco categorias principais:

Categoria O que faz
Seletores Simples Selecionam elementos pelo nome, ID ou classe
Seletores Combinatórios Selecionam elementos com base em sua relação com outros elementos
Pseudo-classes Selecionam elementos em um estado específico (ex.: hover, foco, visitado)
Pseudo-elementos Selecionam parte de um elemento (ex.: primeira letra, primeira linha)
Seletores de Atributos Selecionam elementos por atributos ou valores de atributos

1) Seletores Simples

Seletor Exemplo Função
#id #titulo Seleciona o elemento com id="titulo"
.classe .intro Seleciona todos os elementos com class="intro"
* * Seleciona todos os elementos
element p Seleciona todos os elementos <p>
element, element div, p Seleciona todos os <div> e <p>

Seletor de ID

#para1 {
    text-align: center;
    color: red;
}

Regra: um ID não pode começar com número.

Seletor de Classe

.center {
    text-align: center;
    color: red;
}

Aplicando apenas ao <p>:

p.center {
    text-align: center;
    color: red;
}

Um elemento pode ter várias classes:

<p class="center grande">Texto</p>

Seletor Universal

* {
    margin: 0;
}

Agrupamento de Seletores

h1, h2, p {
    text-align: center;
    color: red;
}

2) Seletores Combinatórios

Nome Símbolo Exemplo Seleciona
Descendente (espaço) div p Todos <p> dentro de um <div>
Filho Direto > div > p <p> que são filhos diretos de <div>
Próximo Irmão + div + p Primeiro <p> logo após um <div>
Irmãos Subsequentes ~ div ~ p Todos <p> que tenham o mesmo pai após o <div>

3) Pseudo-classes

Usadas para estilizar elementos em certos estados.

Exemplos comuns:

a:link { color: red; }       /* link não visitado */
a:visited { color: green; }   /* link visitado */
a:hover { color: magenta; }  /* mouse sobre */
a:active { color: blue; }    /* clicando */

Exemplo com foco em campo:

input:focus {
    background-color: yellow;
}

Exemplo com primeiros filhos:

p:first-child {
    color: blue;
}

4) Pseudo-elementos

Usados para estilizar parte de um elemento.

Pseudo-elemento Exemplo Função
::first-line p::first-line Estiliza a primeira linha de um texto
::first-letter p::first-letter Estiliza a primeira letra
::before h3::before Insere conteúdo antes
::after h3::after Insere conteúdo depois
::selection ::selection Estiliza texto selecionado
::marker ::marker Estiliza marcadores de listas

Exemplo:

p::first-letter {
    color: red;
    font-size: xx-large;
}

5) Seletores de Atributo

Seletor Seleciona elementos...
[attr] com o atributo presente
[attr="valor"] cujo valor é exatamente igual
[attr~="valor"] contendo uma palavra específica
[attr^="valor"] que começam com o valor
[attr$="valor"] que terminam com o valor
[attr*="valor"] que contêm o valor

Exemplo estilizando formulários:

input[type="text"] {
    background-color: pink;
}
input[type="button"] {
    background-color: lightgreen;
}

📝 EXERCÍCIOS

Exercício 1: Identificação

Classifique cada seletor como: (E) Elemento, (C) Classe, (ID), (PC) Pseudo-classe, (PE) Pseudo-elemento, (A) Atributo.

SeletorTipo
p____
.menu____
#principal____
a:hover____
p::first-letter____
input[type="password"]____

Resolução:

SeletorTipo
p(E) Elemento
.menu(C) Classe
#principal(ID)
a:hover(PC) Pseudo-classe
p::first-letter(PE) Pseudo-elemento
input[type="password"](A) Atributo

Exercício 2: Complete

a) O seletor # é usado para selecionar elementos pelo _______.

b) O seletor . é usado para selecionar elementos pela _______.

c) O seletor A B significa que B está _______ dentro de A.

Resolução:

a) O seletor # é usado para selecionar elementos pelo ID.

b) O seletor . é usado para selecionar elementos pela Classe.

c) O seletor A B significa que B está descendente (dentro) de A.

Exercício 3: Escreva o CSS pedido

a) Todos os <h2> com texto verde.

________________ {
    color: green;
}

b) Todos os elementos com classe "aviso" devem ficar com fundo amarelo:

______________ {
    background-color: yellow;
}

c) O elemento com id "titulo" deve ficar centralizado:

______________ {
    text-align: center;
}

Resolução:

a) Todos os <h2> com texto verde.

h2 {
    color: green;
}

b) Todos os elementos com classe "aviso" devem ficar com fundo amarelo:

.aviso {
    background-color: yellow;
}

c) O elemento com id "titulo" deve ficar centralizado:

#titulo {
    text-align: center;
}

Exercício 4: Corrija o código

p {
    color red
    text-align center;
}

Resolução:

Faltou um dois-pontos (:) após 'color' e um ponto-e-vírgula (;) após 'red'.

p {
    color: red;
    text-align: center;
}

Exercício 5: Desafio

Dado o HTML:

<h1>Bem-vindo!</h1>
<p class="destaque">Aprender CSS é divertido!</p>

Crie um CSS onde:

  • <h1> é azul
  • .destaque tem fonte 20px e cor laranja
/* Resposta aqui */

Resolução:

h1 {
    color: blue;
}

.destaque {
    font-size: 20px;
    color: orange;
}
