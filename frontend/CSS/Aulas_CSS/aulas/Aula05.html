🎨 Cores em CSS

Em CSS, as cores podem ser definidas de diferentes maneiras. Você pode usar nomes de cores ou valores numéricos, como RGB, HEX, HSL, RGBA e HSLA.

✅ 1. Nomes de Cores

Você pode usar nomes pré-definidos, como red, blue, tomato, violet, etc.

Exemplos:

<h1 style="background-color:DodgerBlue;">Hello World</h1>
<p style="background-color:Tomato;">Lorem ipsum...</p>

<h1 style="color:Tomato;">Hello World</h1>
<p style="color:DodgerBlue;">Lorem ipsum...</p>
<p style="color:MediumSeaGreen;">Ut wisi enim...</p>

<h1 style="border:2px solid Tomato;">Hello World</h1>
<h1 style="border:2px solid DodgerBlue;">Hello World</h1>
<h1 style="border:2px solid Violet;">Hello World</h1>

🌈 2. RGB

Representa as cores vermelho, verde e azul, cada um variando de 0 a 255:

rgb(vermelho, verde, azul)

Exemplos:

color: rgb(255, 0, 0);    /* vermelho */
color: rgb(0, 0, 0);      /* preto */
color: rgb(255, 255, 255); /* branco */

RGBA → RGB + Transparência

rgba(vermelho, verde, azul, alfa)
  • alfa = 0.0 → transparente
  • alfa = 1.0 → opaco

Exemplo:

background-color: rgba(255, 0, 0, 0.5); /* vermelho semi-transparente */

💠 3. HEX

Usa valores hexadecimais:

#RRGGBB

Exemplos:

color: #ff0000; /* vermelho */
color: #000000; /* preto */
color: #ffffff; /* branco */

Abreviação (3 dígitos)

#rrggbb → #rgb

Exemplos:

body { background-color: #fc9; } /* #ffcc99 */
h1 { color: #f0f; }  /* #ff00ff */
p  { color: #b58; }  /* #bb5588 */

🎚️ 4. HSL

HSL significa:

Nome Significa Faixa
H Matiz (Hue) 0–360
S Saturação (Saturation) 0%–100%
L Luminosidade (Lightness) 0%–100% 
hsl(matiz, saturação, luminosidade)

Exemplos:

color: hsl(0, 100%, 50%);    /* vermelho puro */
color: hsl(120, 100%, 50%); /* verde puro */
color: hsl(240, 100%, 50%); /* azul puro */

HSLA → HSL + Transparência

hsla(matiz, saturação, luminosidade, alfa)

📝 Exercícios

Exercício 1: Escreva uma regra CSS para deixar um texto azul

Nome de cor:

RGB:

HEX:

HSL:

Resolução:

Nome de cor: color: blue;

RGB: color: rgb(0, 0, 255);

HEX: color: #0000ff;

HSL: color: hsl(240, 100%, 50%);

Exercício 2: Converta para HEX

rgb(255, 0, 0) = ?

rgb(0, 0, 0) = ?

rgb(255, 255, 255) = ?

Resolução:

rgb(255, 0, 0) = #ff0000

rgb(0, 0, 0) = #000000

rgb(255, 255, 255) = #ffffff

Exercício 3: O que significa o valor 0.3 em rgba(0, 200, 100, 0.3)?

...?

Resolução:

Significa o valor do canal alfa (transparência).

Um valor de 0.3 indica que a cor terá 30% de opacidade (ou 70% de transparência).

Exercício 4: Complete

hsl(0, ___%, ___%) representa um tom de cinza.

Resolução:

Para criar um tom de cinza, a Saturação (S) deve ser 0%. A Matiz (H) pode ser qualquer valor (inclusive 0) e a Luminosidade (L) define o quão claro ou escuro é o cinza (ex: 50% para cinza médio).

Resposta: hsl(0, 0%, 50%)

Exercício 5: Crie uma caixa com

  • fundo verde claro
  • borda preta
  • texto branco

(Use qualquer formato de cor)

Resolução (Exemplo):

Usando uma classe .caixa:

.caixa {
  background-color: lightgreen;
  border: 1px solid #000000;
  color: white;
}
