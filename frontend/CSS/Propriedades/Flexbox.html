Propriedades Flexbox CSS

O Flexbox é essencial para layouts modernos e responsivos, substituindo muitas técnicas complexas de posicionamento com CSS tradicional.

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
display flex, inline-flex Cria contêiner flex
flex-direction row, column Direção dos itens
flex-wrap wrap, nowrap Quebra de linha
flex-flow row wrap Shorthand direction + wrap
justify-content center, space-between Alinhamento no eixo principal
align-items center, stretch Alinhamento no eixo transversal
align-content space-around Alinhamento de múltiplas linhas
order -1, 0, 1 Ordem dos itens
flex-grow 0, 1, 2 Capacidade de crescimento
flex-shrink 0, 1 Capacidade de redução
flex-basis auto, 200px Tamanho inicial
flex 1, 0 0 auto Shorthand grow + shrink + basis
align-self flex-start, center Alinhamento individual

Dicas de Boas Práticas

  • Use flex: 1 para itens que devem ocupar espaço igual
  • Combine flex-wrap: wrap com flex-basis para grids responsivos
  • Prefira gap em vez de margins para espaçamento entre itens
  • Use align-items: center para centralização vertical fácil
  • Experimente flex: auto vs flex: 1 para comportamentos diferentes

display: flex

A propriedade display: flex define um contêiner flexível. Quando aplicada a um elemento, torna seus filhos diretos em itens flex.

Comportamento:

  • Cria um contexto flex para os filhos diretos
  • Os itens se organizam em uma direção (linha ou coluna)
  • Permite controle avançado de alinhamento e distribuição

Exemplos:

/* Contêiner flex básico */
.container {
    display: flex;
}

/* Flex inline */
.inline-flex {
    display: inline-flex;
}

/* Uso prático */
.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.card-container {
    display: flex;
    gap: 20px;
    flex-wrap: wrap;
}

flex-direction

A propriedade flex-direction define a direção principal na qual os itens flex são dispostos no contêiner.

Valores possíveis:

  • row (padrão) - Esquerda para direita
  • row-reverse - Direita para esquerda
  • column - Topo para base
  • column-reverse - Base para topo

Exemplos:

/* Direção padrão (linha) */
.row-container {
    display: flex;
    flex-direction: row;
}

/* Linha invertida */
.row-reverse-container {
    display: flex;
    flex-direction: row-reverse;
}

/* Coluna */
.column-container {
    display: flex;
    flex-direction: column;
}

/* Coluna invertida */
.column-reverse-container {
    display: flex;
    flex-direction: column-reverse;
}

/* Uso prático */
.sidebar {
    display: flex;
    flex-direction: column;
    gap: 10px;
}

.horizontal-menu {
    display: flex;
    flex-direction: row;
    justify-content: center;
}

flex-wrap

A propriedade flex-wrap especifica se os itens flex devem quebrar linha ou não quando não couberem no contêiner.

Valores possíveis:

  • nowrap (padrão) - Todos os itens em uma linha
  • wrap - Quebra em múltiplas linhas (topo para base)
  • wrap-reverse - Quebra em múltiplas linhas (base para topo)

Exemplos:

/* Sem quebra (padrão) */
.nowrap-container {
    display: flex;
    flex-wrap: nowrap;
}

/* Com quebra normal */
.wrap-container {
    display: flex;
    flex-wrap: wrap;
}

/* Com quebra reversa */
.wrap-reverse-container {
    display: flex;
    flex-wrap: wrap-reverse;
}

/* Uso prático */
.gallery {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}

.responsive-grid {
    display: flex;
    flex-wrap: wrap;
    justify-content: space-between;
}

flex-flow

A propriedade flex-flow é uma shorthand que combina flex-direction e flex-wrap.

Sintaxe:

flex-flow: <flex-direction> <flex-wrap>;

Exemplos:

/* Direction e wrap separados */
.container {
    flex-direction: row;
    flex-wrap: wrap;
}

/* Shorthand equivalente */
.container {
    flex-flow: row wrap;
}

/* Outros exemplos */
.column-wrap {
    flex-flow: column wrap;
}

.row-nowrap {
    flex-flow: row nowrap;
}

.row-reverse-wrap {
    flex-flow: row-reverse wrap;
}

/* Uso prático */
.nav-menu {
    display: flex;
    flex-flow: row wrap;
    justify-content: space-around;
}

.vertical-stack {
    display: flex;
    flex-flow: column nowrap;
    gap: 10px;
}

justify-content

A propriedade justify-content alinha os itens flex ao longo do eixo principal (horizontal em row, vertical em column).

Valores possíveis:

  • flex-start (padrão) - Alinha no início
  • flex-end - Alinha no final
  • center - Alinha ao centro
  • space-between - Espaço igual entre itens
  • space-around - Espaço igual ao redor
  • space-evenly - Espaço igual entre e ao redor

Exemplos:

/* Alinhamento inicial */
.start-container {
    display: flex;
    justify-content: flex-start;
}

/* Alinhamento final */
.end-container {
    display: flex;
    justify-content: flex-end;
}

/* Centralizado */
.center-container {
    display: flex;
    justify-content: center;
}

/* Espaço entre */
.space-between-container {
    display: flex;
    justify-content: space-between;
}

/* Espaço ao redor */
.space-around-container {
    display: flex;
    justify-content: space-around;
}

/* Espaço uniforme */
.space-evenly-container {
    display: flex;
    justify-content: space-evenly;
}

/* Uso prático */
.header {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.centered-content {
    display: flex;
    justify-content: center;
    align-items: center;
}

.card-group {
    display: flex;
    justify-content: space-around;
    flex-wrap: wrap;
}

align-items

A propriedade align-items alinha os itens flex ao longo do eixo transversal (vertical em row, horizontal em column).

Valores possíveis:

  • stretch (padrão) - Estica para preencher
  • flex-start - Alinha no início
  • flex-end - Alinha no final
  • center - Alinha ao centro
  • baseline - Alinha pela linha de base do texto

Exemplos:

/* Esticar (padrão) */
.stretch-container {
    display: flex;
    align-items: stretch;
}

/* Alinhamento inicial */
.start-container {
    display: flex;
    align-items: flex-start;
}

/* Alinhamento final */
.end-container {
    display: flex;
    align-items: flex-end;
}

/* Centralizado */
.center-container {
    display: flex;
    align-items: center;
}

/* Por linha de base */
.baseline-container {
    display: flex;
    align-items: baseline;
}

/* Uso prático */
.toolbar {
    display: flex;
    align-items: center;
    gap: 10px;
}

.card {
    display: flex;
    flex-direction: column;
    align-items: center;
    text-align: center;
}

.form-group {
    display: flex;
    align-items: baseline;
    gap: 8px;
}

align-content

A propriedade align-content alinha as linhas flex quando há espaço extra no eixo transversal (só funciona com múltiplas linhas).

Valores possíveis:

  • stretch (padrão) - Estica as linhas
  • flex-start - Linhas no início
  • flex-end - Linhas no final
  • center - Linhas centralizadas
  • space-between - Espaço igual entre linhas
  • space-around - Espaço igual ao redor das linhas

Exemplos:

/* Apenas funciona com múltiplas linhas */
.multi-line-container {
    display: flex;
    flex-wrap: wrap;
    height: 300px; /* Espaço extra necessário */
    align-content: stretch;
}

/* Linhas no início */
.start-lines {
    align-content: flex-start;
}

/* Linhas no final */
.end-lines {
    align-content: flex-end;
}

/* Linhas centralizadas */
.center-lines {
    align-content: center;
}

/* Espaço entre linhas */
.space-between-lines {
    align-content: space-between;
}

/* Espaço ao redor */
.space-around-lines {
    align-content: space-around;
}

/* Uso prático */
.gallery-wall {
    display: flex;
    flex-wrap: wrap;
    align-content: space-around;
    gap: 10px;
    height: 500px;
}

order

A propriedade order controla a ordem em que os itens aparecem no contêiner flex.

Valores possíveis:

  • Número inteiro (positivo, negativo ou zero)
  • Valor padrão: 0

Exemplos:

/* Ordem padrão */
.item {
    order: 0;
}

/* Primeiro item */
.first-item {
    order: -1;
}

/* Último item */
.last-item {
    order: 1;
}

/* Ordem específica */
.item-1 { order: 3; }
.item-2 { order: 1; }
.item-3 { order: 2; }

/* Uso prático */
.featured {
    order: -1; /* Move para o início */
}

.archived {
    order: 999; /* Move para o final */
}

/* Reordenamento responsivo */
@media (max-width: 768px) {
    .sidebar {
        order: 2;
    }
    
    .main-content {
        order: 1;
    }
}

flex-grow

A propriedade flex-grow define a capacidade de um item crescer se necessário. Especifica quanto espaço o item deve ocupar no contêiner.

Valores possíveis:

  • Número (incluindo decimais)
  • Valor padrão: 0 (não cresce)

Exemplos:

/* Não cresce (padrão) */
.no-grow {
    flex-grow: 0;
}

/* Cresce para preencher espaço disponível */
.grow-1 {
    flex-grow: 1;
}

.grow-2 {
    flex-grow: 2; /* Ocupa o dobro do espaço que grow-1 */
}

.grow-3 {
    flex-grow: 3; /* Ocupa o triplo do espaço que grow-1 */
}

/* Uso prático */
.sidebar {
    flex-grow: 1;
}

.main-content {
    flex-grow: 3; /* 3 vezes maior que a sidebar */
}

.equal-columns > * {
    flex-grow: 1; /* Todas as colunas com tamanho igual */
}

flex-shrink

A propriedade flex-shrink define a capacidade de um item encolher se necessário.

Valores possíveis:

  • Número (incluindo decimais)
  • Valor padrão: 1 (encolhe proporcionalmente)

Exemplos:

/* Encolhe normalmente (padrão) */
.shrink-normal {
    flex-shrink: 1;
}

/* Não encolhe */
.no-shrink {
    flex-shrink: 0;
}

/* Encolhe mais que o normal */
.shrink-double {
    flex-shrink: 2; /* Encolhe o dobro dos itens com valor 1 */
}

/* Uso prático */
.fixed-sidebar {
    flex-shrink: 0; /* Nunca encolhe */
    width: 250px;
}

.flexible-content {
    flex-shrink: 1; /* Encolhe normally */
}

.image-container {
    flex-shrink: 0; /* Mantém o tamanho da imagem */
}

flex-basis

A propriedade flex-basis define o tamanho inicial de um item flex antes que o espaço restante seja distribuído.

Valores possíveis:

  • auto (padrão) - Tamanho base no conteúdo
  • Tamanho fixo: 200px, 50%, 10rem
  • content - Tamanho base apenas no conteúdo

Exemplos:

/* Tamanho automático (padrão) */
.auto-basis {
    flex-basis: auto;
}

/* Tamanho fixo em pixels */
.pixel-basis {
    flex-basis: 200px;
}

/* Tamanho percentual */
.percent-basis {
    flex-basis: 33.33%;
}

/* Base apenas no conteúdo */
.content-basis {
    flex-basis: content;
}

/* Uso prático */
.grid-item {
    flex-basis: 300px;
    flex-grow: 1;
}

.responsive-column {
    flex-basis: 250px;
    flex-shrink: 0;
}

.fluid-layout {
    flex-basis: 0; /* Distribuição igual */
    flex-grow: 1;
}

flex

A propriedade flex é uma shorthand que combina flex-grow, flex-shrink e flex-basis.

Sintaxe:

flex: <flex-grow> <flex-shrink> <flex-basis>;

Valores comuns:

  • flex: initial - Equivale a 0 1 auto
  • flex: auto - Equivale a 1 1 auto
  • flex: none - Equivale a 0 0 auto
  • flex: <number> - Equivale a <number> 1 0

Exemplos:

/* Shorthand completa */
.complete-flex {
    flex: 1 1 200px;
}

/* Apenas grow */
.grow-only {
    flex: 1; /* Equivale a 1 1 0 */
}

/* Valores pré-definidos */
.initial {
    flex: initial; /* 0 1 auto */
}

.auto {
    flex: auto; /* 1 1 auto */
}

.none {
    flex: none; /* 0 0 auto */
}

/* Uso prático */
.equal-flex > * {
    flex: 1; /* Itens com tamanho igual */
}

.fixed-size {
    flex: 0 0 200px; /* Tamanho fixo, não cresce nem encolhe */
}

.fluid-item {
    flex: 1 1 0; /* Cresce e encolhe igualmente */
}

align-self

A propriedade align-self permite sobrescrever o align-items do contêiner para um item específico.

Valores possíveis:

  • auto (padrão) - Herda do contêiner
  • stretch - Estica para preencher
  • flex-start - Alinha no início
  • flex-end - Alinha no final
  • center - Alinha ao centro
  • baseline - Alinha pela linha de base

Exemplos:

/* Container com alinhamento padrão */
.container {
    display: flex;
    align-items: center;
}

/* Sobrescreve alinhamento para itens específicos */
.top-aligned {
    align-self: flex-start;
}

.bottom-aligned {
    align-self: flex-end;
}

.centered {
    align-self: center;
}

.stretched {
    align-self: stretch;
}

.baseline-aligned {
    align-self: baseline;
}

/* Uso prático */
.sticky-header {
    align-self: flex-start;
    position: sticky;
    top: 0;
}

.pushed-to-bottom {
    align-self: flex-end;
    margin-top: auto;
}

.special-card {
    align-self: stretch; /* Preenche altura disponível */
}
