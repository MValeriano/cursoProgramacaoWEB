Propriedades de Background CSS

Essas propriedades oferecem controle completo sobre a aparência do fundo dos elementos, permitindo criar designs complexos e visualmente atraentes.

Tabela de Referência Rápida

Propriedade Valores Comuns Padrão Descrição
background shorthand - Define todas as propriedades de fundo
background-attachment scroll, fixed, local scroll Comportamento de rolagem do fundo
background-clip border-box, padding-box, content-box, text border-box Área de pintura do fundo
background-color color, transparent transparent Cor de fundo
background-image url(), linear-gradient(), none none Imagem de fundo
background-origin padding-box, border-box, content-box padding-box Área de posicionamento do fundo
background-position top, center, bottom, left, right, x% y% 0% 0% Posição da imagem
background-repeat repeat, repeat-x, repeat-y, no-repeat repeat Repetição da imagem
background-size auto, cover, contain, length, percentage auto Tamanho da imagem

Dicas de Boas Práticas

  • Use a shorthand background para código mais limpo, mas lembre-se da ordem
  • Sempre forneça uma background-color de fallback caso a imagem não carregue
  • Use background-size: cover para imagens de fundo que devem preencher o elemento
  • Experimente background-attachment: fixed para efeitos parallax
  • Use múltiplas imagens de fundo para sobreposições complexas
  • Teste background-clip: text para textos com fundo criativo (com prefixo -webkit-)
  • Combine gradientes com imagens para overlays e efeitos visuais

background

A propriedade background é uma shorthand que permite definir todas as propriedades de fundo em uma única declaração.

Sintaxe:

background: [color] [image] [repeat] [attachment] [position] / [size] [origin] [clip];

Valores possíveis:

  • Combina todas as propriedades individuais de background
  • A ordem geralmente não importa, exceto para:
  • background-position e background-size devem ser separados por /
  • background-origin e background-clip - se apenas um valor for especificado, aplica-se a ambos

Exemplos:

/* Shorthand completo */
.element {
    background: #ffffff url("imagem.jpg") no-repeat fixed center / cover padding-box content-box;
}

/* Apenas cor */
.simple {
    background: #f0f0f0;
}

/* Cor e imagem */
.color-image {
    background: #000 url("textura.png") repeat;
}

/* Gradiente */
.gradient {
    background: linear-gradient(45deg, red, blue);
}

/* Múltiplos backgrounds */
.multiple {
    background: 
        url("image1.jpg") no-repeat left top,
        url("image2.png") repeat-x center bottom,
        linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5));
}

background-attachment

A propriedade background-attachment define se a imagem de fundo rola com o conteúdo ou é fixa.

Valores possíveis:

  • scroll - A imagem rola com o elemento (padrão)
  • fixed - A imagem é fixa em relação à viewport
  • local - A imagem rola com o conteúdo do elemento
  • inherit - Herda do elemento pai

Exemplos:

/* Fundo que rola com a página */
.scroll-bg {
    background-attachment: scroll;
}

/* Efeito parallax - fundo fixo */
.parallax {
    background-image: url("fundo.jpg");
    background-attachment: fixed;
    background-position: center;
    background-repeat: no-repeat;
    background-size: cover;
}

/* Fundo que rola com o conteúdo do elemento */
.local-bg {
    background-attachment: local;
    overflow: auto;
    height: 200px;
}

/* Múltiplos backgrounds com attachments diferentes */
.multi-attach {
    background: 
        url("bg1.jpg") fixed,
        url("bg2.png") scroll;
}

background-clip

A propriedade background-clip define a área de pintura do fundo.

Valores possíveis:

  • border-box - O fundo se estende até a borda (padrão)
  • padding-box - O fundo se estende até o padding
  • content-box - O fundo se estende apenas até o conteúdo
  • text - O fundo é recortado pelo texto (experimental)

Exemplos:

/* Fundo até a borda */
.border-clip {
    background-clip: border-box;
    border: 10px dashed rgba(0,0,0,0.3);
    padding: 20px;
}

/* Fundo até o padding */
.padding-clip {
    background-clip: padding-box;
    border: 10px dashed rgba(0,0,0,0.3);
    padding: 20px;
}

/* Fundo apenas no conteúdo */
.content-clip {
    background-clip: content-box;
    border: 10px dashed rgba(0,0,0,0.3);
    padding: 20px;
}

/* Fundo recortado pelo texto */
.text-clip {
    background: linear-gradient(45deg, red, blue);
    background-clip: text;
    -webkit-background-clip: text;
    color: transparent;
    font-size: 3em;
    font-weight: bold;
}

background-color

A propriedade background-color define a cor de fundo de um elemento.

Valores possíveis:

  • color - Qualquer valor de cor CSS
  • transparent - Fundo transparente (padrão)
  • inherit - Herda do elemento pai

Exemplos:

/* Cores básicas */
.red { background-color: red; }
.hex { background-color: #ff0000; }
.rgb { background-color: rgb(255, 0, 0); }
.rgba { background-color: rgba(255, 0, 0, 0.5); }
.hsl { background-color: hsl(0, 100%, 50%); }

/* Transparente */
.transparent { background-color: transparent; }

/* Com fallback para imagens */
.with-fallback {
    background-color: #f0f0f0;
    background-image: url("imagem.jpg");
}

/* Gradiente (usando background-image) */
.gradient-bg {
    background-image: linear-gradient(to right, red, yellow);
}

background-image

A propriedade background-image define uma ou mais imagens de fundo.

Valores possíveis:

  • none - Sem imagem (padrão)
  • url() - Caminho para a imagem
  • linear-gradient() - Gradiente linear
  • radial-gradient() - Gradiente radial
  • conic-gradient() - Gradiente cônico
  • repeating-linear-gradient() - Gradiente linear repetido
  • repeating-radial-gradient() - Gradiente radial repetido
  • Múltiplas imagens separadas por vírgula

Exemplos:

/* Imagem única */
.single-image {
    background-image: url("fundo.jpg");
}

/* Múltiplas imagens */
.multiple-images {
    background-image: 
        url("textura.png"),
        url("padrao.png");
}

/* Gradiente linear */
.linear-gradient {
    background-image: linear-gradient(45deg, #ff0000, #0000ff);
}

/* Gradiente radial */
.radial-gradient {
    background-image: radial-gradient(circle, red, yellow, green);
}

/* Gradiente cônico */
.conic-gradient {
    background-image: conic-gradient(red, yellow, green, blue, red);
}

/* Combinação de gradiente e imagem */
.combined {
    background-image: 
        linear-gradient(rgba(255,255,255,0.8), rgba(255,255,255,0.8)),
        url("fundo.jpg");
}

background-origin

A propriedade background-origin define a área de posicionamento da imagem de fundo.

Valores possíveis:

  • padding-box - A imagem é posicionada em relação ao padding (padrão)
  • border-box - A imagem é posicionada em relação à borda
  • content-box - A imagem é posicionada em relação ao conteúdo

Exemplos:

/* Posicionamento em relação ao padding */
.padding-origin {
    background-origin: padding-box;
    border: 10px dashed rgba(0,0,0,0.5);
    padding: 20px;
}

/* Posicionamento em relação à borda */
.border-origin {
    background-origin: border-box;
    border: 10px dashed rgba(0,0,0,0.5);
    padding: 20px;
}

/* Posicionamento em relação ao conteúdo */
.content-origin {
    background-origin: content-box;
    border: 10px dashed rgba(0,0,0,0.5);
    padding: 20px;
}

/* Diferente do clip */
.different-origin-clip {
    background-origin: content-box;
    background-clip: padding-box;
    border: 10px dashed rgba(0,0,0,0.5);
    padding: 20px;
}

background-position

A propriedade background-position define a posição inicial da imagem de fundo.

Valores possíveis:

  • keyword - top, bottom, left, right, center
  • percentage - Porcentagem horizontal e vertical
  • length - Valor em px, em, rem, etc.
  • Combinações de dois valores (horizontal e vertical)

Exemplos:

/* Palavras-chave */
.top-left { background-position: top left; }
.center { background-position: center; }
.bottom-right { background-position: bottom right; }

/* Porcentagens */
.percentage { background-position: 25% 75%; }

/* Valores específicos */
.pixel { background-position: 10px 20px; }
.mixed { background-position: center 20%; }

/* Múltiplas imagens com posições diferentes */
.multiple-positions {
    background-image: url("imagem1.png"), url("imagem2.png");
    background-position: top left, bottom right;
}

/* Posicionamento com calc() */
.calc-position {
    background-position: calc(100% - 20px) calc(100% - 10px);
}

background-repeat

A propriedade background-repeat define como a imagem de fundo é repetida.

Valores possíveis:

  • repeat - Repete em ambas as direções (padrão)
  • repeat-x - Repete apenas horizontalmente
  • repeat-y - Repete apenas verticalmente
  • no-repeat - Não repete
  • space - Repete sem cortar, distribuindo espaço entre as imagens
  • round - Repete e redimensiona para caber sem cortar

Exemplos:

/* Repetição padrão */
.repeat { background-repeat: repeat; }

/* Repetição horizontal */
.repeat-x { background-repeat: repeat-x; }

/* Repetição vertical */
.repeat-y { background-repeat: repeat-y; }

/* Não repetir */
.no-repeat { background-repeat: no-repeat; }

/* Repetir com espaçamento */
.space { background-repeat: space; }

/* Repetir e redimensionar */
.round { background-repeat: round; }

/* Múltiplas imagens com repetições diferentes */
.multiple-repeat {
    background-image: url("imagem1.png"), url("imagem2.png");
    background-repeat: no-repeat, repeat-x;
}

background-size

A propriedade background-size define o tamanho da imagem de fundo.

Valores possíveis:

  • auto - Tamanho original (padrão)
  • length - Largura e altura em px, em, rem, etc.
  • percentage - Porcentagem da área do elemento
  • cover - Redimensiona para cobrir todo o elemento (pode cortar a imagem)
  • contain - Redimensiona para caber todo o elemento (sem cortar)

Exemplos:

/* Tamanho automático */
.auto { background-size: auto; }

/* Tamanho específico */
.specific { background-size: 100px 200px; }

/* Porcentagem */
.percentage { background-size: 50% 75%; }

/* Cobrir todo o elemento */
.cover { background-size: cover; }

/* Conter a imagem sem cortar */
.contain { background-size: contain; }

/* Múltiplas imagens com tamanhos diferentes */
.multiple-sizes {
    background-image: url("imagem1.png"), url("imagem2.png");
    background-size: cover, contain;
}

/* Usando na shorthand */
.shorthand-size {
    background: url("imagem.jpg") center / cover no-repeat;
}
