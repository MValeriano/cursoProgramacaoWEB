Propriedades CSS Grid Layout

O CSS Grid é extremamente poderoso para criar layouts complexos e responsivos de forma intuitiva e eficiente!

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
display grid, inline-grid Define o contêiner grid
grid-template-columns 1fr 2fr, repeat(3, 1fr) Define colunas do grid
grid-template-rows 100px 1fr, minmax() Define linhas do grid
grid-template-areas Nomes entre aspas Define áreas nomeadas
gap 20px, 10px 15px Espaço entre células
justify-items start, center, stretch Alinha itens horizontalmente
align-items start, center, stretch Alinha itens verticalmente
grid-column 1 / 3, span 2 Posiciona item nas colunas
grid-row 2 / 4, span 3 Posiciona item nas linhas
grid-area Nome ou 1 / 1 / 3 / 3 Define área ou posição

display: grid

A propriedade display: grid transforma um elemento em um contêiner de grid. Seus filhos diretos se tornam automaticamente itens do grid.

Valores:

  • grid - Cria um grid de nível de bloco
  • inline-grid - Cria um grid de nível inline
.container {
    display: grid;
}

grid-template-columns

Define as colunas do grid especificando o tamanho de cada coluna.

Valores:

  • px, %, em, rem - Unidades de medida
  • fr - Unidade fracionária (fraction)
  • auto - Tamanho automático
  • minmax(min, max) - Define um intervalo de tamanho
  • repeat(n, size) - Repete um padrão
  • min-content, max-content - Baseado no conteúdo

Exemplos:

.container {
    /* 3 colunas fixas */
    grid-template-columns: 100px 200px 150px;
    
    /* 3 colunas com frações iguais */
    grid-template-columns: 1fr 1fr 1fr;
    
    /* Colunas responsivas */
    grid-template-columns: repeat(3, 1fr);
    
    /* Layout com sidebar */
    grid-template-columns: 250px 1fr;
    
    /* Colunas com tamanho mínimo e máximo */
    grid-template-columns: minmax(200px, 1fr) 2fr;
    
    /* Colunas automáticas */
    grid-template-columns: auto 1fr auto;
}

grid-template-rows

Define as linhas do grid especificando o tamanho de cada linha.

Valores:

(mesmos que grid-template-columns)

Exemplos:

.container {
    /* Linhas fixas */
    grid-template-rows: 50px 100px 150px;
    
    /* Linhas com frações */
    grid-template-rows: 1fr 2fr 1fr;
    
    /* Linha de cabeçalho e conteúdo */
    grid-template-rows: 80px 1fr;
    
    /* Linhas com minmax */
    grid-template-rows: minmax(100px, auto) 1fr;
}

grid-template-areas

Define um template visual para o grid usando nomes de áreas.

Valores:

  • Nomes de áreas entre aspas
  • . para células vazias
  • Múltiplas strings representando linhas

Exemplos:

.container {
    grid-template-areas: 
        "header header header"
        "sidebar content content"
        "footer footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer { grid-area: footer; }

gap (grid-gap)

Shorthand para definir row-gap e column-gap simultaneamente.

Valores:

grid-gap: <row-gap> <column-gap>;

Nota: Em versões modernas do CSS, usa-se gap em vez de grid-gap.

Valores (grid-column-gap / grid-row-gap):

  • px, em, rem, %

Exemplos (Antigo):

.container {
    grid-column-gap: 20px;
    grid-row-gap: 15px;
}

Exemplos (Moderno):

.container {
    gap: 20px;            /* row e column 20px */
    gap: 15px 10px;       /* row 15px, column 10px */
}

justify-items

Alinha os itens do grid ao longo do eixo inline (horizontal).

Valores:

  • start - Alinha no início
  • end - Alinha no final
  • center - Centraliza
  • stretch - Estica para preencher (padrão)

Exemplos:

.container {
    justify-items: start;   /* Alinha à esquerda */
    justify-items: center;  /* Centraliza horizontalmente */
    justify-items: stretch; /* Estica para preencher a célula */
}

align-items

Alinha os itens do grid ao longo do eixo block (vertical).

Valores:

(mesmos que justify-items)

Exemplos:

.container {
    align-items: start;    /* Alinha no topo */
    align-items: center;   /* Centraliza verticalmente */
    align-items: stretch;  /* Estica para preencher a célula */
}

justify-content

Alinha todo o grid dentro do contêiner ao longo do eixo inline (horizontal).

Valores:

  • start, end, center
  • stretch, space-around, space-between, space-evenly

Exemplos:

.container {
    justify-content: start;         /* Alinha à esquerda */
    justify-content: center;        /* Centraliza horizontalmente */
    justify-content: space-between; /* Espaço entre as colunas */
}

align-content

Alinha todo o grid dentro do contêiner ao longo do eixo block (vertical).

Valores:

(mesmos que justify-content)

Exemplos:

.container {
    align-content: start;         /* Alinha no topo */
    align-content: center;        /* Centraliza verticalmente */
    align-content: space-around;  /* Espaço ao redor das linhas */
}

grid-auto-columns / grid-auto-rows

Define o tamanho das colunas/linhas criadas implicitamente (quando há mais itens do que células definidas).

Valores:

  • px, fr, auto, minmax(), etc.

Exemplos:

.container {
    grid-auto-rows: 100px;     /* Novas linhas terão 100px */
    grid-auto-columns: 1fr;    /* Novas colunas terão 1fr */
}

grid-auto-flow

Controla como os itens são colocados automaticamente no grid.

Valores:

  • row - Preenche por linhas (padrão)
  • column - Preenche por colunas
  • dense - Tenta preencher espaços vazios

Exemplos:

.container {
    grid-auto-flow: row;       /* Preenche linha por linha */
    grid-auto-flow: column;    /* Preenche coluna por coluna */
    grid-auto-flow: row dense; /* Preenche linhas com densidade */
}

Propriedades para Itens do Grid

Estas propriedades são aplicadas diretamente aos itens filhos do contêiner grid.

grid-column-start / grid-column-end

Define onde um item começa e termina nas colunas.

grid-row-start / grid-row-end

Define onde um item começa e termina nas linhas.

grid-column / grid-row

Shorthands para definir início e fim de coluna/linha.

Valores: grid-column: <start> / <end>;

Valores: grid-row: <start> / <end>;

grid-area

Pode ser usado para:

  • Atribuir um nome de área (para usar com grid-template-areas)
  • Shorthand para grid-row-start, grid-column-start, grid-row-end, grid-column-end

Valores: grid-area: <name>;

Valores: grid-area: <row-start> / <column-start> / <row-end> / <column-end>;

Exemplos (grid-column/row):

.item {
    grid-column-start: 1;
    grid-column-end: 3;
    grid-row-start: 1;
    grid-row-end: 2;
}

.item {
    grid-column: 1 / 3;        /* Ocupa da linha 1 à 3 */
    grid-row: 2 / 4;           /* Ocupa da linha 2 à 4 */
    grid-column: 1 / span 2;   /* Começa na 1 e ocupa 2 colunas */
}

Exemplos (grid-area):

/* Para áreas nomeadas */
.item {
    grid-area: header;
}

/* Como shorthand de posicionamento */
.item {
    grid-area: 1 / 2 / 3 / 4; /* row-start / col-start / row-end / col-end */
}

Padrões Comuns de Layout

Exemplos de código para padrões de layout comuns usando CSS Grid.

Layout Básico com Áreas

.container {
    display: grid;
    grid-template-areas: 
        "header header"
        "sidebar content"
        "footer footer";
    grid-template-columns: 250px 1fr;
    grid-template-rows: 80px 1fr 60px;
    gap: 20px;
    height: 100vh;
}

Grid Responsivo

.responsive-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

Galeria de Imagens

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
    grid-auto-rows: 200px;
    gap: 10px;
}

Formulário com Grid

.form-grid {
    display: grid;
    grid-template-columns: 1fr 2fr;
    gap: 15px;
    align-items: center;
}
