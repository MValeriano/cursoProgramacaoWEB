Propriedades de Texto CSS

Essas propriedades são essenciais para o controle tipográfico avançado e layout de texto em CSS.

Tabela de Referência Rápida

Propriedade Valores Comuns Uso Principal
direction ltr, rtl Direção do texto
letter-spacing normal, 2px, -1px Espaço entre caracteres
text-align left, center, right, justify Alinhamento horizontal
text-decoration none, underline, line-through Decoração do texto
text-indent 2em, 40px, 10% Recuo da primeira linha
text-shadow 2px 2px 4px #000 Sombra do texto
text-transform none, uppercase, capitalize Capitalização
white-space normal, nowrap, pre Tratamento de espaços
word-break normal, break-all Quebra de palavras
word-spacing normal, 0.5em Espaço entre palavras
overflow-wrap normal, break-word Quebra de palavras longas

Dicas de Boas Práticas

  • Use text-align: justify com moderação - pode criar rios de espaço
  • Combine letter-spacing com text-transform: uppercase para títulos
  • Use overflow-wrap: break-word para conteúdo com URLs longas
  • Evite text-decoration: blink - é irritante e não é suportado
  • Teste white-space em conteúdo dinâmico
  • Use text-shadow sutilmente para melhor legibilidade

direction

A propriedade direction especifica a direção do texto: da direita para a esquerda (rtl) ou da esquerda para a direita (ltr).

Valores possíveis:

  • ltr - Da esquerda para a direita (padrão)
  • rtl - Da direita para a esquerda
  • inherit - Herda do elemento pai

Exemplos:

/* Texto normal (ocidental) */
.portugues {
    direction: ltr;
    text-align: left;
}

/* Texto árabe/hebraico */
.arabe {
    direction: rtl;
    text-align: right;
    font-family: "Arabic Typesetting", serif;
}

/* Exemplo prático */
.rtl-text {
    direction: rtl;
    unicode-bidi: bidi-override;
}

letter-spacing

A propriedade letter-spacing aumenta ou diminui o espaço entre caracteres.

Valores possíveis:

  • normal - Espaçamento normal (padrão)
  • length - Espaço adicional em px, em, rem, etc.
  • inherit - Herda do elemento pai

Exemplos:

/* Espaçamento normal */
.normal {
    letter-spacing: normal;
}

/* Espaçamento aumentado */
.wide {
    letter-spacing: 2px;
}

/* Espaçamento reduzido */
.tight {
    letter-spacing: -1px;
}

/* Uso prático */
.heading {
    letter-spacing: 1.5px;
    text-transform: uppercase;
}

.caption {
    letter-spacing: 0.5px;
}

.emphasis {
    letter-spacing: 2px;
    font-weight: bold;
}

text-align

A propriedade text-align especifica o alinhamento horizontal do texto.

Valores possíveis:

  • left - Alinha à esquerda (padrão)
  • right - Alinha à direita
  • center - Centraliza
  • justify - Justifica (alinha às duas margens)
  • start - Alinha ao início (depende da direção)
  • end - Alinha ao fim (depende da direção)
  • inherit - Herda do elemento pai

Exemplos:

/* Alinhamentos básicos */
.left-align {
    text-align: left;
}

.center-align {
    text-align: center;
}

.right-align {
    text-align: right;
}

.justify-align {
    text-align: justify;
}

/* Uso prático */
.header {
    text-align: center;
}

.article {
    text-align: justify;
    text-justify: inter-word;
}

.caption {
    text-align: right;
    font-style: italic;
}

.quote {
    text-align: center;
    font-style: italic;
}

text-align-last

A propriedade text-align-last especifica como alinhar a última linha de um texto.

Valores possíveis:

  • auto - Aplicado pelo navegador (padrão)
  • left - Alinha à esquerda
  • right - Alinha à direita
  • center - Centraliza
  • justify - Justifica
  • start - Alinha ao início
  • end - Alinha ao fim
  • inherit - Herda do elemento pai

Exemplos:

/* Justificar a última linha */
.justify-last {
    text-align: justify;
    text-align-last: justify;
}

/* Centralizar a última linha */
.center-last {
    text-align: justify;
    text-align-last: center;
}

/* Alinhar à direita a última linha */
.right-last {
    text-align: justify;
    text-align-last: right;
}

/* Uso em parágrafos */
.paragraph {
    text-align: justify;
    text-align-last: left;
    margin-bottom: 1em;
}

text-decoration

A propriedade text-decoration especifica a decoração adicionada ao texto (shorthand).

Valores possíveis:

  • none - Sem decoração (padrão)
  • underline - Linha abaixo do texto
  • overline - Linha acima do texto
  • line-through - Linha através do texto
  • blink - Texto piscante (não recomendado)
  • Combinações múltiplas

Propriedades individuais:

  • text-decoration-line
  • text-decoration-color
  • text-decoration-style
  • text-decoration-thickness

Exemplos:

/* Decorações básicas */
.underline {
    text-decoration: underline;
}

.overline {
    text-decoration: overline;
}

.line-through {
    text-decoration: line-through;
}

.multiple {
    text-decoration: underline overline;
}

/* Decorações avançadas */
.fancy-underline {
    text-decoration: underline wavy red 2px;
}

.custom-line {
    text-decoration-line: underline;
    text-decoration-color: blue;
    text-decoration-style: dashed;
    text-decoration-thickness: 3px;
}

/* Remover sublinhado de links */
a {
    text-decoration: none;
}

a:hover {
    text-decoration: underline;
}

text-indent

A propriedade text-indent especifica o recuo da primeira linha de um bloco de texto.

Valores possíveis:

  • length - Recuo fixo em px, em, rem, etc.
  • percentage - Recuo em % da largura do elemento pai
  • each-line - Recua a primeira linha após quebra forçada
  • hanging - Inverte o recuo (primeira linha sem recuo, demais com recuo)
  • inherit - Herda do elemento pai

Exemplos:

/* Recuo básico */
.indent-para {
    text-indent: 2em;
}

.indent-px {
    text-indent: 40px;
}

/* Recuo percentual */
.indent-percent {
    text-indent: 10%;
}

/* Recuo negativo (extensão) */
.hanging-indent {
    text-indent: -2em;
    padding-left: 2em;
}

/* Recuo especial para cada linha */
.each-line-indent {
    text-indent: 2em each-line;
}

/* Uso prático */
.article p {
    text-indent: 1.5em;
    margin-bottom: 1em;
}

.blockquote {
    text-indent: -1em;
    padding-left: 1em;
    border-left: 3px solid #ccc;
}

text-justify

A propriedade text-justify especifica o método de justificação quando text-align: justify é usado.

Valores possíveis:

  • auto - Navegador escolhe (padrão)
  • none - Justificação desativada
  • inter-word - Ajusta espaços entre palavras
  • inter-character - Ajusta espaços entre caracteres
  • distribute - Similar ao inter-word (legado)

Exemplos:

/* Justificação entre palavras */
.justify-words {
    text-align: justify;
    text-justify: inter-word;
}

/* Justificação entre caracteres */
.justify-chars {
    text-align: justify;
    text-justify: inter-character;
}

/* Para idiomas asiáticos */
.cjk-text {
    text-align: justify;
    text-justify: inter-character;
}

/* Uso prático */
.newspaper {
    text-align: justify;
    text-justify: inter-word;
    column-count: 2;
}

.article {
    text-align: justify;
    text-justify: auto;
    line-height: 1.6;
}

text-shadow

A propriedade text-shadow adiciona sombra ao texto.

Sintaxe:

text-shadow: offset-x offset-y blur-radius color;

Valores possíveis:

  • none - Sem sombra (padrão)
  • offset-x - Deslocamento horizontal (obrigatório)
  • offset-y - Deslocamento vertical (obrigatório)
  • blur-radius - Raio de desfoque (opcional)
  • color - Cor da sombra (opcional)
  • Múltiplas sombras separadas por vírgula

Exemplos:

/* Sombra simples */
.shadow-basic {
    text-shadow: 2px 2px #000;
}

/* Sombra com desfoque */
.shadow-blur {
    text-shadow: 2px 2px 5px #000;
}

/* Sombra colorida */
.shadow-color {
    text-shadow: 1px 1px 2px red;
}

/* Múltiplas sombras */
.shadow-multiple {
    text-shadow: 1px 1px 2px black, 0 0 25px blue, 0 0 5px darkblue;
}

/* Efeitos criativos */
.emboss {
    text-shadow: 1px 1px 1px #fff, -1px -1px 1px #000;
    color: #808080;
}

.glow {
    text-shadow: 0 0 10px #fff, 0 0 20px #fff, 0 0 30px #e60073;
}

text-transform

A propriedade text-transform controla a capitalização do texto.

Valores possíveis:

  • none - Sem transformação (padrão)
  • capitalize - Primeira letra de cada palavra em maiúscula
  • uppercase - Todas as letras em maiúscula
  • lowercase - Todas as letras em minúscula
  • full-width - Caracteres de largura total (CJK)
  • inherit - Herda do elemento pai

Exemplos:

/* Transformações básicas */
.none-case {
    text-transform: none;
}

.capitalize-case {
    text-transform: capitalize;
}

.uppercase-case {
    text-transform: uppercase;
}

.lowercase-case {
    text-transform: lowercase;
}

/* Uso prático */
.heading {
    text-transform: uppercase;
    letter-spacing: 2px;
}

.caption {
    text-transform: capitalize;
}

.code {
    text-transform: lowercase;
    font-family: monospace;
}

.menu-item {
    text-transform: capitalize;
}

white-space

A propriedade white-space especifica como os espaços em branco são tratados.

Valores possíveis:

  • normal - Colapsa espaços, quebra linhas normalmente (padrão)
  • nowrap - Colapsa espaços, sem quebra de linha
  • pre - Preserva espaços, quebra apenas em
    e nova linha
  • pre-wrap - Preserva espaços, quebra normally
  • pre-line - Colapsa espaços, preserva quebras
  • break-spaces - Similar ao pre-wrap, quebra espaços
  • inherit - Herda do elemento pai

Exemplos:

/* Comportamentos básicos */
.normal-space {
    white-space: normal;
}

.nowrap-space {
    white-space: nowrap;
}

.pre-space {
    white-space: pre;
}

.pre-wrap-space {
    white-space: pre-wrap;
}

.pre-line-space {
    white-space: pre-line;
}

/* Uso prático */
.code-block {
    white-space: pre;
    font-family: monospace;
    background: #f4f4f4;
}

.nowrap-text {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}

.poem {
    white-space: pre-line;
    font-style: italic;
}

word-break

A propriedade word-break especifica como quebrar palavras quando atingem o final da linha.

Valores possíveis:

  • normal - Quebra padrão (padrão)
  • break-all - Quebra em qualquer caractere
  • keep-all - Não quebra em caracteres CJK
  • break-word - Quebra palavras longas (legado, use overflow-wrap)
  • inherit - Herda do elemento pai

Exemplos:

/* Comportamentos de quebra */
.normal-break {
    word-break: normal;
}

.break-all {
    word-break: break-all;
}

.keep-all {
    word-break: keep-all;
}

/* Uso prático */
.long-words {
    word-break: break-all;
}

.cjk-text {
    word-break: keep-all;
}

.url-break {
    word-break: break-all;
    font-family: monospace;
}

word-spacing

A propriedade word-spacing aumenta ou diminui o espaço entre palavras.

Valores possíveis:

  • normal - Espaço normal (padrão)
  • length - Espaço adicional em px, em, rem, etc.
  • inherit - Herda do elemento pai

Exemplos:

/* Espaçamento normal */
.normal-word-space {
    word-spacing: normal;
}

/* Espaçamento aumentado */
.wide-word-space {
    word-spacing: 0.5em;
}

/* Espaçamento reduzido */
.tight-word-space {
    word-spacing: -1px;
}

/* Uso prático */
.justified-text {
    word-spacing: 0.1em;
    text-align: justify;
}

.heading {
    word-spacing: 0.2em;
    letter-spacing: 1px;
}

.poetic {
    word-spacing: 0.3em;
    line-height: 1.8;
}

word-wrap / overflow-wrap

A propriedade overflow-wrap (antiga word-wrap) especifica se o navegador pode quebrar palavras para evitar transbordamento.

Valores possíveis:

  • normal - Quebra apenas em pontos de quebra normais (padrão)
  • break-word - Quebra palavras longas
  • anywhere - Quebra em qualquer ponto
  • inherit - Herda do elemento pai

Exemplos:

/* Comportamentos de quebra */
.normal-wrap {
    overflow-wrap: normal;
}

.break-word {
    overflow-wrap: break-word;
}

.anywhere-wrap {
    overflow-wrap: anywhere;
}

/* Uso prático */
.container {
    overflow-wrap: break-word;
}

.long-content {
    overflow-wrap: anywhere;
}

.url-container {
    overflow-wrap: break-word;
    font-family: monospace;
}
