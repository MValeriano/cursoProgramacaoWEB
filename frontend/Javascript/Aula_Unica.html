JavaScript Básico - Guia Completo

1. Introdução ao JavaScript

O que é JavaScript?

JavaScript é uma linguagem de programação que permite adicionar interatividade e comportamento dinâmico às páginas web.

Características principais:

  • Linguagem de script do lado do cliente
  • Interpretada pelos navegadores
  • Multiparadigma (orientada a objetos, funcional, imperativa)
  • Não precisa de compilação
  • Padronizada como ECMAScript

Incluindo JavaScript em HTML

<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Básico</title>
    <!-- JavaScript externo -->
    <script src="script.js" defer></script>
    
    <!-- JavaScript interno -->
    <script>
        console.log("JavaScript carregado!");
    </script>
</head>
<body>
    <!-- JavaScript inline (não recomendado) -->
    <button onclick="alert('Clique!')">Clique aqui</button>
</body>
</html>

3. Variáveis e Tipos de Dados

Declaração de Variáveis

Como declarar variáveis com var, let e const.

Tipos de Dados Primitivos

String, Number, Boolean, Undefined, Null, Symbol, BigInt.

Verificação de Tipos

Usando o operador typeof.

Declaração:

// var (escopo de função - evite usar)
var nomeVar = "valor antigo";

// let (escopo de bloco - use para variáveis que mudam)
let nome = "João";
nome = "Maria"; // Reatribuição permitida

// const (escopo de bloco - use para constantes)
const PI = 3.14159;
// PI = 3.14; // ERRO: Não pode reatribuir

Tipos Primitivos:

// String (texto)
let nome = "João";
let sobrenome = 'Silva';
let template = `Olá, ${nome}!`; // Template literal

// Number (números)
let idade = 25;
let preco = 19.99;
let infinito = Infinity;
let naoNumero = NaN;

// Boolean (verdadeiro/falso)
let ativo = true;
let desativado = false;

// Undefined (não definido)
let indefinido;
console.log(indefinido); // undefined

// Null (nulo)
let vazio = null;

// Symbol (ES6 - valor único)
let id = Symbol("id");

// BigInt (números grandes)
let numeroGrande = 9007199254740991n;

Verificação de Tipos:

typeof "Hello";       // "string"
typeof 42;            // "number"
typeof true;          // "boolean"
typeof undefined;     // "undefined"
typeof null;          // "object" (peculiaridade do JavaScript)
typeof Symbol("id");  // "symbol"
typeof 42n;           // "bigint"

4. Operadores

Operadores Aritméticos

+, -, *, /, %, **, ++, --

Operadores de Atribuição

=, +=, -=, *=, /=, %=, **=

Operadores de Comparação

==, ===, !=, !==, >, <, >=, <=

Operadores Lógicos

&&, ||, !

Operador Ternário

condição ? valorSeVerdadeiro : valorSeFalso

Aritméticos:

let a = 10, b = 3;
console.log(a + b);   // 13 (adição)
console.log(a - b);   // 7 (subtração)
console.log(a * b);   // 30 (multiplicação)
console.log(a / b);   // 3.333... (divisão)
console.log(a % b);   // 1 (resto da divisão)
console.log(a ** b);  // 1000 (exponenciação)

let contador = 5;
contador++;           // 6 (pós-incremento)
++contador;           // 7 (pré-incremento)

Atribuição:

let x = 10;
x += 5;   // x = x + 5 → 15
x -= 3;   // x = x - 3 → 12
x *= 2;   // x = x * 2 → 24

Comparação:

// Igualdade simples (valor)
5 == "5";     // true

// Igualdade estrita (valor e tipo)
5 === "5";    // false

// Diferença estrita
5 !== "5";    // true

// Comparações numéricas
10 > 5;       // true

Lógicos:

// AND (E) - &&
true && true;     // true

// OR (OU) - ||
true || false;    // true

// NOT (NÃO) - !
!true;            // false

Ternário:

let idade = 20;
let status = idade >= 18 ? "Adulto" : "Menor";

5. Estruturas de Controle

Condicionais

if/else if/else e switch/case.

Loops

for, while, do...while, for...of, for...in.

Controle de Loops

break e continue.

if/else if/else:

let hora = 14;
if (hora < 12) {
    console.log("Bom dia!");
} else if (hora < 18) {
    console.log("Boa tarde!");
} else {
    console.log("Boa noite!");
}

switch/case:

let diaSemana = 3;
let nomeDia;
switch (diaSemana) {
    case 1: nomeDia = "Domingo"; break;
    case 2: nomeDia = "Segunda-feira"; break;
    case 3: nomeDia = "Terça-feira"; break;
    default: nomeDia = "Dia inválido";
}
console.log(nomeDia); // "Terça-feira"

for loop:

for (let i = 0; i < 5; i++) {
    console.log("Número: " + i);
}

while loop:

let contador = 0;
while (contador < 5) {
    console.log("Contador: " + contador);
    contador++;
}

for...of (arrays):

let frutas = ["maçã", "banana", "laranja"];
for (let fruta of frutas) {
    console.log(fruta);
}

for...in (objetos):

let pessoa = {nome: "João", idade: 30};
for (let propriedade in pessoa) {
    console.log(propriedade + ": " + pessoa[propriedade]);
}

break/continue:

for (let i = 0; i < 10; i++) {
    if (i === 5) {
        break; // para o loop
    }
    if (i % 2 === 0) {
        continue; // pula para a próxima iteração
    }
    console.log(i); // 1, 3
}

6. Funções

Declaração de Função

A forma clássica de definir uma função.

Expressão de Função

Atribuir uma função anônima a uma variável.

Arrow Function (ES6)

Sintaxe mais curta para funções.

Parâmetros e Argumentos

Definindo valores padrão e passando dados.

Escopo de Função

Entendendo variáveis globais e locais.

Declaração:

function cumprimentar(nome) {
    return "Olá, " + nome + "!";
}

Expressão:

const somar = function(a, b) {
    return a + b;
};

Arrow Function:

// Forma completa
const multiplicar = (a, b) => {
    return a * b;
};

// Forma simplificada (retorno implícito)
const dividir = (a, b) => a / b;

// Um parâmetro (parênteses opcionais)
const quadrado = x => x * x;

Parâmetros Padrão:

function calcular(a, b, operacao = "somar") {
    if (operacao === "somar") return a + b;
    if (operacao === "subtrair") return a - b;
    return "Operação inválida";
}
console.log(calcular(10, 5)); // 15

Escopo:

let global = "Sou global";
function testeEscopo() {
    let local = "Sou local";
    console.log(global); // Acessível
    console.log(local);  // Acessível
}
// console.log(local); // ERRO

7. Arrays

Criando e Acessando Arrays

Como criar e manipular listas de dados.

Métodos de Arrays Comuns

push, pop, shift, unshift, indexOf, includes.

Iteração em Arrays

forEach, map, filter, find, reduce.

Criando e Acessando:

let frutas = ["maçã", "banana", "laranja"];
console.log(frutas[0]); // "maçã"
frutas[1] = "pera";
console.log(frutas); // ["maçã", "pera", "laranja"]

Métodos Comuns:

let array = [1, 2, 3];
array.push(4);       // [1, 2, 3, 4]
let ultimo = array.pop(); // [1, 2, 3], ultimo = 4
array.unshift(0);    // [0, 1, 2, 3]
let primeiro = array.shift(); // [1, 2, 3], primeiro = 0
let indice = array.indexOf(2); // 1
let existe = array.includes(3); // true

Iteração:

let numeros = [1, 2, 3, 4, 5];

// forEach
numeros.forEach((numero, index) => {
    console.log(`Índice ${index}: ${numero}`);
});

// map (cria novo array)
let quadrados = numeros.map(num => num * num);

// filter (filtra elementos)
let pares = numeros.filter(num => num % 2 === 0);

// reduce (agrega valores)
let soma = numeros.reduce((acc, val) => acc + val, 0); // 15

8. Objetos

Criando e Acessando Objetos

Como criar e manipular estruturas de chave-valor.

Métodos Úteis de Objetos

Object.keys(), Object.values(), Object.entries(), Object.assign().

Criando e Acessando:

let pessoa = {
    nome: "João",
    idade: 30,
    "país de origem": "Brasil",
    saudacao: function() {
        return `Olá, meu nome é ${this.nome}`;
    }
};

console.log(pessoa.nome); // "João"
console.log(pessoa["idade"]); // 30
pessoa.profissao = "Desenvolvedor";
console.log(pessoa.saudacao()); // "Olá, meu nome é João"

Métodos Úteis:

let carro = {
    marca: "Toyota",
    modelo: "Corolla",
    ano: 2022
};

console.log(Object.keys(carro)); // ["marca", "modelo", "ano"]
console.log(Object.values(carro)); // ["Toyota", "Corolla", 2022]
console.log(Object.entries(carro));
// [["marca", "Toyota"], ["modelo", "Corolla"], ["ano", 2022]]

let carroCopia = Object.assign({}, carro);

9. Manipulação do DOM

Selecionando Elementos

getElementById, getElementsByClassName, getElementsByTagName, querySelector, querySelectorAll.

Modificando Conteúdo

innerHTML, textContent, innerText.

Modificando Atributos e Classes

setAttribute, getAttribute, classList.add, classList.remove, classList.toggle.

let elemento = document.getElementById("meuElemento");

imagem.classList.add("nova-classe");

10. Eventos

Adicionando Event Listeners

addEventListener e onclick.

Eventos Comuns

click, mouseover, keydown, submit, load, resize.

Prevenindo Comportamento Padrão

Usando event.preventDefault().

Delegação de Eventos

Otimizando eventos em listas.

Adicionando Eventos:

let botao = document.getElementById("meuBotao");
botao.addEventListener("click", function(event) {
    console.log("Botão clicado!");
    console.log(event.target);
});

Prevenindo Padrão:

let link = document.getElementById("meuLink");
link.addEventListener("click", function(event) {
    event.preventDefault(); // Impede o link de navegar
    console.log("Link clicado, mas não navega");
});

let formulario = document.getElementById("meuFormulario");
formulario.addEventListener("submit", function(event) {
    event.preventDefault(); // Impede o envio do formulário
    console.log("Formulário não enviado");
});

Delegação de Eventos:

let lista = document.getElementById("minhaLista");
lista.addEventListener("click", function(event) {
    if (event.target.tagName === "LI") {
        console.log("Item da lista clicado:", event.target.textContent);
    }
});

JavaScript (embutido no <script>):

// Array para armazenar as tarefas
let tarefas = [];

// Elementos do DOM
const inputTarefa = document.getElementById('novaTarefa');
const btnAdicionar = document.getElementById('btnAdicionar');
const btnLimpar = document.getElementById('btnLimpar');
const listaTarefas = document.getElementById('listaTarefas');
const totalTarefas = document.getElementById('totalTarefas');
const tarefasConcluidas = document.getElementById('tarefasConcluidas');
const tarefasPendentes = document.getElementById('tarefasPendentes');

// Função para adicionar tarefa
function adicionarTarefa() {
    const texto = inputTarefa.value.trim();
    
    if (texto === '') {
        alert('Por favor, digite uma tarefa!');
        return;
    }
    
    // Criar objeto da tarefa
    const tarefa = {
        id: Date.now(), // ID único baseado no timestamp
        texto: texto,
        concluida: false,
        dataCriacao: new Date()
    };
    
    // Adicionar ao array
    tarefas.push(tarefa);
    
    // Limpar input
    inputTarefa.value = '';
    
    // Atualizar a interface
    renderizarTarefas();
    atualizarEstatisticas();
}

// Função para renderizar todas as tarefas
function renderizarTarefas() {
    // Limpar lista
    listaTarefas.innerHTML = '';
    
    // Adicionar cada tarefa
    tarefas.forEach(tarefa => {
        const elemento = document.createElement('div');
        elemento.className = `tarefa ${tarefa.concluida ? 'concluida' : ''}`;
        elemento.innerHTML = `
            <span>${tarefa.texto}</span>
            <div>
                <button onclick="alternarTarefa(${tarefa.id})">
                    ${tarefa.concluida ? 'Desfazer' : 'Concluir'}
                </button>
                <button onclick="removerTarefa(${tarefa.id})">Remover</button>
            </div>
        `;
        listaTarefas.appendChild(elemento);
    });
}

// Função para alternar estado da tarefa
function alternarTarefa(id) {
    tarefas = tarefas.map(tarefa => {
        if (tarefa.id === id) {
            return { ...tarefa, concluida: !tarefa.concluida };
        }
        return tarefa;
    });
    
    renderizarTarefas();
    atualizarEstatisticas();
}

// Função para remover tarefa
function removerTarefa(id) {
    tarefas = tarefas.filter(tarefa => tarefa.id !== id);
    renderizarTarefas();
    atualizarEstatisticas();
}

// Função para limpar tarefas concluídas
function limparConcluidas() {
    tarefas = tarefas.filter(tarefa => !tarefa.concluida);
    renderizarTarefas();
    atualizarEstatisticas();
}

// Função para atualizar estatísticas
function atualizarEstatisticas() {
    const total = tarefas.length;
    const concluidas = tarefas.filter(t => t.concluida).length;
    const pendentes = total - concluidas;
    
    totalTarefas.textContent = total;
    tarefasConcluidas.textContent = concluidas;
    tarefasPendentes.textContent = pendentes;
}

// Event Listeners
btnAdicionar.addEventListener('click', adicionarTarefa);

btnLimpar.addEventListener('click', limparConcluidas);

// Adicionar tarefa pressionando Enter
inputTarefa.addEventListener('keypress', function(event) {
    if (event.key === 'Enter') {
        adicionarTarefa();
    }
});

// Inicializar estatísticas
atualizarEstatisticas();

// Adicionar algumas tarefas de exemplo
tarefas = [
    { id: 1, texto: 'Aprender JavaScript básico', concluida: true, dataCriacao: new Date() },
    { id: 2, texto: 'Praticar com exercícios', concluida: false, dataCriacao: new Date() },
    { id: 3, texto: 'Criar um projeto simples', concluida: false, dataCriacao: new Date() }
];

renderizarTarefas();
atualizarEstatisticas();
