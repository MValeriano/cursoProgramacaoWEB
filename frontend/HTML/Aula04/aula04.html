6. Listas

Tag Função
<ul> Lista não ordenada (com bolinhas)
<ol> Lista ordenada (numerada)
<li> Item de lista

Tag <ul>

A tag <ul> é usada para agrupar uma coleção de itens que não têm uma ordem numérica ou sequencial específica. Cada item da lista é marcado com um bullet point (marcador) por padrão.

Características importantes:

  • É um elemento de bloco
  • Pode conter apenas elementos <li> como filhos diretos
  • Os marcadores podem ser customizados com CSS (disc, circle, square, none)
  • Pode ser aninhado para criar sublistas
  • Comumente usado para menus, índices e listas de itens sem ordem específica

Atributos principais:

  • type - Define o tipo de marcador (disc, circle, square) - Obsoleto em HTML5, use CSS
  • class - Para aplicar estilos CSS
  • id - Para identificação única

Declaração:

<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>

<!-- Lista com sublista -->
<ul>
    <li>Item principal 1
        <ul>
            <li>Subitem 1.1</li>
            <li>Subitem 1.2</li>
        </ul>
    </li>
    <li>Item principal 2</li>
</ul>

<!-- Lista com CSS personalizado -->
<ul class="lista-personalizada">
    <li>Item com estilo customizado</li>
    <li>Outro item</li>
</ul>

Tag <ol>

A tag <ol> é usada para agrupar uma coleção de itens onde a sequência é importante. Cada item é numerado automaticamente em ordem crescente.

Características importantes:

  • É um elemento de bloco
  • Pode conter apenas elementos <li> como filhos diretos
  • A numeração é automática e começa em 1 por padrão
  • Suporta diferentes tipos de numeração (números, letras, algarismos romanos)
  • Pode ser invertida ou começar de um número específico

Atributos principais:

  • type - Define o tipo de numeração (1, A, a, I, i)
  • start - Define o número inicial da lista
  • reversed - Inverte a ordem da numeração (do maior para o menor)

Declaração:

<!-- Lista ordenada padrão (numérica) -->
<ol>
    <li>Primeiro item</li>
    <li>Segundo item</li>
    <li>Terceiro item</li>
</ol>

<!-- Lista ordenada com letras maiúsculas -->
<ol type="A">
    <li>Item A</li>
    <li>Item B</li>
    <li>Item C</li>
</ol>

<!-- Lista ordenada começando em 10 -->
<ol start="10">
    <li>Item 10</li>
    <li>Item 11</li>
    <li>Item 12</li>
</ol>

<!-- Lista ordenada reversa -->
<ol reversed>
    <li>Item 3</li>
    <li>Item 2</li>
    <li>Item 1</li>
</ol>

<!-- Lista com algarismos romanos -->
<ol type="I">
    <li>Capítulo I</li>
    <li>Capítulo II</li>
    <li>Capítulo III</li>
</ol>

Tag <li>

A tag <li> (list item) é usada para definir cada item em uma lista, seja ela ordenada (<ol>) ou não ordenada (<ul>). É o elemento que contém o conteúdo real de cada item da lista.

Características importantes:

  • É um elemento de bloco
  • Deve estar dentro de um elemento <ul>, <ol> ou <menu>
  • Pode conter outros elementos HTML (texto, imagens, links, outras listas)
  • Em listas ordenadas, o valor de um item pode ser alterado com o atributo value

Dicas de Uso

  • Para menus de navegação: Use <ul> com <li> contendo links
  • Para instruções passo a passo: Use <ol> para indicar sequência
  • Para listas de recursos/benefícios: Use <ul> com ícones customizados
  • Para rankings/classificações: Use <ol> com numeração
  • Sempre aninhe <li> dentro de <ul> ou <ol> - não use <li> sozinho

Atributos principais:

  • value - Em listas ordenadas, define o número do item (apenas para <ol>)

Declaração:

<!-- Item em lista não ordenada -->
<ul>
    <li>Item sem ordem específica</li>
</ul>

<!-- Item em lista ordenada -->
<ol>
    <li>Primeiro item</li>
    <li value="5">Item com valor 5 (a numeração pula para 5)</li>
    <li>Próximo item será 6</li>
</ol>

<!-- Item com conteúdo complexo -->
<ul>
    <li>
        <h3>Título do item</h3>
        <p>Descrição do item.</p>
        <img src="imagem.jpg" alt="Imagem do item">
    </li>
</ul>

<!-- Item com link -->
<ul>
    <li><a href="#home">Home</a></li>
    <li><a href="#sobre">Sobre</a></li>
</ul>
