7. Tabelas

Tag Função
<table> Tabela
<tr> Linha
<td> Célula
<th> Cabeçalho da tabela
<thead>, <tbody> Divisão semântica da tabela

Dicas de Uso

As tabelas são ideais para exibir dados tabulares, como planilhas, listas de preços, horários, comparações e dados estatísticos.

  • Use <thead>, <tbody> e <tfoot> para melhorar a semântica e acessibilidade
  • Use scope em <th> para indicar se o cabeçalho é para linha ou coluna
  • Use caption para fornecer uma legenda descritiva para a tabela
  • Use colspan e rowspan para mesclar células quando necessário
  • Evite usar tabelas para layout - use CSS Grid ou Flexbox para layout de página
  • Sempre forneça títulos ou descrições para tabelas complexas
  • Use CSS para estilização em vez de atributos obsoletos como border, cellpadding

Tag <table>

A tag <table> é o elemento container que define uma tabela HTML. Todas as outras tags de tabela devem estar contidas dentro dela. As tabelas são usadas para exibir dados em formato tabular, com linhas e colunas.

Características importantes:

  • É um elemento de bloco
  • Pode conter elementos como <caption>, <colgroup>, <thead>, <tbody>, <tfoot>, <tr>
  • A estrutura semântica é importante para acessibilidade
  • Pode ser estilizada com CSS para controlar aparência e layout
  • Não deve ser usada para layout de página (use CSS Grid ou Flexbox)

Atributos principais:

  • border - Define a borda da tabela (obsoleto em HTML5, use CSS)
  • cellpadding - Espaço entre o conteúdo da célula e sua borda (obsoleto)
  • cellspacing - Espaço entre células (obsoleto)
  • width - Largura da tabela (obsoleto, use CSS)

Declaração:

<table>
    <tr>
        <th>Nome</th>
        <th>Idade</th>
    </tr>
    <tr>
        <td>João</td>
        <td>25</td>
    </tr>
</table>

Tag <tr>

A tag <tr> (table row) é usada para criar uma linha dentro de uma tabela. Cada <tr> pode conter uma ou mais células, que podem ser <th> (cabeçalho) ou <td> (dados).

Características importantes:

  • Deve estar dentro de <table>, <thead>, <tbody> ou <tfoot>
  • Pode conter apenas <th> ou <td> como filhos diretos
  • Pode ser estilizada com CSS para alterar a aparência da linha
  • As linhas são renderizadas na ordem em que aparecem no código

Declaração:

<table>
    <tr> <!-- Linha 1: Cabeçalho -->
        <th>Produto</th>
        <th>Preço</th>
    </tr>
    <tr> <!-- Linha 2: Dados -->
        <td>Notebook</td>
        <td>R$ 2500,00</td>
    </tr>
</table>

Tag <td>

A tag <td> (table data) é usada para criar uma célula que contém dados em uma tabela. Deve estar dentro de uma linha (<tr>).

Características importantes:

  • É um elemento de bloco
  • Deve estar dentro de um <tr>
  • Pode conter qualquer conteúdo (texto, imagens, links, outras tabelas, etc.)
  • Pode usar atributos para mesclagem de células (colspan e rowspan)
  • Por padrão, o texto é alinhado à esquerda e verticalmente ao meio

Atributos principais:

  • colspan - Número de colunas que a célula deve ocupar
  • rowspan - Número de linhas que a célula deve ocupar
  • headers - Associar a célula a um ou mais cabeçalhos (para acessibilidade)

Declaração:

<table>
    <tr>
        <td>Nome</td>
        <td>João</td>
    </tr>
    <tr>
        <td>Idade</td>
        <td>25</td>
    </tr>
</table>

<!-- Exemplo com colspan -->
<table>
    <tr>
        <td colspan="2">Célula que ocupa duas colunas</td>
    </tr>
    <tr>
        <td>Coluna 1</td>
        <td>Coluna 2</td>
    </tr>
</table>

<!-- Exemplo com rowspan -->
<table>
    <tr>
        <td rowspan="2">Célula que ocupa duas linhas</td>
        <td>Linha 1</td>
    </tr>
    <tr>
        <td>Linha 2</td>
    </tr>
</table>

Tag <th>

A tag <th> (table header) é usada para criar uma célula de cabeçalho. Normalmente é exibida em negrito e centralizada por padrão. Fornece contexto semântico para os dados da coluna ou linha.

Características importantes:

  • É um elemento de bloco
  • Deve estar dentro de um <tr>
  • Por padrão, o texto é em negrito e centralizado
  • Pode usar scope para definir o escopo (col, row, colgroup, rowgroup)
  • Pode usar abbr para uma versão abreviada do conteúdo
  • Importante para acessibilidade e SEO

Atributos principais:

  • scope - Define o escopo do cabeçalho (col, row, colgroup, rowgroup)
  • abbr - Fornece uma abreviação para o conteúdo do cabeçalho
  • colspan - Mesclagem de colunas
  • rowspan - Mesclagem de linhas

Declaração:

<table>
    <tr>
        <th scope="col">Nome</th>
        <th scope="col">Idade</th>
    </tr>
    <tr>
        <td>Maria</td>
        <td>30</td>
    </tr>
</table>

<!-- Exemplo com scope row -->
<table>
    <tr>
        <th scope="row">Nome:</th>
        <td>Maria</td>
    </tr>
    <tr>
        <th scope="row">Idade:</th>
        <td>30</td>
    </tr>
</table>

<!-- Exemplo com abbr -->
<table>
    <tr>
        <th abbr="Preço unitário">Preço Unit.</th>
        <th abbr="Quantidade">Qtd</th>
    </tr>
</table>

Tag <thead>

A tag <thead> (table head) é usada para agrupar um conjunto de linhas que formam o cabeçalho da tabela. Deve conter uma ou mais tags <tr> com células <th>.

Características importantes:

  • Deve ser usado dentro de <table>
  • Deve conter pelo menos uma linha (<tr>)
  • Normalmente é seguido por <tbody> e <tfoot>
  • Útil para rolagem de tabelas longas, onde o cabeçalho permanece visível
  • Melhora a acessibilidade e a semântica
  • Pode ser estilizado separadamente do corpo da tabela

Declaração:

<table>
    <thead>
        <tr>
            <th>Mês</th>
            <th>Vendas</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Janeiro</td>
            <td>R$ 1000,00</td>
        </tr>
    </tbody>
</table>

Tag <tbody>

A tag <tbody> (table body) é usada para agrupar o conteúdo principal da tabela. Pode aparecer uma ou mais vezes, mas normalmente é usado uma vez. Deve conter as linhas com os dados da tabela.

Características importantes:

  • Deve ser usado dentro de <table>
  • Pode conter uma ou mais linhas (<tr>)
  • Normalmente segue <thead> e precede <tfoot>
  • Útil para estilização e rolagem de tabelas longas
  • Se não for especificado, o navegador cria um <tbody> implícito

Declaração:

<table>
    <thead>
        <tr>
            <th>Produto</th>
            <th>Preço</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Notebook</td>
            <td>R$ 2500,00</td>
        </tr>
        <tr>
            <td>Mouse</td>
            <td>R$ 50,00</td>
        </tr>
    </tbody>
</table>
