9. Scripts e Estilos

Tag Função
<style> CSS direto no HTML
<link> Importa CSS externo
<script> Código JavaScript
<meta> Fornecer metadados sobre o documento HTML

Essas tags são fundamentais para adicionar comportamento e estilo às páginas web, transformando HTML estático em aplicações interativas e visualmente atraentes.

Tag <style>

A tag <style> é usada para incluir folhas de estilo CSS diretamente no documento HTML, sem a necessidade de um arquivo externo. Os estilos definidos dentro desta tag afetam apenas o documento atual.

Características importantes:

  • Deve estar dentro da seção <head> (melhor prática)
  • É um elemento de bloco
  • Pode conter qualquer código CSS válido
  • Útil para estilos específicos de uma única página
  • Menos eficiente que CSS externo para estilos reutilizáveis

Atributos principais:

  • type - Tipo de conteúdo (padrão é "text/css") - Opcional em HTML5
  • media - Define para quais dispositivos/mídias o estilo se aplica
  • scoped - Define que os estilos só se aplicam ao elemento pai (obsoleto)

Dicas de Boas Práticas:

  • Use para estilos específicos de página única
  • Evite para estilos reutilizáveis (use CSS externo)
  • Coloque no <head> para evitar FOUC (Flash of Unstyled Content)
  • Use media queries para responsividade

Declaração:

<!DOCTYPE html>
<html>
<head>
    <style>
        body {
            font-family: Arial, sans-serif;
            margin: 0;
            padding: 20px;
        }
        
        h1 {
            color: #333;
            border-bottom: 2px solid #ccc;
        }
        
        .destaque {
            background-color: yellow;
            padding: 10px;
        }
    </style>
</head>
<body>
    <h1>Título da Página</h1>
    <p class="destaque">Texto destacado</p>
</body>
</html>

Tag <link>

A tag <link> é usada para importar recursos externos para o documento HTML. É mais comumente usada para vincular folhas de estilo CSS externas, mas também pode ser usada para ícones, pré-carregamento de recursos e mais.

Características importantes:

  • É uma tag vazia (self-closing)
  • Deve estar dentro da seção <head>
  • Não afeta a aparência visual do documento por si só
  • Pode ser usada para múltiplos recursos
  • Melhor prática para CSS reutilizável em múltiplas páginas

Atributos principais:

  • rel - Tipo de relação com o documento (obrigatório)
  • href - URL do recurso (obrigatório para CSS)
  • type - Tipo de conteúdo (opcional para CSS em HTML5)
  • media - Para quais dispositivos/mídias o recurso se aplica
  • crossorigin - Para requisições CORS
  • integrity - Verificação de integridade do

Valores comuns para rel:

  • stylesheet - Folha de estilo CSS
  • icon / shortcut icon - Ícone da página
  • preload - Pré-carregar recurso
  • preconnect - Estabelecer conexão antecipada
  • alternate - Versão alternativa do documento
  • canonical - URL canônica para SEO

Dicas de Boas Práticas:

  • Use para CSS externo e recursos reutilizáveis
  • Prefira <link> sobre @import para CSS
  • Use preload para recursos críticos
  • Use integrity para CDNs de terceiros

Declaração:

<!DOCTYPE html>
<html>
<head>
    <!-- CSS externo -->
    <link rel="stylesheet" href="estilos.css">
    
    <!-- CSS com media query -->
    <link rel="stylesheet" href="mobile.css" media="(max-width: 768px)">
    
    <!-- Ícone da página (favicon) -->
    <link rel="icon" href="favicon.ico" type="image/x-icon">
    
    <!-- Pré-carregamento de recursos -->
    <link rel="preload" href="fonte.woff2" as="font" type="font/woff2" crossorigin>
    
    <!-- CSS com verificação de integridade -->
    <link rel="stylesheet" 
          href="https://cdn.example.com/bootstrap.css"
          xintegrity="sha384-123456..."
          crossorigin="anonymous">
</head>
<body>
    <!-- Conteúdo da página -->
</body>
</html>

Tag <script>

A tag <script> é usada para incluir código JavaScript diretamente no HTML ou vincular arquivos JavaScript externos. Pode ser colocada no <head> ou <body>, sendo recomendado no final do <body> para melhor performance.

Características importantes:

  • Pode conter código inline ou referenciar arquivo externo
  • Pode bloquear a renderização da página se não usado corretamente
  • Suporta diferentes tipos de módulos JavaScript
  • Pode ser executado imediatamente ou de forma assíncrona/diferida

Atributos principais:

  • src - URL do arquivo JavaScript externo
  • type - Tipo de script (text/javascript, module, etc.)
  • async - Executa o script assincronamente
  • defer - Adia a execução até que o HTML seja parseado
  • crossorigin - Para requisições CORS
  • integrity - Verificação de integridade do script

Dicas de Boas Práticas:

  • Coloque no final do <body> para melhor performance
  • Use defer para scripts que precisam do DOM
  • Use async para scripts independentes
  • Use type="module" para código ES6 moderno
  • Sempre use integrity com CDNs

Declaração:

<!DOCTYPE html>
<html>
<head>
    <title>Página com Scripts</title>
    
    <!-- Script externo com defer (recomendado para scripts no head) -->
    <script src="analytics.js" defer></script>
</head>
<body>
    <h1>Minha Página</h1>
    
    <!-- Script inline -->
    <script>
        console.log('Página carregada');
        
        function saudacao() {
            alert('Olá, mundo!');
        }
    </script>
    
    <!-- Script externo (recomendado no final do body) -->
    <script src="app.js"></script>
    
    <!-- Script como módulo ES6 -->
    <script type="module">
        import { funcao } from './modulo.js';
        funcao();
    </script>
    
    <!-- Script externo com async (executa assim que disponível) -->
    <script src="widget.js" async></script>
    
    <!-- Script de terceiros com integridade -->
    <script src="https://cdn.example.com/library.js"
            xintegrity="sha384-abcdef..."
            crossorigin="anonymous"></script>
</body>
</html>

Tag <meta>

A tag <meta> é usada para representar metadados que não podem ser representados por outras tags HTML como <title>, <link>, <script>, <style>. Esses metadados são usados para especificar conjunto de caracteres, descrição da página, palavras-chave, autor, viewport, etc.

Características importantes:

  • É uma tag vazia (self-closing)
  • Sempre fica dentro da seção <head>
  • Não é exibida na página, mas é lida pelo navegador e motores de busca
  • Pode ser usada para controlar o layout em dispositivos móveis (viewport)

Atributos principais:

  • charset - Define a codificação de caracteres (ex: UTF-8)
  • name - Nome do metadado (viewport, description, keywords, etc.)
  • content - Conteúdo associado ao metadado
  • http-equiv - Fornece cabeçalhos HTTP equivalentes (refresh, content-type, etc.)

Dicas de Uso:

  • Sempre inclua charset="UTF-8" para evitar problemas de codificação
  • Use a viewport para design responsivo
  • Forneça uma descrição para melhorar o SEO
  • Use http-equiv="refresh" com cuidado (pode ser irritante para usuários)

Declaração:

<head>
    <!-- Codificação de caracteres -->
    <meta charset="UTF-8">

    <!-- Viewport para design responsivo -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Descrição para SEO -->
    <meta name="description" content="Uma página de exemplo sobre tags HTML">

    <!-- Palavras-chave (menos importante hoje) -->
    <meta name="keywords" content="HTML, CSS, JavaScript">

    <!-- Autor -->
    <meta name="author" content="João Silva">

    <!-- Atualização automática (a cada 30 segundos) -->
    <meta http-equiv="refresh" content="30">

    <!-- Compatibilidade com IE -->
    <meta http-equiv="X-UA-Compatible" content="IE=edge">

    <!-- Controlar o comportamento de zoom em dispositivos móveis -->
    <meta name="viewport" content="width=device-width, user-scalable=no">
</head>
