Exercícios de HTML

6. Listas

Exercício 1

Enunciado: Crie uma lista não ordenada de ingredientes para uma receita de bolo.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Receita de Bolo</title>
</head>
<body>
    <h1>Bolo de Chocolate</h1>
    <h2>Ingredientes</h2>
    <ul>
        <li>2 xícaras de farinha de trigo</li>
        <li>1 xícara de açúcar</li>
        <li>1 xícara de chocolate em pó</li>
        <li>1 xícara de leite</li>
        <li>3 ovos</li>
        <li>1/2 xícara de óleo</li>
        <li>1 colher de sopa de fermento</li>
    </ul>
</body>
</html>

Exercício 2

Enunciado: Crie uma lista ordenada com os passos para montar um computador.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Montagem de Computador</title>
</head>
<body>
    <h1>Como Montar um Computador</h1>
    <ol>
        <li>Prepare a bancada e os componentes</li>
        <li>Instale a placa-mãe no gabinete</li>
        <li>Instale o processador na placa-mãe</li>
        <li>Instale a memória RAM</li>
        <li>Conecte os cabos de alimentação</li>
        <li>Instale o armazenamento (SSD/HD)</li>
        <li>Feche o gabinete e conecte os periféricos</li>
    </ol>
</body>
</html>

Exercício 3

Enunciado: Crie uma lista de definição com termos de informática e suas definições.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Glossário de Informática</title>
</head>
<body>
    <h1>Glossário de Informática</h1>
    <dl>
        <dt>HTML</dt>
        <dd>Linguagem de marcação utilizada para criar páginas web.</dd>
        
        <dt>CSS</dt>
        <dd>Linguagem de estilo usada para definir a apresentação de documentos HTML.</dd>
        
        <dt>JavaScript</dt>
        <dd>Linguagem de programação que permite interatividade em páginas web.</dd>
    </dl>
</body>
</html>

    <ol>
        <li>Preparação
            <ul>
                <li>Verifique os requisitos do sistema</li>
                <li>Faça backup dos dados importantes</li>
            </ul>
        </li>
        <li>Instalação
            <ul>
                <li>Execute o arquivo de instalação</li>
                <li>Siga as instruções do assistente</li>
            </ul>
        </li>
        <li>Configuração
            <ul>
                <li>Abra o software</li>
                <li>Configure as preferências</li>
            </ul>
        </li>
    </ol>
</body>
</html>

Exercício 8

Enunciado: Crie uma lista de links de navegação usando lista não ordenada.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Navegação</title>
</head>
<body>
    <nav>
        <ul>
            <li><a href="#home">Home</a></li>
            <li><a href="#sobre">Sobre</a></li>
            <li><a href="#servicos">Serviços</a></li>
            <li><a href="#contato">Contato</a></li>
        </ul>
    </nav>
</body>
</html>
