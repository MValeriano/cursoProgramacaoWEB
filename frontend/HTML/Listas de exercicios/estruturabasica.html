Exercícios de HTML

1. Estrutura básica da página

Exercício 1

Enunciado: Crie uma página HTML básica para um blog pessoal. A página deve ter a estrutura completa com DOCTYPE, html, head e body. No head, inclua o título "Meu Blog Pessoal" e charset UTF-8.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu Blog Pessoal</title>
</head>
<body>
    <!-- Conteúdo do blog será adicionado aqui -->
</body>
</html>

Exercício 2

Enunciado: Crie a estrutura básica de uma página de receitas. Inclua o título "Receitas da Vovó" e defina o idioma como português brasileiro.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Receitas da Vovó</title>
</head>
<body>
    <h1>Bem-vindo às Receitas da Vovó</h1>
</body>
</html>

Exercício 3

Enunciado: Desenvolva a estrutura inicial de um site de notícias chamado "Jornal Diário". Inclua todos os elementos essenciais de uma página HTML.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jornal Diário</title>
</head>
<body>
    <header>
        <h1>Jornal Diário</h1>
    </header>
</body>
</html>

Exercício 4

Enunciado: Crie uma página HTML para um portfólio profissional. A página deve ter estrutura completa e título "Meu Portfólio - João Silva".

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="description" content="Portfólio profissional de João Silva">
    <title>Meu Portfólio - João Silva</title>
</head>
<body>
    <h1>João Silva - Desenvolvedor Web</h1>
</body>
</html>

Exercício 5

Enunciado: Construa a estrutura básica de uma landing page para um produto. Inclua metadados para SEO com descrição e palavras-chave.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Produto revolucionário para facilitar seu dia a dia">
    <meta name="keywords" content="produto, inovação, tecnologia, facilidade">
    <title>SuperProduto - Revolucione Seu Dia</title>
</head>
<body>
    <h1>Conheça o SuperProduto</h1>
</body>
</html>
