Exercícios de HTML

5. Links e mídia

Exercício 1

Enunciado: Crie uma página de perfil pessoal com uma imagem de perfil, um link para o portfólio e um link para enviar email.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Perfil Pessoal - Ana Costa</title>
</head>
<body>
    <h1>Ana Costa</h1>
    <img src="foto-perfil.jpg" alt="Foto de Ana Costa" width="200">
    <p>Desenvolvedora Front-end e UX Designer</p>
    
    <h2>Links</h2>
    <ul>
        <li><a href="https://www.meuportfolio.com" target="_blank">Portfólio</a></li>
        <li><a href="mailto:ana.costa@email.com">Enviar Email</a></li>
    </ul>
</body>
</html>

Exercício 2

Enunciado: Crie uma galeria de imagens com 3 imagens, cada uma com link para uma versão em tamanho maior.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Galeria de Fotos</title>
</head>
<body>
    <h1>Galeria de Fotos</h1>
    <div class="galeria">
        <a href="foto1-grande.jpg">
            <img src="foto1-pequena.jpg" alt="Paisagem 1" width="300">
        </a>
        <a href="foto2-grande.jpg">
            <img src="foto2-pequena.jpg" alt="Paisagem 2" width="300">
        </a>
        <a href="foto3-grande.jpg">
            <img src="foto3-pequena.jpg" alt="Paisagem 3" width="300">
        </a>
    </div>
</body>
</html>

Exercício 3

Enunciado: Crie uma página com um vídeo local que tenha controles e uma imagem de poster.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Vídeo Demonstrativo</title>
</head>
<body>
    <h1>Vídeo Demonstrativo do Produto</h1>
    <video controls width="600" poster="poster.jpg">
        <source src="video-demo.mp4" type="video/mp4">
        Seu navegador não suporta o elemento de vídeo.
    </video>
</body>
</html>

Exercício 5

Enunciado: Crie uma página que incorpora um vídeo do YouTube usando iframe.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Vídeo do YouTube</title>
</head>
<body>
    <h1>Vídeo Incrível do YouTube</h1>
    <iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" 
            title="Vídeo do YouTube" frameborder="0" 
            allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
            allowfullscreen>
    </iframe>
</body>
</html>

Exercício 7

Enunciado: Crie uma página com links âncora para diferentes seções da mesma página.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Página com Navegação Interna</title>
</head>
<body>
    <header>
        <h1>Guia de Viagem</h1>
        <nav>
            <a href="#introducao">Introdução</a> |
            <a href="#destinos">Destinos</a> |
            <a href="#dicas">Dicas</a>
        </nav>
    </header>

    <section id="introducao">
        <h2>Introdução</h2>
        <p>Bem-vindo ao nosso guia de viagem...</p>
    </section>

    <section id="destinos">
        <h2>Destinos Populares</h2>
        <p>Confira os destinos mais procurados...</p>
    </section>

    <section id="dicas">
        <h2>Dicas de Viagem</h2>
        <p>Dicas para tornar sua viagem inesquecível...</p>
    </section>
</body>
</html>

Exercício 9

        Seu navegador não suporta o elemento de vídeo.
    </video>
    <p>Conteúdo da página sobre o vídeo de fundo...</p>
</body>
</html>

Exercício 10

    <meta charset="UTF-8">

    <p>Clique no link para baixar o efeito sonoro:</p>
    <a href="efeito-sonoro.mp3" download>Baixar Efeito Sonoro</a>

</html>
