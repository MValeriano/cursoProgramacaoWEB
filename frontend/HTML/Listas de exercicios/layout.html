Exercício 1

Enunciado: Crie a estrutura básica de um blog usando header, main, footer, article e section.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu Blog Pessoal</title>
</head>
<body>
    <header>
        <h1>Blog do Desenvolvedor</h1>
        <nav>
            <a href="#home">Home</a> |
            <a href="#sobre">Sobre</a> |
            <a href="#contato">Contato</a>
        </nav>
    </header>

    <main>
        <article>
            <header>
                <h2>Como Aprender HTML em 2024</h2>
                <p>Publicado em: 15 de Março, 2024</p>
            </header>
            
            <section>
                <h3>Introdução</h3>
                <p>HTML continua sendo a base fundamental para desenvolvimento web...</p>
            </section>
            
            <section>
