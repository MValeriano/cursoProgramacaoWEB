7. Tabelas

Exercício 1

Enunciado: Crie uma tabela com horário de aulas de uma escola.

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Horário de Aulas</title>
</head>
<body>
    <h1>Horário de Aulas - 1º Ano A</h1>
    <table border="1">
        <tr>
            <th>Horário</th>
            <th>Segunda</th>
            <th>Terça</th>
            <th>Quarta</th>
            <th>Quinta</th>
            <th>Sexta</th>
        </tr>
        <tr>
            <td>07:00-08:00</td>
            <td>Matemática</td>
            <td>Português</td>
            <td>História</td>
            <td>Geografia</td>
            <td>Ciências</td>
        </tr>
        <tr>
            <td>08:00-09:00</td>
            <td>Português</td>
            <td>Matemática</td>
            <td>Inglês</td>
            <td>Educação Física</td>
            <td>Artes</td>
        </tr>
    </table>
</body>
</html>

Exercício 4

Enunciado: Crie uma tabela semântica com thead, tbody e tfoot.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Folha de Pagamento</title>
</head>
<body>
    <h1>Folha de Pagamento - Abril/2024</h1>
    <table border="1">
        <thead>
            <tr>
                <th>Funcionário</th>
                <th>Salário Base</th>
                <th>Descontos</th>
                <th>Líquido</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Ana Silva</td>
                <td>R$ 3.000,00</td>
                <td>R$ 450,00</td>
                <td>R$ 2.550,00</td>
            </tr>
            <tr>
                <td>Carlos Oliveira</td>
                <td>R$ 4.000,00</td>
                <td>R$ 600,00</td>
                <td>R$ 3.400,00</td>
            </tr>
        </tbody>
        <tfoot>
            <tr>
                <td colspan="3">Total</td>
                <td>R$ 5.950,00</td>
            </tr>
        </tfoot>
    </table>
</body>
</html>

Exercício 6

Enunciado: Crie uma tabela com legenda (caption) e cabeçalhos de escopo (scope).

Resolução:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Notas dos Alunos</title>
</head>
<body>
    <table border="1">
        <caption>Notas do 1º Bimestre - Turma A</caption>
        <tr>
            <th scope="col">Aluno</th>
            <th scope="col">Matemática</th>
            <th scope="col">Português</th>
            <th scope="col">Ciências</th>
        </tr>
        <tr>
            <th scope="row">João</th>
            <td>8,5</td>
            <td>7,0</td>
            <td>9,0</td>
        </tr>
        <tr>
            <th scope="row">Maria</th>
            <td>9,0</td>
            <td>8,5</td>
            <td>8,0</td>
        </tr>
    </table>
</body>
</html>

</head>
<body>
    <h1>Lista de Contatos</h1>
    <table border="1" style="width:100%;">
        <tr style="background-color: #f2f2f2;">
            <th>Nome</th>
            <th>Email</th>
            <th>Telefone</th>
        </tr>
        <tr>
            <td>Ana Costa</td>
            <td>ana@email.com</td>
            <td>(11) 9999-1111</td>
        </tr>
        <tr style="background-color: #f2f2f2;">
            <td>Carlos Silva</td>
