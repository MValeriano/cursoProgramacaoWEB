8. Formulários

Tag Função
<form> Formulário
<input> Campo de entrada (texto, checkbox, radio etc.)
<textarea> Área de texto maior
<label> Rótulo para campo
<button> Botão
<select> Caixa de seleção
<option> Opção dentro do <select>
<fieldset> Agrupar elementos relacionados em um formulário
<legend> Definir uma legenda para um elemento <fieldset>
<datalist> Fornecer uma lista de opções pré-definidas para um elemento <input>

Os formulários são essenciais para a interação do usuário em sites e aplicações web, permitindo coletar dados, realizar buscas, enviar mensagens e muito mais.

Tag <form>

A tag <form> é usada para criar um formulário HTML para coleta de dados do usuário. Todos os elementos de entrada devem estar dentro de um formulário para serem enviados ao servidor.

Características importantes:

  • É um elemento de bloco
  • Pode conter vários tipos de elementos de entrada
  • Os dados são enviados para o servidor quando o formulário é submetido
  • Pode validar dados do lado do cliente usando atributos HTML5
  • Suporta métodos GET e POST para envio de dados

Atributos principais:

  • action - URL para onde os dados do formulário são enviados
  • method - Método HTTP (GET ou POST)
  • enctype - Tipo de codificação (importante para upload de arquivos)
  • target - Onde abrir a resposta (_blank, _self, etc.)
  • autocomplete - Ativa/desativa preenchimento automático
  • novalidate - Desativa validação do formulário
  • name - Nome do formulário

Declaração:

<form action="/processar-dados" method="POST">
    <!-- Elementos do formulário aqui -->
</form>

<!-- Formulário com validação -->
<form action="/cadastro" method="POST" autocomplete="on">
    <!-- Campos do formulário -->
</form>

<!-- Formulário para upload de arquivos -->
<form action="/upload" method="POST" enctype="multipart/form-data">
    <input type="file" name="arquivo">
</form>

Tag <input>

A tag <input> é a mais versátil para entrada de dados, podendo se comportar de diferentes formas dependendo do atributo type. É uma tag vazia (self-closing).

Características importantes:

  • É um elemento inline
  • Tag vazia (não possui tag de fechamento)
  • O comportamento muda radicalmente conforme o type
  • Suporta validação nativa do HTML5
  • Pode ser associado a um <label> para melhor acessibilidade

Atributos principais:

  • type - Tipo do campo (text, password, email, number, checkbox, radio, etc.)
  • name - Nome do campo (obrigatório para envio de dados)
  • value - Valor inicial do campo
  • placeholder - Texto de exemplo
  • required - Campo obrigatório
  • disabled - Desabilita o campo
  • readonly - Campo somente leitura
  • maxlength - Número máximo de caracteres
  • min / max - Valores mínimo/máximo (para números, datas)
  • pattern - Expressão regular para validação

Declaração:

<!-- Texto simples -->
<input type="text" name="nome" placeholder="Digite seu nome">

<!-- Email com validação -->
<input type="email" name="email" required>

<!-- Senha -->
<input type="password" name="senha" required>

<!-- Número -->
<input type="number" name="idade" min="0" max="120">

<!-- Data -->
<input type="date" name="nascimento">

<!-- Checkbox -->
<input type="checkbox" name="termos" value="aceito">

<!-- Radio buttons -->
<input type="radio" name="genero" value="masculino">
<input type="radio" name="genero" value="feminino">

<!-- Arquivo -->
<input type="file" name="foto">

<!-- Cor -->
<input type="color" name="cor_favorita">

<!-- Intervalo -->
<input type="range" name="volume" min="0" max="100">

<!-- Busca -->
<input type="search" name="busca">

<!-- URL -->
<input type="url" name="website">

<!-- Telefone -->
<input type="tel" name="telefone">

Tag <textarea>

A tag <textarea> é usada para entrada de texto longo, como comentários, mensagens, descrições, etc. Diferente do <input type="text">, permite múltiplas linhas de texto.

Características importantes:

  • É um elemento inline
  • Possui tag de abertura e fechamento
  • O conteúdo fica entre as tags (não usa value)
  • Pode ser redimensionado pelo usuário (controlável via CSS)
  • Suporta quebras de linha

Atributos principais:

  • name - Nome do campo
  • rows - Número de linhas visíveis
  • cols - Número de colunas (largura em caracteres)
  • placeholder - Texto de exemplo
  • required - Campo obrigatório
  • disabled - Desabilita o campo
  • readonly - Campo somente leitura
  • maxlength - Número máximo de caracteres
  • wrap - Define como o texto é quebrado (soft, hard)

Declaração:

<textarea name="mensagem" rows="4" cols="50" placeholder="Digite sua mensagem"></textarea>

<!-- Textarea com conteúdo inicial -->
<textarea name="endereco" rows="3">
Rua das Flores, 123
Centro
São Paulo - SP
</textarea>

<!-- Textarea não redimensionável -->
<textarea name="comentario" style="resize: none;"></textarea>

Tag <label>

A tag <label> melhora a acessibilidade ao associar um texto a um campo. Clicar no label foca ou ativa o campo associado.

Características importantes:

  • É um elemento inline
  • Pode ser associado usando for + id ou envolvendo o campo
  • Melhora a usabilidade, especialmente em dispositivos touch
  • Importante para acessibilidade (leitores de tela)

Atributos principais:

  • for - ID do elemento de formulário ao qual o label está associado

Declaração:

<!-- Associação usando for e id -->
<label for="nome">Nome completo:</label>
<input type="text" id="nome" name="nome">

<!-- Associação envolvendo o elemento -->
<label>
    <input type="checkbox" name="newsletter"> 
    Desejo receber newsletter
</label>

<!-- Múltiplos labels para o mesmo campo -->
<label for="email">E-mail:</label>
<label for="email">(Digite um e-mail válido)</label>
<input type="email" id="email" name="email">

Tag <button>

A tag <button> é usada para criar botões interativos. Pode ser usado dentro de formulários ou em qualquer lugar da página.

Características importantes:

  • É um elemento inline
  • Pode conter conteúdo HTML (texto, imagens, etc.)
  • Diferente do <input type="button">, permite conteúdo rico
  • Se usado dentro de um formulário sem type, o padrão é "submit"
  • Pode ser estilizado com CSS de forma mais flexível

Atributos principais:

  • type - Tipo do botão (submit, reset, button)
  • name - Nome do botão (para formulários)
  • value - Valor do botão (enviado com o formulário)
  • disabled - Desabilita o botão
  • form - Associar o botão a um formulário (por id) mesmo estando fora

Declaração:

<!-- Botão de envio -->
<button type="submit">Enviar formulário</button>

<!-- Botão de reset -->
<button type="reset">Limpar</button>

<!-- Botão comum -->
<button type="button">Clique aqui</button>

<!-- Botão com conteúdo HTML -->
<button type="submit">
    <img src="icone-enviar.png" alt=""> 
    Enviar
</button>

<!-- Botão desabilitado -->
<button type="button" disabled>Indisponível</button>

Tag <select>

A tag <select> cria um controle que permite selecionar uma ou múltiplas opções de uma lista. É comumente usado para opções pré-definidas.

Características importantes:

  • É um elemento inline
  • Deve conter tags <option> ou <optgroup>
  • Pode ser de seleção única ou múltipla
  • O valor enviado é o value da opção selecionada
  • Pode ser agrupado com <optgroup>

Atributos principais:

  • name - Nome do campo
  • multiple - Permite seleção múltipla
  • size - Número de opções visíveis
  • disabled - Desabilita a lista
  • required - Campo obrigatório
  • form - Associar a um formulário (por id) mesmo estando fora

Declaração:

<!-- Lista suspensa simples -->
<select name="cidade">
    <option value="sp">São Paulo</option>
    <option value="rj">Rio de Janeiro</option>
    <option value="mg">Belo Horizonte</option>
</select>

<!-- Lista com opção padrão -->
<select name="estado">
    <option value="">Selecione um estado</option>
    <option value="SP">São Paulo</option>
    <option value="RJ">Rio de Janeiro</option>
</select>

<!-- Lista com seleção múltipla -->
<select name="interesses" multiple>
    <option value="esportes">Esportes</option>
    <option value="musica">Música</option>
    <option value="leitura">Leitura</option>
</select>

<!-- Lista com grupos de opções -->
<select name="carro">
    <optgroup label="Marcas Japonesas">
        <option value="toyota">Toyota</option>
        <option value="honda">Honda</option>
    </optgroup>
    <optgroup label="Marcas Alemãs">
        <option value="bmw">BMW</option>
        <option value="mercedes">Mercedes</option>
    </optgroup>
</select>

Tag <option>

A tag <option> representa uma opção que pode ser selecionada em um elemento <select>, <optgroup> ou <datalist>.

Características importantes:

  • Deve estar dentro de <select>, <optgroup> ou <datalist>
  • Pode ser agrupada com <optgroup>
  • O texto visível é o conteúdo entre as tags
  • O valor enviado é o atributo value (se não houver, usa o conteúdo)

Atributos principais:

  • value - Valor a ser enviado quando a opção é selecionada
  • selected - Define a opção como selecionada por padrão
  • disabled - Desabilita a opção
  • label - Texto alternativo para a opção (útil em <optgroup>)

Declaração:

<select name="fruta">
    <option value="maca">Maçã</option>
    <option value="banana" selected>Banana</option>
    <option value="laranja">Laranja</option>
</select>

<!-- Opção com valor diferente do texto -->
<select name="codigo">
    <option value="1">Opção Um</option>
    <option value="2">Opção Dois</option>
</select>

<!-- Opção desabilitada -->
<select name="opcoes">
    <option value="1">Disponível</option>
    <option value="2" disabled>Indisponível</option>
</select>

Tag <fieldset>

A tag <fieldset> é usada para agrupar elementos dentro de um formulário, desenhando uma caixa ao redor dos elementos agrupados. Melhora a acessibilidade e a organização do formulário.

Características importantes:

  • É um elemento de bloco
  • Cria uma borda ao redor dos elementos agrupados
  • Pode ser desabilitado, afetando todos os elementos dentro dele
  • Deve ser usado em conjunto com a tag <legend>

Atributos principais:

  • disabled - Desabilita todos os elementos dentro do fieldset
  • form - Associar o fieldset a um formulário (por id) mesmo estando fora
  • name - Nome do fieldset

Declaração:

<form>
    <fieldset>
        <legend>Informações Pessoais</legend>
        
        <label for="nome">Nome:</label>
        <input type="text" id="nome" name="nome">
        
        <label for="email">Email:</label>
        <input type="email" id="email" name="email">
    </fieldset>

    <fieldset>
        <legend>Preferências</legend>
        
        <label>
            <input type="checkbox" name="newsletter"> Receber newsletter
        </label>
    </fieldset>
</form>

Tag <legend>

A tag <legend> é usada para fornecer uma legenda ou título para um grupo de elementos definido por <fieldset>. Deve ser o primeiro elemento dentro do <fieldset>.

Características importantes:

  • É um elemento inline
  • Deve ser filho direto de <fieldset>
  • Melhora a acessibilidade ao descrever o grupo de campos
  • Pode ser estilizado com CSS

Declaração:

<fieldset>
    <legend>Dados de Contato</legend>
    
    <label for="telefone">Telefone:</label>
    <input type="tel" id="telefone" name="telefone">
    
    <label for="endereco">Endereço:</label>
    <input type="text" id="endereco" name="endereco">
</fieldset>

Tag <datalist>

A tag <datalist> é usada para fornecer uma lista de opções para um campo de entrada, permitindo que o usuário selecione uma opção da lista ou digite um valor personalizado. A lista é vinculada ao input através do atributo list.

Características importantes:

  • É um elemento inline
  • Não é exibido por padrão, apenas quando o input é focado
  • Pode ser usado com diferentes tipos de input (text, number, etc.)
  • As opções são definidas com a tag <option>

Atributos principais:

  • id - Identificador único (obrigatório para vincular com input)

Declaração:

<label for="navegador">Escolha um navegador:</label>
<input list="navegadores" id="navegador" name="navegador">

<datalist id="navegadores">
    <option value="Chrome">
    <option value="Firefox">
    <option value="Safari">
    <option value="Edge">
    <option value="Opera">
</datalist>

Exemplo completo

Abaixo está um exemplo completo de um formulário HTML, com o CSS e JavaScript que estavam no seu texto original, agora separados para melhor visualização.

HTML (Estrutura do Formulário)

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Formulário de Cadastro</title>
    <!-- O CSS estaria aqui -->
</head>
<body>
    <h1>Formulário de Cadastro</h1>
    
    <form action="/cadastrar" method="POST" id="form-cadastro">
        <!-- Dados Pessoais -->
        <div class="campo">
            <label for="nome">Nome completo:</label>
            <input type="text" id="nome" name="nome" required maxlength="100">
        </div>
        
        <div class="campo">
            <label for="email">E-mail:</label>
            <input type="email" id="email" name="email" required>
        </div>
        
        <div class="campo">
            <label for="senha">Senha:</label>
            <input type="password" id="senha" name="senha" required minlength="6">
        </div>
        
        <div class="campo">
            <label>Gênero:</label>
            <div class="grupo-radio">
                <div class="radio-item">
                    <input type="radio" id="masculino" name="genero" value="masculino">
                    <label for="masculino">Masculino</label>
                </div>
                <div class="radio-item">
                    <input type="radio" id="feminino" name="genero" value="feminino">
                    <label for="feminino">Feminino</label>
                </div>
                <div class="radio-item">
                    <input type="radio" id="outro" name="genero" value="outro">
                    <label for="outro">Outro</label>
                </div>
            </div>
        </div>
        
        <!-- Informações Adicionais -->
        <div class="campo">
            <label for="cidade">Cidade:</label>
            <select id="cidade" name="cidade" required>
                <option value="">Selecione sua cidade</option>
                <option value="sp">São Paulo</option>
                <option value="rj">Rio de Janeiro</option>
                <option value="bh">Belo Horizonte</option>
                <option value="poa">Porto Alegre</option>
            </select>
        </div>
        
        <div class="campo">
            <label for="interesses">Áreas de interesse:</label>
            <select id="interesses" name="interesses" multiple size="4">
                <option value="tech">Tecnologia</option>
                <option value="sports">Esportes</option>
                <option value="music">Música</option>
                <option value="books">Livros</option>
                <option value="travel">Viagens</option>
            </select>
        </div>
        
        <div class="campo">
            <label for="bio">Biografia:</label>
            <textarea id="bio" name="bio" rows="4" placeholder="Conte um pouco sobre você..."></textarea>
        </div>
        
        <!-- Termos e Condições -->
        <div class="campo">
            <label>
                <input type="checkbox" name="termos" value="aceito" required>
                Aceito os termos e condições
            </label>
        </div>
        
        <div class="campo">
            <label>
                <input type="checkbox" name="newsletter" value="sim">
                Desejo receber newsletter
            </label>
        </div>
        
        <!-- Botões -->
        <div class="campo">
            <button type="submit">Cadastrar</button>
            <button type="reset">Limpar</button>
            <button type="button" id="btn-ajuda">Ajuda</button>
        </div>
    </form>

    <!-- O JavaScript estaria aqui -->
</body>
</html>
