5. Links e Mídia

Tag Função
<a> Link / âncora
<img> Imagem
<video> Vídeo incorporado
<audio> Áudio
<iframe> Incorporar outra página / mapas / vídeos

Tag <a>

A tag <a> (âncora) é fundamental para a navegação na web, permitindo conectar documentos e recursos. Pode linkar para páginas externas, seções internas da mesma página, emails, telefones e arquivos.

Características importantes:

  • É um elemento inline
  • Pode conter texto, imagens ou outros elementos
  • O atributo href define o destino do link
  • Pode ser usado para criar âncoras dentro da mesma página
  • Suporta diferentes protocolos (http, mailto, tel, etc.)

Atributos principais:

  • href - URL de destino (obrigatório para links funcionais)
  • target - Onde abrir o link (_blank, _self, _parent, _top)
  • rel - Relação com o documento de destino (nofollow, noopener, etc.)
  • download - Força o download do recurso
  • title - Informações adicionais sobre o link

Declaração:

<!-- Link para página externa -->
<a href="https://www.exemplo.com" target="_blank">Visite nosso site</a>

<!-- Link para página interna -->
<a href="sobre.html">Sobre nós</a>

<!-- Âncora interna -->
<a href="#secao1">Ir para seção 1</a>

<!-- Link para email -->
<a href="mailto:contato@empresa.com">Envie um email</a>

<!-- Link para telefone -->
<a href="tel:+5511999999999">Ligue para nós</a>

<!-- Link de download -->
<a href="documento.pdf" download>Baixar PDF</a>

Tag <img>

A tag <img> é usada para incorporar imagens em documentos HTML. É uma tag vazia (não possui tag de fechamento) e requer o atributo src para funcionar corretamente.

Características importantes:

  • É um elemento inline
  • Tag vazia (self-closing)
  • Suporta formatos como JPEG, PNG, GIF, SVG, WebP
  • O atributo alt é essencial para acessibilidade
  • Pode ser tornada responsiva com CSS

Atributos principais:

  • src - Caminho para o arquivo de imagem (obrigatório)
  • alt - Texto alternativo para acessibilidade (obrigatório)
  • width e height - Dimensões da imagem
  • loading - Controle de carregamento (lazy, eager)
  • srcset - Para imagens responsivas
  • sizes - Tamanhos para diferentes viewports

Declaração:

<!-- Imagem básica -->
<img src="foto.jpg" alt="Descrição da imagem">

<!-- Imagem com dimensões -->
<img src="logo.png" alt="Logo da empresa" width="200" height="100">

<!-- Imagem responsiva -->
<img src="imagem.jpg" 
     srcset="imagem-pequena.jpg 480w, imagem-grande.jpg 1080w"
     sizes="(max-width: 600px) 480px, 1080px"
     alt="Imagem responsiva">

<!-- Imagem com carregamento lazy -->
<img src="produto.jpg" alt="Foto do produto" loading="lazy">

Tag <video>

A tag <video> permite embedar conteúdo de vídeo com controles de reprodução nativos. Suporta múltiplos formatos através da tag <source>.

Características importantes:

  • É um elemento inline
  • Possui controles nativos de play, pause, volume
  • Suporta formatos como MP4, WebM, OGG
  • Pode conter múltiplas fontes para compatibilidade
  • Texto dentro da tag é exibido se o vídeo não carregar

Atributos principais:

  • src - Caminho para o arquivo de vídeo
  • controls - Exibe controles de reprodução
  • autoplay - Inicia a reprodução automaticamente
  • loop - Reproduz em loop
  • muted - Inicia sem áudio
  • poster - Imagem de capa antes da reprodução
  • width e height - Dimensões do player

Declaração:

<!-- Vídeo básico com controles -->
<video src="video.mp4" controls>
    Seu navegador não suporta o elemento de vídeo.
</video>

<!-- Vídeo com múltiplas fontes -->
<video controls width="640" height="360">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    Seu navegador não suporta a tag de vídeo.
</video>

<!-- Vídeo autoplay em loop (muted é geralmente necessário para autoplay) -->
<video autoplay muted loop>
    <source src="animacao.mp4" type="video/mp4">
</video>

<!-- Vídeo com imagem de capa -->
<video controls poster="capa.jpg">
    <source src="video.mp4" type="video/mp4">
</video>

Tag <audio>

A tag <audio> funciona de forma similar à tag <video>, mas para conteúdo apenas de áudio. Também suporta múltiplos formatos através da tag <source>.

Características importantes:

  • É um elemento inline
  • Possui controles de reprodução específicos para áudio
  • Suporta formatos como MP3, WAV, OGG
  • Pode conter múltiplas fontes para compatibilidade
  • Texto dentro da tag é exibido se o áudio não carregar

Atributos principais:

  • src - Caminho para o arquivo de áudio
  • controls - Exibe controles de reprodução
  • autoplay - Inicia a reprodução automaticamente
  • loop - Reproduz em loop
  • muted - Inicia mudo

Declaração:

<!-- Áudio básico com controles -->
<audio src="musica.mp3" controls>
    Seu navegador não suporta o elemento de áudio.
</audio>

<!-- Áudio com múltiplas fontes -->
<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    <source src="audio.ogg" type="audio/ogg">
    Seu navegador não suporta a tag de áudio.
</audio>

<!-- Áudio autoplay em loop -->
<audio autoplay loop>
    <source src="background.mp3" type="audio/mpeg">
</audio>

Tag <iframe>

A tag <iframe> (inline frame) permite embedar conteúdo externo como outras páginas web, mapas, vídeos do YouTube, documentos PDF, etc. Cria um contexto de navegação separado.

Características importantes:

  • É um elemento inline
  • Cria um "navegador dentro do navegador"
  • Útil para incorporar conteúdo de terceiros
  • Requer cuidados com segurança e performance
  • Pode ser restrito com atributos de sandboxing

Atributos principais:

  • src - URL do conteúdo a ser incorporado
  • width e height - Dimensões do iframe
  • title - Descrição para acessibilidade (obrigatório)
  • frameborder - Exibe ou oculta a borda (0 ou 1)
  • allowfullscreen - Permite modo tela cheia
  • sandbox - Restringe permissões do iframe
  • loading - Controle de carregamento (lazy, eager)

Declaração:

<!-- Incorporar página externa -->
<iframe src="https://www.exemplo.com" 
        width="800" 
        height="600"
        title="Página de exemplo">
</iframe>

<!-- Incorporar vídeo do YouTube -->
<iframe width="560" 
        height="315" 
        src="https://www.youtube.com/embed/VIDEO_ID"
        title="Vídeo do YouTube"
        frameborder="0" 
        allowfullscreen>
</iframe>

<!-- Incorporar mapa do Google Maps -->
<iframe src="https://www.google.com/maps/embed?pb=..."
        width="600" 
        height="450" 
        style="border:0;" 
        allowfullscreen="" 
        loading="lazy"
        title="Localização no mapa">
</iframe>

<!-- Iframe com sandbox para segurança -->
<iframe src="conteudo-externo.html"
        sandbox="allow-scripts"
        title="Conteúdo externo seguro">
</iframe>
