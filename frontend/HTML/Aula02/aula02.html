Guia de Referência HTML

Sobre os Atributos

  • Todos os elementos HTML podem ter atributos;
  • Os atributos fornecem informações adicionais sobre um elemento;
  • Os atributos sempre são definidos na tag de abertura do elemento;
  • Os atributos podem ser em pares nome/valor (ex: nome=”valor”) ou apenas o nome;

Atributos Globais

accesskey
Define uma tecla de atalho para focar no elemento.
class
Define quais classes CSS serão aplicadas no elemento.
hidden
Define o elemento como oculto.
id
Define uma identificação única para o elemento.
style
Define estilos CSS diretamente no elemento.
tabindex
Define a posição do elemento na ordem de tabulação da página.
title
Define informações sobre o elemento.

1. Estrutura básica da página

Tag Função
<!DOCTYPE> Define o tipo de documento
<html> Define o documento HTML
<head> Contém metadados e configurações
<title> Define o título da aba do navegador
<body> Contém o conteúdo visível da página

Tag <!DOCTYPE>

A Tag <!DOCTYPE> representa o tipo de documento e ajuda os navegadores a exibir as páginas da web corretamente.

  • Deve aparecer apenas uma vez, no topo da página (antes de quaisquer tags HTML).
  • A Tag <!DOCTYPE> não diferencia maiúsculas de minúsculas.

Declaração:

<!DOCTYPE html>

Tag <html>

Tag usada para definir um documento HTML.
Esta é a tag raíz da estrutura do documento.
Com exceção do DOCTYPE todas as tags são filhas ou descendentes da tag html.

atributodescriçãoexemplo de uso
xmlns Define que o arquivo está em conformidade com XHTML. http://www.w3.org/1999/xhtml

Declaração :

<html> 
    <!-- Conteúdo aqui -->
</html>

Tag <head>

Tag usada para definir o cabeçalho do documento HTML.
Esta tag serve como contêiner para as tags de cabeçalho.
Dentro desta tag pode ser incluído o título do documento, estilos, scripts, meta informações e etc.

Declaração :

<head>
    <!-- Metadados aqui -->
</head>

Tag <title>

Tag usada para definir o título do documento.
Esta tag deve ser usada dentro da tag head.

  • O título da página normalmente é visto na janela do navegador.
  • O título também é apresentado quando o usuário adiciona a página nos favoritos.
  • O título é importante para mecanismos de pesquisas.

Declaração :

<title>Título da Página</title>

Tag <body>

Tag usada para definir o corpo do documento.
Todo o conteúdo da página deve estar dentro da tag body.
Todos atributos de layout foram removidos no HTML5.

Declaração :

<body>
    <!-- Conteúdo visível aqui -->
</body>

2. Conteúdo e texto

Tag Função
<h1> até <h6> Títulos (h1 é o mais importante)
<p> Parágrafo de texto
<span> Agrupa texto inline (sem quebra de linha)
<br> Quebra de linha
<hr> Linha horizontal (separador)

Tag <h1> a <h6>

As tags de heading (<h1> a <h6>) representam seis níveis de títulos, onde <h1> é o mais importante e <h6> o menos importante. Essas tags são fundamentais para a estruturação do conteúdo e têm grande importância para SEO.

Características importantes:

  • <h1> deve ser usado apenas uma vez por página, representando o título principal
  • A hierarquia deve ser respeitada (não pular de <h1> para <h3> sem usar <h2>)
  • São elementos de bloco que ocupam toda a largura disponível

Declaração:

<h1>Título Principal da Página</h1>
<h2>Seção Importante</h2>
<h3>Subseção</h3>
<h4>Tópico específico</h4>
<h5>Detalhe</h5>
<h6>Informação menos relevante</h6>

Tag <p>

A tag <p> é usada para agrupar sentenças e formar parágrafos. Os navegadores adicionam automaticamente uma margem antes e depois de cada parágrafo.

Características importantes:

  • É um elemento de bloco
  • Automaticamente adiciona espaçamento vertical entre parágrafos
  • Não deve ser usado para criar espaçamento entre outros elementos (use CSS para isso)

Declaração:

<p>Este é um parágrafo de texto comum que contém várias sentenças formando uma unidade de pensamento.</p>
<p>Este é outro parágrafo separado do anterior pelo espaçamento automático.</p>

Tag <span>

A tag <span> é um contêiner genérico inline que não adiciona nenhuma formatação visual por si só, mas é muito útil para aplicar CSS ou manipular partes específicas do texto via JavaScript.

Características importantes:

  • É uma tag vazia (self-closing)
  • É um elemento inline (não causa quebra de linha)
  • Não tem significado semântico por padrão
  • Ideal para selecionar trechos específicos de texto

Declaração:

<p>Este é um texto com <span class="destaque">uma parte destacada</span> usando span.</p>
<p>Preço: R$ <span id="preco-produto">99,90</span></p>

Tag <br>

A tag <br> força uma quebra de linha no texto, sem adicionar o espaçamento vertical que um parágrafo novo adicionaria. É uma tag vazia (self-closing).

Características importantes:

  • Não possui tag de fechamento
  • Útil para endereços, poemas ou situações onde a estrutura de linha é importante
  • Não deve ser usado para criar espaçamento entre elementos (use CSS para isso)

Declaração:

<p>Nome: João Silva<br>
Endereço: Rua das Flores, 123<br>
Cidade: São Paulo</p>

Tag <hr>

A tag <hr> cria uma linha horizontal que funciona como uma quebra temática entre parágrafos ou seções do conteúdo. No HTML5, representa uma quebra temática, não apenas visual.

Características importantes:

  • É uma tag vazia (self-closing)
  • No HTML5 ganhou significado semântico de "mudança temática"
  • Por padrão, os navegadores renderizam com uma borda e margens
  • Pode ser estilizada com CSS para diferentes aparências

Declaração:

<section>
    <h2>Primeira Seção</h2>
    <p>Conteúdo da primeira seção...</p>
</section>

<hr>

<section>
    <h2>Segunda Seção</h2>
    <p>Conteúdo da segunda seção...</p>
</section>

3. Formatação e ênfase

Tag Função
<b> Negrito (sem significado semântico)
<strong> Texto importante (semântico + negrito)
<i> Itálico
<em> Ênfase (semântico + itálico)
<mark> Destacar texto (marca-texto)

Tag <b>

A tag <b> é usada para chamar a atenção para um trecho de texto sem indicar que ele tem importância especial. Deve ser usada apenas quando nenhuma outra tag semântica for apropriada.

Características importantes:

  • Apenas altera a aparência visual (negrito)
  • Não transmite importância semântica
  • Útil para palavras-chave, nomes de produtos ou outros elementos que precisam se destacar visualmente
  • Elemento inline

Declaração:

<p>Este é um texto normal e <b>esta parte está em negrito</b> para destacar visualmente.</p>
<p>O produto <b>SuperClean</b> está em promoção esta semana.</p>

Tag <strong>

A tag <strong> dá ao texto um forte sentido de importância. Visualmente é renderizado em negrito, mas semanticamente transmite que o conteúdo é significativo.

Características importantes:

  • Renderizado visualmente em negrito
  • Transmite importância semântica
  • Leitores de tela dão ênfase vocal ao conteúdo
  • Elemento inline
  • Pode ser aninhado para aumentar a importância

Declaração:

<p><strong>Atenção:</strong> Este site requer JavaScript para funcionar corretamente.</p>
<p>Não <strong>nunca</strong> compartilhe sua senha com outras pessoas.</p>

Tag <i>

A tag <i> é usada para texto que deve ser diferenciado do texto normal por razões tipográficas, sem significado especial.

Características importantes:

  • Apenas altera a aparência visual (itálico)
  • Não transmite ênfase semântica
  • Usado para termos técnicos, pensamentos, ou texto em outra língua
  • Elemento inline

Declaração:

<p>O termo <i>quantum computing</i> refere-se à computação quântica.</p>
<p>Ele pensou: <i>Será que isso vai funcionar?</i></p>
<p>O nome da espécie é <i>Felis catus</i>.</p>

Tag <em>

A tag <em> indica ênfase textual. Visualmente é renderizado em itálico, mas semanticamente transmite que o conteúdo deve ser enfatizado.

Características importantes:

  • Renderizado visualmente em itálico
  • Transmite ênfase semântica
  • Leitores de tela modificam a entonação para o conteúdo
  • Elemento inline
  • O nível de ênfase aumenta com o aninhamento

Declaração:

<p>Você <em>precisa</em> terminar este projeto até sexta-feira.</p>
<p>Eu <em>realmente</em> gostei do filme.</p>
<p>É importante <em><em>muito</em> importante</em> chegar no horário.</p>

Tag <mark>

A tag <mark> é usada para destacar partes do texto que são relevantes no contexto atual, como se tivessem sido marcadas com um marcador amarelo.

Características importantes:

  • Renderizado com fundo amarelo por padrão
  • Útil para destacar termos em resultados de busca ou trechos relevantes
  • Elemento inline
  • A cor de destaque pode ser customizada com CSS

Declaração:

<p>O documento menciona que a reunião será na <mark>sala de conferências B</mark> às 15h.</p>
<p>Search results for: HTML tags<br>
HTML <mark>semantic</mark> elements provide meaning to the content.</p>

4. Organização de layout

Tag Função
<div> Bloco genérico (ocupa toda linha)
<section> Seção da página
<header> Cabeçalho
<footer> Rodapé
<nav> Menu de navegação
<article> Conteúdo independente
<main> Conteúdo principal da página

Tag <div>

A tag <div> é o elemento de bloco mais básico e versátil do HTML. Não possui significado semântico intrínseco e é usado principalmente para agrupamento e aplicação de estilos CSS.

Características importantes:

  • É um elemento de bloco (ocupa toda a largura disponível)
  • Não possui significado semântico
  • Pode conter qualquer tipo de conteúdo
  • Amplamente usado para criar layouts com CSS
  • Deve ser usado quando nenhum elemento semântico for apropriado

Declaração:

<div class="container">
    <h1>Título</h1>
    <p>Parágrafo dentro de uma div.</p>
</div>

<div id="sidebar" class="lateral">
    <h3>Menu Lateral</h3>
</div>

Tag <section>

A tag <section> representa uma seção genérica de conteúdo que forma uma parte autônoma da funcionalidade do documento. Deve conter um título (h1-h6) para identificar seu tema.

Características importantes:

  • Elemento de bloco
  • Possui significado semântico (agrupa conteúdo por tema)
  • Deve ser usado para divisões temáticas, não apenas para estilização
  • Pode ser aninhado
  • Ideal para agrupar conteúdo relacionado

Declaração:

<section class="introducao">
    <h2>Introdução</h2>
    <p>Texto introdutório sobre o assunto...</p>
</section>

<section class="beneficios">
    <h2>Benefícios</h2>
    <p>Lista de benefícios...</p>
</section>

Tag <header>

A tag <header> é usada para agrupar elementos introdutórios ou links de navegação. Pode conter logos, títulos, menus e outras informações de cabeçalho.

Características importantes:

  • Elemento de bloco
  • Pode ser usado múltiplas vezes (em cada seção ou artigo)
  • Normalmente contém elementos de heading (h1-h6)
  • Pode conter elementos de navegação
  • Não deve ser confundido com a tag <head>

Declaração:

<header class="cabecalho-principal">
    <h1>Meu Site</h1>
    <nav>
        <a href="#home">Home</a>
        <a href="#sobre">Sobre</a>
    </nav>
</header>

<article>
    <header>
        <h2>Título do Artigo</h2>
        <p>Por: Autor</p>
    </header>
</article>

Tag <footer>

A tag <footer> contém informações sobre o autor, copyright, links relacionados e informações de contato. Pode ser usado no nível da página ou em seções específicas.

Características importantes:

  • Elemento de bloco
  • Pode ser usado múltiplas vezes na página
  • Normalmente contém informações de copyright, autor, links de contato
  • Pode aparecer no final de artigos, seções ou da página inteira

Declaração:

<footer class="rodape-principal">
    <p>&copy; 2024 Minha Empresa. Todos os direitos reservados.</p>
    <address>
        Contato: <a href="mailto:contato@empresa.com">contato@empresa.com</a>
    </address>
</footer>

<article>
    <p>Conteúdo do artigo...</p>
    <footer>
        <p>Publicado em 15 de Março, 2024</p>
    </footer>
</article>

Tag <nav>

A tag <nav> é usada para agrupar os principais links de navegação do site. Não é necessário colocar todos os links dentro de <nav>, apenas os blocos principais de navegação.

Características importantes:

  • Elemento de bloco
  • Usado para navegação principal, menus, índices
  • Pode aparecer em diferentes partes da página
  • Normalmente contém listas de links
  • Não deve ser usado para todos os grupos de links, apenas para navegação principal

Declaração:

<nav class="menu-principal">
    <ul>
        <li><a href="#home">Home</a></li>
        <li><a href="#sobre">Sobre</a></li>
        <li><a href="#servicos">Serviços</a></li>
        <li><a href="#contato">Contato</a></li>
    </ul>
</nav>

<nav class="breadcrumb">
    <a href="#home">Home</a> > 
    <a href="#produtos">Produtos</a> > 
    <span>Detalhes</span>
</nav>

Tag <article>

A tag <article> é usada para conteúdo que pode ser distribuído independentemente, como posts de fórum, artigos de blog, notícias, comentários, etc.

Características importantes:

  • Elemento de bloco
  • Deve fazer sentido por si só, independente do resto do site
  • Pode ser aninhado, mas o conteúdo interno deve ser relacionado ao artigo
  • Pode conter <header>, <footer>, e outras seções
  • Ideal para conteúdo que pode ser sindicado

Declaração:

<article class="post-blog">
    <header>
        <h2>Título do Artigo</h2>
        <p>Publicado em <time datetime="2024-03-15">15 de Março de 2024</time></p>
    </header>
    
    <p>Conteúdo principal do artigo...</p>
    
    <footer>
        <p>Autor: João Silva</p>
        <nav>
            <a href="#comentarios">Comentários</a>
        </nav>
    </footer>
</article>

Tag <main>

A tag <main> é usada para envolver o conteúdo central único da página. Deve conter o conteúdo que é diretamente relacionado ao tópico central da página.

Características importantes:

  • Elemento de bloco
  • Deve ser único por página (não pode haver múltiplos <main>)
  • Não deve ser descendente de <article>, <aside>, <footer>, <header>, ou <nav>
  • Ajuda na acessibilidade, permitindo que leitores de tela identifiquem o conteúdo principal
  • Não substitui a estrutura semântica, complementa-a

Declaração:

<main class="conteudo-principal">
    <h1>Título Principal da Página</h1>
    
    <section>
        <h2>Introdução</h2>
        <p>Texto introdutório...</p>
    </section>
    
    <article>
        <h2>Artigo em Destaque</h2>
        <p>Conteúdo do artigo...</p>
    </article>
</main>
