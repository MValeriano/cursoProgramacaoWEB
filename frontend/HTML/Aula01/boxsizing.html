Guia Visual: Box-Sizing

Entendendo como o CSS calcula o tamanho dos seus elementos.

O que é o "Box Model" (Modelo de Caixa)?

Todo elemento HTML na sua página é uma caixa retangular. O "Box Model" é como o CSS descreve essa caixa, que é composta por quatro partes:

Margin (Margem)
Border (Borda)
Padding (Preenchimento)
Content (Conteúdo)

A propriedade box-sizing decide como a width (largura) e height (altura) que você define se relacionam com essas partes.

O Padrão: box-sizing: content-box

Por padrão, quando você define width: 200px, você está definindo a largura apenas do conteúdo.

O padding e a border são adicionados a essa largura, tornando a caixa maior do que você esperava.

Exemplo: width: 200px

Conteúdo

200px

Cálculo da Largura Total:

200px (width) + 40px (padding) + 20px (border) = 260px

Isso torna o layout difícil, pois a caixa ocupa 260px de espaço, não os 200px que você definiu.

O Método Moderno: box-sizing: border-box

Com border-box, quando você define width: 200px, você está definindo a largura total da caixa.

O padding e a border são "empurrados para dentro", e o navegador ajusta o espaço do conteúdo automaticamente.

Exemplo: width: 200px

Conteúdo

(auto: 160px)

Cálculo da Largura Total:

Largura Total = 200px

Isso é muito mais intuitivo. A caixa ocupa exatamente os 200px que você definiu.

Comparação: width: 200px, padding: 20px, border: 10px

content-box (Padrão)

A width (200px) é aplicada apenas ao conteúdo.

Conteúdo

200px

Largura Total Visível:

200px (conteúdo)
+ 40px (padding L/R)
+ 20px (border L/R)
= 260px

border-box (Moderno)

A width (200px) é aplicada à caixa inteira.

Conteúdo

(160px)

Largura Total Visível:

= 200px

Recomendação: Use border-box em Tudo!

Usar border-box torna a criação de layouts muito mais fácil e previsível. Você não precisa mais fazer contas (ex: 200px - 40px de padding = 160px) para fazer duas caixas caberem lado a lado.

A maioria dos desenvolvedores aplica esta regra no início de seu CSS:

/* 1. Faz o 'border-box' ser o padrão para o HTML */
html {
  box-sizing: border-box;
}

/* 2. Faz todos os elementos herdarem esse comportamento */
*, *::before, *::after {
  box-sizing: inherit;
}

Isso garante que todos os elementos da sua página usem o modelo border-box, mais intuitivo.
