Módulo 1: Introdução à Lógica de Programação

O que é Lógica de Programação?

É a técnica de organizar o raciocínio para resolver problemas de forma que o computador consiga executar. Pense nisso como uma receita de bolo: uma sequência de passos claros e na ordem correta. Se a ordem estiver errada, o resultado não será o esperado.

O que é um Algoritmo?

Um algoritmo é simplesmente essa sequência de passos. Ele pode ser representado de várias formas, desde uma linguagem natural até o código final.

Exemplo: Calcular a média de duas notas

Abaixo, veja o mesmo algoritmo em pseudocódigo e em código real.

# Pseudocódigo Início Leia nota1 Leia nota2 media ← (nota1 + nota2) / 2 Se media >= 7 Então Escreva "Aprovado" Senão Escreva "Reprovado" Fim # Código PHP $nota1 = 8; $nota2 = 6; $media = ($nota1 + $nota2) / 2; if ($media >= 7) { echo "Aprovado"; } else { echo "Reprovado"; }
// Pseudocódigo Início Leia nota1 Leia nota2 media ← (nota1 + nota2) / 2 Se media >= 7 Então Escreva "Aprovado" Senão Escreva "Reprovado" Fim // Código JavaScript let nota1 = 8; let nota2 = 6; let media = (nota1 + nota2) / 2; if (media >= 7) { console.log("Aprovado"); } else { console.log("Reprovado"); }

Módulo 2: Variáveis e Constantes

Variáveis

São espaços na memória do computador para armazenar dados que podem mudar durante a execução do programa. Toda variável tem um nome, tipo e valor.

Constantes

São como variáveis, mas seu valor é definido uma vez e não pode ser alterado.

# Variáveis $nome = "Maria"; // String $idade = 25; // Inteiro $preco = 19.90; // Float $ativo = true; // Boolean # Constante define("PI", 3.14159); echo PI;
// Variáveis let nome = "Maria"; // String let idade = 25; // Number (inteiro) let preco = 19.90; // Number (float) let ativo = true; // Boolean // Constante const PI = 3.14159; console.log(PI);

Módulo 3: Operadores

São os símbolos que executam operações sobre variáveis e valores.

Aritméticos

+, -, *, /, % (resto)

Atribuição

=, +=, -=

Comparação

==, ===, !=, >, <

Lógicos

&& (E), || (OU), ! (NÃO)

Módulo 5: Controle de Fluxo

Permite que o programa tome decisões e execute diferentes blocos de código com base em condições.

If / Else If / Else, Ternário e Switch

// If / Else $idade = 16; if ($idade >= 18) { echo "Maior"; } else { echo "Menor"; } // Ternário $resultado = ($idade >= 18) ? "Maior" : "Menor"; // Switch $dia = 3; switch ($dia) { case 1: echo "Domingo"; break; case 2: echo "Segunda"; break; default: echo "Outro dia"; }
// If / Else let idade = 16; if (idade >= 18) { console.log("Maior"); } else { console.log("Menor"); } // Ternário let resultado = (idade >= 18) ? "Maior" : "Menor"; // Switch let dia = 3; switch (dia) { case 1: console.log("Domingo"); break; case 2: console.log("Segunda"); break; default: console.log("Outro dia"); }

Módulo 6: Estruturas de Repetição

Também chamados de loops, executam um bloco de código repetidamente enquanto uma condição for atendida.

// For for ($i = 1; $i <= 5; $i++) { echo $i; } // While $i = 1; while ($i <= 5) { echo $i; $i++; } // Do While $i = 1; do { echo $i; $i++; } while ($i <= 5);
// For for (let i = 1; i <= 5; i++) { console.log(i); } // While let i = 1; while (i <= 5) { console.log(i); i++; } // Do While let i = 1; do { console.log(i); i++; } while (i <= 5);

Formas de organizar e armazenar múltiplos valores de forma eficiente.

// Array (vetor) $frutas = ["maçã", "banana", "laranja"]; echo $frutas[1]; // banana

Módulo 8: Funções

Blocos de código reutilizáveis que realizam uma tarefa específica. A base para um código limpo e organizado.

function soma($a, $b) { return $a + $b; } echo soma(5, 3); // 8
function soma(a, b) { return a + b; } console.log(soma(5, 3)); // 8
