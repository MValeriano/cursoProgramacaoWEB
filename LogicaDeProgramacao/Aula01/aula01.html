Problema do Dia

Você foi contratado por uma pizzaria para calcular o valor de um pedido. O preço da pizza depende do sabor ($35,00) e da quantidade de coberturas extras ($5,00 por cobertura). O cliente também pode ter um cupom de desconto de 15%. Descreva em português os passos para calcular o preço final e determinar se o cupom se aplica.

Conteúdo da Aula

1. Introdução à Lógica de Programação

**O que é lógica de programação?**
É a organização coerente de instruções para resolver problemas. A base de todo programa é a sequência lógica: **entrada → processamento → saída**.

2. Variáveis e Constantes

**Variáveis** são espaços de armazenamento para valores que podem mudar. **Constantes** armazenam valores fixos.

Exemplos:


// PHP
$nome = "João";          // string
$idade = 25;             // int
$altura = 1.75;          // float
$estudante = true;       // boolean
define("PI", 3.14159);   // constante
                            

// JavaScript
let nome = "João";       // string
let idade = 25;          // number
let altura = 1.75;       // number
let estudante = true;    // boolean
const PI = 3.14159;      // constante

3. Operadores

Operadores são símbolos que realizam operações em valores e variáveis.

  • **Aritméticos:** `+`, `-`, `*`, `/`, `%`, `**`
  • **Atribuição:** `=`, `+=`, `-=`, `*=`, `/=`
  • **Comparação:** `==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`
  • **Lógicos:** `&&` (AND), `||` (OR), `!` (NOT)

4. Estruturas de Entrada e Saída

A **entrada** permite que o programa receba dados, enquanto a **saída** permite que ele exiba informações.

Exemplos:


// PHP
echo "Hello World!";
$nome = readline("Digite seu nome: ");
                            

// JavaScript
console.log("Hello World!");
let nome = prompt("Digite seu nome:");
alert("Bem-vindo, " + nome);
