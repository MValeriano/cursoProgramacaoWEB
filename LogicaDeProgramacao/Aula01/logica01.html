Módulo 1: Introdução à Lógica de Programação

A lógica de programação é a base do pensamento computacional. Antes de escrever uma única linha de código, você precisa aprender a organizar seu raciocínio. É como uma receita de bolo: passos claros, em uma ordem precisa.

O que é um Algoritmo?

Um algoritmo é uma sequência de passos para resolver um problema. Pode ser um simples conjunto de instruções ou algo mais complexo. Aqui estão alguns exemplos para ilustrar a ideia.

Pseudocódigo

Início
  Leia nota1
  Leia nota2
  media ← (nota1 + nota2) / 2
  Se media >= 7 Então
      Escreva "Aprovado"
  Senão
      Escreva "Reprovado"
Fim

Código real (PHP e JavaScript)

PHP:
$nota1 = 8; $nota2 = 6; $media = ($nota1 + $nota2) / 2;
if ($media >= 7) {
    echo "Aprovado";
} else {
    echo "Reprovado";
}
JavaScript:
let nota1 = 8; let nota2 = 6; let media = (nota1 + nota2) / 2;
if (media >= 7) {
    console.log("Aprovado");
} else {
    console.log("Reprovado");
}

Exemplo do mundo real: Fazer café

  • Colocar água na cafeteira.
  • Colocar pó de café no filtro.
  • Ligar a cafeteira.
  • Esperar a água passar pelo pó.
  • Servir o café.

A ordem é crucial. Assim como um algoritmo precisa de uma sequência correta para funcionar.

Módulo 2: Variáveis e Constantes

Variáveis e constantes são os "contêineres" para armazenar informações no seu programa. Entender a diferença entre eles e seus tipos de dados é fundamental para manipular a informação corretamente.

Variáveis

São espaços na memória do computador para dados que podem mudar de valor. Elas possuem nome, tipo e valor.

PHP:
$nome = "Maria";
$idade = 25;

JavaScript:
let nome = "Maria";
let idade = 25;

Constantes

Ao contrário das variáveis, as constantes armazenam valores que não podem ser alterados durante a execução do programa.

PHP:
define("PI", 3.14159);
echo PI;

JavaScript:
const PI = 3.14159;
console.log(PI);

Tipos de Dados

A natureza da informação define seu tipo. Programação requer que você defina o tipo para que o computador saiba como tratar os dados.

🔢

Inteiro

Números inteiros (10)

📈

Real/Float

Números com casas decimais (3.14)

📝

String

Textos ("Olá")

✅

Boolean

Verdadeiro ou Falso

Módulo 3: Operadores

Operadores são símbolos que nos permitem realizar operações lógicas ou matemáticas com os dados. Eles são essenciais para tomar decisões e realizar cálculos em um programa.

Operadores Aritméticos

  • + soma
  • - subtração
  • * multiplicação
  • / divisão
  • % resto da divisão

Operadores de Atribuição

  • = atribui valor
  • += soma e atribui
  • -= subtrai e atribui

Operadores de Comparação

  • == igual (valor)
  • === estritamente igual (valor e tipo)
  • != diferente

Operadores Lógicos

  • && (E lógico)
  • || (OU lógico)
  • ! (NÃO)

Módulo 4: Estruturas de Entrada e Saída

Para que seu programa seja útil, ele precisa se comunicar com o usuário. A saída exibe informações, e a entrada coleta dados do usuário.

Saída de Dados

PHP:
echo "Olá";

JS:
console.log("Olá");

Entrada de Dados

PHP (terminal):
readline("Digite seu nome: ");

JS (navegador):
let nome = prompt("Digite seu nome:");
alert("Bem-vindo, " + nome);

Módulo 5: Controle de Fluxo

O controle de fluxo permite que seu programa tome decisões e escolha caminhos diferentes com base em condições. Isso torna seu código dinâmico e inteligente.

If, Else If, Else

A estrutura mais comum para tomar decisões. Executa um bloco de código se uma condição for verdadeira.

$idade = 16;
if ($idade >= 18) {
    echo "Maior de idade";
} else {
    echo "Menor de idade";
}

Operador Ternário

Uma forma abreviada para um "if/else" simples. É ideal para atribuições de valor baseadas em uma condição.

let idade = 20;
let resultado = (idade >= 18) ? "Maior" : "Menor";
console.log(resultado);

Switch Case

Usado para testar uma única variável contra múltiplos valores. Mais legível que uma longa cadeia de "if/else if".

$dia = 3;
switch ($dia) {
    case 1: echo "Domingo"; break;
    case 2: echo "Segunda"; break;
    case 3: echo "Terça"; break;
    default: echo "Dia inválido";
}

Módulo 6: Estruturas de Repetição

Estruturas de repetição, ou laços, permitem que você execute um bloco de código várias vezes, economizando tempo e esforço. São a essência da automação em programação.

For

Ideal para quando você sabe exatamente quantas repetições precisa.

for (let i = 1; i <= 10; i++) {
    console.log("Número: " + i);
}

While

Repete enquanto uma condição for verdadeira. Use quando o número de repetições é incerto.

$i = 1;
while ($i <= 5) {
    echo $i;
    $i++;
}

Do While

Similar ao "while", mas garante que o bloco de código seja executado pelo menos uma vez antes de verificar a condição.

let i = 1;
do {
    console.log(i);
    i++;
} while (i <= 5);

Módulo 7: Estruturas de Dados

Estruturas de dados são formas especializadas de organizar a informação. Elas permitem armazenar e acessar dados de maneira eficiente para a solução de problemas complexos.

Arrays e Matrizes

Arrays (ou vetores) são coleções ordenadas de itens. Matrizes são arrays dentro de arrays, criando uma estrutura de grade.

Array:
$frutas = ["maçã", "banana", "laranja"];
echo $frutas[1]; // banana

Matriz:
let notas = [
  [8, 7, 9],
  [6, 5, 7]
];
console.log(notas[1][2]); // 7

Objetos

Objetos são estruturas que permitem agrupar dados relacionados e funções. Eles são essenciais na programação orientada a objetos.

let pessoa = {
  nome: "Ana",
  idade: 25,
  profissao: "Engenheira"
};
console.log(pessoa.nome);

Visualizando uma Pilha (Stack)

Uma pilha é uma estrutura de dados do tipo "Último a Entrar, Primeiro a Sair" (LIFO). Clique nos botões para empilhar e desempilhar valores e veja o conceito em ação.

Módulo 8: Funções

Funções são blocos de código reutilizáveis que realizam uma tarefa específica. Elas tornam seu código mais limpo, organizado e fácil de manter.

Criando Funções

PHP:
function soma($a, $b) {
    return $a + $b;
}
echo soma(3, 4);

JS:
function soma(a, b) {
    return a + b;
}
console.log(soma(3, 4));

Escopo de Variáveis

  • Global: pode ser acessada em qualquer lugar do programa.
  • Local: só existe dentro da função onde foi criada.

Módulo 9: PHP/JS em HTML

Aprenda a integrar o poder do backend (PHP) e do frontend (JavaScript) diretamente em suas páginas web para criar aplicações dinâmicas.

PHP no HTML

<!DOCTYPE html>
<html>
<body>
  <h1><?php echo "Olá, mundo!"; ?></h1>
</body>
</html>

JavaScript no HTML

<!DOCTYPE html>
<html>
<body>
  <h1 id="msg"></h1>
  <script>
    document.getElementById("msg").innerText = "Olá, mundo!";
  </script>
</body>
</html>
