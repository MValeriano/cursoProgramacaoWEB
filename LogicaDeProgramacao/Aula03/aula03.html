Aula 03: Estruturas de Dados e Funções

Nossa Filosofia: Resolvendo Problemas

Nesta aula, vamos aprender a organizar dados de forma eficiente (em **Arrays** e **Objetos**) e a criar blocos de código reutilizáveis (**Funções**). Essas ferramentas são essenciais para construir programas maiores e mais complexos.

Problema do Dia

Sua tarefa é criar um sistema simples de cadastro de alunos para uma escola. Pense em como você armazenaria as informações de cada aluno (nome, idade, notas) e como criaria uma rotina para calcular a média de notas de cada um deles.

Conteúdo da Aula

9. Arrays

**Arrays** são estruturas de dados que armazenam uma coleção de itens (elementos) em uma única variável. Os itens podem ser acessados por um índice.

Exemplos:


// PHP
$frutas = array("maçã", "banana", "laranja");
$pessoa = ["nome" => "João", "idade" => 25];
                            

// JavaScript
let frutas = ["maçã", "banana", "laranja"];
let pessoa = {nome: "João", idade: 25};

10. Objetos

**Objetos** são estruturas mais complexas que armazenam dados e funcionalidades relacionadas.

Exemplos:


// JavaScript
let carro = {
    marca: "Ford",
    modelo: "Fiesta",
    ano: 2020,
    ligar: function() {
        return "Carro ligado!";
    }
};
                            

// PHP
$carro = (object) [
    'marca' => 'Ford',
    'modelo' => 'Fiesta',
    'ano' => 2020
];

11. Funções

**Funções** são blocos de código reutilizáveis. Elas podem receber entradas, processá-las e retornar um valor.

Exemplos:


// PHP
function soma($a, $b) {
    return $a + $b;
}

// Escopo
$global = 10;
function teste() {
    global $global;
    $local = 5;
    return $global + $local;
}
                            

// JavaScript
function soma(a, b) {
    return a + b;
}

// Escopo
let global = 10;
function teste() {
    let local = 5;
    return global + local;
}

12. Inserindo PHP/JavaScript em HTML

O PHP é uma linguagem de servidor, processada antes da página ser enviada ao navegador. Já o JavaScript é uma linguagem de cliente, processada diretamente no navegador.

Exemplos:


// HTML com PHP
<!DOCTYPE html>
<html>
<body>
    <?php
    echo "Data: " . date('d/m/Y');
    ?>
</body>
</html>
                            

// HTML com JavaScript
<!DOCTYPE html>
<html>
<body>
    <script>
    document.write("Hora: " + new Date().toLocaleTimeString());
    </script>
</body>
</html>
