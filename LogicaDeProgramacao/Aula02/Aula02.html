Problema do Dia

Sua tarefa é criar um algoritmo para um caixa eletrônico. Ele deve pedir o valor que o usuário deseja sacar e, em seguida, mostrar quantas notas de R$ 50, R$ 20, R$ 10, R$ 5 e R$ 2 ele receberá, sempre dando a maior nota possível primeiro. Pense na lógica antes de escrever qualquer código!

5. Estruturas Condicionais

As estruturas condicionais (`if`, `else if`, `else`) permitem que o seu programa tome decisões com base em certas condições. 


// Exemplo em PHP/JavaScript
if ($idade >= 18) {
    echo "Maior de idade";
} elseif ($idade >= 12) {
    echo "Adolescente";
} else {
    echo "Criança";
}

6. Operador Ternário

O operador ternário é uma forma concisa de escrever uma estrutura condicional `if/else`. 


// Exemplo em PHP/JavaScript
$status = ($idade >= 18) ? "Adulto" : "Menor";

7. Switch Case

O `switch` é usado para selecionar um de muitos blocos de código a serem executados. É uma alternativa mais limpa para múltiplos `if/else if`. 


// Exemplo em PHP/JavaScript
switch ($diaSemana) {
    case 1: echo "Domingo"; break;
    case 2: echo "Segunda"; break;
    // ...
    default: echo "Dia inválido";
}

8. Estruturas de Repetição

As estruturas de repetição (`for`, `while`, `do-while`) permitem executar um bloco de código repetidamente, o que é fundamental para automação de tarefas. 


// Exemplo em PHP/JavaScript
// for
for ($i = 0; $i < 10; $i++) {
    echo $i;
}

// while
$i = 0;
while ($i < 10) {
    echo $i;
    $i++;
}

// do while
$i = 0;
do {
    echo $i;
    $i++;
} while ($i < 10);
