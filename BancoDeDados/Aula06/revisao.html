1. Comando INSERT - Inserindo Dados

**Para que serve?** Adicionar novos registros (linhas) em uma tabela.

Sintaxe Básica
INSERT INTO nome_tabela (coluna1, coluna2, coluna3, ...)
VALUES (valor1, valor2, valor3, ...);
Exemplo Prático
INSERT INTO clientes (nome, email, telefone, endereco)
VALUES ('Carlos Santana', 'santana@hotmail.com', '(91) 9999-5555', 'Rua dos pardais 183');

2. Comando UPDATE - Modificando Dados

**Para que serve?** Alterar valores de registros existentes em uma tabela.

Sintaxe Básica
UPDATE nome_tabela
SET coluna1 = novo_valor, coluna2 = novo_valor2, ...
WHERE condição;
⚠️ CUIDADO! Sem a cláusula `WHERE`, o comando `UPDATE` irá alterar **TODOS** os registros da tabela!
Exemplo Prático
UPDATE clientes
SET telefone = (41) 7555-3333
WHERE nome = 'João Pereira';
Resultado Visual
ANTES: 

+------------+--------------+-----------------+
| cliente_id | nome         | telefone        |
+------------+--------------+-----------------+
| 2          | João Pereira | (41) 96666-4444 |
+------------+--------------+-----------------+
DEPOIS: 

+------------+--------------+-----------------+
| cliente_id | nome         | telefone        |
+------------+--------------+-----------------+
| 2          | João Pereira | (41) 7555-3333  | ← ALTERADO!
+------------+--------------+-----------------+

3. Comando DELETE - Removendo Dados

**Para que serve?** Excluir registros permanentemente de uma tabela.

Sintaxe Básica
DELETE FROM nome_tabela
WHERE condição;
⚠️ CUIDADO EXTREMO! Sem a cláusula `WHERE`, o comando `DELETE` irá excluir **TODOS** os registros da tabela!
Exemplo Prático
DELETE FROM clientes
WHERE cliente_id = 5;
Resultado Visual
ANTES:

+------------+-------------------+

4. Comando SELECT + WHERE - Consultando com Filtros

**Para que serve?** Recuperar dados específicos de uma tabela usando condições.

Sintaxe Básica
SELECT coluna1, coluna2, ...
FROM nome_tabela
WHERE condição;
Operadores de Comparação
Operador Significado Exemplo
`=` Igual `WHERE endereco = 'Rua das Palmeiras, 321 - Curitiba'`
`<>` Diferente `WHERE endereco <> 2`
`<` Menor que `WHERE telefone < 10`
`>` Maior que `WHERE email > 5`
`<=` Menor ou igual `WHERE telefone <= 12`
`>=` Maior ou igual `WHERE email >= 8`
Operadores Especiais
Operador Uso Exemplo
`BETWEEN` Intervalo de valores `WHERE telefone BETWEEN 1 AND 5`
`LIKE` Correspondência de padrões com `%` `WHERE nome LIKE '%Caderno%'`
`IN` Lista de valores possíveis `WHERE endereco IN (1, 2)`
Operadores Lógicos
Operador Função Exemplo
`AND` Ambas as condições devem ser verdadeiras `WHERE endereco = 'Rua das Palmeiras, 321 - Curitiba' AND telefone > 10`
`OR` Pelo menos uma condição deve ser verdadeira `WHERE endereco = 'Rua das Palmeiras, 321 - Curitiba' OR endereco = 2`
`NOT` Nega uma condição `WHERE NOT endereco = 2`
Exemplo Prático Combinado
SELECT cliente_id, nome, telefone
FROM clientes
WHERE (data_cadastro LIKE '2023%' OR nome LIKE '%a%')
AND cliente_id BETWEEN 2 AND 4;

✏️ Exercícios - SELECT + WHERE

Exercício 4.1

Selecione a `nome` e o `email` de todos os clientes com `email` igual a 'marisantos@locals.com'. 

SELECT nome, email
FROM clientes
WHERE email = 'marisantos@locals.com';
Exercício 4.2

Encontre todos os clientes que tem a data do cadastro o ano de 2023 e que contêm a letra 'e' no nome. 

SELECT *
FROM clientes
WHERE data_cadastro LIKE '2023%' AND nome LIKE '%e%';

💡 Dica Final

Sempre faça um **SELECT** antes de um **UPDATE** ou **DELETE** para verificar quais registros serão afetados. 

-- Primeiro verifique com SELECT para ver o resultado:
SELECT * FROM clientes WHERE nome = 'João Pereira';

-- Se o resultado estiver correto, execute o UPDATE:
UPDATE clientes SET telefone = (41) 7555-3333 WHERE nome = 'João Pereira';
