DTL: Linguagem de Transação de Dados

Garanta a integridade e consistência das suas operações.

O Que é DTL?

A Linguagem de Transação de Dados (DTL) é um subconjunto da SQL que gerencia as transações, garantindo que as operações sejam executadas de forma segura e confiável. Uma transação é uma sequência de uma ou mais operações lógicas que devem ser tratadas como uma única unidade de trabalho.

Propriedades ACID

As transações em bancos de dados relacionais são garantidas pelas propriedades ACID, que asseguram a confiabilidade do processamento.

⚛️

Atomicidade

Todas as operações de uma transação são executadas com sucesso, ou nenhuma delas é. É o princípio do "tudo ou nada".

✅

Consistência

A transação leva o banco de dados de um estado consistente para outro. As regras de integridade do BD são mantidas.

isolé

Isolamento

Transações simultâneas não interferem umas nas outras. O resultado final é o mesmo de se elas fossem executadas sequencialmente.

🧱

Durabilidade

Uma vez que a transação é concluída (commit), suas alterações são permanentes e sobrevivem a falhas do sistema.

💾

Comando COMMIT

Finaliza uma transação com sucesso, salvando permanentemente todas as alterações feitas no banco de dados. 

BEGIN TRANSACTION;
UPDATE Contas
SET saldo = saldo - 100
WHERE id = 123;
UPDATE Contas
SET saldo = saldo + 100
WHERE id = 456;
COMMIT; -- Salva todas as alterações
↩️

Comando ROLLBACK

Desfaz todas as alterações de uma transação não finalizada, restaurando o banco de dados para o estado em que estava antes do início da transação. 

BEGIN TRANSACTION;
UPDATE Livros
SET estoque = estoque - 1
WHERE titulo = 'O Iluminado';
-- Ocorre um erro inesperado...
ROLLBACK; -- Desfaz a operação
📍

Comando SAVEPOINT

Cria um ponto de salvamento temporário dentro de uma transação. Permite reverter apenas para aquele ponto, sem desfazer a transação inteira. 

BEGIN TRANSACTION;
INSERT INTO Clientes (...)
SAVEPOINT cliente_adicionado;
INSERT INTO Vendas (...);
-- Se a inserção de Vendas falhar...
ROLLBACK TO SAVEPOINT cliente_adicionado;
-- Apenas a venda é desfeita.

O uso correto da DTL é a chave para garantir que as operações críticas sejam seguras e que os dados permaneçam íntegros, mesmo em caso de falhas.
