DCL: A Linguagem de Segurança

Linguagem de Controle de Dados - Gerencie permissões de acesso.

O Que é DCL?

A Linguagem de Controle de Dados (DCL) é um subconjunto da SQL que lida com a gestão de permissões e controle de acesso aos dados. Ela é fundamental para a segurança do banco de dados, permitindo que administradores definam quem pode executar quais operações.

🔒

Comando GRANT

É usado para conceder privilégios (permissões) a usuários ou a grupos de usuários em objetos do banco de dados (tabelas, visões, etc.).

Conceder permissão para selecionar dados

GRANT SELECT ON Clientes TO 'usuario_leitura';

Conceder múltiplas permissões

GRANT INSERT, UPDATE ON Livros TO 'equipe_vendas';

Dar todos os privilégios

GRANT ALL PRIVILEGES ON Vendas TO 'administrador';
🔓

Comando REVOKE

É usado para remover privilégios que foram concedidos anteriormente a um usuário ou grupo de usuários.

Revogar permissão para selecionar

REVOKE SELECT ON Clientes FROM 'usuario_leitura';

Revogar múltiplas permissões

REVOKE INSERT, UPDATE ON Livros FROM 'equipe_vendas';

Revogar todos os privilégios

REVOKE ALL PRIVILEGES ON Vendas FROM 'administrador';

A DCL é essencial para manter a integridade e a segurança do banco de dados.

Ela garante que apenas as pessoas certas tenham acesso às informações certas.
