DQL: A Linguagem da Informação

Linguagem de Consulta de Dados - Extraia insights do seu banco.

O Que é DQL?

A Linguagem de Consulta de Dados (DQL) é o subconjunto da SQL dedicado à recuperação de dados. Seu comando principal, o SELECT, é o mais utilizado e essencial para a análise de dados.

📄

O Comando SELECT

É a instrução fundamental para solicitar dados de uma ou mais tabelas.

Selecionar todas as colunas

SELECT * FROM Livros;

Selecionar colunas específicas

SELECT titulo, preco FROM Livros;

Usando alias

SELECT titulo AS 'Título do Livro' FROM Livros;
🎯

Cláusula WHERE

Filtra os registros com base em condições, mostrando apenas os que atendem aos critérios.

Filtro simples

SELECT * FROM Livros
WHERE preco > 50.00;

Com operadores lógicos

SELECT nome FROM Clientes
WHERE cidade = 'Rio de Janeiro' AND idade > 25;
📊

Cláusula GROUP BY

Agrupa linhas que têm os mesmos valores para uma ou mais colunas, geralmente usada com funções de agregação.

Contar por editora

SELECT editora, COUNT(*)
FROM Livros
GROUP BY editora;
⚠️

Cláusula HAVING

Filtra os grupos criados pelo GROUP BY com base em uma condição agregada.

Grupos com mais de 100 livros

SELECT editora, COUNT(*)
FROM Livros
GROUP BY editora
HAVING COUNT(*) > 100;
⬆️⬇️

Cláusula ORDER BY

Ordena o conjunto de resultados em ordem ascendente (ASC) ou descendente (DESC).

Ordenar por preço

SELECT titulo, preco FROM Livros
ORDER BY preco DESC;
🔗

Junções (JOINs)

Combina linhas de duas ou mais tabelas com base em uma coluna comum.

Clientes e seus pedidos

SELECT C.nome, V.data_venda
FROM Clientes AS C
JOIN Vendas AS V
ON C.cliente_id = V.cliente_id;

Dominar a DQL é fundamental para transformar dados brutos em informações úteis e estratégicas.

Ela é a base para qualquer análise ou relatório.
