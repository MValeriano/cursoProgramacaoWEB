DDL: A Linguagem da Estrutura

Linguagem de Definição de Dados - Mude o esqueleto do seu banco de dados.

O Que é DDL?

A Linguagem de Definição de Dados (DDL) é um subconjunto da SQL usado para definir e gerenciar a estrutura dos objetos de um banco de dados. Em vez de manipular os dados em si, você está trabalhando com o "esqueleto" do banco, como tabelas, índices e visões.

➕

CREATE

Usado para criar novos objetos no banco de dados. É o primeiro passo para construir sua estrutura de dados.

CREATE TABLE

CREATE TABLE Clientes (
    cliente_id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE
);

CREATE DATABASE

CREATE DATABASE LojaOnline;

CREATE INDEX

CREATE INDEX idx_email ON Clientes (email);
🔧

ALTER

Permite modificar a estrutura de um objeto já existente. Você pode adicionar, remover ou alterar colunas.

Adicionar Coluna

ALTER TABLE Clientes
ADD telefone VARCHAR(20);

Remover Coluna

ALTER TABLE Clientes
DROP COLUMN telefone;

Modificar Coluna

ALTER TABLE Clientes
MODIFY COLUMN nome VARCHAR(150);
🗑️

DROP

Usado para remover objetos do banco de dados de forma definitiva. Cuidado, esta operação não pode ser desfeita!

Remover Tabela

DROP TABLE Clientes;

Remover Banco de Dados

DROP DATABASE LojaOnline;

Remover Índice

DROP INDEX idx_email;

O DDL é essencial para o design e a manutenção de qualquer banco de dados relacional.

É a fundação sobre a qual todos os seus dados serão construídos.
