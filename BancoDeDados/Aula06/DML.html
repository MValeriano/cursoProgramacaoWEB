DML: A Linguagem da Ação

Linguagem de Manipulação de Dados - Interaja com os dados do seu banco.

O Que é DML?

A Linguagem de Manipulação de Dados (DML) é um subconjunto da SQL usado para gerenciar e manipular os dados que estão armazenados nos objetos de um banco de dados. É o que permite inserir, selecionar, atualizar e remover dados.

Dominar a DML é a chave para interagir de forma eficiente com qualquer banco de dados.

Ela permite transformar dados brutos em insights valiosos.

🔎

SELECT

Usado para recuperar dados de uma ou mais tabelas. É o comando mais comum e versátil da SQL.

Recuperar todos os dados

SELECT * FROM Clientes;

Com filtro (WHERE)

SELECT nome, email FROM Clientes
WHERE cidade = 'São Paulo';

Com agrupamento (GROUP BY)

SELECT cidade, COUNT(*)
FROM Clientes
GROUP BY cidade;
➕

INSERT

Usado para inserir novos registros em uma tabela. Você pode adicionar uma linha completa ou em colunas específicas.

Inserir todos os valores

INSERT INTO Clientes
VALUES (1, 'Ana', 'ana@email.com');

Inserir valores específicos

INSERT INTO Clientes (nome, email)
VALUES ('Pedro', 'pedro@email.com');
✏️

UPDATE

Usado para modificar valores de registros existentes em uma tabela. Sempre use a cláusula WHERE para evitar alterar todos os dados.

Atualizar um registro

UPDATE Clientes
SET telefone = '987654321'
WHERE cliente_id = 1;

Atualizar múltiplos registros

UPDATE Livros
SET preco = preco * 1.10
WHERE editora = 'Cia. das Letras';
❌

DELETE

Usado para remover um ou mais registros de uma tabela. Assim como no UPDATE, é crucial usar a cláusula WHERE.

Remover um registro

DELETE FROM Clientes
WHERE cliente_id = 2;

Remover todos os registros

DELETE FROM Vendas;
