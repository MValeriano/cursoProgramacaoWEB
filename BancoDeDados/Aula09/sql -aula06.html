1. Fundamentos de Banco de Dados

Um banco de dados é um sistema organizado para armazenar, gerenciar e recuperar dados. O **SGBD (Sistema de Gerenciamento de Banco de Dados)** é o software que permite a interação com esses dados.

Conceitos Fundamentais do SGBD
  • 🔒 **Segurança:** Controla quem pode acessar o quê.
  • ✅ **Integridade:** Garante a validade e a consistência dos dados.
  • 🤝 **Concorrência:** Permite que múltiplos usuários acessem dados simultaneamente sem problemas.
  • 🔄 **Transações:** Garante que as operações sejam concluídas ou desfeitas em sua totalidade (propriedades **ACID**).
  • 🩹 **Recuperação de Falhas:** Permite restaurar o banco após uma falha.

2. Modelagem de Dados

Modelo Conceitual (Diagrama ER)

É a representação de alto nível dos dados, focada nas regras de negócio. Usa o **Diagrama de Entidade-Relacionamento (ER)**.

  • **Entidades:** Objetos de interesse (ex: `Cliente`, `Livro`).
  • **Atributos:** Características das entidades (ex: `nome`, `preco`).
  • **Relacionamentos:** Como as entidades se conectam (ex: `Cliente` *compra* `Livro`).
  • **Cardinalidade:** Quantas instâncias de uma entidade podem se relacionar com outra (ex: 1:1, 1:N, N:M).
Modelo Lógico e Físico

**Lógico:** Traduz o modelo conceitual para uma estrutura de tabelas, sem especificar o SGBD.

**Físico:** A implementação real do banco de dados, com tipos de dados específicos e otimizações.

3. As Linguagens do SQL

O SQL é dividido em linguagens, cada uma com um propósito diferente.

DQL (Data Query Language)

Para **consultar e buscar** dados. É a parte mais utilizada.

Comando Principal: `SELECT`

DML (Data Manipulation Language)

Para **manipular dados**, ou seja, inserir, atualizar e remover.

Comandos: `INSERT`, `UPDATE`, `DELETE`

DDL (Data Definition Language)

Para **definir a estrutura** do banco de dados, como tabelas.

Comandos: `CREATE`, `ALTER`, `DROP`

DCL (Data Control Language)

Para **controlar o acesso** e as permissões de usuários.

Comandos: `GRANT`, `REVOKE`

DTL (Data Transaction Language)

Para gerenciar **transações** e garantir a consistência dos dados.

Comandos: `BEGIN`, `COMMIT`, `ROLLBACK`

4. SQL na Prática

Aqui estão alguns dos comandos mais importantes que você praticou.

DQL: Consultando Dados

-- Selecionar todos os clientes
SELECT * FROM clientes;

-- Selecionar nome e preço de livros com preço > 40
SELECT titulo, preco FROM livros WHERE preco > 40;

DML: Manipulando Dados

-- Inserir um novo autor
INSERT INTO autores (nome, nacionalidade) VALUES ('Clarice Lispector', 'Brasileira');

-- Atualizar o preço de um livro
UPDATE livros SET preco = 55.00 WHERE titulo = 'Dom Casmurro';

-- Excluir um livro
DELETE FROM livros WHERE titulo = 'Dom Casmurro';

5. Relacionamentos e JOINs

`JOINs` são essenciais para conectar tabelas e obter dados de forma consolidada.

INNER JOIN

Retorna apenas as linhas que têm correspondência nas duas tabelas. 

SELECT c.nome, v.data_venda
FROM clientes c
JOIN vendas v ON c.cliente_id = v.cliente_id;

LEFT JOIN

Retorna todas as linhas da tabela da esquerda e as correspondentes da direita. 

SELECT l.titulo, a.nome
FROM livros l
LEFT JOIN livro_autores la ON l.livro_id = la.livro_id
LEFT JOIN autores a ON la.autor_id = a.autor_id;
