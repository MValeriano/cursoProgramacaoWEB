Sessão 2: Filtros Básicos

Livraria ZedeLivros

💰 2.1 - Livros Caros

Objetivo: Encontrar livros acima de R$ 40,00.

Tarefa: Mostre os livros que custam mais de R$ 40,00.

Solução 
SELECT * FROM Livros WHERE preco > 40.00;

🇧🇷 2.2 - Autores Brasileiros

Objetivo: Descobrir autores nacionais.

Tarefa: Liste todos os autores brasileiros.

Solução 
SELECT * FROM Autores WHERE nacionalidade = 'Brasileira';

✅ 2.3 - Vendas Concluídas

Objetivo: Ver vendas finalizadas.

Tarefa: Mostre as vendas que têm status "concluída".

Solução 
SELECT * FROM Vendas WHERE status = 'concluída';

📦 2.4 - Estoque Baixo

Objetivo: Identificar livros com pouco estoque.

Tarefa: Liste os livros com menos de 40 unidades em estoque.

Solução 
SELECT * FROM Livros WHERE estoque < 40;

👤 2.5 - Cliente Específico

Objetivo: Encontrar dados de um cliente.

Tarefa: Mostre todas as informações da cliente "Ana Silva".

Solução 
SELECT * FROM Clientes WHERE nome = 'Ana Silva';

🔍 2.6 - Livro por Título

Objetivo: Encontrar um livro específico.

Tarefa: Liste os dados do livro "Dom Casmurro".

Solução 
SELECT * FROM Livros WHERE titulo = 'Dom Casmurro';

📅 2.7 - Vendas de Janeiro

Objetivo: Ver vendas de um período.

Tarefa: Mostre as vendas feitas em janeiro de 2024.

Solução 
SELECT * FROM Vendas WHERE data_venda BETWEEN '2024-01-01' AND '2024-01-31';

🕰️ 2.8 - Autores Nascidos no Século XX

Objetivo: Encontrar autores modernos.

Tarefa: Liste autores nascidos a partir de 1900.

Solução 
SELECT * FROM Autores WHERE data_nascimento >= '1900-01-01';

💲 2.9 - Faturas Pagas

Objetivo: Ver faturas quitadas.

Tarefa: Mostre as faturas com status "paga".

Solução 
SELECT * FROM Faturas WHERE status = 'paga';

🏛️ 2.10 - Livros da Companhia das Letras

Objetivo: Ver livros de uma editora.

Tarefa: Liste os livros publicados pela "Companhia das Letras".

Solução 
SELECT * FROM Livros WHERE editora = 'Companhia das Letras';
