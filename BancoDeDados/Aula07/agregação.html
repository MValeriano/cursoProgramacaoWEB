Funções de Agregação no PostgreSQL

Transformando dados em resumos significativos

O que são Funções de Agregação?

Funções de agregação realizam **cálculos em um conjunto de valores** e retornam um **único valor**. Elas são essenciais para relatórios e análises de dados, permitindo obter resumos como totais, médias e contagens de grandes volumes de informação.

Principais Funções:

  • **`SUM()`**: Soma os valores de uma coluna.
  • **`COUNT()`**: Conta o número de linhas ou valores.
  • **`AVG()`**: Calcula a média aritmética.
  • **`MIN()`** e **`MAX()`**: Encontram os valores mínimo e máximo.

Estrutura de Dados dos Exemplos

Para nossos exemplos práticos, vamos usar a seguinte tabela de vendas.

-- Criação da tabela de vendas CREATE TABLE vendas ( venda_id SERIAL PRIMARY KEY, data_venda DATE NOT NULL, cliente_id INTEGER, vendedor_id INTEGER, produto VARCHAR(100), quantidade INTEGER, valor_unitario DECIMAL(10,2), total DECIMAL(10,2) ); -- Inserção dos dados de exemplo INSERT INTO vendas (data_venda, cliente_id, vendedor_id, produto, quantidade, valor_unitario, total) VALUES ('2024-01-15', 1, 101, 'Notebook', 2, 2500.00, 5000.00), ('2024-01-15', 2, 102, 'Mouse', 5, 50.00, 250.00), ('2024-01-16', 1, 101, 'Teclado', 3, 120.00, 360.00), ('2024-01-17', 3, 103, 'Monitor', 1, 800.00, 800.00), ('2024-01-17', 2, 102, 'Notebook', 1, 2500.00, 2500.00), ('2024-01-18', 1, 101, 'Mouse', 2, 50.00, 100.00), ('2024-01-18', 4, 103, 'Tablet', 2, 700.00, 1400.00);

As Funções em Ação

1. `SUM()` - Soma

Calcula o total de uma coluna numérica.

SELECT SUM(total) AS total_geral FROM vendas;

2. `COUNT()` - Contagem

Conta o número de registros.

SELECT COUNT(*) AS total_vendas FROM vendas;

3. `AVG()` - Média

Calcula a média de uma coluna.

SELECT AVG(total) AS media_vendas FROM vendas;

4. `MIN()` e `MAX()` - Extremos

Encontram o menor e o maior valor.

SELECT MIN(total) AS menor_venda, MAX(total) AS maior_venda FROM vendas;

Agrupando e Filtrando Agregações

As cláusulas `GROUP BY` e `HAVING` trabalham juntas para criar e filtrar grupos de dados.

`GROUP BY`

Agrupa linhas com valores idênticos para aplicar uma agregação.

SELECT produto, SUM(total) AS total_vendido FROM vendas GROUP BY produto;

`HAVING`

Filtra os resultados **após** a agregação.

SELECT vendedor_id, COUNT(*) AS total_vendas FROM vendas GROUP BY vendedor_id HAVING COUNT(*) > 2;

A Diferença Crucial: WHERE vs. HAVING

  • **`WHERE`**: Filtra **linhas individuais** antes da agregação.
  • **`HAVING`**: Filtra **grupos de linhas** depois da agregação.

É um dos conceitos mais importantes para otimizar suas consultas. Lembre-se: `WHERE` atua sobre os dados brutos, enquanto `HAVING` atua sobre os dados já agregados.

Exercícios Práticos

Agora que você entende as principais funções e cláusulas, pratique com os exemplos abaixo. Copie e cole o código para ver os resultados!

1. Soma por Produto

SELECT produto, SUM(total) AS total_produto FROM vendas GROUP BY produto;

2. Contagem de Clientes Distintos

SELECT COUNT(DISTINCT cliente_id) AS clientes_ativos FROM vendas;

3. Vendas de Vendedores com Mais de 1 Venda

SELECT vendedor_id, COUNT(*) AS total_vendas FROM vendas GROUP BY vendedor_id HAVING COUNT(*) > 1;
