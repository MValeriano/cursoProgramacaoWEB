📖 5.1 - Clientes que Compraram Machado

Objetivo: Encontrar fãs do autor.

Tarefa: Liste clientes que compraram livros de Machado de Assis.

Solução 

SELECT DISTINCT c.nome
FROM Clientes c
JOIN Vendas v ON c.cliente_id = v.cliente_id
JOIN Venda_Itens vi ON v.venda_id = vi.venda_id
JOIN Livros l ON vi.livro_id = l.livro_id
JOIN Livro_Autores la ON l.livro_id = la.livro_id
JOIN Autores a ON la.autor_id = a.autor_id
WHERE a.nome = 'Machado de Assis';

🚫 5.2 - Livros Nunca Vendidos

Objetivo: Identificar livros parados.

Tarefa: Mostre livros que nunca foram vendidos.

Solução 

SELECT l.titulo
FROM Livros l
LEFT JOIN Venda_Itens vi ON l.livro_id = vi.livro_id
WHERE vi.livro_id IS NULL;

🏆 5.3 - Maior Compra

Objetivo: Encontrar a venda de maior valor.

Tarefa: Mostre a venda com o maior valor total.

Solução 

SELECT *
FROM Vendas
ORDER BY total DESC
LIMIT 1;

🌟 5.4 - Clientes que Mais Compram

Objetivo: Identificar melhores clientes.

Tarefa: Liste os 3 clientes que mais fizeram compras.

Solução 

SELECT c.nome, COUNT(v.venda_id) AS total_compras
FROM Clientes c
JOIN Vendas v ON c.cliente_id = v.cliente_id
GROUP BY c.nome
ORDER BY total_compras DESC
LIMIT 3;

📈 5.5 - Faturamento por Mês

Objetivo: Analisar performance mensal.

Tarefa: Mostre o total vendido por mês.

Solução 

SELECT strftime('%Y-%m', data_venda) AS mes, SUM(total) AS faturamento_total
FROM Vendas
GROUP BY mes
ORDER BY mes;
