💰 4.1 - Total por Cliente

Objetivo: Saber quanto cada cliente gastou.

Tarefa: Mostre o nome do cliente e o total gasto por ele.

Solução 

SELECT c.nome, SUM(v.total) AS total_gasto
FROM Clientes c
JOIN Vendas v ON c.cliente_id = v.cliente_id
GROUP BY c.nome;

📚 4.2 - Livros Mais Vendidos

Objetivo: Descobrir os livros populares.

Tarefa: Liste os livros e quantas vezes foram vendidos.

Solução 

SELECT l.titulo, SUM(vi.quantidade) AS total_vendido
FROM Livros l
JOIN Venda_Itens vi ON l.livro_id = vi.livro_id
GROUP BY l.titulo
ORDER BY total_vendido DESC;

✍️ 4.3 - Autores Mais Publicados

Objetivo: Ver autores com mais livros.

Tarefa: Mostre quantos livros cada autor tem.

Solução 

SELECT a.nome, COUNT(la.livro_id) AS total_livros
FROM Autores a
JOIN Livro_Autores la ON a.autor_id = la.autor_id
GROUP BY a.nome
ORDER BY total_livros DESC;

📊 4.4 - Vendas por Status

Objetivo: Agrupar vendas por situação.

Tarefa: Conte quantas vendas têm cada status.

Solução 

SELECT status, COUNT(*) AS numero_de_vendas
FROM Vendas
GROUP BY status;

⚖️ 4.5 - Média de Preços por Editora

Objetivo: Comparar preços entre editoras.

Tarefa: Mostre a média de preço dos livros de cada editora.

Solução 

SELECT editora, AVG(preco) AS preco_medio
FROM Livros
GROUP BY editora;
