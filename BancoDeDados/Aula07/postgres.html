AULA: INTRODUÇÃO AO POSTGRESQL

Um dos Bancos de Dados Relacionais mais robustos e avançados do mercado!

O que é PostgreSQL?

O **PostgreSQL**, também conhecido como "Postgres", é um poderoso sistema de gerenciamento de banco de dados relacional de código aberto (SGBDR). Ele é como uma grande biblioteca digital onde podemos armazenar, organizar e recuperar informações de forma segura e eficiente.

Por que usar PostgreSQL?
  • ⭐
    Grátis e de Código Aberto: É uma solução gratuita, o que significa que você pode usá-la em qualquer projeto, desde um pequeno hobby até uma grande aplicação corporativa, sem custos de licença.
  • ⭐
    Confiabilidade e Estabilidade: É conhecido por sua robustez e alta tolerância a falhas. Seus dados estão seguros e as transações são garantidas pelas propriedades **ACID** (Atomicidade, Consistência, Isolamento e Durabilidade).
  • ⭐
    Comunidade Ativa e Ampla Adoção: Possui uma comunidade global de desenvolvedores e usuários que fornecem suporte contínuo e contribuem para seu constante aprimoramento.
  • ⭐
    Recursos Avançados: Suporta recursos complexos como **chaves estrangeiras**, **gatilhos** (triggers), **procedimentos armazenados** e muito mais.
  • ⭐
    Suporte a Geolocalização: É amplamente utilizado em aplicativos de mapeamento e análise espacial devido ao suporte nativo a dados geoespaciais com a extensão **PostGIS**.

Conceitos e Comandos Básicos

Conceitos Essenciais
  • **Banco de Dados:** Uma pasta que contém várias tabelas.
  • **Tabela:** Uma planilha com linhas e colunas.
  • **Linha (Registro):** Cada entrada na tabela.
  • **Coluna (Campo):** Cada característica dos registros.

Criando e Manipulando Dados

Criando um Banco de Dados

No PostgreSQL, você pode criar um banco de dados usando o comando `CREATE DATABASE` no terminal, por exemplo: 

create database meubancodedados;
Criando Tabelas e Inserindo Dados

Para definir a estrutura dos dados, usamos o comando `CREATE TABLE`. Veja um exemplo de uma tabela `usuarios` com colunas `id`, `nome` e `idade`: 

CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nome VARCHAR(255),
    idade INTEGER
);

Para adicionar um novo registro (uma linha), usamos o comando `INSERT`: 

INSERT INTO usuarios (nome, idade) VALUES ('Hugo', 30);
Consultando Dados (SELECT)

Para ver os dados de uma tabela, usamos o `SELECT`. 

-- Para ver todos os dados da tabela
SELECT * FROM usuarios;

-- Para filtrar dados, usamos a cláusula WHERE
SELECT * FROM usuarios WHERE idade > 25;
Atualizando e Excluindo Dados (UPDATE e DELETE)

Para modificar um registro, use o `UPDATE`, sempre com um filtro `WHERE` para evitar atualizar dados indesejados. Para remover, use o `DELETE`. 

-- Atualizar a idade do usuário com ID 1
UPDATE usuarios SET idade = 35 WHERE id = 1;

-- Excluir o usuário com ID 1
DELETE FROM usuarios WHERE id = 1;
