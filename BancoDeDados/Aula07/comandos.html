Comandos Essenciais do PostgreSQL

Uma referência rápida para dominar as operações básicas de SQL.

SELECT

O comando **SELECT** é a sua principal ferramenta para extrair dados de um banco de dados. Pense nele como se estivesse pedindo ao banco para lhe mostrar informações específicas. Ele é versátil e forma a base para quase tudo o que você fará com SQL. Seja para extrair uma tabela completa ou apenas alguns detalhes específicos, o **SELECT** é a forma de solicitar que o banco de dados compartilhe os dados com você.

Exemplos
-- Para ver todas as informações sobre os funcionários
SELECT * FROM employees;

-- Para ver apenas os nomes e departamentos
SELECT name, department FROM employees;

WHERE

A cláusula **WHERE** funciona como uma lente de aumento para suas consultas, permitindo que você se concentre apenas nos dados específicos de que precisa. Em vez de recuperar todas as linhas de uma tabela, você pode aplicar condições para restringir os resultados. Isso torna suas consultas mais eficientes e o resultado mais relevante.

Exemplos
-- Encontrar funcionários do departamento 'Sales'
SELECT * FROM employees WHERE department = 'Sales';

-- Encontrar funcionários do departamento 'Sales' que ganham mais de 50000
SELECT * FROM employees WHERE department = 'Sales' AND salary > 50000;

ORDER BY

A cláusula **ORDER BY** organiza seus dados para que você possa vê-los com mais clareza. Ela permite que você classifique os resultados por uma ou mais colunas, facilitando a análise e a compreensão das informações. Você pode ordenar em ordem crescente (`ASC`) ou decrescente (`DESC`).

Exemplos
-- Classificar funcionários por salário, do maior para o menor
SELECT * FROM employees ORDER BY salary DESC;

-- Classificar primeiro por departamento e depois por nome
SELECT * FROM employees ORDER BY department, name;

JOIN

O comando **JOIN** é usado para combinar dados de duas ou mais tabelas. Isso é particularmente útil quando seu banco de dados é normalizado e as informações relacionadas estão em tabelas separadas. O **JOIN** garante que seus dados permaneçam bem organizados e fáceis de consultar.

Exemplos
-- Unir tabelas 'employees' e 'departments' para ver nome e departamento
SELECT employees.name, departments.name
FROM employees
JOIN departments ON employees.department_id = departments.id;

-- Usar LEFT JOIN para incluir funcionários sem departamento
SELECT employees.name, departments.name
FROM employees
LEFT JOIN departments ON employees.department_id = departments.id;

GROUP BY

A cláusula **GROUP BY** é uma ferramenta essencial para organizar e resumir dados em suas consultas. Ela ajuda você a dividir grandes conjuntos de dados em grupos menores e significativos com base em colunas específicas. É especialmente útil com funções agregadas como `COUNT()` e `AVG()`.

Exemplos
-- Contar quantos funcionários há em cada departamento
SELECT department, COUNT(*) FROM employees GROUP BY department;

-- Encontrar o salário médio de cada departamento
SELECT department, AVG(salary) FROM employees GROUP BY department;

HAVING

A cláusula **HAVING** é como um filtro para dados agrupados. Enquanto o **WHERE** filtra linhas individuais, o **HAVING** permite que você aplique condições aos resultados agregados após o agrupamento. Isso é útil para focar em grupos que atendem a critérios específicos.

Exemplo
-- Encontrar departamentos onde o salário médio é superior a 50000
SELECT department, AVG(salary)
FROM employees
GROUP BY department
HAVING AVG(salary) > 50000;

LIMIT

A cláusula **LIMIT** é perfeita para trabalhar com grandes conjuntos de dados quando você precisa visualizar apenas uma pequena parte. É ideal para uma checagem rápida ou para depuração.

Exemplo
-- Limitar os resultados para as 10 primeiras linhas
SELECT * FROM employees LIMIT 10;

CREATE, INSERT, UPDATE, DELETE

Esses comandos formam a espinha dorsal do gerenciamento de banco de dados, permitindo que você adicione, modifique ou remova dados em suas tabelas. O domínio desses comandos permite que você assuma o controle total dos seus dados.

Exemplos
-- Adicionar um novo funcionário
INSERT INTO employees (name, department) VALUES ('John Doe', 'Marketing');

-- Atualizar o departamento de um funcionário
UPDATE employees SET department = 'HR' WHERE id = 1;

-- Excluir um registro de funcionário
DELETE FROM employees WHERE id = 1;
