AULA 3: DEFINIÇÃO DE ESTRUTURAS (DDL)

Aprenda a criar e modificar a estrutura de um banco de dados.

O que é DDL?

A **DDL** (Data Definition Language) é o conjunto de comandos SQL usado para **definir, modificar e remover a estrutura** do seu banco de dados. Com ela, você constrói a "casa" que vai guardar seus dados.

Comando CREATE: Criando Tabelas

O comando CREATE TABLE é usado para criar uma nova tabela no banco de dados.

Sintaxe

CREATE TABLE nome_tabela (
    coluna1 tipo_de_dado,
    coluna2 tipo_de_dado,
    ...
);

Principais Tipos de Dados

Eles definem o tipo de informação que cada coluna pode armazenar.

  • INTEGER: Números inteiros. Ex: idade, quantidade.
  • TEXT / VARCHAR: Cadeias de caracteres. Ex: nomes, endereços.
  • DECIMAL / REAL: Números com casas decimais. Ex: preços, saldos.
  • DATE: Armazena datas.

Constraints (Restrições)

Regras que garantem a integridade e a validade dos dados.

  • PRIMARY KEY: Identificador único para cada registro. Não pode ser nula e deve ser única.
  • FOREIGN KEY: Liga uma coluna a outra tabela, criando relacionamentos.
  • NOT NULL: Garante que a coluna não pode ter um valor nulo.
  • UNIQUE: Todos os valores na coluna devem ser únicos.
  • DEFAULT: Define um valor padrão caso nenhum valor seja fornecido.

Comando ALTER: Modificando Tabelas

Use o comando ALTER TABLE para adicionar, modificar ou remover colunas de uma tabela existente.

Adicionar Coluna

ALTER TABLE nome_tabela
ADD COLUMN nova_coluna tipo_dado;

Modificar Coluna

ALTER TABLE nome_tabela
MODIFY COLUMN coluna tipo_dado;

Remover Coluna

ALTER TABLE nome_tabela
DROP COLUMN coluna;

Comando DROP: Excluindo Estruturas

O comando DROP TABLE é usado para excluir uma tabela inteira. **Use com extrema cautela**, pois a operação é irreversível. 

DROP TABLE nome_tabela;
🚫 AVISO: Isso apaga a tabela e todos os seus dados.

EXERCÍCIOS DDL

Vamos praticar a definição de estruturas com o nosso banco de dados.
📘 Exercício 1: Criando uma Tabela

Crie uma nova tabela chamada `fornecedores` com as colunas: `fornecedor_id` (PRIMARY KEY, INTEGER), `nome` (TEXT, NOT NULL), `cidade` (TEXT) e `contato` (TEXT). 

CREATE TABLE fornecedores (
    fornecedor_id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    cidade TEXT,
    contato TEXT
);
📘 Exercício 2: Adicionando uma Coluna

Adicione uma nova coluna chamada `email` (TEXT) à tabela `fornecedores`. 

ALTER TABLE fornecedores
ADD COLUMN email TEXT;
📘 Exercício 3: Modificando uma Coluna

Altere o tipo de dado da coluna `contato` na tabela `fornecedores` para `INTEGER`. 

ALTER TABLE fornecedores
MODIFY COLUMN contato INTEGER;
📘 Exercício 4: Removendo uma Coluna

Remova a coluna `cidade` da tabela `fornecedores`. 

ALTER TABLE fornecedores
DROP COLUMN cidade;
📘 Exercício 5: Adicionando uma Tabela de Relacionamento

Crie uma tabela chamada `livros_fornecedores` para relacionar `livros` com `fornecedores`, usando `livro_id` e `fornecedor_id` como chaves estrangeiras. 

CREATE TABLE livros_fornecedores (
    livro_id INTEGER,
    fornecedor_id INTEGER,
    PRIMARY KEY(livro_id, fornecedor_id),
    FOREIGN KEY(livro_id) REFERENCES livros(livro_id),
    FOREIGN KEY(fornecedor_id) REFERENCES fornecedores(fornecedor_id)
);
📘 Exercício 6: Removendo a Tabela

Exclua a tabela `fornecedores`. 

DROP TABLE fornecedores;
