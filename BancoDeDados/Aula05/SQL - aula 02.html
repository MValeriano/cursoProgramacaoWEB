AULA 2: MANIPULAÇÃO DE DADOS (DML)

Aprenda a inserir, atualizar e excluir dados de forma segura.

Comando INSERT: Adicionando Novos Registros

O comando INSERT é usado para adicionar novos registros (linhas) em uma tabela. É a sua porta de entrada para popular o banco de dados.

Sintaxe Básica

Você especifica a tabela e, em seguida, os valores para cada coluna na ordem em que elas aparecem na tabela. 

INSERT INTO nome_tabela VALUES (valor1, valor2, ...);

Sintaxe Específica

É uma boa prática listar as colunas em que você está inserindo os dados. Isso torna o código mais legível e seguro contra futuras alterações na estrutura da tabela. 

INSERT INTO nome_tabela (coluna1, coluna2, ...)
VALUES (valor1, valor2, ...);

Comando UPDATE: Modificando Dados

O comando UPDATE é utilizado para modificar dados existentes em uma ou mais linhas de uma tabela.

Sintaxe

Você usa a cláusula SET para definir os novos valores e a cláusula WHERE para especificar quais registros devem ser atualizados. 

UPDATE nome_tabela
SET coluna1 = novo_valor1, coluna2 = novo_valor2, ...
WHERE condicao;
⚠️ ATENÇÃO: Sempre use a cláusula WHERE com UPDATE, ou você irá modificar todos os registros da tabela!

Comando DELETE: Removendo Registros

O comando DELETE é usado para remover uma ou mais linhas de uma tabela.

Sintaxe

Assim como o UPDATE, a cláusula WHERE é crucial para especificar quais registros devem ser removidos. 

DELETE FROM nome_tabela
WHERE condicao;
🚫 CUIDADO: O DELETE sem WHERE remove todos os dados da tabela, e a operação é irreversível (a menos que uma transação esteja sendo usada).

EXERCÍCIOS DML

Pratique os comandos INSERT, UPDATE e DELETE com as tabelas de nossa livraria!
📘 Exercício 1: Novo Cliente

Adicione um novo cliente com nome "João Santos", e-mail "joao.santos@email.com" e telefone "(11) 98765-4321". 

INSERT INTO clientes (nome, email, telefone)
VALUES ('João Santos', 'joao.santos@email.com', '(11) 98765-4321');
📘 Exercício 2: Adicionando um Livro

Insira um novo livro na tabela `livros` com o título "O Guia do Mochileiro das Galáxias", preço 35.50, estoque de 50 unidades e editora "Sextante". 

INSERT INTO livros (titulo, preco, estoque, editora)
VALUES ('O Guia do Mochileiro das Galáxias', 35.50, 50, 'Sextante');
📘 Exercício 3: Alterando o Telefone

Atualize o telefone do cliente "Ana Silva" para "(21) 99999-8888". 

UPDATE clientes
SET telefone = '(21) 99999-8888'
WHERE nome = 'Ana Silva';
📘 Exercício 4: Livro em Promoção

Reduza o preço de todos os livros da editora "Penguin" em 10%. 

UPDATE livros
SET preco = preco * 0.90
WHERE editora = 'Penguin';
📘 Exercício 5: Ajuste de Estoque

Aumente o estoque do livro "Dom Casmurro" em 15 unidades. 

UPDATE livros
SET estoque = estoque + 15
WHERE titulo = 'Dom Casmurro';
📘 Exercício 6: Removendo Autor

Exclua o autor "Jane Austen" da tabela `autores`. 

DELETE FROM autores
WHERE nome = 'Jane Austen';
📘 Exercício 7: Venda Cancelada

Altere o status da venda com ID 1 para "cancelada". 

UPDATE vendas
SET status = 'cancelada'
WHERE venda_id = 1;
📘 Exercício 8: Excluindo Fatura

Remova a fatura com o valor total de 125.75. 

DELETE FROM faturas
WHERE valor_total = 125.75;
📘 Exercício 9: Livros Esgotados

Atualize o preço de todos os livros com estoque igual a zero para R$ 0,00 (considerando que são gratuitos para divulgação). 

UPDATE livros
SET preco = 0.00
WHERE estoque = 0;
📘 Exercício 10: Limpeza de Vendas Antigas

Remova todas as vendas feitas antes de 2024. 

DELETE FROM vendas
WHERE data_venda < '2024-01-01';
