O que é um SGBD?

Sistema de Gerenciamento de Banco de Dados

A espinha dorsal de qualquer aplicação que armazena dados.

O que é um SGBD?

Um **SGBD** é um software que permite aos usuários e aplicações criar, gerenciar e interagir com um banco de dados de forma eficiente. Ele atua como uma camada de abstração entre a aplicação e os dados, simplificando a complexidade do armazenamento e da recuperação.

Pense nele como um zelador que organiza, protege e disponibiliza todas as informações do seu negócio.

Por que Usar um SGBD?

Segurança dos Dados

Controla o acesso, garantindo que apenas usuários autorizados possam ver ou modificar os dados.

Controle de Redundância e Integridade

Evita a duplicação de informações e garante que os dados sejam consistentes e confiáveis.

Acesso Múltiplo

Permite que vários usuários acessem e modifiquem o banco de dados simultaneamente sem causar problemas.

Backup e Recuperação

Ferramentas para criar cópias de segurança e restaurar o banco de dados em caso de falhas.

Abstração de Dados

Esconde a complexidade de como e onde os dados são armazenados fisicamente.

Linguagem de Manipulação

Fornece uma linguagem padrão (como o SQL) para interagir com o banco de dados.

Principais Funções de um SGBD

DDL (Linguagem de Definição de Dados)

Comandos para definir a estrutura do banco de dados.

  • **CREATE:** Cria objetos (tabelas, índices).
  • **ALTER:** Modifica a estrutura de um objeto.
  • **DROP:** Exclui um objeto.

DML (Linguagem de Manipulação de Dados)

Comandos para manipular os dados dentro das tabelas.

  • **INSERT:** Adiciona novos dados.
  • **SELECT:** Recupera dados.
  • **UPDATE:** Modifica dados existentes.
  • **DELETE:** Remove dados.

DCL (Linguagem de Controle de Dados)

Comandos para controlar o acesso e as permissões de usuários.

  • **GRANT:** Concede permissões.
  • **REVOKE:** Revoga permissões.

Tipos de SGBDs

SGBD Relacional (SQL)

Organiza os dados em **tabelas** com colunas e linhas. Usa chaves para definir relacionamentos.

**Exemplos:** MySQL, PostgreSQL, Oracle, SQL Server.

SGBD Não Relacional (NoSQL)

Projetado para lidar com dados não estruturados ou semi-estruturados, oferecendo flexibilidade e escalabilidade.

**Exemplos:** MongoDB, Cassandra, Redis.
