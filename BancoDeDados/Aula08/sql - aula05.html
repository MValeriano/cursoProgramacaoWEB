AULA 5: CONSULTAS AVANÇADAS E TRANSAÇÕES

Domine o SQL para análises complexas e controle de dados.

Funções Agregadas

Funções agregadas realizam cálculos em um conjunto de valores e retornam um único valor. Elas são essenciais para resumos e análises.

  • COUNT(): Conta o número de linhas.
  • SUM(): Soma os valores de uma coluna.
  • AVG(): Calcula a média dos valores.
  • MAX(): Retorna o valor máximo de uma coluna.
  • MIN(): Retorna o valor mínimo de uma coluna.

GROUP BY e HAVING

A cláusula GROUP BY é usada em conjunto com funções agregadas para agrupar os resultados por uma ou mais colunas.

Já a cláusula HAVING é usada para filtrar os grupos criados pelo GROUP BY. Diferente do `WHERE`, que filtra linhas, o `HAVING` filtra grupos. 

-- Exemplo: Contar livros por editora
SELECT editora, COUNT(*) AS total_livros
FROM livros
GROUP BY editora;

-- Exemplo: Contar editoras com mais de 5 livros
SELECT editora, COUNT(*) AS total_livros
FROM livros
GROUP BY editora
HAVING COUNT(*) > 5;

Subconsultas (Subqueries)

Uma subconsulta é uma consulta `SELECT` aninhada dentro de outra consulta. Ela é usada para retornar dados que serão usados na consulta principal. 

-- Encontre o livro mais caro
SELECT titulo, preco FROM livros
WHERE preco = (SELECT MAX(preco) FROM livros);

Transações (DTL)

Uma transação é uma única unidade de trabalho. Ou todas as operações dentro dela são concluídas com sucesso, ou nenhuma delas é. Isso garante a consistência do banco de dados.

Os principais comandos DTL são:

  • BEGIN TRANSACTION: Inicia uma nova transação.
  • COMMIT: Salva as alterações de forma permanente no banco de dados.
  • ROLLBACK: Desfaz todas as alterações desde o `BEGIN TRANSACTION`.

Views

Uma `VIEW` é uma tabela virtual baseada no resultado de uma instrução `SELECT`. Ela não armazena dados, mas sim a consulta que a gerou. Isso simplifica consultas complexas e pode ser usada para segurança, limitando o acesso a certas colunas. 

-- Exemplo: Criar uma view para ver dados de clientes e vendas
CREATE VIEW historico_compras AS
SELECT
    c.nome AS nome_cliente,
    v.data_venda,
    v.total
FROM clientes c
JOIN vendas v ON c.cliente_id = v.cliente_id;

EXERCÍCIOS AVANÇADOS

Agora, vamos colocar em prática o que aprendemos sobre funções, agrupamentos e subconsultas.
📘 Exercício 1: Faturamento Total

Calcule o valor total de todas as vendas já realizadas. 

SELECT SUM(total) FROM vendas;
📘 Exercício 2: Média de Preço dos Livros

Qual é o preço médio dos livros na livraria? 

SELECT AVG(preco) FROM livros;
📘 Exercício 3: Vendas por Cliente

Mostre o nome de cada cliente e o número total de compras que ele fez. 

SELECT c.nome, COUNT(v.venda_id) AS total_compras
FROM clientes c
JOIN vendas v ON c.cliente_id = v.cliente_id
GROUP BY c.nome;
📘 Exercício 4: Livros com Estoque Abaixo da Média

Liste os títulos dos livros cujo estoque está abaixo da média de estoque de todos os livros. 

SELECT titulo FROM livros
WHERE estoque < (SELECT AVG(estoque) FROM livros);
📘 Exercício 5: Ranking de Vendas por Cliente

Calcule o valor total gasto por cada cliente e ordene do maior para o menor. 

SELECT c.nome, SUM(v.total) AS total_gasto
FROM clientes c
JOIN vendas v ON c.cliente_id = v.cliente_id
GROUP BY c.nome
ORDER BY total_gasto DESC;
📘 Exercício 6: Faturamento por Mês

Mostre o faturamento total para cada mês. 

SELECT STRFTIME('%Y-%m', data_venda) AS mes, SUM(total) AS faturamento
FROM vendas
GROUP BY mes
ORDER BY mes;
