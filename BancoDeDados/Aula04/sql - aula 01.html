AULA 1: INTRODUÇÃO AO SQL

Descobrindo o poder da Linguagem de Bancos de Dados.

O que é SQL?

A **SQL** (Structured Query Language) é a linguagem padrão utilizada para **gerenciar e manipular bancos de dados relacionais**. É a ferramenta essencial para qualquer pessoa que trabalhe com dados, pois permite desde a simples consulta de informações até a construção de estruturas complexas.

Pense no SQL como um idioma que você usa para "conversar" com o banco de dados. Você faz perguntas e dá comandos, e o banco de dados responde ou executa as ações.

Tipos de Linguagem SQL

A SQL é dividida em diferentes tipos de comandos, cada um com uma função específica:

  • DQL (Data Query Language): Para consultar e recuperar dados. O principal comando é o SELECT.
  • DML (Data Manipulation Language): Para inserir, atualizar e excluir dados. Comandos como INSERT, UPDATE e DELETE.
  • DDL (Data Definition Language): Para criar, modificar e excluir a estrutura do banco de dados, como tabelas. Comandos: CREATE, ALTER e DROP.
  • DCL (Data Control Language): Para gerenciar permissões e acesso. Comandos: GRANT e REVOKE.
  • DTL (Data Transaction Language): Para controlar transações e garantir a integridade dos dados. Comandos: COMMIT, ROLLBACK.

Introdução aos Comandos DQL

Nesta aula, vamos focar nos comandos mais usados: os de consulta.

SELECT: A Base de Tudo

O comando SELECT é usado para solicitar dados de uma tabela.

Selecionando Todas as Colunas

Use o asterisco (*) como um coringa para selecionar todas as colunas de uma tabela. 

SELECT * FROM nome_tabela;

Selecionando Colunas Específicas

Liste os nomes das colunas que você deseja ver, separando-os com vírgulas. 

SELECT coluna1, coluna2 FROM nome_tabela;

WHERE: Filtrando Dados

A cláusula WHERE é utilizada para filtrar os resultados e mostrar apenas as linhas que atendem a uma condição específica. 

SELECT * FROM nome_tabela WHERE condicao;

EXERCÍCIOS DQL BÁSICOS

Vamos praticar o que aprendemos com o banco de dados da livraria ZedeLivros!
📘 Exercício 1: Catálogo Completo

Mostre todas as informações da tabela `livros`. 

SELECT * FROM livros;
📘 Exercício 2: Dados dos Autores

Liste todas as colunas da tabela `autores`. 

SELECT * FROM autores;
📘 Exercício 3: Nomes dos Clientes

Exiba apenas os nomes de todos os clientes. 

SELECT nome FROM clientes;
📘 Exercício 4: Títulos e Preços

Liste o título e o preço de todos os livros. 

SELECT titulo, preco FROM livros;
📘 Exercício 5: Vendas de Janeiro

Mostre todas as informações das vendas feitas em janeiro de 2024. 

SELECT * FROM vendas
WHERE data_venda LIKE '2024-01%';
📘 Exercício 6: Livros Baratos

Liste os livros que custam menos de R$ 30,00. 

SELECT * FROM livros
WHERE preco < 30;
📘 Exercício 7: Autores Brasileiros

Mostre o nome e a data de nascimento de todos os autores brasileiros. 

SELECT nome, data_nascimento FROM autores
WHERE nacionalidade = 'brasileira';
📘 Exercício 8: Estoque Baixo

Exiba os títulos dos livros que têm menos de 20 unidades em estoque. 

SELECT titulo FROM livros
WHERE estoque < 20;
📘 Exercício 9: Faturas Abertas

Liste todas as faturas que ainda estão com o status "aberta". 

SELECT * FROM faturas
WHERE status = 'aberta';
📘 Exercício 10: Vendas Concluídas

Mostre todas as vendas que já foram concluídas (status "concluída"). 

SELECT * FROM vendas
WHERE status = 'concluída';
