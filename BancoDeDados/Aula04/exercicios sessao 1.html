Sessão 1: Consultas Básicas

Livraria ZedeLivros

👥 1.1 - Conhecendo os Clientes

Objetivo: Ver todos os clientes cadastrados.

Tarefa: Mostre todas as informações de todos os clientes.

Solução 
SELECT * FROM Clientes;

📖 1.2 - Catálogo Completo

Objetivo: Ver todos os livros disponíveis.

Tarefa: Liste todos os dados de todos os livros.

Solução 
SELECT * FROM Livros;

✍️ 1.3 - Nossa Equipe de Autores

Objetivo: Conhecer todos os autores.

Tarefa: Mostre todas as informações sobre os autores.

Solução 
SELECT * FROM Autores;

🛒 1.4 - Histórico de Vendas

Objetivo: Ver todas as vendas realizadas.

Tarefa: Liste todos os registros de vendas.

Solução 
SELECT * FROM Vendas;

👤 1.5 - Apenas os Nomes

Objetivo: Ver somente os nomes dos clientes.

Tarefa: Mostre apenas os nomes de todos os clientes.

Solução 
SELECT nome FROM Clientes;

💲 1.6 - Títulos e Preços

Objetivo: Conhecer os títulos e preços dos livros.

Tarefa: Liste somente os títulos e preços de todos os livros.

Solução 
SELECT titulo, preco FROM Livros;

🌎 1.7 - Autores e Nacionalidades

Objetivo: Saber de onde são os autores.

Tarefa: Mostre os nomes e nacionalidades de todos os autores.

Solução 
SELECT nome, nacionalidade FROM Autores;

📅 1.8 - Datas das Vendas

Objetivo: Ver quando as vendas aconteceram.

Tarefa: Liste apenas as datas de todas as vendas.

Solução 
SELECT data_venda FROM Vendas;

✍️ 1.9 - Nomes dos Autores

Objetivo: Conhecer os nomes dos autores.

Tarefa: Mostre somente os nomes de todos os autores.

Solução 
SELECT nome FROM Autores;

🏛️ 1.10 - Editoras dos Livros

Objetivo: Saber quais editoras temos.

Tarefa: Liste todas as editoras dos livros (sem repetir).

Solução 
SELECT DISTINCT editora FROM Livros;
