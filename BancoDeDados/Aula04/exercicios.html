📚 Exercícios de SQL

Livraria ZedeLivros

📝 1. Listagem Básica

Objetivo: Listar todas as informações dos clientes cadastrados na livraria.

Tarefa: Escreva uma consulta que mostre todos os dados de todos os clientes.

Solução 
SELECT * FROM Clientes;

💰 2. Filtro por Preço

Objetivo: Encontrar livros com preço superior a R$ 40,00 para uma promoção especial.

Tarefa: Mostre todos os livros que custam mais de R$ 40,00.

Solução 
SELECT * FROM Livros WHERE preco > 40.00;

🛍️ 3. Vendas por Cliente

Objetivo: Relacionar cada cliente com suas respectivas vendas.

Tarefa: Liste o nome de cada cliente junto com a data e o valor total de suas compras.

Solução 

SELECT c.nome, v.data_venda, v.valor_total
FROM Clientes c
INNER JOIN Vendas v ON c.id_cliente = v.id_cliente;

🛒 4. Detalhes das Compras

Objetivo: Verificar o que cada cliente comprou em detalhes.

Tarefa: Mostre o nome do cliente, o título do livro comprado, a quantidade e o preço unitário de cada item vendido.

Solução 

SELECT c.nome, l.titulo, iv.quantidade, iv.preco_unitario
FROM Clientes c
INNER JOIN Vendas v ON c.id_cliente = v.id_cliente
INNER JOIN ItensVenda iv ON v.id_venda = iv.id_venda
INNER JOIN Livros l ON iv.id_livro = l.id_livro;

✍️ 5. Autores dos Livros

Objetivo: Descobrir quem são os autores de cada livro.

Tarefa: Liste todos os livros com o nome de seus respectivos autores.

Solução 

SELECT l.titulo, a.nome
FROM Livros l
INNER JOIN Autores a ON l.id_autor = a.id_autor;

🧾 6. Faturas das Vendas

Objetivo: Consultar as faturas geradas para cada venda.

Tarefa: Mostre o número da venda, a data da venda, o valor total da fatura e seu status.

Solução 

SELECT f.id_fatura, v.data_venda, f.valor_total, f.status
FROM Faturas f
INNER JOIN Vendas v ON f.id_venda = v.id_venda;

🥇 7. Ranking de Clientes

Objetivo: Identificar os clientes que mais compram na livraria.

Tarefa: Calcule quantas compras cada cliente fez e o valor total gasto por eles.

Solução 

SELECT c.nome, COUNT(v.id_venda) AS total_compras, SUM(v.valor_total) AS total_gasto
FROM Clientes c
LEFT JOIN Vendas v ON c.id_cliente = v.id_cliente
GROUP BY c.nome
ORDER BY total_gasto DESC;

❤️ 8. Fãs de Machado de Assis

Objetivo: Encontrar quais clientes compraram livros do autor Machado de Assis.

Tarefa: Liste os nomes dos clientes que adquiriram obras deste autor (sem repetir nomes).

Solução 

SELECT DISTINCT c.nome
FROM Clientes c
INNER JOIN Vendas v ON c.id_cliente = v.id_cliente
INNER JOIN ItensVenda iv ON v.id_venda = iv.id_venda
INNER JOIN Livros l ON iv.id_livro = l.id_livro
INNER JOIN Autores a ON l.id_autor = a.id_autor
WHERE a.nome = 'Machado de Assis';

📦 9. Livros em Estoque

Objetivo: Verificar quais livros estão com estoque baixo.

Tarefa: Mostre os livros que têm menos de 30 unidades em estoque.

Solução 
SELECT * FROM Livros WHERE estoque < 30;

📅 10. Vendas do Mês

Objetivo: Analisar as vendas realizadas em janeiro de 2024.

Tarefa: Liste todas as vendas feitas no mês de janeiro de 2024, mostrando o nome do cliente e o valor total.

Solução 

SELECT c.nome, v.valor_total
FROM Vendas v
INNER JOIN Clientes c ON v.id_cliente = c.id_cliente
WHERE v.data_venda BETWEEN '2024-01-01' AND '2024-01-31';

🇧🇷 11. Autores Brasileiros

Objetivo: Descobrir quais autores são brasileiros.

Tarefa: Mostre todos os autores que têm nacionalidade brasileira.

Solução 
SELECT * FROM Autores WHERE nacionalidade = 'Brasileira';

🏢 12. Livros por Editora

Objetivo: Agrupar os livros por editora.

Tarefa: Conte quantos livros cada editora publicou e mostre o resultado em ordem alfabética pelo nome da editora.

Solução 

SELECT e.nome, COUNT(l.id_livro) AS total_livros
FROM Editoras e
INNER JOIN Livros l ON e.id_editora = l.id_editora
GROUP BY e.nome
ORDER BY e.nome ASC;

⏰ 13. Faturas em Atraso

Objetivo: Identificar faturas que estão com pagamento em aberto e vencidas.

Tarefa: Liste as faturas que estão com status "aberta" e cuja data de vencimento já passou (considere a data atual como 2024-02-20).

Solução 

SELECT *
FROM Faturas
WHERE status = 'aberta' AND data_vencimento < '2024-02-20';

📈 14. Livros Mais Vendidos

Objetivo: Descobrir quais livros são os mais vendidos.

Tarefa: Mostre o título de cada livro e a quantidade total vendida, ordenando do mais vendido para o menos vendido.

Solução 

SELECT l.titulo, SUM(iv.quantidade) AS total_vendido
FROM Livros l
INNER JOIN ItensVenda iv ON l.id_livro = iv.id_livro
GROUP BY l.titulo
ORDER BY total_vendido DESC;

👤 15. Clientes que Não Compraram

Objetivo: Identificar clientes que ainda não fizeram nenhuma compra.

Tarefa: Liste os clientes que não possuem nenhuma venda registrada.

Solução 

SELECT c.nome
FROM Clientes c
LEFT JOIN Vendas v ON c.id_cliente = v.id_cliente
WHERE v.id_cliente IS NULL;
