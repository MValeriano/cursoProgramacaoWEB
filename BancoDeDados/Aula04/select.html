A Instrução SELECT em SQL

A porta de entrada para a recuperação e análise de dados

O que é a instrução SELECT?

A instrução **SELECT** é a operação mais comum e fundamental na **Linguagem de Manipulação de Dados (DML)**. Sua função principal é **recuperar dados** de uma ou mais tabelas, permitindo transformá-los e construir resumos significativos **sem alterar a tabela original**.

É a base de qualquer consulta, usada para solicitar e exibir informações de forma organizada.

1. Selecionando Dados Básicos

A forma mais simples de usar o `SELECT` é com o asterisco (*), que atua como um curinga para selecionar todas as colunas de uma tabela.

Todas as Colunas

SELECT * FROM CUSTOMER;

Colunas Específicas

Liste as colunas que você deseja ver, separadas por vírgulas.

SELECT Name, City FROM CUSTOMER;

2. Expressões e Aliases

Vá além da seleção simples. Realize cálculos em colunas e atribua nomes mais legíveis aos resultados.

Cálculos Dinâmicos

Crie novas colunas calculadas na hora.

SELECT PRICE * 1.07 FROM PRODUCTS;

Aliases com AS

Dê um nome (alias) mais amigável ao resultado.

SELECT PRICE * 1.07 AS TAXED_PRICE FROM PRODUCTS;

3. Filtrando Dados com a Cláusula WHERE

A cláusula **WHERE** é a ferramenta essencial para **filtrar registros**, exibindo apenas aqueles que correspondem a uma ou mais condições.

  • **Operadores de Comparação:** `=, !=, >, <, >=, <=`.
  • **Operadores Lógicos:** `AND`, `OR`, `NOT` para combinar condições.
  • **`IN` e `NOT IN`:** Para listar múltiplos valores.
  • **`LIKE`:** Para buscar padrões em strings (com `%` e `_`).
  • **`IS NULL` / `IS NOT NULL`:** Para verificar valores inexistentes.

4. Agregando Dados com GROUP BY e Funções

Agregue dados para obter um total a partir de múltiplos registros. A cláusula **GROUP BY** permite agrupar esses totais por uma ou mais colunas.

Funções de Agregação

  • `COUNT()`: Conta o número de registros.
  • `SUM()`: Soma valores numéricos.
  • `AVG()`: Calcula a média.
  • `MIN()`/`MAX()`: Encontra valores mínimo/máximo.

Exemplo com GROUP BY

SELECT Category, COUNT(*) AS TotalProducts FROM Products GROUP BY Category;

5. Filtrando Grupos com HAVING

A cláusula **HAVING** é usada para **filtrar resultados após a agregação**. Diferentemente do `WHERE`, que filtra registros individuais, o `HAVING` atua sobre os grupos criados pelo `GROUP BY`.

SELECT Category, COUNT(*) FROM Products GROUP BY Category HAVING COUNT(*) > 10;

6. Outras Cláusulas e Conceitos Chave

ORDER BY

**Ordena** o conjunto de resultados. Use `ASC` para ascendente (padrão) e `DESC` para descendente.

DISTINCT

Garante que os resultados sejam **únicos**, eliminando linhas duplicadas.

CASE

Adiciona **lógica condicional** (como um `IF-THEN-ELSE`) dentro de uma consulta.

JOIN

**Combina dados** de duas ou mais tabelas com base em uma coluna relacionada.

Subqueries

Aninha uma consulta `SELECT` dentro de outra para filtrar ou retornar valores.

Operações de Conjunto

Combina resultados de múltiplas consultas com `UNION`, `INTERSECT` e `EXCEPT`.
